# finance-market-review：复盘专项

本文件只含流程与骨架，不得夹带市场事实、数字或板块名。它在 finance-mode 之上加流程，不改其规则。

## 适用与不适用

- 适用：某个交易日的全市场结构判断——普涨 / 分化 / 少数主线带动、主线是谁、强弱变化、广度与量能、连板梯队与情绪、隔夜外盘与日历催化。
- 不适用：单个标的的估值与基本面（走 finance-analyze-stock）；某行业跨多日的持续跟踪（走 finance-industry-track）；某个未来事件的情景推演（走 finance-forecast-event）。复盘里顺带点到这些时只给线索，不展开。
- 用户只要「简单说」：仍执行第 1 批检索，只交付骨架里的结论段与反证段。

## 检索顺序（两批并行，一轮输出）

第 1 批（彼此独立，一起发）：
1. 当日总量与阶段标签：指数涨跌、成交额与量比、涨停 / 跌停家数、阶段 / 周期标签及其来源字段。
2. 广度：上涨 / 下跌 / 平盘家数，连同样本覆盖数与缺失数一起取；广度只认从全样本截面聚合的那张表。
3. 一级行业**全截面**：全部行业的涨跌与成交，按涨跌排序取两端。全集表才能回答「最强 / 最弱」。
4. 题材涨停热度全集：各题材涨停家数、占比、排名，用它回答「涨停集中在哪」。
5. 同日主线结构：主线板块的强度、涨停数、净流入等字段，**它是人工筛选的子集**，只能回答主线内部的结构，不能当全市排名。
6. 连板梯队与高度：梯队名单、最高板、晋级情况。

第 2 批（只在第 1 批结果决定了对象之后）：
7. 主线板块的成分股量价（涨幅、成交、换手、新高状态），用于判断主线内部是普涨还是龙头带动。
8. 隔夜外盘与日历：只在题面或第 1 批结果显示外部驱动时查。
9. 个人记忆：用户此前对本轮主线或市场阶段的判断（先验），用于增量更新与四态对照。

每一批返回后先逐项看状态：被标注为回填复制的外盘行不可用；截断到前若干行的返回不是全集；子集表的空值是未核验不是否定。

## 分析骨架

1. **定性**：普涨修复 / 分化 / 少数主线带动，三选一或明确「介于」。判据写清：广度（上涨占比）、涨幅分布（中位数与均值的关系）、集中度（前几个行业或题材的成交与涨停占比）。
2. **主线识别与强弱**：主线是谁、靠什么认定（涨停热度排名、行业涨幅、成交占比、新高家数中的至少两项互证）、与前一日比是走强还是走弱。
3. **主线内部结构**：龙头带动还是普涨、梯队高度、是否出现分歧（炸板、开板、断板）。
4. **非主线**：被抛弃的方向、跌幅两端、缩量还是放量下跌（放量必须有成交额变化基准，没有就只说涨跌不说量）。
5. **外部与催化**：隔夜、日历事件，只写有数据支撑的部分。
6. **反证**：至少两条能推翻定性的具体条件，每条写清需要看什么数据、阈值由当日数据给出而不是臆造。
7. **跟踪信号清单**：明日及后续要盯的三到五个可观测信号，含触发条件——这是后续跟踪的基线接口。

## 防遗漏清单（复盘专项的硬覆盖项）

- 全集边界：凡是「最多 / 最强 / 集中在 / 只有」的表述，核对用的是全集表；主线表、梯队表、看板表都是子集，子集内的名次不能写成全市名次。
- 量价不是资金：成交额、涨幅、换手不能写成「资金流入 / 撤出 / 迁移」；没有净流入或主动买卖数据就不写资金方向。
- 指数贡献需要贡献数据：「某方向带动指数上涨」需要权重与贡献数据；只有相对强弱时写「领涨」，不写「带动指数」。
- 广度与中位数一致：同一截面、同一口径下，下跌家数过半则中位数为负；两者矛盾先查口径或样本，不用「权重结构」解释。
- 一股多题材：按题材相加的涨停家数会重复，数涨停家数先按个股去重，或直接用全市总数。
- 阶段标签的来源：市场阶段、周期阶段是不同标签族，各自核对来源字段；置信度不是校准准确率。
- 数据截至日：盘中或次日早间查询会回到上一交易日，正文写明数据日期。

## 交付前自检（在 finance-mode 五项之上）

1. 定性用了广度 + 分布 + 集中度三类证据中的至少两类吗？
2. 每个「最」字都对应全集表吗？
3. 有没有把量价写成资金、把领涨写成带动？
4. 反证条件是具体可观测的吗？阈值来自当日数据吗？
5. 跟踪信号清单给了吗？
6. 没查到的部分（量能基准、外盘、资金）明说「未取得」了吗？

## 输出骨架

```
## 结论
一句定性 + 两到三条关键数据（带日期与来源）
## 主线与强弱
## 主线内部结构
## 非主线与两端
## 外部与催化（有数据才写）
## 反证：什么情况下上面判断不成立
## 证据边界与缺口
## 跟踪信号清单
## 追问建议（≤4）
```

「简单说」时只交付结论、反证、跟踪信号三段。
