# finance-market-review：复盘专项

只含研究方法，不携带市场事实。遵守 finance-mode，依次完成以下步骤；用户要简答时缩短交付，不改变证据标准。

## 1. 固定问题与检验对象

先确定交易日、信息截止、实体层级和用户真正要检验的判断。把当日盘面与未来持续性分开：

- **当日判定**：那个交易日的上涨参与面、强弱分布、量能与集中程度。
- **解释性判断**：为何出现这种结构。需要能区分候选原因的材料，量价形态本身只支持描述。
- **观察剧本**：后续什么变化支持或削弱某个前瞻假设，不是改写当日已经发生的涨跌家数。

按本仓词表分开三个问题：当日领涨看同类实体的同日涨幅排序；成交主流看申万一级成交占比口径；主线表名单只说明该来源登记了哪些方向。三者可以不同，分别报告。严格双红说明细分题材的量价状态，不单独定义主流。

完成条件：知道每个核心判断在说谁、哪个比较集、哪个时段；需要前后比较的判断已明确基线日或基线窗。

## 2. 第一批取证：同日截面并行

用授权工具清单的真实 schema。结构化表名是 finance_query 的 dataset 参数，不是工具名。

1. 市场总量：指数、成交、涨跌停与阶段标签。阶段标签同时取来源，量能同时取比较基准。
2. 市场广度：涨跌平家数、样本数、缺失数；能取得时取全样本涨幅分布。
3. 同类行业截面：同日涨幅排序；成交主流另取同口径成交或占比，不从涨幅排名推断。
4. 题材涨停热度：排名、分母、来源覆盖；连板梯队另取名单与高度，保持两张表的范围独立。
5. 主线表：读取名单、完整计数、每组预览与缺项。名单用于选研究对象，预览用于提出待核判断。
6. 个人记忆仅在用户有旧判断或需要增量比较时查，标为先验。

每项返回后先记录：实际日期、实体单位、比较集、已见数量、已知总数、缺项、截取前的排序或聚合。工具诊断只作为诊断。

## 3. 全集边界：先算能证明什么，再补决定性证据

对准备写入正文的“多数、全部、最强、只有、集中、没有”逐一匹配比较集：

- **多数**：若比较集总数为 N，已见 n 个互不重复的同类成员，其中 k 个符合条件，符合数只能落在 `[k, k + N - n]`。下界超过 N 的一半可确认多数；上界不超过一半可否定多数；区间跨过一半则未定。未知值计入未判成员，分组行不能冒充个股数。
- **排名**：目标比较集上的排序在截取前完成，且指标、日期和缺值处理明确，才支持该范围内的名次。取到前几名不要求把全部行展示出来，但不得扩大查询本身的范围。
- **集中度**：分子、分母使用同一成员规则和单位。一股多题材：题材家数之和是只次，除非按个股去重，否则不转成全市个股占比。
- **不存在**：要求对应范围已完整核查；只查某张榜单时只能说“该榜单中未见”。空结果不证明现实中不存在。
- 总数未知或成员规则不清时，先给“已见部分”的事实；需要总体判断才补查完整计数、聚合或缺失部分。仍补不到，就保留这项缺口，同时交付已经成立的其他判断。

主线表每组只预览部分板块时，先用以上上下界判断是否足够；不足则补主线内部的完整统计。不能用同日一级行业的涨幅替代细分板块内部的计数。

完成条件：每个总体判断都有可核对的范围证据，或者已明确收窄为局部观察；不把所有部分数据一律判为不能回答。

## 4. 第二批取证与判断

只补会改变结论的缺口：内部强弱需要成员或同层板块统计；放量需要自身可比基线；催化需要消息来源；跨日走强需要同口径前后数据。

按独立维度组织结论，不强迫在“普涨”和“主线集中”之间二选一：参与面可以较广，同时某些方向领涨。广度与中位数一致：同一有效截面下多数收益为负，中位数就不会为正；发现矛盾先查分母和缺失口径。

| 判断 | 所需依据 | 缺少时仍可说 |
|---|---|---|
| 当日领涨、落后 | 同比较集的价格排序 | 已见对象的涨跌 |
| 放量、缩量 | 自身同口径成交基线或明确的成交变化率 | 当日成交额或成交排名 |
| 比上一期走强 | 同一对象、指标和窗口的前后比较 | 当日相对位置 |
| 资金方向、参与者身份 | 对应资金或身份数据 | 量价、梯队结构；量价不是资金，缺高标也不证明机构参与 |
| 对指数涨跌的贡献 | 权重与贡献分解 | 同期领涨或落后；指数贡献需要贡献数据 |
| 连续出现、阶段升级 | 逐日连续覆盖和相应阶段规则 | 来源表在窗口内记录到的出现次数 |

每个事实附日期与来源。解释性判断标为推断，保留替代解释；仅仅加“推断”不能替代它所需要的证据。

## 5. 反证与观察剧本分别收敛

**当日判定的反证**针对同一交易日、同一比较集、同一口径。例如补齐遗漏成员、修正重复或缺值处理后，原来的广度或集中判断是否会改变。指出究竟哪项证据可能改变哪句判断；现有证据已经确定的事实无需为了凑反证再编一条。

**未来持续性的验证**先写清前瞻假设，再写观察变量、可验证窗口和支持/削弱条件。未来行情变化更新这个假设，不会让过去的统计事实作废。后来发现当日资料有误属于后验订正，不能冒充当时已知。

观察阈值来自已有规则、给出算式的基线推导，或显式声明的待检验假设。没有依据时使用有业务含义的方向、相对关系或条件，保留待定阈值。下一交易日以交易日历为准，未查日历就写“下一交易日”。

跟踪信号清单只保留与上述前瞻假设相连的观察项，供后续 track 使用；不自动持久化，不给交易指令。

## 6. 交付前自检

逐句核对核心判断和摘要，而不只核对末尾的缺口段：

1. 主语、比较集和时间是否与证据一致？多数有计数或上下界，排名有正确排序范围吗？
2. 每个量能变化有自身基线吗？价格、成交排名、名单出现次数有没有被写成资金、身份或阶段事实？
3. 当日反证能否真的改变当日判断？未来条件是否绑定了单独的前瞻假设？
4. 每个数字是观测、计算还是假设？算式、单位、来源和日期能对账吗？
5. 缺证的句子是否已经收窄，而不是前文断言、后文免责声明？有依据的内容是否仍保留？

修正具体判断后交付，不在答案里自授“全部检查通过”。

## 输出骨架

```text
## 结论
当日盘面判断与关键依据，区分当日领涨、成交主流、登记名单
## 广度、量能与强弱
## 主线内部结构与未覆盖范围
## 当日判断的反证与证据边界
## 跟踪信号清单：假设、观察窗口、支持或削弱条件
## 追问建议
```

外部与催化只在有资料时加入。简答保留结论、关键边界、后续观察，不删掉会改变结论的限制。
