# finance-analyze-stock：个股深度与财报复盘

本文件只含流程与骨架，不得夹带市场事实、数字或板块名。它在 finance-mode 之上加流程，不改其规则。

## 适用与不适用

- 适用：首次完整覆盖一只股票；对一期财报做窄切面复盘；用户问估值、隐含预期、竞争格局、催化。
- 不适用：纯事实（现价、市值、某个财务数）——主线程直接查；多只标的横向比较——拆成并行子任务后主线程合并；行业全景——走 finance-industry-track。
- 用户已有研究史（个人记忆里该标的条目充分、近期讨论过）：降级为增量更新，只写变化与新证据，不重复背景。

## 检索顺序（两批并行，一轮输出）

第 1 批：
1. 实体解析与基础档：确认代码、全称、所属行业与所在题材映射（图谱关系只是线索）。
2. 行情快照与近期走势、技术位、新高状态。
3. 已披露财务：最近若干期，锚定报告期、披露日、累计 / 单季口径；多公司比较在同一次调用里把可比公司一起取。
4. 公告与互动：经营事实、订单、产能、减持 / 解禁、监管。
5. 知识库与证据索引：公司页的边际变化、研究线索、观察列表，分层引用。
6. 个人记忆：用户此前对该标的的判断与纠偏原则（先验）。

第 2 批（由第 1 批决定对象后）：
7. 竞对与上下游的同口径数据（只取第 1 批里识别出的两到三家）。
8. 新闻与催化：近期事件，拆事实 / 解读 / 情绪。
9. 两融、大宗、解禁日程（涉及筹码与供给时）。
10. 反方检索：针对核心假设做一次反证检索。

## 分析骨架

1. **一句话定位**：做什么、靠什么赚钱、在产业链哪个位置、当前市场给它的标签。
2. **业务与竞争格局**：量、价、结构；份额与格局变化；上下游议价。图谱里的关系只证明登记过关联，不自动证明采购份额或受益强度。
3. **财务质量**：实际值、同口径上期值、披露前一致预期三列分开；按业务拆量价结构与一次性损益；用经营现金流、应收、存货、资本开支交叉检查利润质量。毛利率变动不单独证明定价权。一致预期缺失时写「未取得可比的一致预期」，不把同比增长或披露后研报当作超预期证明。
4. **估值与隐含预期**：当前估值在自身历史与可比公司中的位置；用倒推法写出「当前价格隐含了什么假设」；负市盈率不按越低越便宜解读；没有可比口径就只给区间推理并标推断。
5. **催化与风险**：事件日历、管理层指引（待验证预期，与已实现业绩分开）、筹码供给（解禁、减持、两融变化）。
6. **情景与判断**：基准 / 乐观 / 悲观三情景，各给触发条件与可验证时点；对照用户此前判断说明支持 / 削弱 / 无变化 / 信息不足。
7. **反证**：什么数据出现会推翻主判断。
8. **验证窗口**：下一个披露窗口或可观测事件，以及要看的量。

## 防遗漏清单

- 报告期锚定：每个财务数带报告期与披露日，不把三季报说成当前；累计 / 单季不混。
- 单季还原：工具只给累计口径，自己还原的单季数写明是推算。
- 多期比较同口径：币种、单位、会计口径一致后再谈差额。
- 公司级硬事实要公告：订单 / 中标 / 产能 / 量产只有新闻或研报来源时写「待验证线索」，点明缺的一手材料。
- 筹码数据的时间语义：解禁是未来日程，两融按交易日标记，不把抓取日当数据日。
- 新股 / 冷门标的：数据全空时如实写「来源覆盖不足」，不用同名或同题材公司冒充。
- 不给买卖建议、不承诺收益；「值多少」只写假设与区间。

## 交付前自检（在 finance-mode 五项之上）

1. 每个财务数都带报告期了吗？累计与单季分开了吗？
2. 一致预期有来源吗？没有就写了「未取得」吗？
3. 估值判断给了隐含假设和比较集吗？
4. 公司级硬事实有公告支撑吗？没有就标「待验证线索」了吗？
5. 三情景各有触发条件和可验证时点吗？
6. 用户先验做了四态对照吗（有先验时）？

## 输出骨架

```
## 结论
核心判断 + 基准情景 + 最大风险（各一句）
## 业务与格局
## 财务质量（报告期 / 实际 / 上期 / 预期）
## 估值与隐含预期
## 催化、筹码与风险
## 情景与验证时点
## 反证
## 证据边界与缺口
## 跟踪信号清单
## 追问建议（≤4）
```

财报复盘的窄切面（用户只问某一期）：只交付「财务质量」「与预期对照」「验证时点」「反证」四段，不展开业务全景。
