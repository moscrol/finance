# Stock Deep Dive / 复盘先验（输出契约 + 质检门）

## 为什么需要这个 skill

高分模版（agent-memory `10_knowledge/finance-stock-deep-dive-95-generation-path.md`、
`finance-answer-self-review-framework.md`、`finance-answer-orchestrator.md`）以前只是
「知识笔记」，靠 LLM 在长上下文里记得去照做，输出不稳定。本 skill 把它们硬化成：

1. **当次必读的输出契约**（本文件）——dispatcher 命中触发词后必须加载；
2. **程序化质检门**（`scripts/answer_lint.py`）——最终稿 exit 0 才能交付，
   体例同 `task-planner/check_task_plan.py` 的 exit-code 门。

规则管结构，LLM 管表达。

## 适用范围

- `deep-dive`：个股深挖（"XX 怎么看"、"深挖 XX"）。
- `forecast`：复盘先验 / 次日行情前瞻（"明天怎么看"、"复盘先验"）。

只读 skill：不写 DuckDB、不写飞书、不改知识库。

## 标准流程（严格按序）

### 第 0 步 · 验鲜

查 canonical `db/market_feature_store.duckdb` 关键表 `max(trade_date)`。
未验鲜不得声称使用最新盘面；数据缺口必须在答案里显式写出。

### 第 1 步 · 确定性数据块（先取数，后写作）

个股深挖必须先准备三个数据块，再开始写叙事（缺数据写"缺口"，不许跳过）：

- **D1 市场价值与替代队列**：区间涨幅、峰值涨幅、峰后回撤、收益保留率、半衰期代理、
  题材状态、相对强度、同题材强势替代表达。回答"市场有没有真的创造价值"。
- **D2 客户证据硬度**：把证据分成 硬证据 / 候选证据 / 弱证据（研报推断）/ 反证与缺口。
  硬证据才能支撑当期逻辑；L1 观点不能当基本面兑现。
- **D3 二阶导研究队列**：P0 盘面已选择的强势替代表达、P1 目标股再升级条件、
  P2 产业瓶颈补盲，附反向观察。

复盘先验必须合并四源：全量盘面复盘（容量前三/双红/新高/涨停热度/涨家数 MA5）、
晚间卖方胜率、外盘双源（fupanhui global-market + 必要时 web 补最新收盘）、晨汇材料。
双红是强约束：方向涨幅强但 `diff_ratio` 为负，只能判"缩量强修复/存量抱团"。

### 第 2 步 · 核心矛盾句（内部）

写出："真实业务是什么、市场在交易什么、最大证据缺口/反证是什么"。

### 第 3 步 · 叙事生成

视角完整但不机械分块；每段回答"这个事实改变了什么判断"。
禁止把旧标签重新润色——最新数据必须能改变判断（参考汇成股份教训：
旧逻辑唤醒 → 二次加速定价 → 高位分歧观察）。

### 第 4 步 · 影子用户反驳（内部，一次重写）

对初稿追问：是否在套模板？是否孤立看个股（没放进大盘/情绪/板块容量/平行题材竞争）？
"受益"证据够硬还是只有 L1 观点？目标是不是这条链的最优表达？生命周期升级还是降级？
有没有主动找反证和二阶导？有缺口就重写。只输出最终稿，不输出审稿过程。

### 第 5 步 · 质检门（硬性）

```bash
# 把最终稿写到临时文件后：
python3 skills/stock-deep-dive/scripts/answer_lint.py /tmp/answer.md --type deep-dive
python3 skills/stock-deep-dive/scripts/answer_lint.py /tmp/answer.md --type forecast
```

- exit 0 → 可以交付；
- exit 1 → 按输出的 MISSING 维度补写后重跑，最多两轮；两轮仍不过 →
  在答案开头标注「低置信：未通过质检门，缺 X/Y」再交付，不许静默交付；
- exit 2 → 用法错误。

## 输出契约（lint 检查的维度）

### deep-dive 必须覆盖

1. 市场状态/盘面融合（大盘阶段、量能、涨家数/双红/涨停热度至少其二）
2. 公司本体（真实主营/业务是什么）
3. 市场价值成绩单（区间/峰值涨幅、回撤、收益保留、相对强度之一）
4. 证据分层（硬证据 vs 弱证据/研报推断，显式区分）
5. 反证/证据缺口
6. 逻辑生命周期（阶段判断 + 升级/降级/证伪条件）
7. 二阶导/替代表达（更优表达是谁、研究应发散到哪）
8. 条件化结论（"如果…则…"或升级/降级触发条件，不许单一定论）

### forecast 必须覆盖

1. 市场阶段与量能承接
2. 双红/边际量约束（明确区分放量新启动 vs 缩量修复）
3. 外盘/隔夜信息（含 source_trade_date 或"未取到"声明）
4. 卖方/机构信息权重（或显式"未读取"）
5. 策略选择结果（策略一二三四中选谁、对应题材/个股、为什么）
6. 次日验证条件（怎么算命中/证伪）
7. 反证/风险情形

## 红线

- 未验鲜不得写"最新盘面"；未读取候选池不得伪装成真实策略输出。
- L1 研报观点不得写成公司基本面兑现。
- 质检门两轮不过必须标注低置信，禁止静默交付。
