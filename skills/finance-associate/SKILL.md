# finance-associate：横向联想

只含研究方法，不携带市场事实。它在 finance-mode 之上加流程，不改其规则。联想是「发散」不是「结论」：每条联想都要说明「为什么可能影响投研判断」和「如何验证」，不是泛泛脑暴。

## 使用边界

- 用于在标的、行业、事件或用户 thesis 旁边补充相邻线索。
- 已有分析要去重：用户已经覆盖的关联不重复；不相关的维度不强凑。
- 输出是待验证线索，不自动升级为投资结论，不给买卖建议。

## 标准流程（逐步推进，不要跳步）

1. **明确起点**：联想的核心对象（公司 / 行业 / 事件 / 概念）、当前 thesis、用户希望扩展的方向；列出已覆盖的关联以便去重。
2. **查图谱（先于其他，这是联想的骨架）**：先实体解析消歧，再取两跳邻域 → 填维度 1（产业链）和 2（竞对）。图谱里的关系只证明登记过关联，不自动证明因果、采购份额或受益强度；空结果如实写「图谱待补」。
3. **查记忆与证据索引**：同主题 / 同板块的历史观点、矛盾观点、推理模式 → 填维度 5（观点交叉）和 6（历史模式）。个人记忆标为先验。
4. **补资讯**：新闻检索与事件日历取最新政策 / 事件 → 填维度 3（宏观）和 4（事件）；市场定价参考有则引用、无则写「无市场定价参考」；材料不足再网页检索与取页。以上三步彼此独立，并行发射。
5. **汇总**：按六维输出，每个维度独立评估；无价值的维度写「暂无显著关联」，不编造。

## 联想六维

1. **产业链传导**：沿上下游追两到三跳，每跳标传导逻辑（谁是谁的核心供应商 / 客户、占比口径）。来源标签 `[graph]`。
2. **竞对映射**：同环节 / 同赛道竞争者，对比份额、技术路线、产能、估值位置，标差异化卖点与风险。来源 `[fact]`。
3. **宏观 ↔ 微观联动**：受哪些宏观因子影响（利率、汇率、大宗、产业政策、地缘），标最近变化方向与预期影响。来源 `[fact]` / `[search]`。
4. **事件涟漪**：最近或将发生的事件如何传导（扩产 / 缩产、政策、财报、并购），给影响路径、时间窗口；可能性用定性或带来源的市场定价，不硬编数字。来源 `[search]` / `[market]`。
5. **多方观点交叉**：不同机构 / 作者对该主题的观点对照（多空、买卖方、国内外），保留归属与日期，重复转述不算独立证据。来源 `[memory]`。
6. **历史模式匹配**：是否出现过类似场景（供需结构 / 估值位置 / 政策周期），同时列相似点与关键差异、当时的后续走势、可借鉴教训；历史后验表现不当作当时已知信息。来源 `[memory]` / `[fact]`。

## 输出骨架

```text
## 🔗 联想分析：{主题}
### 1. 产业链传导   — A→B→C 每跳传导逻辑 [graph]
### 2. 竞对映射     — 表格：公司 / 份额 / 技术路线 / 估值 / 差异化 [fact]
### 3. 宏观 ↔ 微观  — 因子 → 对主题影响 [fact / inference]
### 4. 事件涟漪     — 事件 / 可能性 / 影响路径 / 时间窗 [search / market]
### 5. 观点交叉     — 各方立场对照（归属 + 日期）[memory]
### 6. 历史模式     — 类比 / 当时走势 / 关键差异 / 可借鉴 [memory]
## 🎯 核心结论      — 最值得追下去的一条线索，以及怎么验证它
## 追问建议（≤4）
```

## 来源标注（硬要求，不可省）

每条联想标 `[graph]` / `[fact]` / `[search]` / `[market]` / `[memory]` / `[inference]`；记忆证据进一步区分用户记忆与共享来源。推断得到的关联必须标 `[inference]`，不可冒充有数据支撑。

## 交付前自检

1. 六个维度都单独评估了吗？没内容的写「暂无显著关联」了吗？
2. 每条线索都有「为什么相关 / 如何验证 / 可能影响」三件套吗？
3. 图谱关系有没有被写成因果或受益强度？
4. 历史类比列了关键差异吗？有没有把后验当当时已知？
5. 矛盾观点是并列保留的，还是被强行统一了？

## 输出契约

交付完整六维联想图 + 🎯 核心结论；不得用完成状态或摘要短版替代。不写入记忆；值得沉淀的推理模式只在用户确认后提议。
