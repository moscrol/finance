# 题材雷达（只读）金标准

本 skill **默认不写** `concepts/` / `entities/`。IMA 15 章写库走知识库 `concept-ingest`。夜报全景走知识库 `theme-radar-reports`，也不要用自动生成页的空「核心标的」栏当完成样本。

## 样本（只认这一套）

| 角色 | 打开这份 | 为什么是它 |
|---|---|---|
| **形状（每次）** | `references/judgment-framework.md` | 八步：一句话定锚 → 需求场景 → 产业链 → 细分方向 → 发酵进度 → 公司分级 → 验证清单 → 反证。 |
| **库内定锚密度** | 知识库 `wiki/concepts/电子布.md` | 一句话不是同义反复；产业链位置清楚；核心标的带数字（宏和科技营收/净利）；信号缺口显式（价格信号可空）。雷达输出应对齐这种密度，而不是只丢一串公司名。 |

换金标准：改本文件。

## 不要当成金标准

| 反例 | 为什么不够 |
|---|---|
| `wiki/synthesis/发酵复盘-电子布-2026-06-12.md` | 自动全景模板；「核心标的（第一梯队待 baseline 补证）」是空栏。可学章节骨架，不可学空核心标的。 |
| 把辅助概念公司升核心 | SKILL 已禁止；韬定律类新词只能观察池。 |

## 对照清单

1. 定锚不能同义反复。
2. 公开定义 / 纪要发酵 / 年报能力栈 / 公告事实 / 盘面认同五层分开写。
3. 公司分核心 / 观察 / 泛化 / 剔除；无 L3 不进核心。
4. 信号层缺数据就写「待补」，不编盘面。
5. 默认只读；用户没点名写库就不要调用 concept-ingest。
