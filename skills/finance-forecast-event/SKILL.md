# finance-forecast-event：事件推演

只含流程与骨架，不携带市场事实。它在 finance-mode 之上加流程，不改其规则。

## 核心理念（这是本专项的增量，不可省）

真实世界事件的走向往往由少数关键人物的决策驱动。事件推演的增量价值 = 情景树 + **关键决策者行为模拟** + 置信度标注。**禁止退化为「查一下记忆和网页就给个概率」**——缺了行为模拟这个维度，等于没走本流程。

触发判断：用户说「推演 / 概率 / 可能性 / 情景 / 赔率 / 兑现」→ 立即走完整流程；语义是推演但没说触发词（例如问某件事年内会发生几次）→ 先一句话确认「这个走完整事件推演吧？」再开始。

## 使用边界

- 用于尚未发生或结果未完全落定的金融事件（财报预期、政策、产品催化、诉讼、并购等），以及已发生消息的传导判断。
- 结论必须表达为情景与定性可能性（或带来源的市场定价参考），不能写成确定性预言；没有校准依据时不硬编概率数字。
- 伦理红线：不预测暴力事件的具体时间地点。不承诺收益，不给买卖指令。

## 两种输入

- **已发生的消息 / 突发**：走六步法。
- **未来事件**：走情景树。
- 两者都先做：明确事件的截止时间、「怎样算发生」、可观测的判定信号；区分**事件发生的可能性**与**发生后的条件影响**，两者不是一回事。

## 标准流程（逐步推进，不要跳步）

1. **界定事件**：事件、截止时间、判定标准（怎样算「发生」）、可观测信号。
2. **查记忆**（不可省）：相关历史事件、相似情景的演化、相关决策者 / 作者的历史立场与推理模式；标为先验。
3. **查图谱**：涉及具体公司 / 产业链时取传导路径；关系是线索不是因果。
4. **收集证据**（并行发射）：历史基准与当前新闻 / 公告先用新闻检索与公告查询；市场定价参考有则引用（带时点，只是定价参考不是真实概率）、无则写「无市场定价参考」；材料不足再网页检索与取页；**反方证据主动找**。
5. **决策者行为模拟**：识别能左右结果的关键决策者（监管、管理层、关键机构、关键作者）；基于其可核验的历史行为模式、权限与当前约束、惯用逻辑、偏好与盲区，模拟其在本事件下的可能选择。模拟是推演不是真相，必须标置信度与局限；记忆数据不足时明说，不硬编造画像。
6. **构建情景树**：两到五个互斥情景并保留一个「未覆盖结果」；每个情景列触发条件、支持证据、反方证据、定性可能性及其理由与不确定性来源、对标的影响、观察窗口。
7. **领先指标**：给出需要继续监控的前瞻信号与失效条件。

## 六步法（已发生的消息）

1. **判级**：事件级别（公司 / 行业 / 宏观）、确认阶段（传闻 / 媒体 / 官方）、是否一次性。
2. **溯源**：原始发布主体是谁；多家转载不构成交叉验证；来源缺失写「无法核实」，不判定事件没发生。
3. **拆传导链**：从事件到各受影响对象的路径，每一跳写附加假设。
4. **量级**：用可得数据给数量级或区间，标推断；没有可比基线和定价模型时，不用「实际涨幅减猜测的合理涨幅」量化情绪溢价。
5. **定价进度**：已交易了多少（板块与标的的近期表现、涨停热度），还剩什么没被定价。
6. **裁决**：带条件的判断——「基准情景 X，推翻条件 Y，验证窗口 Z」；已证实事实不自动成为交易指令。

## 输出骨架（标题逐字保留）

```text
# 事件推演 — {事件}
> 数据截止：{日期} · 判定标准：{怎样算发生} · 截止时间：{事件时点}

## 1. 事件界定        — 事件、判定标准、可观测信号
## 2. 关键决策者模拟   — 谁能左右结果 + 历史模式 + 本次可能选择（含置信度与局限）
## 3. 传导链 / 情景树  — 已发生消息：路径 × 假设 × 量级 × 定价进度；未来事件：互斥情景 × 触发条件 × 证据 × 影响
## 4. 市场定价参考     — 有则引用并带时点；无则标「无市场定价参考」，转定性
## 5. 领先指标        — 后续监控信号 + 失效条件
## 证据边界与缺口
## 🎯 核心结论        — 最可能情景 + 总体倾向（定性或区间，非确定性）
## 追问建议（≤4）
```

## 降级

- 无相关市场定价 → 标「无市场定价参考」，依赖定性分析。
- 决策者历史数据不足 → 缩减画像维度，显式标注置信度降级，不硬编造。
- 数据源不可用 → 按 finance-mode 的降级纪律转网页 / 用户材料，说明降级路径。

## 防遗漏清单

- 事实 / 解读 / 情绪三层分开，情绪与宣传措辞不充当业务进展证据。
- 传播次数与独立来源数分开。
- 事件日期可以晚于信息截止日（日历类），引用时写清它是计划日。
- 受益强度不能从图谱关系或题材归属推出，需要公司级证据。
- 「会不会」的问题改写为「沿哪条路径、看什么信号」。
- 推演不自动登记为事实或记忆。

## 交付前自检（在 finance-mode 五项之上）

1. 事件的截止时间与「怎样算发生」写了吗？
2. 发生的可能性与发生后的影响分开了吗？
3. 决策者模拟做了吗？标了置信度与局限吗？数据不足时明说了吗？
4. 每条传导跳都写了附加假设吗？定价进度有数据支撑吗？
5. 领先信号与失效条件给了吗？

## 来源标注与输出契约

历史基准标记忆来源（区分用户记忆与共享来源）、传导路径标图谱、新闻 / 定价标数据源、行为模拟标 `[inference]` 并附依据。交付必须是完整推演——含决策者模拟、情景树或传导链、🎯 核心结论；不得用完成状态、路径清单或摘要短版替代，更不得退化成只查记忆与网页的轻量结论。交付后（用户触发）：新的推理模式或反事实洞察只在用户确认后提议写入记忆。
