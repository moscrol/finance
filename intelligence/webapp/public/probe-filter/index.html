使用说明

1. 标定目标
在 Arena 网页开 5-10 个新会话，用探针挑出满意的模型，打 tag 跑
python probe.py run --adapter manual --sessions 5 --rounds 3 --tag my-target

2. 生成指纹
python intelligence/arena/generate_target_profile.py --log model_pin_probe/data/log.jsonl --tag my-target --out ~/.local/share/finance-arena/target_profiles.json

3. 开启过滤
export ARENA_PROBE_FILTER_ENABLED=1
export ARENA_PROBE_TARGET_PROFILE=~/.local/share/finance-arena/target_profiles.json
export ARENA_PROBE_FILTER_MODE=hard # 或 soft/retry
export ARENA_PROBE_FILTER_MAX_RETRIES=3

4. 原理
风格指纹 15维：长度、对数、句长、CJK比例、全角标点、emoji、Markdown标题/列表/加粗/表格/代码、开场白/结束语/第一人称
余弦距离 < threshold (默认0.08-0.12) → 目标，否则过滤
