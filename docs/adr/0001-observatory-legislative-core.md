# 观测台立法三句：未闭合的最低层、进步≠合并、L2 分栏

观测台若按「最弱哪层」跨层打分，就会在禁止无出处红黄绿的同时偷运一套综合色；
若把每一笔 merge 都当成进步，chore 会逼生成器误报失败；若把本机 worktree
和仓 PR 史混成一张 L2 表，另一台机器上的在途会消失。所以立法收口为三句：
五问①只标 P0→P6 第一根未达完成判据的 rung（下层未闭合则上层记 `未评`）；
声称的进步必须留下 L1 翻转或曲线位移，普通合并只要求可见；L2 必须分
「本机 / 仓」两栏。详见 `docs/superpowers/specs/2026-08-15-progress-observatory.md` §1。
