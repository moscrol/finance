# 个股标准化预演不冒充通用日更

同花顺 dump 的元/股与 canonical（统一事实表）的亿元/手不同，且没有交易参考前收、股票名、换手率或独立停牌/新股状态。先以显式股票范围做只读双日标准化预演，固定未复权价格、纯现金除息参考前收和十进制半进舍入口径；不直接扩用 2026-09-11 单日修复白名单，也不接生产发布，避免把「所选输入可计算」变成「全市场事实已恢复」。

## 取舍

- **计划交易日而非最近有行情日**：只取目标及前一计划交易日。缺前日可能是停牌、新股或抓漏，不能仅凭缺行判断，拒绝借更早裸收或旧 canonical 前收。代价是本片不能处理这些特殊状态，待独立事实合同完善。
- **纯现金事件而非套用通用除权公式**：当前只支持每股现金分红且送转/配股相关字段明确为零；NULL 不是零，非零不忽略。授课模块已有送转/配股公式，但参考价舍入、特殊交易状态与适用范围未经本片验证，不能复制它就声称正式涨幅已覆盖。
- **十进制文本计算而非浮点 `round`**：用已入库 DOUBLE 的十进制文本构造 Decimal，固定精度50、ROUND_HALF_UP 和完整运算上下文；先将现金除息参考价舍入到分，再算涨幅。最终输出仍是 JSON 数值，不宣称恢复供应商原始精度，也不把本片算法重命名为旧修复器的浮点/DECIMAL混合算法。未来写入需单独核验边界差异。
- **声明分母而非观察分母**：`--stock-code` 必填，可重复传不同代码；缺股不减少请求数。代码正则只验证形状/市场配对，不证明上市或在市；股票范围不是全市场独立名册。
- **一条读取语句而非先验后重读**：两日行情和当日事件在同一语句快照中取出，校验、计算和输入指纹消费同一份行。没有新建表/台账或持久行情版本；指纹不是独立真实性证明。

没有事件行只意味着「未记录事件」：`adjustment_coverage=unverified`、`provider_completeness=unverified`、`request_complete=null`，`production_ready=false`。即使全范围可算，也没有验证股票名/换手率、换池分类、复权历史序列、3/5/10/20日收益窗口或日报/队列/矩阵/snapshot产物。生产仍须走既有 daily-full staging 校验及原子换库，板块接入走 `SectorUniverseStore`，不建旁路写入口。

接口与字段见 [运行口径](../data-sources/runtime-and-pitfalls.md#个股标准化只读预演本分支代码未部署)。
