# LLM 问答方法论手册（蒸馏自 Knevo Workshop 2026/6/30）

> 用途：日常与任何 LLM（Knevo / Devin / Claude / codex）对话时的提问、追问、反馈与沉淀纪律。
> 原则：用户给方向感和取舍，系统补变量、反问、推演和证据链。目标不是要答案，而是把自己的盘感外化、校准、沉淀成复利。

## 0. 三条铁律

1. **判断必须可证伪**：任何"看好/看空"都要落成「验证信号 + 时间窗 + 证伪条件 + 动作分层」，否则不算判断，不许沉淀。
2. **验证后才入库**：已被市场验证的框架/错因/口径才进经验库；未验证的挂决策追踪等结果；一次性情绪、没有触发条件的漂亮说法，不沉淀。
3. **共振不是终点**：觉得答案和自己共振时，紧接着追证据、反例、证伪信号，把共振凝练成可复用框架再入库。

## 1. 一日标准流

早起复盘 → 盘前定监控清单 → 盘中信号翻译 → 收盘复盘沉淀。

| 时点 | 问法模板 | 要求产出 |
|---|---|---|
| 盘前 | 今天最需要盯的主线、分歧和风险是什么？给我 9:30 / 10:00 / 14:30 三个时间点的观察重点。 | 主矛盾 + 情绪扰动 + 裁判变量，压缩成监控清单 |
| 盘中 | 我观察到【时间+对象+异动+相对强弱】，判断这是情绪脉冲、资金切换、主线扩散还是假突破？给确认信号、反向信号、不同持仓状态下的动作。 | 性质判断 + 双向信号 + 动作分层 |
| 收盘 | 今天哪些判断被市场验证，哪些只是情绪扰动？明天的关键问题是什么？ | 次日情景、板块落点、交易纪律 |

盘中监控的正确姿势：**先定义信号再量化**——"帮我盯：PCB 涨停封单是否松动、科创50 能否站稳 1770、量是否萎缩；偏空我就不动"。不要只问"现在怎么看"。

## 2. 八种可复用 prompt 骨架

| 模式 | 适用 | 骨架 |
|---|---|---|
| 情景推演 | FOMC/财报/地缘/政策等二元或多分支事件 | 事件 → 乐观/中性/悲观 → 传导对象 → 持仓动作 → 证伪信号。先问主要矛盾和真正裁判变量，宏观只有改变中观产业/资金路径/持仓对象时才进情景树 |
| 盘中信号清单 | 开盘/午盘/尾盘/事件前后 | 时间窗 → 2-4 个信号 → 偏多/偏空阈值 → 买/等/减/不动 |
| 新闻映射产业链 | 新闻/研报/扩产/订单/技术突破 | 新闻 → 上中下游 → 直接受益/情绪映射 → 确定性/弹性排序。新闻是触发器不是答案 |
| 横向对比排序 | 多个标的/方向都讲得通 | 候选 → 维度（确定性/弹性/兑现时间/拥挤度/是否已定价） → 排序 → **排序何时会变** |
| 仓位/交易框架 | 已有持仓或准备建仓 | 当前位置/仓位 → 基本面信号 → 情绪信号 → 加减仓触发 → 失效条件 |
| 时间轴与领先指标 | 慢变量判断 | 核心命题 → 未来阶段 → 每阶段领先指标 → 拐点信号。别只问最终结论 |
| 历史类比带边界 | 行情像某段历史 | 案例 → 相似点 → **不同点** → 最危险的错误类比 → 当前启发 |
| 复盘回放 | 判断已被部分验证/证伪 | 旧判断 → 市场结果 → 哪条假设命中/失效 → 是否入库/修正 |

## 3. 进阶四层（L1→L4）

- **L1 钉事实**：传闻/小作文先核真伪与口径，再拆传导范围、可交易与不可交易部分。事实不稳，估值弹性仓位全会漂。
- **L2 做推演**：情景树、时间轴、预期差。推板块推票的本质是**排序**而不是名单。
- **L3 读市场结构**：
  - 行为模拟：谁有权改变变量？他的激励？转向后传导到哪条链、哪个时间窗？
  - 资金推演：博弈阶段问玩家属性和心理（场内/场外买盘的大小、属性、心理），比继续问基本面更有增量。
  - 价值迁移：重大催化拆短期情绪 / 中期业绩路径（订单、毛利率、客户结构、验证节点）/ 长期角色与利润池迁移。
- **L4 校准自己**：
  - 认知压力测试：行情高热时问"Risk Off 拐点由什么触发？分早期预警/加速信号/拐点确认三层，各对应什么仓位动作"。把"还能不能追"改写成"拐点如何确认、动作如何分层"。
  - 记忆召回：持仓不舒服时，让系统结合旧框架解释体感来源——风险保护、叙事切换、还是框架需要修正；"不要只按当前主线评价它，拆出它独立的时间线和验证点"。
  - 盘感翻译：把"我共振/我上头/这票逻辑干净"翻译成可复用框架 + 证据 + 反例 + 触发/失效条件。

## 4. 按自身状态选问法

| 状态 | 更好的问法 |
|---|---|
| 已经很懂 | 我已有 thesis，请帮我找反例、关键验证项、估值隐含情景、错误会发生在哪一步 |
| 刚接触新赛道 | 帮我画产业地图：上中下游、核心玩家、利润池、技术路线、A 股映射、未来三个月催化 |
| 准备交易 | 哪个方向确定性最高/弹性最大？什么时候验证？失败信号是什么？ |
| 想要超预期 | 保留开放式提问，不过度约束模板 |

## 5. 反馈三分法（对话结束前必做）

| 情形 | 动作 |
|---|---|
| 共振 | 追深：核心证据、反例、证伪信号 → 凝练成框架 → 入库 |
| 相悖/验证出错 | 给证据纠错，要求系统回看归因、更新框架（不是只改结论）；也逼自己确认到底谁对 |
| 看起来对但未验证 | 写入决策追踪（判断+验证标准+命中口径），等市场回答后回放假设链，命中总结可复用条件，未命中归因漏了什么指标/排序哪里失真，再回流成经验 |

## 6. 问题资产管理

- **周期性问题**：固定每周/每财报季反复问（持仓复盘、主线拥挤度、宏观三情景、核心票验证点），常问常新。
- **经典框架问题**：沉淀成模板（推板块、推票、压力测试、事件传导、产业链排序）。
- **新颖角度问题**：类比、哲学、历史映射、玩家心理单独收藏，长期塑造审美。

## 7. 会话卫生

- 按项目分会话：每日盘面 / 行业 / 个股 / 事件分开；同一 session 共享上下文效果更好，但太长会互相干扰。
- 提问前挂载对应技能/记忆；对话结束跑"反思洞察"，逐条接受/拒绝待入库记忆。
- 定期检视记忆库/决策库，删除过期口径；用胜率审视判断质量。
