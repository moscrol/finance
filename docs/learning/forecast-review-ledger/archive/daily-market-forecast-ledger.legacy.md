# 日度市场前瞻验证台账

这里记录“盘前/前瞻研判 -> 收盘验证 -> 经验修正”的闭环。每条研判都是可验证假设，不是结论定律，也不是投资建议。

使用原则：

- 前瞻只使用当时可得信息，必须写清观察视角和数据缺口。
- 推论要可验证，尽量落到涨家数、成交额、行业集中度、双红题材、新高集群、涨停热度、相对强度、逻辑生命周期等字段。
- 收盘后统一标注 `命中 / 部分命中 / 未命中 / 暂不可验证`，并写明错在哪里、下一次如何修正。
- 高频聊天纠偏不写进 Agent Memory；只有反复有效的方法论，再升级到长期记忆。

## 次日行情研判四源合议框架

次日行情判断不能只靠全量盘面外推。更稳的做法是把四类当时可得信息合并：全量盘面复盘给出市场阶段、情绪、量能和板块结构；晚间卖方和机构胜率给出信息扩散、覆盖密度和潜在新 alpha；外盘市场给出全球风险偏好与 AI/半导体/算力链映射；晨汇给出早间新增事件、产业变量和盘中待验证方向。

第一性原理是：价格由资金推动，资金会在“已有强度、边际信息、流动性环境、风险偏好”之间重新分配。盘面告诉我们钱昨天在哪里、是否拥挤；卖方和晨汇告诉我们新信息今天可能往哪里扩散；美股告诉我们外部映射是顺风还是逆风。四者一致时，假设置信度提高；四者冲突时，要优先写反证和路径分歧。

外盘要使用“双源口径”：复盘会 `/reviews/global-market` 是结构化底座，适合入库、回测和与 A 股交易日对齐，但可能只返回上一完整外盘日，必须记录 `source_trade_date`；如果需要真正“当晚美股收盘”或盘前最新涨跌幅，则用 web/finance search 补纳指、费半/SOXX、QQQ、NVDA、AMD、TSM、特斯拉、中概/港股映射等最新数据。不能把复盘会昨日外盘误当成最新隔夜。

策略一二三四不能作为静态标签硬套，要还原成市场状态语言：

- 市场分歧或探底修复时，核心问题是资金会选择“主流题材强势股回流”还是“流动性切换”。前者对应策略三的底层逻辑：前期被市场选择过的强势题材/强势股，在分歧后如果没有证伪，可能出现回流确认；后者对应策略二的底层逻辑：弱市中资金从高位拥挤处切到低位、滞涨、多周期仍有题材记忆的方向。
- 市场上涨时，先分清结构性上涨还是普涨。结构性上涨要看主线容量、双红、成交前三行业和核心股相对强度，接近策略一的主线流动性池思路；普涨或强趋势延续时，要看加权强度、新高延续、重复入榜和主线 regime，接近策略四的强者恒强/趋势延续思路。
- 市场高位拥挤时，不能因为题材强就线性看多。要比较高覆盖方向是否仍有核心新高、涨停扩散和成交承接；如果只有卖方继续推、盘面没有扩散，就是共识确认甚至兑现风险。

每条前瞻假设都要标明来自哪类输入：`全量盘面`、`晚间卖方`、`复盘会外盘`、`web 最新美股`、`晨汇`。缺哪类信息就写缺口，不能用印象补齐。
