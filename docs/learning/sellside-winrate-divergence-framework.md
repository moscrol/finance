# 晚间卖方与机构胜率发散框架

> 样板用途：回答“晚间卖方怎么看 / 胜率高的机构在推什么 / 哪些方向值得发散”时，先学习这套推理方式，而不是复述研报标题。核心是把机构胜率当作信息权重调节器，再用覆盖密度、证据硬度和盘面位置判断哪些是新 alpha，哪些只是共识确认或兑现风险。

## 核心原则

机构胜率不是买入信号，而是“这条卖方信息应该被赋予多大研究权重”的调节器。卖方观点的本质是信息扩散节点：同一个观点被谁说、在什么窗口有效、是否已经扎堆、有没有硬事实、盘面有没有选择，决定它是研究入口还是反向信号。

最基础的四因子是：

- 机构胜率：看 T+5、T+10 超额胜率、样本数、均超额、均最高、均回撤，判断这个机构更擅长短催化还是中短期趋势。
- 覆盖密度：低覆盖说明共识未形成，高覆盖说明市场可能已经充分听过。
- 证据硬度：公告、订单、涨价函、交期、客户认证、扩产、央视/监管/上市公司披露，比框架性周观点更硬。
- 盘面位置：方向是否进入双红、容量行业、新高集群、涨停热度或强势股榜；若方向强但目标股不强，要解释市场没有选择它的含义。

## 推理顺序

先拆机构窗口。T+5 很强但 T+10 衰减，通常是短催化、情绪点火或事件交易；T+5 和 T+10 都强，才更像可延续的产业趋势或中短期重估。样本数太少时不能神化胜率，样本数大但均超额低时也只能当趋势确认。

再看卖方观点处在什么生命周期。高胜率机构推低覆盖方向，可能是早期 alpha 入口；高胜率机构推高覆盖扎堆方向，更多是共识确认，甚至可能提示兑现风险。第 1 篇报告是信息差，第 N 篇报告可能就是情绪扩散末端。

然后看证据有没有变硬。真正值得发散的不是“某机构看好某方向”，而是它有没有带来新事实：涨价、缺货、交期拉长、客户认证、订单落地、产能扩建、资本开支、进口替代断供。只有观点，没有事实，就只能进观察；有事实但覆盖已高，要等分歧或找二阶分支。

最后沿产业瓶颈发散。不要沿研报标题发散，要从事实反推瓶颈：涨价对应供需缺口，缺货对应产能瓶颈，交期拉长对应设备/零部件/材料约束，扩产对应 CAPEX 受益，客户认证对应国产替代入口。发散目标可以是更直接的设备、材料、零部件、封测、供电、上游耗材或替代方案，而不一定是研报主推股票。

## 输出分类

优先发散：高胜率机构 + 低覆盖 + 硬事实 + 盘面未充分反映。这里要进入研究队列，继续找产业链暴露、同链公司、财务弹性和验证指标。

只作确认：逻辑是真的，但覆盖密度高、卖方扎堆、盘面已大幅演绎。这里不把它当新 alpha，只用来确认主线仍在，重点找低位二阶分支或等待分歧。

反向谨慎：高胜率机构仍在推，但 T+5 强 T+10 弱、覆盖密度极高、盘面已经加速，或者强板块里目标股掉队。这里要主动问：是不是已经从预期交易进入兑现阶段？

## 回答样板

我不会把机构胜率直接翻译成“买谁”。更准确地说，胜率高的机构在晚间卖方里出现时，只说明这条信息值得提高研究权重；它是不是机会，还要看这条信息处在什么覆盖密度、证据硬度和盘面位置。

如果一个机构 T+5 胜率很强、T+10 衰减明显，它更像短催化捕捉者，适合发现事件点火，不适合在一致高潮后追。如果一个机构 T+5/T+10 都强，且回撤不大，它的观点更适合当中短期趋势信号。这里第一步不是看它推了什么股票，而是判断它擅长的时间窗口。

第二步看拥挤度。同样是高胜率机构，如果推的是存储、半导体设备、光模块这种高覆盖方向，很多时候只是共识确认，甚至是兑现风险；如果推的是功率半导体调价、测试设备、SST/中压 UPS、某个材料涨价或断供这种低覆盖硬事实，才更像值得发散的入口。

第三步从事实反推瓶颈。比如调价不是结论，调价背后要问是 8 寸代工紧、AI 挤占产能、汽车工业需求回暖，还是高压料号缺货；扩产不是结论，扩产背后要问最先受益的是设备、测试、洁净室、材料还是封测。这样发散出来的机会，才可能比研报标题更靠近产业瓶颈。

所以回答晚间卖方时，我会把方向分成三类：优先发散、只作确认、反向谨慎。优先发散看高胜率、低覆盖、硬事实、盘面未充分反映；只作确认看逻辑真但卖方已经扎堆；反向谨慎看短窗胜率强但中窗衰减、覆盖极高或盘面已兑现。最后再落回市场结构：方向有没有双红、容量、新高、涨停和强势股确认；如果方向强但标的不强，就不能把它当主线核心，只能视为后排跟随或待验证线索。

## 可复用规则

- 卖方胜率是信息权重，不是交易结论。
- 第 1 篇报告可能是信息差，第 N 篇报告可能是兑现风险。
- 高胜率机构推低覆盖硬事实，优先发散；推高覆盖共识，先反向审稿。
- T+5 强 T+10 弱，偏短催化；T+5/T+10 都强，才更像趋势信号。
- 发散要沿产业瓶颈走：涨价、缺货、交期、认证、订单、扩产分别指向不同环节。
- 最终必须落回盘面：双红、容量行业、新高集群、涨停热度、强势股榜和目标标的相对强度。
