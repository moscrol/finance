# Narrative Answer Composer

## 问题

金融问答不能只靠模板。模板能防漏项，但容易让回答变成：

- 公司本体一段；
- 盘面一段；
- 二阶导一段；
- 反证一段。

这种写法看似完整，但缺少一条真正的判断链。用户要的是：站在多个视角上推演，而不是按视角填空。

## 核心解法

把问答拆成两层：

1. **视角清单**：只做内部自检，保证不漏公司本体、产业链、证据、盘面、生命周期、二阶导和反证。
2. **叙事编排器**：先抓核心矛盾，再让所有视角服务这个矛盾。

核心矛盾句要回答三件事：

- 这家公司真实业务是什么？
- 市场正在交易什么预期？
- 最大证据缺口或反证是什么？

例如裕太微：

> 裕太微的问题不是有没有 AI 连接芯片想象，而是市场已经把“PHY 国产替代 + Marvell/DSP 远期映射”交易了一轮，但真正能把逻辑从预期交易推到业绩验证的 L3 证据还不够。

## 写作规则

最终回答不按清单机械分标题。每段都要回答：

- 这个事实改变了我对空间、生命周期、资金选择或证据硬度的什么判断？
- 资金为什么选择、放弃或犹豫？
- 有没有更强的同链替代表达？
- 这个逻辑是升级、维持、降级还是等待验证？

## 可复用知识点

这是垂直 Agent 常见问题：**rubric 防漏项，composer 防模板化**。

在法律、医疗、投研、代码审查等场景都一样：先用 rubric 保证覆盖，再用核心矛盾或主问题组织叙事。否则模型会完成检查表，却没有形成判断。
