## 3. q4：有取舍的线索池，不等于自主发现与原始取证完成

原答：[q4](../knevo-distill/batches/2026-09-24-research-continuation/q4-answer.txt)。

**可保留：**开头承认只能自查当前会话，不能冒称覆盖30天；给出五条候选、保留两条、解释放下三条；将新发生、刚发现旧事实和旧消息重传分开；给出传导环节、参与者证据与逻辑候选。这是比堆新闻更可继续研究的组织方式。

**限制与反例：**

1. **发现范围被前序话题约束。** 候选仍集中于既有半导体/存储上下文，其他行业自述未展开。只支持「在当前研究域内产生候选」，不能证明全市场自主发现能力。检索入口和次数也是自述，不是已核执行史。
2. **最早检索命中不等于首次公开。** L23-29表把券商、内部观点库和媒体转述置于「首次公开时间与原始出处」，多项原文明确未取得。应分别记事件日、原始披露日、本次发现日；原始披露日未证实就保留未知。
3. **分类前后漂移。** 长鑫7月上市在候选表写「新发生」，后表写「我刚发现的旧事实」；相对于09-22的近30天窗口，7月不是新发生事件。上市真值本轮也未核。9月增资和7月上市不能混为同一事件时点。
4. **传导没有补齐就写成盈利下限。** L64把「长约化＋国产扩产」合为一条结论，并认定设备材料最直接受益。锁量不等于锁价、有价格下限不等于净利润有下限，海外原厂条款也不能自动适用于国内供应链。该研究卡实际合并了两条仍缺连接证据的机制。
5. **共识判断超出样本。** L61用不同月份的卖方报告、ETF申购、估值和一次海外路演，推出「国内已共识、海外主动多头未认同」。这些分别代理关注、持仓、资金或估值，缺同一命题、同一时间窗、样本分母及实际预期分布。不能据此确定共识边界，更不能推导盈利预期差。
6. **绝对化资料入口。** 将长鑫定期报告称为核查扩产的「唯一入口」、把未来季报视为低难度必有材料，缺披露范围核验。公司采购、项目公告、供应商披露各自可能覆盖不同主张，不能固定唯一来源。

后续最有价值的工作是选一条候选取得原始资料，证明它确实改变了一个旧判断；不继续扩长线索清单。

## 4. q5：动态竞争结构可用，产品口径和会计归因不成立

原答：[q5](../knevo-distill/batches/2026-09-24-research-continuation/q5-answer.txt)。

**可保留：**从客户购买对象、计价、切换成本展开，补竞争者扩产与客户反制；分别分析需求增长但利润留存/流失、需求放缓但优势维持；追踪采购成本与成品实现价格、合同条款、产品结构。这种研究视角可以跨行业使用。

**关键失败：**

- **F1，研究单元仍过宽。** 同时讨论DRAM、NAND、HBM、消费模组、企业SSD和车规料，L26-27却概括为「原厂不能换、模组几乎随时换」，进而认定模组扩产障碍几乎为零。认证、固件适配、质量追溯、客户准入、资金与供货保障须逐产品和客户核对；原答自己承认定制段有壁垒，不能拿消费渠道个案判全部模组。
- **F2，错配价格不能识别一条产品链的利润差。** L66用09-15的DDR5次级颗粒高价与09-08的SATA 256GB SSD降价，宣布「价差被两端挤压、证据链完整」。前者是DRAM颗粒，后者是NAND存储成品，不是匹配的投入/产出对；日期、规格、币种、渠道、实际采购批次也未对齐。即使两条行情都真，也不能直接量出任一家模组业务的毛利变化。
- **F3，库存持有收益被写成会计重估。** L32-36先把H1利润主体定为「库存重估红利」，末卡又承认无法计算库存与经常性价差的贡献。按成本与可变现净值孰低的通常存货框架，低成本存货售出时扩大毛利，不等于把未售存货按涨价直接重估确认收益；历史减值转回另受条件与原计提额约束。本轮没有该公司会计附注，不裁决实际使用哪项政策，更不能量定主要利润来源。
- **F4，长约不是一方向的护城河。** 锁量、浮动价、固定价、最低采购、取消权及重谈条件决定上下游谁承担风险。未取得合同或电话会原文，不能断言原厂保住下限、模组必被锁住成本；供需逆转时也不能无条件写「长约反而锁定低价」。
- **F5，历史正反例缺机制等价与完整窗口。** 集运、面板、DRAM、HBM的对照给出了思路，但资本强度、认证路径、产品差异并未配平。DRAM自2017后的「波动收敛、利润留存」与当前HBM「定价权稳固」没有完整周期数据支持；集运规模数字也自标未核，不作历史金标。
- **F6，否决指标仍有其他解释。** 毛利率升且周转天数降，可能来自产品结构、收入增长改变分母等，不必等于同产品价差扩大。两三周报道重复出现不等于连续独立观测；A/H发行折价不能直接证明经营壁垒强弱。

可继续的窄题：选择一家公司的一个业务段，用同规格投入/产出价格、销量/组合和存货成本批次核验毛利机制。不能吸收「原厂留得住、模组留不住」为通用定律。

## 5. q6：名义集中识别正确，未知变量在汇总中被填成确定风险

原答：[q6](../knevo-distill/batches/2026-09-24-research-continuation/q6-answer.txt)。题设是虚构组合，禁止映射现实公司。

**可保留：**直接客户不同不保证最终需求独立；都用铜不保证影响方向相同；检查成本占比、调价、库存、套保以及时滞；45%是甲乙的组合名义权重，权益内部占比为45/80=56.25%，不直接等于组合损失。这些结构在题设内有依据。

**需要纠正：**

1. **最大风险和只有两个因子都未识别。** L9、L87、研究卡把丙丁归为同一个「国内周期」，与甲乙合成「实际两个因子」。电网投资与汽车需求不能仅凭发生在国内就合为同一预算池；其他成本、融资、流动性等因子仍未知。甲乙是明确应查的共同依赖，不足以排序为最大组合风险或判丙丁共同性最弱。
2. **币种未知却确定自然对冲。** 穿透表写币种未披露，L25/L45/L50却给80%汇率敞口、甲乙受损、丙丁受益，并称唯一内部自然对冲。没有收入/成本/负债币种、定价与套保，无法判方向和幅度；海外终端不保证外币收入，国内用铜也不保证进口外币成本。
3. **权重不是因子敏感度上限。** L52把45%称为单一因子暴露上限，但没有定义暴露是配置权重、经营弹性还是股价敏感度。只有在限定无杠杆多头、仅甲乙两仓等条件下，它可作为这两仓完全损失对组合的贡献上限，不能推广为所有共同因子敏感度上限。
4. **收入占比乘法忽略传导系数和估值。** L58给出含未知「利润传导系数」的近似式，随后从收入占比合计不足30%直接断言真实集中低于15%。原式尚有未知系数，不能据收入占比单独完成这个上界判断；不同公司占比也不能直接相加冒充组合加权占比。即使估到经营弹性，仍未估出股价和组合回报。
5. **现金性质不能补设。** L56「现金不产生正收益」不成立为一般规则；计息、币种、受限状态和组合计价基准均未给。可说现金不自动构成特定经营因子的反向头寸，不能说现金必定零收益、必定按固定比例降低风险。
6. **未知阈值变成管理规则。** 最终卡35%、20%、相关性0.3以及正文5%铜成本等数字没有校准或授权风险预算。两季客户下修、单季延后等也不能机械等同升级/噪声。应保留为待讨论情景而非通用门槛。

正确研究产物应是「已识别共同依赖＋还不能定量的敏感度＋补查计划」，而不是强迫把不完整组合压成已确定的两因子模型。

- **F8，同一指标被同时判不能区分和直接判决。** L27说扣非只能确认、不能区分A2/B2，甚至称其用途是「排除利润造假」；L62却把三季报称为「直接判决A2/B2」。财报可以更新经营命题，不能单凭结果消灭财务真实性疑问或识别股价因果。
- **F9，客户扩产越级变供应商订单。** O3写大额资本开支披露就补上设备链订单环；欠缺采购范围、设备类型、供应商份额、合同与交付。新增的三星电气转述只能在核实后说明该公司该合同，不能据此给全部半导体公司套重大合同门槛，或把无公告二分为「未发生/未触发」。
- **F10，涨价停滞不必然等于机制失效。** 高价维持、销量/组合、成本滞后仍可支持盈利；必须将价格水平、涨速、实际销量与利润分开。q8自己就允许「价格高位不再涨、利润仍增」，q9却要求价格不停涨。更不能把存储价格续涨设为长川等所有设备业务的必要条件。
- **F11，删掉量能判据后又以价格同步判基本面。** O5要求设计、模组等同向涨来支持价格机制，但这些环节成本、产品与预期不同；同向涨也兼容主题交易。只能作为待解释的市场现象，不能单独区分经营命题。
- **F12，修订卡仍改变条件。** 定义A2列「毛利率升、扣非升、或首次订单」；观察表各项可升级，最终卡改为扣非与毛利率双升且价格续涨，既无任务依据也未统一业务范围。没有把「任两项」重复一遍，不等于新的必要条件成立。
- **F13，节奏约定被用于实质降级。** L75称连续三周只是观察节奏；L66和卡却用其暂停/降级研究，实际已是决策阈值。对月度/季度合约价，三周没有更新也不是三周价格持平。个位数、连续两期等同样未标定；正文“两期才支持B”的谨慎没有完整保留到末卡「任一回落」的判断强度中。
- **F14，缺口处理只覆盖两项且过度概括。** 四状态表只处理O1/O2，未覆盖O3-O5；报价的「没更新」「窗口未到」也不应一律写不适用。检索失败本身不证明公司恶化，但若旧结论依赖的唯一证据失去支撑，应撤回其「已证实」身份；不能永远只换标签而不动置信度。毛利率不是报价的一比一替代，供应商扩产资料也不能替代公司订单原文。

资料优先级仍不理想：已承认H1原文没取到，却首选等待三四周的Q3，并假定Q3会披露存货结构和解决H1非经常项目。应先核已存在的H1原文和当前报价原件，未来具体日期与披露明细另验。
