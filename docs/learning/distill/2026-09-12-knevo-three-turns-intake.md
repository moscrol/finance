## 3. 答卷可直接判定的发现

### 第 1 轮：不能作为合格的事前预测样本

1. **信息可得时间越界**：题目截止 09-11 15:00；答卷第 1 题明确引用 15:01、16:53、17:36 的收评，数据表还列 T+1 两融和 `as_of=09-12` 估值，却声明全部信息均在截止前公开。事件发生在盘中，不证明盘后文章在盘中已可得。对 09-12 标记的估值只能说缺少截止前版本证明，不能仅凭查询日期断言其数值发生过变化。
2. **局部数据越级解释总体**：正文承认 09-11 仅有沪市两融，却据此断言全市场杠杆撤退、放量不来自新增资金。说明口径缺口之后，结论仍必须受该缺口限制；融资余额也不能穷尽资金来源。
3. **竞争解释前后不一致**：第 3 题写当前最强证据偏向 B（情绪轮动），第 6 题却将“我倾向的 A（基本面）”作为原判断，未说明中间有什么新证据导致转换。
4. **当前与未来触发器混用**：第 7 题把“连续两日净流出”设为未来降级条件，又说 09-10/11 已构成连续样本；该条件还含“不反包”，不能只核流出就宣告整项成立。需要完整判定基准时点各条件的状态。
5. **未经验证的细节不入知识层**：DeepSeek 产品与需求减量、供应商数量、财报数、资金流、所谓 AH 表现等均未逐项外核。原文保留供定位，不当事实结论，更不借预测期后来走势替越界样本补打胜分。

### 第 2、3 轮：结构有用，若干结论越过材料

| 项 | 判定与边界 |
|---|---|
| 四个基础比例 | 正确：甲年计划额 0.5/20=2.5%、0.5/2=25%；乙 0.4/5=8%、0.4/0.5=80%。两年甲总额与一年乙金额不能直接当同窗增长率比较 |
| 预算→采购→交付→利润的拆解 | 适合作为待验结构，但框架协议不是所有订单必经阶段，验收也不是通用收入确认充分条件；不能将这一案例链当通用硬流水线 |
| 低基数直接排最大弹性 | 第 2 轮第 3/5 题先承认缺订单/利润数据，后又断言乙潜在弹性最大、弹性大是事实，证据不足。只有保持订单增量等条件相同时，较小分母才放大比例 |
| 低涨幅被称为必要条件 | “小体量+低涨幅是潜在弹性大的必要条件”不成立；涨幅不是财务增量公式的必要变量，且没有市值/预期数据，不能推出便宜或最大预期差 |
| 净替代被直接近似为零利润增量 | 第 2 轮第 3 题“若替代，增量净利≈0”过强。收入不增时，毛利结构、费用和税负仍可能变化；只能说净增收入与净增利润均需另算 |
| 旧订单重述 | 第 3 轮第 3 题的三分法可保留为候选：新增催化消失、订单存量不变、研究优先级可因乙的新信息相对下降。第 1 题“甲事实保留但降级”则应注明只降相对优先级，不能把旧消息自动降为较软的合同证据 |
| 验收被改写为已确认收入 | 第 3 轮开头显式增加“交付验收即满足收入确认”的假设，后文和摘要却写成“0.4 亿已确认收入”。问题是条件性推演变成了材料事实，而不是否认验收通常是重要迹象。会计边界见下 |
| 框架取消的作用域 | 正确否认“今年收入减少 3 亿”；但又写丙“无任何商业关系证据”“潜在弹性归零”，将客户 R 的本项框架终止外推到公司全体业务。应仅撤回该框架的支持，不抹掉给定的去年相关收入 10 亿 |
| 同源六篇报道 | 正确识别为一个订单公告的传播，不能证明核心供应商地位；传播广度可以另记，不能计成六份独立事实佐证 |
| 合取未知 | 第 3 轮第 7 题正确：交付验收为真、毛利比较未知，AND 结果未知；既不能晋升，也不能把它判为明确反证 |

收入确认的外部校验只采用财政部一手来源：《企业会计准则第 14 号——收入》第四、五、十三条，以履约、控制权与合同条件为准，客户验收是判断迹象之一。该准则支持“验收与已确认收入不能无条件互换”，不用于臆测本虚构合同的其他条款。[财政部原文 PDF](https://m.mof.gov.cn/zcfb/201707/P020170719328747835611.pdf)
