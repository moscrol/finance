# 问答自审框架：质检器与用户影子反驳

> 用途：回答“深挖某股 / 怎么看行情 / 哪个方向有空间”时，生成初稿后先内部自审，再输出最终答案。当前版本已经从单次 prompt 约束升级为 `draft -> 用户影子反驳 -> revise` 二次调用，并在个股问题里注入确定性市场价值、客户证据硬度、二阶导研究队列数据块。

## 质检器

输出前必须检查：

1. 公司本体：主营、产品、客户、收入结构、毛利率、产业链位置和报表传导是否讲清。
2. 产业链暴露：是一阶受益、二阶暴露、三阶映射，还是真瓶颈。
3. 证据层：L1 观点、L2 基本面、L3 订单/认证/量产/客户验证/反证、L4 盘面强度是否分清。
4. 高位主线反证：产业正确是否已被价格反映，新增利润预期和事件锚点是否仍未兑现。
5. 大盘与流动性：大盘阶段、成交额/20日量能、指数/周均线偏离、涨家数、涨停跌停、涨家数 MA5 是否进入推理。
6. 市场风格：大成交趋势、情绪连板、低位切换、高位抱团、防御避险、小票修复或容量核心虹吸。
7. 行业容量：容量前三申万一级、目标所属申万一级、成交占比环比、所属行业涨停结构。
8. 题材结构：所属题材、双红演变、新高集群、涨停热度、同题材前排和目标是否为核心表达。
9. 个股相对强度：成交额、流动性、加权涨幅、3/5/10日强度、新高/涨停、分歧日抗跌、回流日领先。
10. 生命周期四问：阶段、相对过去 N 天变化、市场价值成绩单、升级/降级/证伪条件。
11. 二阶导：从目标股反推真实产业瓶颈和更优表达。
12. 条件化结论：当前身份、置信度、升级条件、降级/证伪条件、跟踪指标。

## 用户影子反驳

生成初稿后，模拟严格用户追问：

- 你是不是又在套模板，而没有从第一性原理解释资金为什么会选择它？
- 你是不是只看了个股，没有放到大盘、情绪、板块容量、双红题材和平行题材竞争里？
- 你说它受益，证据够硬吗？有没有订单、认证、量产、客户验证、收入占比、毛利率？
- 它是不是这条产业链的最优表达？市场更可能奖励谁、抛弃谁、犹豫谁？
- 这条逻辑生命周期到底在哪一段，状态相比过去 N 天是升级还是降级？
- 有没有把上涨空间和逻辑生命周期分开？
- 有没有主动寻找反证：公司否认、收入占比低、仍在研发/送样、客户未确认、涨过后强度掉队？
- 有没有二阶导到更好的投资机会或研究队列？

## 当前实现

- `intelligence/services/answer_quality.py`：生成 `pre_output_quality_gate` 和 `shadow_user_critic`，随问答质量上下文注入。
- `intelligence/services/llm_refine.py`：新增 `synthesize_messages_with_review()`，先生成初稿，再用用户影子审稿提示做二次反驳/重写；若二次调用失败，保留初稿降级。
- `intelligence/services/ask.py`：`ask --compose` 默认启用二次审稿，并在识别到个股时注入三个结构化数据块：
  - `市场价值与替代队列数据块 [D1]`：区间涨幅、峰值涨幅、峰后回撤、峰值收益保留率、半衰期代理、题材状态、个股相对强度排名和同题材强势替代队列。
  - `客户证据硬度数据块 [D2]`：把客户、订单、量产、送样、审厂、导入、收入等证据分成硬证据、候选证据、弱证据/研报推断、反证/缺口。硬证据可支撑当期逻辑，候选证据只能支撑跟踪假设，弱证据不能直接当作基本面兑现。
  - `二阶导研究队列数据块 [D3]`：拆成 P0 盘面已选择的强势替代表达、P1 目标股再升级条件、P2 产业瓶颈补盲，并保留反向观察条件。
- 回归测试：`intelligence/tests/test_answer_quality.py`、`intelligence/tests/test_ask_compose.py` 和 `intelligence/tests/test_experience_cards.py` 防止约束丢失。

## 后续升级

当前版本增加一次 LLM 审稿调用，优点是比单次 prompt 更稳定，能把“用户批判口吻”真正落到修订环节；缺点是延迟和调用成本更高。

如果后续评分仍不稳定，再升级为显式多 agent：

1. 主回答 agent 生成初稿。
2. 质检 agent 输出覆盖率缺口和评分。
3. 用户影子反驳 agent 输出更尖锐的反问。
4. 修订 agent 按缺口重写。
5. 低于阈值时拒绝输出或标记“低置信回答”。
