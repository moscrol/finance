## 一、背景：第五轮对比事实

### 题目

「基于周二的盘面数据，你认为主线是什么。今晚美股科技调整较多，你认为明天盘���会怎么走，哪个方向可能有机会」（2026-08-18 夜）

### 双方行为（实测）

**Workbench**（run_20260819_000940_130301，:8792，continuous runtime）：

- 路由 completed；5 次 tool_request（盘面汇总 / 板块行情 / 主线表），全部本地数据；
- 23 条证据绑定（E1-E23）；「美股调整」标为 user_premise 未核验，条件化挂起；
- verification → repair 一轮；status=partial（预测段未核验表述被裁）；
- **零新闻、零记忆、零外盘数据调用**。

**Knevo**（同题同夜）：

- 工具调用 13+：finance_memory_query ×2、finance_news ×5、finance_quote、finance_northbound、finance_margin_market、finance_memory_stage_extraction、suggest_options；
- 核心分析动作：**领跌结构裁决**（闪迪 -9.29% / 海力士 -8.11% / 美光 -7.47% vs 英伟达仅 -2.71%）→ 存储周期担忧 ≠ AI 逻辑证伪 → 结构性冲击而非全面杀跌 → 错杀买点 / 退潮确认的分支判断；
- 调用用户历史框架（CSP CapEx 证伪信号）与缓存判断（天风口径「找不到恶化的数据」）参与推理。

### 判定

内容实质 Knevo 明显胜；证据纪律 Workbench 胜（E 编号 vs 零引用）。本轮差距主战场在**数据域与推理框架**，不在纪律。

## 二、差距三层归因

### 第一层：数据域缺口（表层，台账已知）

| 缺口 | 台账编号 | 本轮表现 |
|---|---|---|
| 外盘行情 / 结构数据 | #2b（待排期） | external_market 车道返回空；「领跌结构」分析无原材料 |
| 新闻催化 | #2 已建（W7，PR #155）但未进 continuous 工具货架 | 种植业涨停潮、萨克斯 GPU 泡沫警告全程缺席 |
| 用户记忆 | #10 已建（[M] 块，PR #156）但未挂 continuous | trace 零记忆调用 |

### 第二层：推理框架缺口（中层）

research_contract 规定必查站，但没有「竞争性假说排除」思维步骤：

- Knevo：现象 → ≥2 竞争假说（逻辑证伪 vs 周期见顶）→ 用领跌结构裁决 → 操作含义；
- Workbench：取证 → 综述 → 条件化推演。循环在问「证据够不够」，不在问「哪个解释对」。

数据块使用要求是**防错型**（「不得把分歧写成主升」），不是**求真型**（「必须列竞争假说再裁决」）。防错纪律与求真框架是两种东西，目前只有前者。

### 第三层：验证器激励（深层，Goodhart）[推断]

verification 核验断言-证据绑定 → 可绑证据的浅结论比需要论证的深结论更安全 → **深度在当前激励结构里是负资产**。四连 partial（08-17 中际旭创 ×2、08-19 英伟达传导、08-19 外盘题）是模式而非巧合：核验层持续裁掉「证据撑不住的深断言」，模型被激励向浅处退守。

边界：本层为 [推断]，依据是 trace 中 repair 循环一致裁掉预测段未核验表述；未做消融验证（见第五节）。

### 第四层：记忆复利缺位（对位差距）

Knevo 的 finance_memory 提供三样东西：程序性框架（供给侧排序 / 锚龙双锚 / 三阶段轮动）、陈述性先验（天风口径缓存判断）、价值权重（该用户在意什么）。Workbench 的 memory_gate 严格（fail-closed + 人审晋升），但**框架资产未攒、[M] 未接 continuous**——纪律有、复利无。对应 70_tutor T9「认知复利 vs 可靠性复利」命题的实锤。

## 三、优化项（按 ROI 排序）

### P0-1 [M] 记忆块接入 continuous runtime

- 内容：把 PR #156 的 [M] 块（judgments + corrections + 回检胜率，相关性召回）注册进 `build_default_tools` / episode 工具货架。
- 性质：**已建未接**，最快见效。
- 验收：同题复跑，trace 出现记忆工具调用；答案引用用户历史判断并带 [M] 标注。

### P0-2 W7 新闻块接入 episode 工具货架

- 内容：东财资讯搜索（PR #155）作为 news_search provider 接入 loop 工具集。
- 验收：事件驱动题答案出现当日催化事实（带日期 | 来源 | 标题）。

### P1-3 竞争性假说表达契约（零新数据源）

- 内容：market_forecast / news_impact 类型注入��现象 → ≥2 竞争假说 → 裁决证据 → 裁决结论 → 操作含义」模板，与 #9+12（情景树表达契约）同模式。
- 关键设计：假说裁决**只能引用已检索证据编号**；裁决不了必须写「证据不足，两假说并立」——防编造，与禁数值概率同纪律。
- 验收：同题答案出现显式假说对比段。

### P1-4 #2b 外盘数据源（web-access CDP proxy）

- 内容：海外行情 / 新闻经 web-access 通用搜索接入，结构化解析费半 / 英伟达 / 存储链领跌结构。
- 验收：external_market 车道不再返回空；美股题给出领跌结构表。

### P2-5 #14 当日事件驱动主线读法

- 内容：D6 块（中期视角）之外新增「当日资金切换」视角（涨停潮板块 / 北证 50 / 炸板率 / 晋级率），与主线汇总表互补，块内强制「结构主线 ≠ 事件主线」口径声明。
- 验收：复盘题同时给出两种主线并标注口径差异。

### P2-6 框架资产输入通道

- 内容：`foresight_methodology.md`（思考宪法）扩展为框架资产库；把「竞争假说排除」「领跌结构裁决」「行为模拟（谁有权改变变量）」等框架（源自 knevo-distill README 三章）写入；[M] 召回时优先注入。
- 验收：答案出现框架名的显式引用（如「按供给侧排序框架…」）。

## 四、总验收：第六轮同题对比

钉完 P0-1 / P0-2 / P1-3 后复跑本题 + 保留题集，判据：

1. 外盘段：领跌结构数据在位（P1-4 完成前 user_premise 仍可接受，但必须列两个假说）；
2. 答案含 ≥2 竞争假说及显式裁决；
3. 出现 [M] 或框架名引用；
4. 证据编号纪律不回退（E 编号覆盖率不低于本轮）。

## 五、边界与不做的事

- **不放宽 verification**：partial 是纪律不是故障。本 spec 全部优化目标在「让它有料可深」，不在「让它敢说」。
- **不动 memory_gate 晋升纪律**：model_judgment 仍不自动晋升；框架资产走人审通道（P2-6 的 methodology.md 本身就是人审载体）。
- 第二 / 三层归因中标注 [推断] 的部分，实现前先做消融：同题关闭 repair 裁剪跑对照组，验证「深度被裁」假设是否成立。
