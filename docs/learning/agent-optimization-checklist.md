# 本地 Agent 优化清单

> 定位：本地确定性规则负责数据截止、证据绑定和可裁定结构；模型审稿只提供候选意见。
> 未经历史盲测证明能区分 hit/miss 的评分，不得自动阻断、自动晋级经验卡或代替人工裁决。

## P0：本轮落地

- [x] 规则评分改为 `advisory_review`，明确 `decision_eligible=false`。
- [x] 低分不再自动生成经验卡；只写审稿台账，等待人工反馈或盲测验证。
- [x] `answer-score` 不再以低分退出码充当硬闸门。
- [x] 双盲答卷升级到 schema 1.1：
  - 建立 `evidence_catalog`，统一登记 L1-L4、来源时间、字段值和支持/反证方向。
  - 阶段标签绑定 `stage_features`、规则 id、特征值、证据引用和截止日期。
  - 每类阈值记录来源：固定规则 / 回测 / 机械推导 / 经验值。
  - 数字、标的和假设绑定证据引用与 `evidence_as_of`。
  - 假设记录市场 / 方向 / 标的 / 证伪类别及高 / 中 / 低信心档。
- [x] 聚合按信息流、判断类别和信心档分账，避免总分掩盖方向或标的偏弱。
- [x] 聚合输出 AUC、Brier、ECE；当前固定 `decision_eligible=false`，只观察不放权。

## P1：下一批

- [ ] 建立自然语言数值到 DuckDB 字段的映射表，程序化核对数值、方向和实体归类。
- [ ] 把“底部横盘第 N 天 / 健康分歧 / 主线切换”等阶段标签改成版本化特征规则。
- [ ] 扩大与 T-001 同构的历史盲测，分别统计市场、方向、标的、证伪四类结果。
- [ ] 在扩大盲测后检查高/中/低信心命中率单调性，并预注册升级门槛。
- [ ] 只有满足最小样本数、样本外增益、无回归和 TTL 复审，审稿规则才可升级为硬闸门。

## P2：Workbench 展示

- [ ] 右侧检查器分别展示“确定性错误”和“候选审稿意见”，禁止混成一个总分。
- [ ] 每条结论可展开查看来源、数据截止、阈值来源、反证和验证窗口。
- [ ] 对旧记忆命中强制标记“历史基线”，并与当前盘面做支持 / 削弱 / 无变化 / 信息不足对照。

## 升级硬闸门的最低条件

1. 历史盲测方向正确，且 AUC 明显高于 0.5。
2. 高信心命中率高于中信心，中信心高于低信心。
3. 新规则在样本外提高命中或降低严重误报。
4. 规则能说明数据口径、适用范围、失效条件和复审日期。
5. 失败时可定位到数据、检索、证据、阶段、阈值或标的选择中的具体一层。
