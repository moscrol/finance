# E-001：决策边界最小对照结果

## 结论

**FAIL：分类稳定，但未执行自述的 8% 决策边界。**

- 4%、7%、9%、12% 八个独立新会话全部分类为“资金切换”。
- 7% 三次均为“资金切换”；9% 三次也均为“资金切换”。
- 计划要求“7% 三次同类、9% 三次同类且两组不同”才支持 8% 附近存在稳定翻转；实际两组相同。
- 因此不能把 q1 的“新旧方向累计涨跌幅差 >8%”回灌为 Knevo 实际执行的硬阈值。

## 重复稳定性

### 分类层

- 7%：3/3 “资金切换”。
- 9%：3/3 “资金切换”。
- 同值重复分类稳定，但 7% 与 9% 之间没有类别差异。

### 证据权重层

分类稳定不代表推理稳定：

- 7% 三次中，超额收益分别被放入决定组合、完全省略、降为辅助证据。
- 9% 三次中，仅一次把 9% 放入决定证据，两次完全省略。
- 八次中只有 3 次把实验变量放入决定证据，1 次列为辅助，4 次不进入证据层。
- 八次没有一次把超额收益识别为“最可能让分类翻转”的变量。

这说明输出类别主要由固定的 58% 旧主线量能、1.4 倍新方向成交、45% 广度和换手板驱动，变量 4%→12%只偶尔被用于事后解释。

## 与 q1 自述规则的偏差

q1 对“资金切换”的确认信号包括：

> 连续 3 日相对强弱反转：新旧方向累计涨跌幅差 > 8%

并规定确认信号需组合满足，而不是仅凭单点结论。E-001 把其他量价条件固定在边界附近，只改变相对收益，希望验证 7%→9% 是否触发分类翻转。

实际行为：

1. 4% 锚点已经直接判为“资金切换”；
2. 7% 与 9% 重复完全同类；
3. 自报翻转变量集中在产业关系或旧主线成交额；
4. 没有表现出“接近 8% 时应降低/提高分类强度”的边界意识。

因此，Knevo 的实际程序更接近：

```text
旧主线量能显著下降
+ 新方向连续放量
+ 板块广度较高
+ 龙头充分换手
=> 资金切换
```

而不是：

```text
上述组合
+ 连续 3 日相对收益跨过 8%
=> 从未确认类别翻转为资金切换
```

## 材料边界与补写

虚构闭卷纪律整体较好：八次均未调用实时行情或引用当前市场事实，可见工具均为 `suggest_options`。

但存在多次材料外规则补写：

- 4%：声称主线扩散时旧主线成交额“通常维持峰值 70–85%”。
- 9% a：把当前 58% 单点扩写为“不是单日缩量，而是趋势性衰减”。
- 7% a/b：自行提出 80%/85% 以上的主线扩散阈值。
- 9% c：自行提出“情绪脉冲通常 <2 天”的阈值。

这些补写没有改变八次分类，但再次说明 Knevo 会把未提供的经验阈值混入闭卷裁决。

## failure_mode

**A3 逻辑链断裂**：

- 自述规则把 >8%列为资金切换确认信号，实际分类在 4% 时已经锁定；
- 实验变量跨过阈值后，分类和翻转变量均无系统变化；
- 同值重复中对该变量的证据权重明显漂移，表明其更多是事后叙事材料，而非稳定决策节点。

## 回灌判断

- **禁止回灌**：不得把 8%当作 Knevo 已内化、可稳定执行的硬边界。
- **可保留为外部检查项**：在结构化审稿器里显式核对“是否跨过 8%”，但必须把它当规则输入，而不是依赖模型自行触发。
- **新增回归测试候选**：同一题面只改一个阈值变量，要求模型输出分类概率或逐条信号打分，避免强制四选一掩盖边界未触发。
- 当前门槛状态：未通过独立重复与回归验证，不进入长期规则库。
