### 起决定作用的两条证据

#### ① 旧主线缩量撤退 + 板块 X 放量持续 → 资金迁徙闭环

旧主线成交额已萎缩至峰值的 58%，说明持续失血；与此同时板块 X 连续 3 日维持 1.4 倍于自身 5 日均值的成交额。单一侧的缩量或放量都可能只是偶发，但两侧同时出现、方向相反，构成了最核心的「一出一进」资金切换信号——这不是存量博弈中的随机波动，而是有方向性的腾挪。

#### ② 充分换手板龙头 + 45% 成分股涨幅超 5% → 真参与而非假繁荣

龙头走的是充分换手板，意味着市场在任何价格上都经历了多空充分交换，进场资金并非凭借一字板的通道优势硬顶，而是「愿意在这个价格买」。叠加板块内近半数标的涨幅超过 5%，说明流动性外溢到了跟风品种，而非仅靠一两只票撑场面——这是资金切换的典型扩散特征，排除了单一控盘拉抬。

### 还缺什么数据

板块 X 的催化剂或基本面逻辑。目前只知道资金行为层面的信号，但不知道这轮切换是被什么驱动的——是政策事件（行业文件、补贴）、业绩预期（财报季前抢跑）、还是纯粹的比价效应（旧主线太贵、找洼地）。缺少这个，无法判断切换的持续性：有逻辑支撑的切换可能演化为新主线，纯筹码驱动的切换则更容易沦为阶段性轮动后熄火。
