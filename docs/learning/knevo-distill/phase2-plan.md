> 目标：从「它自述自己怎么做」切换到「验证它实际上怎么做」，同时比较 Knevo 与本地 Finance Workbench 的真实增量。

## 一、执行纪律

- B 线预测题必须**先跑本地、冻结答案，再问 Knevo**。
- 本地与 Knevo 使用同一数据截止时间、同一题目和同一输出契约。

- 稳定性和决策边界实验必须使用**新会话**，避免上一题污染下一题。
- 不向 Knevo 透露本地答案，除非该题明确属于 D 线「教师审稿」。
- D 线审稿时不提供未来结果，避免它按后验结果倒推批评。
- 每次记录积分、耗时、触发的 skill/工具（如可见）、数据缺口和追问次数。

  1. 至少 3 次行为一致；
  2. 历史盲测或 T+N 对照确有增益；

## 三、行为蒸馏实验（E 系）

### 4. E-001：决策边界最小对照

⚠️ **重复设计**：4/7/9/12 各跑一遍测不出边界——若 7 与 9 之间翻转，无法区分真阈值和随机漂移。按「3 次一致」门槛：**临界点 7% 和 9% 各重复 3 个新会话；锚点 4% 和 12% 各 1 次**（共 8 会话）。除变量数值外文字逐字一致，每题独立新会话，顺序打乱。

通用题目：

```
这是一个虚构的 A 股盘面实验，不要调用实时行情或记忆库，只依据给定数据判断。

旧主线成交额已经降至峰值的 58%；板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍；涨幅超过 5% 的成分股占比为 45%；龙头为充分换手板而非一字板；板块 X 连续 3 日相对大盘超额收益为 [变量]%。

请在以下四类中只选一类：
情绪脉冲 / 资金切换 / 主线扩散 / 假突破。

输出：
1. 分类；
2. 起决定作用的两条证据；
3. 还缺什么数据；
4. 如果只能改变一个变量，哪个变量最可能让分类翻转；
5. 不要给投资建议。
```

记录表：

```
| 超额收益 | 会话 | 分类 | 决定证据 | 自报翻转变量 | skill/工具 | 积分 |
| 4%  | 1/1 | | | | | |
| 7%  | 1/3 2/3 3/3 | | | | | |
| 9%  | 1/3 2/3 3/3 | | | | | |
| 12% | 1/1 | | | | | |
```

判断标准：分类在 8% 附近**稳定**翻转（7% 三次同类、9% 三次同类且不同）→ 它实际执行了自述阈值；同变量下反复漂移 → 不回灌为硬规则。

## 五、统一评分表

| 维度 | 0 分 | 1 分 | 2 分 |
