# Q14：小作文核验与信源分级（Knevo，32 积分）

问题：一条盘中小作文进来，你的真伪核验步骤、信源分级、『可交易部分』的拆法是什么？判定为假但市场仍在交易时的动作规则是什么？

## 答案原文（CDP 读回，逐字未改）

这是一个交易实战方法论问题，我先检索一下你过往记忆中是否有关于小作文处理的框架或案例，同时确认当前的市场状态。

## 盘中小作文：核验→分级→拆解→行动 的完整框架

这是一套交易台视角下的标准流程，四步串行但有交叉。

---

### 第一步：真伪核验（≤5 分钟，并行执行）

小作文进场的瞬间，做五件事，并行不串行：

| 核查维度 | 具体动作 | 判断标准 |
|---|---|---|
| **发布渠道溯源** | 追溯到最早出处——微信群截图？微博？境外媒体？匿名论坛？ | 能追溯到具名记者/官方账号 → 可信度+1；只有「据传/知情人士」且无法定位原始出处 → 可信度-2 |
| **交叉信源验证** | 同时查 `finance_news`（A股财联社/金十快讯）+ 主流财经媒体官网 + 涉及公司/部委的官方渠道（官网/公众号/互动易） | 两家以上独立信源确认 → 可信度+2；只有单一来源且其他渠道沉默 → 可信度-2 |
| **利益相关方排查** | 用 `finance_entity_resolve` 锁定被点名标的，查谁最受益——是持仓机构出研报的时间点？是游资席位刚上榜？是有期权到期日？ | 存在明显利益相关方且时间点巧合 → 动机存疑，可信度-1 |
| **内容逻辑一致性** | 消息里的数字、日期、人名、政策条文编号是否可交叉验证？政策表述是否符合该部门一贯措辞风格？ | 出现明显事实硬伤（日期不对、部门名称写错、政策编号不存在）→ 直接判定为假 |
| **历史模式比对** | 同类消息历史上出现过几次？每次结果如何？是「狼来了」第 N 次？ | 属于重复出现的模式化谣言（「周末降准」「某大佬进场」）→ 先默认假，除非本次出现新证据 |

**判定结果分四档**（不是二元的真/假）：

- **确认真实**：官方渠道或至少 2 家独立具名信源确认
- **大概率真实**：单一具名信源但逻辑自洽、无利益冲突、历史可信度高
- **无法判断**：信源匿名但内容无明显硬伤、无法证伪
- **确认虚假**：已被官方否认 / 存在事实硬伤 / 能追溯到伪造

---

### 第二步：信源分级（三层金字塔）

不是所有「消息」都叫信息。按来源分级：

```
        ┌──────────────┐
        │  L1：一手披露  │  ← 证监会/交易所公告、公司官方公告、部委正式发文
        │  权重=1.0    │     可信度最高，直接作为交易依据
        ├──────────────┤
        │  L2：具名信源  │  ← 署名记者独家报道、分析师正式研报、行业权威第三方
        │  权重=0.6    │     可作为交易参考，但需交叉验证
        ├──────────────┤
        │  L3：匿名/二手 │  ← 微信群截图、微博大V、「据传」「知情人士」
        │  权重=0.2    │     默认不交易，仅作为监控信号
        └──────────────┘
```

**关键规则**：L3 消息不能独立触发开仓。它只能作为 L1/L2 的加速确认信号。如果 L3 消息引发剧烈波动但 L1/L2 沉默，这个波动本身就是交易机会（见第四步）。

---

### 第三步：「可交易部分」的拆法

一条小作文通常包含三层内容，只有其中一层是可交易的：

| 层次 | 内容 | 可交易性 |
|---|---|---|
| **事实层** | 「X 部门发布了 Y 文件」「Z 公司签订了 Q 合同」 | 可交易——有明确的可验证/可证伪时间点 |
| **解读层** | 「这意味着政策转向」「行业格局重塑」 | 不可独立交易——这是写作者的观点，不是事实 |
| **情绪层** | 「重大利好！」「下周暴涨」 | 完全不可交易——噪音 |

**拆解规则**：
1. 把消息逐句拆开，每一句标注属于哪一层
2. **只对事实层做定价**：假设该事实为真，对标的做情景分析——合理涨跌幅是多少？
3. 把「合理涨跌幅」与当前盘面实际涨跌幅对比：**如果实际波动已经远超该事实能解释的范围，说明市场在交易情绪层而非事实层**

**实例推演**：一条「某部委将出台超预期刺激政策」的小作文——
- 事实层可定价：历史上类似政策出台后板块平均涨 2-4%
- 如果盘面已拉涨 8%+ → 情绪溢价约 4-6%，这 4-6% 就是「不可持续部分」→ 做空/减仓的安全边际
- 如果仅涨 1-2% → 事实层尚未完全定价 → 可考虑做多

---

### 第四步：判定为假但市场仍在交易——动作规则

这是最考验功力的场景。核心原则：**你交易的是市场的「belief」，不是你的「truth」。**

| 情形 | 市场状态 | 动作规则 |
|---|---|---|
| **情形A：官方已明确辟谣** | 市场仍在交易谣言方向 | **这是最好的反向交易窗口**。官方辟谣 = 确定性催化剂。在辟谣后的 5-15 分钟内建反向仓位，止损设在辟谣前高点/低点外 1-2%。因为辟谣后持仓者的认知失调需要时间消化，给了你一个确定性的退出窗口 |
| **情形B：你能证伪但市场不知道** | 市场仍在交易 | **不要急于反向**。你的信息优势需要时间传播。先小仓位试探，等市场出现第一个迟疑信号（量缩、涨速放缓、开始横盘）再逐步加码。你的对手盘不是「假消息」，是「还不知道这是假消息的人」 |
| **情形C：无法证伪但高度可疑** | 市场狂热 | **不参与方向，只做波动率**。如果标的期权活跃（美股），买跨式——不管最后被证实还是证伪，波动率定价的均值回归是你的朋友 |
| **情形D：假消息但触发了真趋势** | 假消息把价格推过了关键技术位，引发了量化/趋势资金的跟进 | **假消息是火柴，真趋势是汽油**。不要因为火柴是假的就做反方向——先退出观望，等趋势资金的方向确认后再决定。这时候「消息假不假」已经不是主导变量了 |

---

### 附：一个快速决策清单（可贴在屏幕旁边）

```
小作文进场 →
├─ 信源能追溯到 L1/L2 吗？
│   ├─ 是 → 按事实层定价，对比盘面，做差值交易
│   └─ 否 → 先假定为 L3，不触发开仓
├─ 盘面波动是否远超事实层能解释的范围？
│   ├─ 是 → 情绪溢价，准备反向
│   └─ 否 → 可能在有效定价，跟踪
├─ 已有官方辟谣？
│   ├─ 是 → 这是确定性信号，反向交易窗口 5-15min
│   └─ 否 → 继续监控
└─ 我有信息优势吗（我知道市场不知道的事）？
    ├─ 是 → 小仓位试探，等市场迟疑信号再加码
    └─ 否 → 只做波动率回归，不做方向
```

---

### 最后一条铁律

**假消息推动的价格运动，回归速度 > 真消息**。真消息的定价可能需要数日消化；假消息的定价通常在 1-3 个交易日内完全回吐。所以做假消息反向时，时间是你的朋友，不需要急着满仓——分步建仓，让均值回归替你赚钱。但在官方辟谣之前，永远不要裸空一个正在被假消息拉升的标的，因为你无法预知市场还要「信」多久。

---

## 架构解读与本地对照

**比我们细的地方有三处，都值得回灌：**

1. **判定分四档，不是二元**。确认真实／大概率真实／无法判断／确认虚假 —— 关键在于"无法判断"是一个**独立且合法的终态**，不被迫塌缩成真或假。我们 morning-briefing 的 L1-L4 证据分层解决的是"证据有多硬"，但没有给"核验结论"留一个显式的未决档；实践里这一档最常见。

2. **信源分级带数值权重且有硬约束**。L1 一手披露=1.0（交易所/公司公告/部委发文）、L2 具名信源=0.6（署名记者、正式研报）、L3 匿名二手=0.2（群截图、"据传"）。硬规则是 **L3 不能独立触发开仓，只能作为 L1/L2 的加速确认**。我们的证据分层没有"某一层不足以独立支撑动作"这条断言，全靠自然语言表述强弱。

3. **"可交易部分"的拆法是本题最有迁移价值的一段**：把一条消息逐句标成事实层／解读层／情绪层，**只对事实层做情景定价**，再把"事实层能解释的合理涨幅"与"盘面实际涨幅"相减，差额即情绪溢价，也就是反向操作的安全边际。它给的推演：类似政策历史上板块平均涨 2-4%，若盘面已拉 8%+，则 4-6% 是不可持续部分。

   这套减法可以直接搬到我们的题材发酵判断上：`fact_sector_daily` 有真实 pct_chg，历史同类催化的涨幅分布我们也能从库里算 —— 也就是说**情绪溢价在我们这边是可计算量，而它只能靠经验估**。这是我们的数据优势能反超它的一处。

**"判假但市场仍在交易"的四情形**（A 官方已辟谣／B 我能证伪但市场不知道／C 无法证伪但狂热／D 假消息触发真趋势）里，B 的表述最锋利：**你的对手盘不是"假消息"，是"还不知道这是假消息的人"** —— 所以不要急于反向，等市场出现第一个迟疑信号（量缩、涨速放缓、横盘）。D 情形则明确说，当趋势资金已跟进，"消息假不假"已不是主导变量。

**边界**：这部分属于交易动作建议（含止损位、建仓窗口"辟谣后 5-15 分钟"），是它的产品定位使然。我们这边**不生成实盘动作**，回灌时只取核验流程、信源权重、三层拆解与情绪溢价算法，不取仓位与时间窗指令。
