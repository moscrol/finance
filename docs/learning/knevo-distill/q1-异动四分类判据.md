# Knevo 蒸馏 Q1：板块异动四分类完整判据（用户代问回贴，2026-07-08）

超节点板块异动四分类完整判据清单
方法论定位说明：以下框架整合了已有的「恐慌底三维体系」「反弹三阶段模板」「中期主线四维筛选」「情绪退潮识别」等方法论（共享记忆库：风远94共享数据库），专门针对板块单日/数日异动做实时定性分类。

## 判断的总流程
每一轮异动发生 → 并行采集以下七维数据 → 按数据落入哪个分类的"确认信号"最多 → 判定性质。

## 七维数据采集清单

| 维度 | 数据 | 口径 | 来源 |
|---|---|---|---|
| D1 板块强度 | 板块涨跌幅、涨停家数/占比 | 当日 vs 前5日均值 | ftshare stock-quotes-list / 涨停板榜单 |
| D2 龙头质量 | 领涨股的涨停封板率、封板时间、炸板次数 | 龙头≥3只共同观察 | finance_news 盘中快讯 + 封板率统计 |
| D3 资金流向 | 主力净流入/超大单净流入 | 板块整体 + 龙头个股 | finance_instrument flow段 / ftshare |
| D4 板块广度 | 上涨家数占比、涨超5%家数、跟涨/补涨比例 | 板块内成分股 | ftshare stock-quotes-list |
| D5 相对强弱 | 板块 vs 大盘指数涨跌幅差、vs 前主线板块 | 当日 + 连续3日 | finance_quote 指数对比 |
| D6 量价关系 | 成交额 vs 前5日均值、龙头换手率 | 放量倍数 | finance_quote(days=5) + 当日 |
| D7 轮动背景 | 前5日市场主线是哪个方向、该板块此前位置（领涨/补涨/冷门） | 定性 + 涨幅数据 | finance_news + memory |

## 分类一：情绪脉冲
定义：由突发新闻/政策/龙头业绩预告引发的单日集中拉升，资金在信息不对称下抢跑，但次日缺乏持续买盘，快速退潮。

判断维度与阈值：
- D2 龙头质量：封板时间集中在早盘前30分钟、多为"一字板"或秒板；阈值 ≥60%龙头在10:00前封板
- D6 量价关系：板块成交额较前5日均值放大 ≥2.5倍（情绪集中释放）
- D4 板块广度：板块内上涨家数占比虚高但大部分涨幅<3%；涨超5%家数 / 上涨家数 < 25%
- D3 资金流向：主力净流入集中在开盘前1小时，午后递减；午后主力净流入 < 上午的 30%
- D5 相对强弱：当日板块跑赢大盘，但前3日板块无累计超额收益；前3日累计超额 < 3%

确认信号（同时满足 ≥3 条）：
1. 龙头一字板/秒板，跟风股涨停少、炸板多
2. 午后主力资金明显流出，全天净流入不及上午50%
3. 板块成交额较5日均值放大 > 2.5 倍
4. 板块涨超5%家数不足上涨家数的 1/4
5. 同一概念下，辨识度最高的龙头涨，但市值第二/第三的标的涨幅断崖式落后

反向信号（排除情绪脉冲的判据）：
- 次日板块继续放量上涨，龙头换手板而非一字板 → 可能升级为资金切换
- 龙虎榜显示机构席位净买入（非游资一日游）
- 成交量次日未断崖萎缩（次日量 / 脉冲日量 > 0.6）
- 同一逻辑链上下游联动（交换机涨 → 交换芯片涨 → 光模块涨）而非单点突进

持续时间：通常 1-3 个交易日。第 3 日仍无右侧确认 → 退潮确认。

## 分类二：资金切换
定义：资金系统性从一个前期过热/叙事受损的主线板块撤出，转向另一个基本面独立、催化剂明确的新方向，伴随持续的相对强弱反转。

判断维度与阈值：
- D5 相对强弱：新方向连续跑赢旧主线；连续 ≥3 日新方向涨 + 旧方向跌/平
- D3 资金流向：旧方向主力持续净流出，新方向主力持续净流入；连续 ≥3 日同向
- D4 板块广度：新方向板块内部涨幅从龙头扩散至二线、三线；第3日起涨超5%家数占比 > 40%
- D6 量价关系：旧方向缩量阴跌、新方向放量上行；旧方向量萎缩至前峰值 < 60%
- D7 轮动背景：旧主线出现叙事裂痕，新方向有独立产业催化；旧主线核心逻辑被质疑 + 新方向H2业绩拐点可见

确认信号（同时满足 ≥4 条）：
1. 连续 3 日相对强弱反转：新旧方向累计涨跌幅差 > 8%
2. 旧方向最脆弱标的（纯叙事无业绩锚）率先崩跌，且不随指数反弹
3. 新方向内部出现产业链联动（交换机→芯片→代工→上游材料顺序扩散）
4. 龙虎榜及主力流向连续 3 日确认：机构席位从旧方向撤、入新方向
5. 新方向龙头从一字板切换为换手板，说明市场参与者从抢跑变为持续博弈
6. 旧方向反弹无力：大盘回暖日旧方向跑输大盘

反向信号（排除资金切换的判据）：
- 新方向在第 2-3 天即出现龙头炸板、高位放量滞涨
- 旧方向核心标的（如光模块的中际旭创）止跌企稳且放量反弹，说明资金并未真正离场
- 新方向的上涨仅集中在1-2只个股，产业链未联动
- 新方向上涨伴随大盘缩量（存量博弈而非增量进场）→ 可能只是短期防御性轮动

持续时间：通常 2-6 周，直到新方向的催化剂兑现或被证伪。

## 分类三：主线扩散
定义：已有主线的龙头股涨幅过大、估值透支短期业绩 → 资金沿产业链逻辑向"亲兄弟"子赛道溢出，表现为主线内部的高低切换而非新旧切换。

判断维度与阈值：
- D7 轮动背景：主线龙头60日涨幅已极大；龙头60日涨幅 > 80%
- D4 板块广度：龙头滞涨/微跌 → 但同产业链二线股加速；当日龙头涨幅 < 板块均值
- D2 龙头质量：主线第一梯队龙头封板率下降；龙头封板率 < 50%（而此前 > 70%）
- D5 相对强弱：扩散方向上补涨标的跑赢龙头；补涨标的 vs 龙头涨跌幅差 > 5%
- D3 资金流向：龙虎榜显示同一方向但高低切换；龙头标的机构净买入减少、补涨标的增加

确认信号（同时满足 ≥3 条）：
1. 龙头60日涨幅 > 80% + 当日跑输板块均值 3%+
2. "亲兄弟"子赛道股价联动：同一产业逻辑、估值差显著的方向（如芯片设备→芯片材料、交换机→交换芯片）
3. 补涨标的 20日涨幅从"还没动"变为"正在动"：20日涨幅从 ~5% 加速至 ~20-30%
4. 主线龙头未破位：扩散期间龙头不破20日均线（说明不是资金撤出而是溢出）
5. 市场整体对主线逻辑仍认可，只是觉得龙头太贵

反向信号（排除主线扩散的判据）：
- 龙头放量跌破 20 日/60 日均线 → 不是扩散，是主线退潮
- 补涨方向完全不具产业逻辑（如从交换机跳到养猪）→ 不是扩散，是无序轮动
- 龙头+补涨同时下跌 → 主线整体资金流出，非内部扩散
- 扩散方向的 BB 值/订单数据不独立：只是概念跟风而非有独立基本面支撑

持续时间：通常 2-4 周，扩散至补涨方向也涨到位（20日涨幅追上龙头累计涨幅的 50-70%）后结束。

## 分类四：假突破
定义：板块指数或龙头突破关键阻力位（前高/整数关口/筹码密集区），但量价背离、跟风不足或遭遇大盘系统性下行，突破后迅速回落至突破前区间。

判断维度与阈值：
- D6 量价关系：突破日成交额低于前一波高点的量；突破日量 / 前高日量 < 0.75
- D4 板块广度：突破日上涨家数占比反而下降；上涨占比 < 突破前3日均值
- D2 龙头质量：龙头突破但跟风股不跟；非龙头标的涨跌幅均值 < 2%
- D1 板块强度：突破后次日即低开并吞噬前一日涨幅的 50%+；次日开盘 < 突破日开盘价 + 当日跌幅 > 突破日涨幅的 50%
- D5 相对强弱：突破日大盘同步回调或在关键阻力位遇阻；大盘当日收跌或冲高回落

确认信号（同时满足 ≥4 条，尤其看重量价背离）：
1. 突破日缩量：突破关键位但量不及前高量的 75%
2. 突破次日低开吞噬：次日收盘跌幅 > 前日涨幅的 50%
3. 龙头独自突破，板块内 80%+ 成分股涨幅 < 2%
4. 突破后 3 日内重新跌回突破前的震荡区间（前高/整数关口下方）
5. 龙虎榜显示游资主导买入，机构席位缺席或净卖出
6. 突破当日及前一日，大盘处于下降趋势（上证/科创50连续收阴）

反向信号（排除假突破的判据）：
- 突破后次日继续放量上行，且量超过突破日 → 有效突破确认
- 板块内出现第二只/第三只龙头接力涨停 → 跟风资金介入
- 回调不破突破位（前高被突破后成为新支撑）且缩量 → 正常回踩
- 大盘同步转强形成共振 → 突破有外部支撑

持续时间：假突破的确认窗口为突破后 1-3 个交易日。第 3 日收盘仍低于突破位 → 假突破确认。

## 四种分类的快速对照表

| 特征 | 情绪脉冲 | 资金切换 | 主线扩散 | 假突破 |
|---|---|---|---|---|
| 驱动源 | 突发消息/催化 | 旧主线叙事裂痕 | 龙头涨太多 | 技术位博弈 |
| 龙头表现 | 一字板/秒板 | 换手板持续上攻 | 龙头滞涨/跑输 | 龙头独涨 |
| 板块广度 | 假广度（多数微涨） | 真扩散（产业链联动） | 高低切换 | 极窄（二线不动） |
| 量能特征 | 脉冲放量 >2.5x | 持续放量 | 温和放量 | 缩量突破 |
| 资金性质 | 游资主导 | 机构+游资 | 机构调仓 | 游资试盘 |
| 次日关键验证 | 能否持续放量 | 旧方向是否继续失血 | 龙头是否破位 | 是否重回突破位下方 |
| 最长持续时间 | 1-3天 | 2-6周 | 2-4周 | 1-3天确认 |
| 失败后走势 | 快速退潮 | 新旧双杀 | 龙头补跌 | 跌回震荡区间 |

## 使用该框架的纪律
1. 不做单日判定：T 日异动 → T+1 日首次分类 → T+2 日确认或修正。
2. 优先排除假突破：假突破是最致命的误判（买在假突破顶 = 最差入场点），任何异动先过一遍假突破 checklist。
3. 信号组合 > 单信号：至少 3 个维度同时指向同一分类才能判定。
4. 允许分类漂移：情绪脉冲可升级为资金切换；资金切换可退化为情绪脉冲。每天用清单重新打分。
