### 分类

资金切换

### 起决定作用的两条证据

1. 旧主线成交额降至峰值 58% + 板块 X 连续 3 日放量（近 5 日均值的 1.4 倍）。这是"一退一进"的镜像信号：旧方向的钱在系统性撤出，而新方向连续 3 天承接了显著高于近期均值的成交额。两个事实拼接在一起，构成"切换"最核心的 evidence pair——不是存量博弈的轮动，而是资金重新选择主战场。
2. 涨幅 >5% 的成分股占比 45% + 龙头为充分换手板。板块内部呈现"广谱上涨 + 真金白银参与"的特征，而非仅靠龙一缩量一字板拉抬板块指数。45% 的高扩散比例说明这不是个别游资的击鼓传花，而换手板意味着买入方承担了真实的对手盘成本——这两点联合排除了"情绪脉冲"和"假突破"。

### 还缺什么数据

- 板块 X 与旧主线的逻辑关系：是同一产业链上下游（→ 指向主线扩散），还是完全不同的行业/风格/驱动逻辑（→ 指向资金切换）。没有这个信息，无法彻底排除"主线扩散"。
- 旧主线成交额萎缩的时间曲线和价格同步走势：是 3 天骤降至 58% 还是 3 个月缓慢下降？同期旧主线价格是阴跌、横盘还是仍在创新高？急跌+价崩 vs 缓降+横盘，含义完全不同。
- 板块 X 的成交额绝对值与历史极值对比：1.4 倍相对近 5 日均值——但近 5 日均值本身已被这 3 天拉高，实际相对前期正常水平的放量倍数可能更高。需要更长周期（如 20 日均值）的对比来确认放量强度。

### 如果只能改变一个变量，哪个最可能让分类翻转

改变：旧主线成交额从「降至峰值的 58%」改为「仍维持峰值的 90% 以上」。

翻转路径：如果旧主线没有退潮，而板块 X 同时放量大涨，那么最自然的解释就从"资金切换"变为主线扩散——旧主线热度不减，增量/存量资金沿产业链或风格向外辐射，带动关联板块共振。旧主线的"退不退"是区分「切换」和「扩散」的底层分水岭。
