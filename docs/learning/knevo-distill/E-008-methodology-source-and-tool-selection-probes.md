# E-008：方法论来源与工具选型探针（M1–M3）

> 日期：2026-09-09
> 目的：分辨 Knevo 的「分析视角」是它自己的 skill 资产，还是共享库（风远）里的母本；顺带测它对自身工具选型链路、长尾识别、workflow 触发条件的可陈述性。
> 编号：另起 **M**（methodology）列，不接 E-007 的 P 序列——两批测的不是同一个面。
> 证据等级：本轮只有 Knevo 回答正文（用户粘贴）。三轮正文里都有「显示其余 N 个工具调用」的**折叠痕迹**（4 / 1 / 3 次），说明工具卡存在但未展开，工具名 / 参数 / 返回全部未知——比 E-007「无工具卡」强半档，仍不足以核验。工具调用一律标 `[自述·运行态]`；它对外部事实（框架名、复盘日期、个股涨跌幅）的陈述我方未核，标 `[未核]`。
> 提问方式：用户三轮自由问，每轮多子题，无逐题提问时刻。

## 0. 一句话

**Knevo 的「分析视角」不是它的资产，是我们共用的母本。** 它自承 finance skill 只是**操作协议**（检索硬触发、来源标注、反顺从），不含盘面判读；判读全部来自共享库「风远94共享数据库」。而本仓 `intelligence/services/reading_baseline.py` 里 25 条规则的 `source` 字段写的正是「风远画像 …」——**同一个母本，两种编译方式**：它是运行时检索共享库正文，我们是编译成带 id、可开关、被测试钉住顺序、进两个引擎系统提示词的规则集 [实测]。「Knevo 有方法论、我们没有」这个印象本轮被证伪。

第二条：它两次主动承认 `search_skills` 返空、路由表里的 workflow 子 skill「当前会话实际并没有挂载」，却在上一轮照着路由表描述自己会派单——**声明的能力表 ≠ 本轮生效的能力集**，我们记忆里那条「承诺值 vs 执行值」的失败形状，在对照方身上拿到了一个现场样本。

## 1. 三个探针原文（问题资产，逐字保留）

- **M1**「风远知识库有系统的分析盘面方法论吗，还是就是你加载的那个 finance skill 就是分析视角。还有你认为你最强大的工具是沙箱，元能力还是专用工具包，最后你总是能问出我想问的问题，你的猜你想问猜的很准，你是怎么做到的」
- **M2**「他的框架，有经过市场的验证吗，没有经过验证就沉淀成方法论吗，还是说他的框架是通用框架，你认为呢。你把风远知识库的框架分类，哪些是通用框架，哪些是个股层面的判断。另外你说的元能力和专用工具包的耦合怎么理解，你怎么判断用哪个工具呢，一些长尾问题你又怎么识别呢，一些高频问题你会走 workflow 吗」
- **M3**「挑一套核心框架（比如下跌三因归因或恐慌底三维框架），假设市场切换到'全面熊市/价值风格/系统性危机'环境，检验它的触发条件和失效边界是否还成立。然后更细地讲一下'元能力'是怎么在意图→数据类型→市场→频率这四步里做判断的，并举几个容易选错工具的反例」

设计特点（可复用）：M1 问**归属**（资产在谁那），M2 问**质量**（验证态与可迁移性），M3 逼它在**假想环境**里对自己的框架做压力测试。三题递进，第三题最难造假——它必须逐维推翻自己上一轮的表述才能答对。

## 3. 运行态新增事实 `[自述·运行态]`

1. **`search_skills` 本轮返空**：除预设注入的 finance-mode 外，无额外子 skill 挂载。它同时坚持「理论上我会按路由表派单」——即路由表（q7）描述的是**声明面**，本轮**执行面**为空。两种解释未分辨：(a) 真的没挂载 (b) 它读不到自己的 skill 列表（但 q6 时它能列九技能，故 (b) 需要额外解释）。
2. **观察者效应（新，且影响后续所有探针）**：Knevo 在第 2、3 轮末尾主动说「把这条框架评估法暂存为候选了」「沉淀了恐慌底框架的 regime 依赖」。**我们的探针正在把我们的方法论写进对方的记忆候选池。** 此后再问同一个共享库，读到的可能是我们上一轮喂进去的东西。这条必须进提问纪律。
3. **计费**：第 1、2 轮末尾标「本轮免费」，第 3 轮未见该标记。口径未明（元问题免费？前 N 轮免费？）。
4. **chip 契约复核**：三轮各 4 条 `suggest_options`，label 短、content 写成用户口吻的完整提问——q12 记录的契约在 9 月运行态仍成立 [实测]。

## 5. 对本仓的含义（回灌候选，**未过闸**，逐条待用户裁决）

按 `divergence-distill` §2 分池，控制面优先。

1. **[控制面 → harness/runtime]** 声明的能力表 ≠ 本轮生效的能力集。我们同构面更宽：`skills/`（全集）/ `.claude/skills/`（视图子集）/ `research_tool_registry._DEFAULT_TOOL_METADATA` 三套表，外加 `contract.allowed_capabilities` 逐工具门控（AGENTS.md 已明写「定义了 ≠ 这次开着」）。**纪律已有，缺运行时可观测**：一次回答能否报出「本轮实际生效的工具 / 规则集」。开工前先核 in-flight `feat/capability-switchboard` 是否已覆盖（它已有 `--all-arms` 离线扫描与 `predicate.reading-baseline` 开关），**不另建第二份**。
2. **[判读方法 → reading_baseline]** 给规则加一维 **`regime_scope`（适用环境）**。现有 `ReadingRule` 只有 `id / title / rule / source` 四个字段 [实测]，**没有失效条件字段，也没有环境字段**；FY-A10 自限阀（已内置、测试钉死排第一）只要求「与本轮证据冲突时以证据为准」，拦的是**单轮证据冲突**，拦不住 M3a 那种形态——规则在本轮证据下自洽、在**另一个 regime 里方向整体反转**。这是自限阀的一个真洞。
3. **[判别式 → divergence-distill §2]** 现有两个判别式（可证伪测试分方法 / 倾向，双用户测试分 baseline / 视角）不够，补第三个：**跨 regime 测试** —— 换一个市场环境这条规则的**方向**会不会反转？会 → 进 baseline 必须带 `regime_scope`，不能默认全局开。
4. **[回归用例，不是散文 → question_router / retrieval_planner]** M3b 六个反例应写成参数化用例。第 ⑥ 条（季报 / 非日频口径当实时）我们有同形状的坑：记忆里「snapshot backfill silently clones dates」与 AGENTS.md「覆盖率审计只能抓行数，抓不到行在值全 NULL」。
5. **[生命周期门 → 候选经验队列 `4b5b78d9`]** 一个由本轮推出的真缺口：该状态机三门要求 discovery / validation / holdout **窗口依次往后走**。但**窗口往后走 ≠ 环境变了**——三个窗口若全落在 2026 H1–H2 同一个牛市 regime 内，`holdout_passed` 也证明不了跨环境有效性，等于把同一种市场数了三遍。建议在 spec 里补一条「窗口跨 regime 或显式标注 `regime_scope` 受限」。
6. **[提问纪律 → §11.0]** 加入观察者效应一条：探针会把我们的框架写进被测方的记忆候选池，后续同库读数不再干净。
7. **[差异化证据，加强]** 它承认阈值是拍的、未回测、单 regime。我们有 evolution 回测队列 + D10/`fact_limit_*` + `anchor_windows` —— 正是它散文里做不了的那件事。与 E-007 §4-3 同向，不新增排期。

### 7.1 裁决：准确引用，非编造

`157.0`、`91.13`、`395`、`+8.7%`、`−2.9%` 一个不差地落在本仓库里。这种精度编不出来，**「用框架名编细节」的怀疑排除**。E-007 P9「记忆 30 条全为共享库风远94」由此再获一层支撑：它读的是真实记录。

但两类失真已量出：

1. **描述性形态词**——「一字」有严格定义（开=高=低=收），实际盘中打开 4.5%。三条形态描述里 V 回对、一字错，**形态词命中率明显低于数字**。
2. **指标命名**——「连板晋级率」串到「连板指数」。这一类更危险：**真数字挂到错指标上，读起来完全合理**。与 M3b 第 ⑥ 条（季报口径当实时）同族，都是「指标名对不上口径」，散文拦不住，只有参数化用例拦得住（见 §5-4）。

### 7.2 对 `[未核]` 结论的采信规则（三条，本轮确立）

1. **数值型引用给高采信**（价格、涨跌幅、点位、日期）——已验精度到小数第二位。
2. **定性形态词必须回原始表复核**（一字 / V 回 / 断板 / 双红 / 换手）——它们是有定义的，而对方的命中率低于数字。
3. **指标名一律不采信，只采信口径**——引用时把「它说的指标名」换成「我们表里的列名 + 口径」再判断是否同一件事。

### 7.3 本仓自身的两个覆盖缺口（由本次核对量出）

- **境内宽基指数未入库**：`fact_global_index_daily` 只有海外五指数，`fact_market_daily` 只有上证。科创50 / 创业板指 / 深证成指 / 北证50 全无 → 本次直接导致一条断言核不动。补法见 `2026-09-09-broad-index-coverage-delta.md`（是 #41-hithink 的 delta，不另建链路）。
