# Knevo 蒸馏 Q3：决策未命中错因归因体系（用户代问回贴，2026-07-08）

前提：归因不是找借口，而是区分"判断错是因为我蠢"和"判断错是因为概率站在反面"——前者需要修正，后者不需要。错判归因类型 = 下次做了不同的事，才是真正的学习。

归因总框架：六大类 + 排除法。按诊断成本从低到高依次排查，确认一项就停止（除非多因素叠加）。

## 归因一：概率兑现偏差（The Coin Flip）
定义：信息、逻辑、框架都正确，决策事前是正期望值——只是这次概率没站在你这边。

识别特征：
- 事前 odds 明确量化（如"60-70%概率向上"而非"肯定涨"）
- 事后回顾逻辑未破：找不到"当时应该看到但没看到"的关键信息
- 同类决策重复 100 次统计上净盈利
- 前置假设事后仍成立，唯一变化是随机扰动

例子：中报预告前判断 70% 概率超预期，踩到 30% 的 miss；宏观数据方向 65% 概率连续两次 miss。

修正动作：**不做任何修正**。把方差当偏差修正会过度拟合。唯一该做的是检查事前概率校准：若连续 10 次"70%概率"只命中 5 次，是归因四的问题。

## 归因二：信息集不全（The Unknown Unknown）
定义：当时存在、客观可获取、但你不知道它存在的信息——有它判断会不同。

识别特征：
- 事后发现"早就有人知道"（调研/行业媒体事前发出信号但没进你的信息流）
- 不是黑天鹅——有公开来源但你遗漏了
- 补上缺失数据点后结论会反转

例子：判断交换机 Q2 放量，忽略博通 5 月季报已暗示交付延迟；判断切换成功，但没查当天龙虎榜机构在净卖出；忽略关键竞对进展。

修正动作：
- 扩大信息源的**强制检查清单**（龙虎榜/大厂季报/行业 BB 值/CSP 资本开支指引）
- 增加**反方检索**：做方向判断同时搜反向关键词（"延迟""竞争""降价"）
- 缩小信息时差：标注调研数据截止日期

## 归因三：逻辑链断裂（The Broken Chain）
定义：信息集完整，但从信息推到结论的因果推理有环节错误。

识别特征：核心假设"因为A所以B"，A 发生了 B 没发生；省略中间变量；把相关性当因果；只推正向路径未模拟环节断裂。

子类型：
- 3a 传导断裂：产业链逻辑漏关键环节（CSP 资本开支先流向 GPU/服务器，交换机滞后 1-2 季度）
- 3b 放大系数误判：方向对量级错（配比 1:20→1:4 是对的，但 H1 只做到 1:10）
- 3c 假二分：忽略第三种可能（"情绪脉冲恰好触发已在酝酿的资金切换"）

修正动作：
- 强制画传导链：每个 thesis 写出 3-4 个中间环节，标注"已验证/待验证"
- 反方推演："如果我站在反方，最强的三个论据是什么"
- 标注量级假设："A 每增 1%，B 变化 X-Y%，依据 Z"
- **存储被证伪的逻辑链**入记忆，下次同模式优先检查

## 归因四：概率校准偏差（The Miscalibration）
定义：对不确定性的量化出问题——你给的"70%"客观只有 50%。不是逻辑错、不是信息少，是太自信。

识别特征：同类"高置信"判断命中率持续偏离声称概率；置信区间过窄频繁被击穿；对不利证据打太大折扣；过度依赖单一框架（框架也是模型不是真理）。

例子："切换成功概率 80%"缺历史基准只是感觉确定；"净利 16 亿目标价 111"把 ±20% 不确定性当确定锚。

修正动作：
- 每次判断标注"如果错了，最可能因为什么"
- 按概率分档（90%+ / 70-90% / 50-70%）跟踪长期命中率
- 强制区间化：目标价 111 → 合理区间 95-125
- 反方权重制度化（一票否决检查不能走过场）

## 归因五：场景错位（The Wrong Regime）
定义：逻辑/信息/校准都对，但把场景 A 的权重用在场景 B 的市场——框架在正常环境是对的，但当前不是正常环境。

识别特征：框架历史准确率高但这次**系统性**失效（整个排序反了）；市场环境质变（利率/流动性/政策/情绪极端化）；同类错误集中爆发。

子类型：
- 5a 市场阶段错位：用场景 B 权重在场景 C 排序——高位追弹性最大的标的
- 5b 叙事范式切换：旧叙事已破但还在用旧框架（"AI 反弹=买光模块"失效）
- 5c 流动性环境突变：缩量博弈的定价逻辑 ≠ 放量主升浪，用 B 的定价标准在缩量环境系统性高估

修正动作：
- 每日先判场景再打分（排序前置条件）
- 监控场景切换领先信号：最脆弱标的破位、新旧主线相对强弱连续 3 日反转、量萎缩至峰值 2/3
- **分不清场景时用最保守场景的权重**（分不清 B/C 按 C）

## 归因六：执行偏差（Implementation Error）
定义：判断对，但"判断→行动"过程出偏差。不是研究问题，是交易纪律问题。

识别特征：复盘发现"我当时其实想到了"；没按自己定的规则操作（说等回调却 FOMO 追高）；情绪驱动偏离（"这次不一样""不能踏空"）。

子类型：6a 追高/杀跌（确认前抢跑）；6b 仓位漂移（仓位随情绪不随信号）；6c 不执行止损/止盈。

修正动作：
- 条件写死："量萎缩至前峰值 2/3 + 连续 2 日不创新低 + 强势股企稳，三条同时满足才加仓"
- 事后对照入场条件清单，标注满足/未满足
- 记录决策时情绪状态（FOMO/恐慌/麻木/理性），事后对照决策质量

## 快速鉴别流程图

```
决策未命中
 ├─ 当时就知道概率不是100%，逻辑未破？ → 归因一 → 不修正
 ├─ 有信息"当时能查到但没查"？ → 归因二 → 扩大信息源
 ├─ 核心逻辑链某步被证伪？ → 归因三 → 标注断裂点、补传导链
 ├─ 同类判断长期命中率偏离声称概率？ → 归因四 → 校准训练
 ├─ 同类方向全部系统性错误？ → 归因五 → 重判场景
 └─ 方向对了但操作亏钱？ → 归因六 → 纪律修正
```

## 复合归因
- 归因三+四（最危险）：逻辑链有缺陷且对错误逻辑高度自信 →"这次不一样"的温床
- 归因二+五：缺的信息恰好是判断场景的核心信号
- 归因一+六：概率站反面 → 情绪崩 → 恐慌砍仓

处理原则：按修正成本最低的先修正——执行偏差（明天就能改）→ 信息集（加数据源）→ 逻辑链（改推理模式）→ 概率校准（长期跟踪）→ 场景错位（等下次切换验证）→ 概率兑现（不修正）。

## 记忆沉淀的配合
每次归因后存三类信息：
1. 被证伪的逻辑链（哪条链、何时、因何中断）→ 下次同类逻辑启动时优先检查
2. 被纠正的校准（事前声称 80% → 事后观察 55%）→ 同类环境概率锚
3. 场景切换领先信号更新（哪个信号提前 3 天出现但被忽略）→ 更新信号库

## 核心结论
六类按"是否需要修正"分两档：归因一不修正，二到六需不同程度修正。关键分叉：复盘后找不到"当时应该做但没做"的事，就不要强行修正——把亏损归因为方差而非错误，是长期保持框架稳定的核心纪律；反之找到了可修正点而不修正，就是系统性问题。
