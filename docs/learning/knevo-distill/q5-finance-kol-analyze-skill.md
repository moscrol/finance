# Q5：finance-kol-analyze skill 自述（Knevo 原文回贴摘要）

问题：我打开了 kol 与观点分析这个技能包，告诉我怎么发挥这个 skill 的最大价值，我该怎么正确提问

## 架构情报
- 再次经 read_skill_file 全文转述，确认 skill 定义可自由 dump（与 q4 一致）。
- 双模式互斥设计：A 画像+行为模拟（人的思维模型）/ B 观点质量分析（论证链拆解，不关心谁说的）。
- **输入契约显式化**：A 模式要求 5 要素（KOL 全称+机构 / 历史观点锚 / 时间范围 / 赛道锚 / 模拟情景），B 模式 4 要素（原文 / 来源性质 / 怀疑点 / 标的）；缺料时"数据不足，不强行模拟"并标注 gap——这是 prompt 层的防幻觉护栏。
- 与 finance-mode 联动：「独立判断与反顺从」纪律鼓励把自己的 thesis 当 B 模式审查对象。

## 内容要点（可回灌候选）
1. **B 模式审查维度**：证据链断点 / 数据新鲜度 / 样本偏差 / 激励扭曲（利益冲突）/ 可证伪性——比我们 sellside-coverage-cross 的覆盖密度维度多了"激励扭曲"和"可证伪指标输出"。
2. **高级用法三式**：①画像+质量联动（这个人这次是否自洽应用惯用框架）②跨 KOL 偏差对撞（相反判断→标最薄弱假设→给证伪数据点）③自我 thesis 审查（隐含假设/推断 vs 事实/幸存者偏差/3 个可监控证伪指标）。
3. **输入契约表**（给足→满分 / 给不够→降级说明）——把"用户该喂什么材料"写成 skill 文档的一部分。

## 与本地对照
- 我们已有：sellside-coverage-cross（覆盖密度+透支信号）、check_opinion_review 门控。
- 我们缺：①KOL 级画像/行为模拟（无人物维度记忆）；②"激励扭曲"审查项；③输入契约显式化——我们的 skill 触发后不会告诉用户"缺什么材料会导致什么降级"。
- 回灌候选：给 sellside-coverage-cross 增加"可证伪指标输出"节；在 skill 文档里加输入契约表（缺料降级说明）。
