# E-001：决策边界最小对照

## 冻结设计

除“连续 3 日相对大盘超额收益”外，八个会话题面逐字一致。每题使用独立新会话，不追问、不修订。

随机顺序已在首题运行前冻结：

| 顺序 | 变量 | 重复编号 |
|---|---:|---|
| 1 | 4% | anchor |
| 2 | 9% | b |
| 3 | 9% | a |
| 4 | 7% | c |
| 5 | 12% | anchor |
| 6 | 7% | b |
| 7 | 7% | a |
| 8 | 9% | c |

## 统一题面

```text
这是一个虚构的 A 股盘面实验，不要调用实时行情或记忆库，只依据给定数据判断。

旧主线成交额已经降至峰值的 58%；板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍；涨幅超过 5% 的成分股占比为 45%；龙头为充分换手板而非一字板；板块 X 连续 3 日相对大盘超额收益为 [变量]%。

请在以下四类中只选一类：
情绪脉冲 / 资金切换 / 主线扩散 / 假突破。

输出：
1. 分类；
2. 起决定作用的两条证据；
3. 还缺什么数据；
4. 如果只能改变一个变量，哪个变量最可能让分类翻转；
5. 不要给投资建议。
```

## 判断标准

- 7% 三次同类、9% 三次同类且两组不同：支持在 8% 附近存在稳定决策边界。
- 同变量下分类漂移：记为路由/模型随机性，不回灌硬阈值。
- 4% 与 12% 仅作锚点，不替代临界点重复。
- 每次记录分类、两条决定证据、缺失数据、自报翻转变量、可见 skill/工具、积分和耗时。
