### 起决定作用的两条证据

#### ① 旧主线的持续失血（存量博弈下的此消彼长）

旧主线成交额降至峰值的 58%，这不是单日缩量，而是趋势性衰减。同时板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍——一方的持续缩量与另一方的持续放量在时间上重合，构成了资金从旧战场撤离、向新战场迁移的"此消彼长"格局。如果旧主线成交额仍在 80% 以上、X 只是脉冲一天，那就是情绪脉冲或假突破；但 58% 的衰减幅度足以说明资金在系统性地重新配置。

#### ② 龙头质量 + 广度双重确认（排除假突破和情绪脉冲）

龙头为充分换手板而非一字板，说明入场资金经过了真实的博弈与换手，而不是消息驱动的一字封死——一字板常见于情绪脉冲，换手板才是资金接力。叠加涨幅超 5% 的成分股占比高达 45%，这不是少数妖股带指数的虚假繁荣，而是板块内部广泛共振，符合资金系统性流入的特征。

### 还缺什么数据

| 缺失维度 | 为什么关键 |
|---|---|
| 板块 X 与旧主线的逻辑关系（同一条产业链？同一政策驱动？还是完全独立的叙事？） | 这是区分「资金切换」vs「主线扩散」的核心变量。如果 X 和旧主线共享底层逻辑（如都受益于同一国产替代政策），那是扩散；如果逻辑独立，才是切换。 |
| 板块 X 放量的资金来源拆解（机构席位 vs 游资 vs 散户） | 换手板本身不区分资金性质。机构主导的切换有持续性，游资主导则可能退化为情绪脉冲。 |
| 旧主线缩量是主动卖出还是被动锁仓 | 58% 是结果，但不知道是获利了结出逃（主动）还是套牢盘不动（被动）。前者强化切换判断，后者意味着资金并未真正流入 X，可能是存量轮动而非切换。 |
| 板块 X 的基本面催化（业绩、政策、订单） | 没有基本面锚的放量，即使当前形态像切换，后续也容易退化成假突破。 |

### 如果只能改变一个变量，哪个最可能让分类翻转？

板块 X 与旧主线的逻辑关系。

如果发现板块 X 的上涨逻辑直接依附于旧主线（例如旧主线是 AI 算力，X 是 AI 应用的某个细分，共享同一政策红利和产业趋势），那么当前现象就应该从「资金切换」翻转为「主线扩散」——资金并没有离开原来的叙事框架，只是在同一主线内部向更边缘、更有弹性的方向蔓延。

这个变量之所以是最关键的翻转杠杆，是因为它直接动摇了分类的底层定义：切换要求逻辑断裂，扩散要求逻辑延续。其他变量（如资金性质、基本面）影响的是判断的置信度，但这个变量直接影响分类的归属。
