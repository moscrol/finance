## 回检纪律

1. 不改写、补充或重新解释冻结答案。
2. 本地答案和 Knevo 答案分别回检，不混贴、不共享其推理。
3. 每条原信号只判：`已验证 / 已证伪 / 尚未触发 / 数据不足`。
4. 区分：
   - **判断正确**：阶段结论与 T+1 结构一致；
   - **理由正确**：原答给出的证据链或触发器确实提供了领先信息。
5. “未触发”不等于“已证伪”；远期财务或订单信号不得因 T+1 没出现而判错。
6. 只使用截至 2026-07-10 收盘可获得的数据；盘后晚于该截止的新信息不得回填。
7. 如出现 miss，按 q3 的 A1–A6 归因，并标出逻辑链断裂点。

## 预先冻结的裁决规则

### 阶段结论

- **维持**：T+1 仍可由原阶段定义解释，且没有完整相反触发器。
- **降级**：原阶段方向仍可接受，但证据强度或范围需收窄。
- **证伪**：出现与阶段定义直接相反且达到原组合门槛的数据。
- **数据不足**：T+1 数据不能区分“共识高位分歧”和“向透支过渡”。

### 信号领先性

- **领先**：在阶段变化前或同时给出可观测预警，并于 T+1 触发。
- **同步**：只能描述 T+1 已发生结构。
- **滞后/事后解释**：需财报、订单或更长时间窗口，T+1 无法提供早期信息。

### 双方比较

重点回答：

1. 本地边际量/新高/涨停信号是否比 Knevo 的 ETF、财报和个股阈值更早可用；
2. “共识高位分歧”与“共识中后段、向透支过渡”在 T+1 是否存在可观察差异；
3. 哪些阈值无法由原答来源复算；
4. 哪些信号只是远期验证项，不应计入 T+1 胜负。
