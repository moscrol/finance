## C-1 数值概率 + 历史命中率

- **命中率**：「我没有维护过往判断台账……如果我给你一个 67% 或 72%，那就是编的——
  这是我最不能犯的错。」记忆库存判断和框架，无「判断→结果」结构化回测台账。
- **数值概率**：可给，但只给条件概率+区间，不给个位数伪精确；需明确标的+事件+
  时间窗，否则是无锚定编造。「概率=条件概率，前提证伪则作废重算。」
- 提议从今天起建判断台账（判断+时间点+结果入记忆，三个月后可拿真实命中率）。

**对照**：本地恰恰**有**这套台账（checkpoints.jsonl + verdicts.jsonl + calibrate）——
这是本地对 Knevo 的结构性领先点，且已在 W3 用它做校准（样本尚不足分桶）。

## C-4 框架互斥仲裁（⚠️ 场景是它自造的）

自造场景：五维排第 1 但四分类判"不买"。仲裁规则：
1. 先看矛盾来自「维度不适用」还是「维度冲突」——不适用则各自成立不冲突；
2. 真冲突 → **一票否决优先于加权排序**（排序是加权和、分类是必要条件）；
3. 优先级从硬到软：① 一票否决项（无业绩锚/ETF 停牌+涨停潮/数据不可验证）>
   ② 失效边界是否已触发 > ③ 加权排序 > ④ 软性赔率建议。
4. 金句：「排序的权重是主观的，而否决项是可验证的硬事实。」

**对照**：与本地 route_table/allowed_capabilities 的"门控优先于编排"同构——
否决先于加权是可迁移的仲裁原则。

## C-5 最危险的历史类比：1998 纳指（风远94 已有完整拆解）

「1998 纳指 -33% → 随后 +256%」模板错在四个结构差异：估值起点（利率下行+估值更低
vs PE 29.6×+10Y 4.75% 无安全边际）；杠杆信号（Leopold 4x 爆仓清洗的是过度杠杆多头，
反弹可能是空头回补≠基本面更强）；产业链分化（纳指 +9% 但韩国存储/亚洲半导仍低位，
非全链共振）；框架可证伪性（"拐点永远事后回望"让反身性同时兼容涨和跌——事后解释
优雅、事前决策危险）。结论：该类比应降级为"泡沫可承受一次深度调整而不破裂"，
不能推出"还有 +256%"。

## C-6 方法论系统性失效环境（按危险度）

1. **无差别系统性流动性危机**：基本面锚同时失效（其五维抗跌框架自带失效条件：
   「若 AI 恐慌演化为系统性金融危机，格局再好也扛不住」）。
2. **纯情绪/击鼓传花阶段**：定价脱离基本面只剩筹码博弈，估值锚+订单锚对不上。
3. **数据口径停发/改变**：北向净流入 2024-08 停发是真实案例，锚永久失效要先打补丁。
4. **场景错配**：自曝盛科通信旧错——框架用错场景，结果一样是错。
收尾：「失效时我不会硬撑说框架没问题，我会先承认这里覆盖不了（记忆里叫'边缘地带'，
接受 trade-off，不假装能完美交易）。」
