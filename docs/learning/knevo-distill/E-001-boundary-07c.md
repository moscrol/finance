### 分类：资金切换

### 起决定作用的两条证据

#### ① 旧主线成交额已萎缩至峰值 58%，构成清晰的资金撤离信号

这不是温和回调——峰值腰斩级别的缩量说明旧主线的赚钱效应与关注度正在系统性消退。资金切换的前提是「旧池子在排水」，58% 这个幅度满足了这一前提。

#### ② 板块 X 在三个维度上同时呈现「连续 3 日」的持续性，排除了单日情绪脉冲

- 成交量连续 3 日为 5 日均值的 1.4 倍 → 放量不是孤点，有持续性；
- 连续 3 日相对大盘超额收益 7% → 超额不是一日游；
- 涨幅超 5% 的成分股占比 45% → 参与面宽，非少数个股绑架指数。

这三项组合在一起，本质是在说「钱持续在进、且进了不止一两只票」。加上龙头是充分换手板（非一字板），说明参与是市场化博弈而非锁仓操纵，进一步排除假突破常见的「无量空拉」特征。

这两条合在一起构成一个完整叙事：旧池子的水在退，新池子的水持续在进，且进水方式健康——这就是资金切换的经典剖面。

### 还缺什么数据

- 旧主线与板块 X 的产业链/主题关系：这是区分「资金切换」与「主线扩散」最关键的一环。如果板块 X 是旧主线的上游/下游/应用端衍生，则分类应向「主线扩散」倾斜；
- 资金属性结构：龙虎榜机构席位 vs 游资席位的净买入分布、大单净流入占比——机构主导的切换比游资驱动的切换持续性更强；
- 板块 X 的催化剂/基本面锚点：政策、业绩、产品周期、海外映射等——有基本面锚的切换比纯题材切换更有持续性，但这对「是否正在发生切换」的分类判断影响有限；
- 旧主线缩量的绝对水位：58% 是相对峰值，但峰值本身是否异常（如事件驱动暴量）会影响「撤离」信号的强度判断。

### 如果只能改变一个变量，最可能让分类翻转

改为：板块 X 被证实是旧主线的直接衍生/扩散方向（如旧主线是 AI 算力，板块 X 是 AI 应用）。

一旦这条成立，旧主线→板块 X 就不是「此消彼长」的替代关系，而是同一主题沿产业链的纵向扩散。此时旧主线成交额的萎缩可以重新解释为「前期过热后的正常回归」而非「被抛弃」——分类将从资金切换翻转为主线扩散。

其他变量的改变（如把连续 3 日缩为 1 日、把 45% 降到 10%）虽然也会动摇判断，但它们改的是「信号质量」而非「叙事类别」——只有产业链关系的改变能从根本上重新定义两段行情之间的逻辑性质。
