## Q1 建仓/加仓/减仓/清仓 + 仓位上限 + 降杠杆

**两条顶层原则**（均标 风远94）：
1. 仓位 = 信号清晰度的函数，不是信念强度的函数。退出信号能精确定义 → 正常仓位；
   退出信号模糊（"边缘地带"）→ 正常仓位的 40–60%。
2. 下跌先归因，再决策；**论断开仓、论据平仓**。

**建仓：先定价锚再定首仓**（三层情景估值定锚，风远94）：超级周期/基准/衰退三档
EPS×PE 概率加权出目标价区间，按当前价位置分四区——观察区 0 仓 / 试探区建计划仓 1/3 /
重仓区加至 2/3 / 崩盘区打满。首仓比例由信号清晰度定：框架内标的 10–15%，
边缘地带 4–8% 且只设论据止损不设价格止损。

**加仓**：
- 禁止条件（优先级最高，风远94）：共识最热时不加——「费半两日 +15% + 融资余额连续
  三日净流入 + 媒体一致看多」同现 = 拥挤度重建信号。
- 右侧加仓：催化落地日且不破关键位 → 一次性加至目标仓，放弃等回踩执念。
- 左侧加仓（分层信号，风远94）：L1 试探信号 ≥4 项（融资单日降幅≤-200亿、跌停≤50家、
  最脆弱标的开板不重封、盘中 V 反 >3%）→ 试探 1–2 成；L2 = L1 全满足 + ≥3 项
  （连续 3 日不创新低、核心补跌资产止跌）→ 加至目标。

**减仓（竞价锚扫描，每日 09:15–09:25 强制，风远94）**：方向锚/高度锚/情绪锚任一
跌幅 ≥5% 或跌停 → 高贝塔持仓竞价减 1/3；双锚同恶化 → 减半；**末龙突破 ATH = 卖点
不是买点**（最后未破前高的成分股补涨突破 = 套牢盘集中解套）；抱团五信号③④同现
（利多不涨 + 连板高标）→ 减至底仓。

**清仓只有一个最高优先级触发**：论据层面证伪 → 无条件清仓不论浮亏。口径 = 产业核心
数据（CSP 砍 CapEx、订单取消、出货量下修、毛利率拐头、商业模式被否定）。

**仓位上限（它自标"我补齐的量化规则"）**：单标的 ≤20%；单一主线 ≤40–50%
（同一逻辑=同一风险敞口）；总权益仓 = f(六周期共振烈度)（风远94）——杠杆/叙事/竞争/
业绩/利率/拥挤度同时施压数：1 周期满仓 / 2 周期 6 成 / 3 周期 4 成 / 4+ 空仓。

**连续亏损降杠杆（它自标"我补齐的量化规则"）**：按账户回撤而非次数——-5% 总仓×2/3
冻结新开仓 / -10% ×1/2 只留核心 / -15% 底仓≤20% / -20% 清仓+强制冷却 5 交易日，
复出单笔首仓 ≤10%。叠加：连 3 笔止损单笔减半；连 5 笔停手一周，重跑 Q2 判别树
确认「框架失效 vs 执行走样」再恢复。

## Q2 浮亏判别树

先归因再看价格。四节点：
1. **逻辑层面**：产业核心逻辑证伪？（CSP CapEx/订单/出货量/毛利率/商业模式）→ 是即清仓
2. **资金层面**：主动卖出 vs 被动减仓（板块 vs 大盘相对强弱、两融、北向、换手、
   龙虎榜席位）→ 板块独立走弱+席位主动砸 = 证伪加深 → 减/清；跟随大盘被动减 =
   流动性挤压 → 下一节点
3. **烈度层面**：六周期共振数 → 1 扛 / 2 减半 / 3 清至底仓 / 4+ 清仓
4. **标的类型**：框架内 → 价格止损 -8~10% 执行；边缘地带 → 只论据止损，浮亏期冻结加仓

口诀（风远94）：「明天流动性恢复正常，它能不能涨回来？」逻辑证伪→走；
流动性挤压→扛；情绪错杀→不但扛还是加仓点。

**关键例外（风远94）**：框架覆盖外的波动事后说"该卖"是幻觉——它的 alpha 恰恰来自
扛住别人扛不住的波动。

## Q3 主线内标的切换

**高切低**：触发=龙头滞涨/长上影 + 低位放量启动（单日量>20 日均量 1.5 倍）；
确认=低位连续 2-3 日领涨创新高 + 龙头不反包；执行=龙头减 1/3-1/2 切低位。
铁律（风远94）：高切低弹性由**筹码干净程度**决定，不是产业逻辑差异。
失败回切：龙头重新放量领涨/反包 → 3 日内切回；低位补涨后滞涨且换手连续 >8%
不创新高 → 撤出。

**龙头切补涨（三层辐射）**：前提=叙事扩散到第三层是双面信号（接受度扩大+逻辑纯度
下降，风远94）；触发=核心获利回吐长上影+第二层炸板+第三层启动；确认=第三层放量
**且有真实业绩/订单锚**；失败回切=第三层被证是情绪溢出（游资主导、无业绩锚、
换手>8% 不创新高）→ 切回核心。

**两条禁忌（风远94）**：① 大票补涨=轮动最末端（最笨重的都开始涨=能涨的都涨完了）；
② 杀杠杆行情切防御=双向踏空（引 Leopold 爆仓后龙头单日 +30% 案例——归因是杠杆清洗时
坚持主线或逆势加仓，不做风格切换）。
