# Knevo 蒸馏 Q2：方向/标的排序五维量化框架（用户代问回贴，2026-07-08）

已有方法论基础（共享记忆库：风远94共享数据库）：中期主线四维框架（供需/催化剂/估值锚/拥挤度）→ 三层选票框架（赛道水位 × 公司纯度 × 赔率位置）→ 供给侧通胀排序（供给弹性≈0 排第一）→ 止跌反弹三维对决（估值安全垫/催化剂时间线/盈利弹性）。本框架是对它们的统一量化升级。

## 一、五个维度的独立量化方法

### 维度一：确定性（Certainty）
定义：核心 thesis 被独立数据验证的程度——不是"我觉得"，而是"第三方可验证的事实已经确认了"。

| 得分 | 量化锚 | 判据 |
|---|---|---|
| 5 | 财报已兑现 + 第三方数据双验证 | 季报利润超预期 + 独立出货/订单数据交叉确认（BB 值、CSP 资本开支、海关数据） |
| 4 | 公司公告已确认 | 业绩预告超预期 / 重大合同公告 / 涨价函公开，但第三方数据尚未完全跟上 |
| 3 | 产业链调研 / 头部卖方确认 | 产业调研数据（交货周期缩短、产能利用率拐点）+ 卖方上调评级/目标价 |
| 2 | 逻辑自洽但数据待验证 | 供需推演逻辑完整，但尚无独立数据点支撑 |
| 1 | 纯叙事，无数据锚 | 仅靠远期故事（"空间万亿""国产替代必然"），无可验证事实节点 |

量化口径：每出现一个独立验证数据点（BB值>1.0 / 季报超预期 / CSP资本开支明确），得分+1；出现证伪信号（季报miss / 订单延迟），得分归零。

### 维度二：弹性（Elasticity）
定义：催化剂兑现后 EPS/股价的放大倍数——"业绩每超预期 1%，EPS 跳升多少"。

| 得分 | 弹性特征 | 量化锚 |
|---|---|---|
| 5 | 负供给弹性 + 经营杠杆极高 | 全球寡头（≤3家）、无新增产能、扩产周期>18月、固定成本占比>60% → 涨价10%=利润翻倍 |
| 4 | 供给受限 + 量价齐升 | 产能有约束、单价从几千跳到几万至十几万、配比暴增 |
| 3 | 量驱动为主，有结构性涨价 | 出货量暴增但 ASP 温和上行 |
| 2 | 纯量驱动 | 出货量增长但 ASP 年降 10-15%，毛利率稳定或微降 |
| 1 | 概念跟风、无定价权 | 供给无约束、拼客户关系、毛利率低且无壁垒 |

量化口径：经营杠杆系数 = 毛利率变化/收入增长率变化（涨价期）；供给弹性 = 全球有效供应商数量 × 最小扩产周期（月）；A 股特有：流通市值/机构持仓集中度（越小弹性越大）。

### 维度三：兑现时间（Time to Catalyst）
定义：下一个可验证催化剂距现在的时间窗口——"什么时候可以确认或证伪"。

| 得分 | 时间窗口 | 典型催化剂 |
|---|---|---|
| 5 | ≤2 周 | 业绩预告窗口期、月度经营数据、周度出货数据 |
| 4 | 2-4 周 | 中报正式披露、政策文件落地、业绩会指引 |
| 3 | 1-3 个月 | Q3 订单起量确认、量产节点、行业展会 |
| 2 | 3-6 个月 | Q4 确收验证、年度资本开支规划、新产品导入 |
| 1 | >6 个月或不可预知 | 远期量产/商用、渗透率突破阈值 |

量化口径：以自然日历月计算最近验证事件，双重加权的催化剂（中报+Q3指引同日）可跳升一档。

### 维度四：拥挤度（Crowding）
定义：有多少钱已押注在这个方向上——"还有多少增量买盘空间"。

| 得分 | 拥挤状态 | 量化锚 |
|---|---|---|
| 5 | 荒漠 | 卖方覆盖<3家、机构持仓<3%、近期无涨停、换手低于90日均值50% |
| 4 | 冷门 | 卖方覆盖3-5家、机构持仓3-5%、20日涨幅<15%、日均换手<3% |
| 3 | 共识形成中 | 卖方覆盖5-10家、机构持仓5-10%、20日涨幅15-30% |
| 2 | 中高拥挤 | 连续涨停潮、卖方一致看多、机构持仓>15%、ETF 持续净申购 |
| 1 | 极端拥挤 | 板块 ETF 停牌/溢价、龙虎榜游资为主、连板≥5、热搜 Top3 |

量化口径：拥挤度 = 机构持仓5年分位数(40%) + 近20日涨幅分位数(30%) + 日均换手分位数(20%) + 舆论热度(10%)；得分 = 5 - floor(拥挤度 × 4)。

### 维度五：是否已定价（Priced-In）
定义：当前股价已包含多少乐观预期——"好到什么程度才算超预期"。

| 得分 | 定价状态 | 量化锚 |
|---|---|---|
| 5 | 严重低估 | PE < 历史中枢-1σ + 卖方一致预期未上调 + 近20日滞涨/下跌 |
| 4 | 定价不足 | PE ≈ 历史中枢 + 卖方开始上调但目标价未触达 + 20日涨幅<同行 |
| 3 | 合理定价 | PE ≈ 卖方一致 PE + 目标价距现价 10-20% |
| 2 | 乐观定价 | PE 已到卖方目标 PE + 需多个假设同时成立才合理 |
| 1 | 极度透支 | PE 远超卖方目标 + 定价锚定极远期 + ETF 被动资金堆砌 |

量化口径：已定价程度 = 当前PE/卖方一致预期PE - 1；结合最近30天卖方目标价上调次数-下调次数；溢价值越负+上调趋势越强=得分越高。

## 二、权重设计（动态，随市场状态漂移）

### 场景 A：恐慌后反弹期 / 止跌初期
确定性 40% / 是否已定价 25% / 兑现时间 15% / 弹性 10% / 拥挤度 10%
逻辑：恐惧状态下唯一能聚集多头信心的是硬数据；杀跌后找最被低估的。
翻转条件：恐慌底确认信号全部亮起（量萎缩 2/3+、价连续 3 日不创新低、强势股不再补跌）→ 切换到场景 B。

### 场景 B：趋势上行 / 主升浪期
弹性 30% / 兑现时间 25% / 确定性 20% / 拥挤度 15% / 是否已定价 10%
逻辑：主升浪赚的就是弹性；催化剂近=节奏可预测；"已定价"的锚会不断上移。
翻转条件：龙头 60 日涨幅>80% + 最脆弱标的（纯叙事）最先放量调整 + 补涨加速但龙头滞涨 → 切换到场景 C。

### 场景 C：高位震荡 / 主线扩散 / 拥挤期
是否已定价 35% / 拥挤度 25% / 确定性 20% / 兑现时间 15% / 弹性 5%
逻辑：核心问题是"故事还剩多少空间"；高拥挤是最大尾部风险；高位谈弹性危险（向上小、向下大）。
翻转条件：最脆弱标的放量破位 + 龙头跌破 60 日均线 → 切换回场景 A（新一轮恐慌底）。

## 三、排序翻转的触发矩阵（7 种）

| 翻转触发 | 权重/得分跳变 | 典型影响 |
|---|---|---|
| 1. 业绩预告超预期/miss | 确定性 ±2 档 | 超预期 3→5 排序跳升 5-8 位；miss 4→1 直接一票否决 |
| 2. 货币政策/利率预期突变 | 弹性权重-20%、确定性+20% | 利率上行 → 场景 B→A，高弹性方向断崖下跌 |
| 3. 板块 ETF 停牌/溢价>5% | 拥挤度强制归 1 | 触发一票否决 |
| 4. 旧主线龙头止跌反弹 | 资金切换逻辑动摇 | 切换分类从"切换"退化为"脉冲"，排序重置 |
| 5. 被卖方全市场覆盖且一致看多 | 拥挤度-2 档、已定价-1 档 | 所有乐观者已入场，只剩卖出的没行动 |
| 6. 宏观系统性风险升级 | 确定性权重→50%、弹性→5% | 全场景跳回 A，弹性最大的方向补跌最深 |
| 7. 新催化剂出现/原有被证伪 | 兑现时间重打分 + 确定性联动 | 量产提前 → 兑现时间与确定性联动跳升 |

## 四、综合得分公式
FinalScore = Σ w_i × S_i × 1{无否决}（w 为当前场景权重之和=1，S 为 1-5 分，触发一票否决则总分为 0）

一票否决清单（任一触发 → 排序置底）：
- BB 值/供需缺口无独立数据支撑（确定性 ≤1）
- 公司自行公告"业务占比不足 1% / 尚在亏损"（纯度归零）
- 板块 ETF 停牌 + 近期连续涨停潮（拥挤度极端）
- 估值锚定极远期（2028-2030）且无近期验证点
- 季报 miss 市场的核心假设（确定性崩溃）

## 五、应用示例：超节点交换机方向（2026.07.08）
确定性 4 / 弹性 5 / 兑现时间 4 / 拥挤度 3 / 是否已定价 2。
处于场景 B 与 C 的边界——7/7 单日 -7.34% 是切换压力测试。场景 C 权重下得分 3.10/5（"是否已定价"拖分明显）；场景 B 下弹性权重 30% 得分更高。当前判据卡在场景选择上，7/8 盘中需确认。

## 六、使用纪律
1. 每次重新打分前先判场景——场景错，排序全错。
2. 场景切换渐进式调整权重（触发条件亮 2-3 个时逐步调），而非一次跳变。
3. 总分绝对值不重要，相对间距才重要——第 1 与第 2 差距 <0.3 分代表"几乎等价，选哪个取决于配套仓位"。
4. 得分有效期最长 2 周——任一维度有新数据必须立即重新打分。
