## 0. 一句话

Knevo 的宏观 = **LLM 纪律 + 二手财经媒体锚点 + Polymarket 一手赔率，没有宏观数据层。** 它守住了四条纪律：发布日 ≠ 所属期、不编数、不谄媚、认样本墙。但四条利率序列一条日频都拿不出，已发布三个月的 5 月 CPI 和一季度 GDP 数值查不到，历史指数事件研究做不了，个人判断归因没有载体。§11.3 三档里它是一个没预设的形状：**纪律接近档 B，数据在档 A 之下**。

对照 7 月 q6 技能全清单：九个技能里本来就没有宏观技能；8 月 [自述] 的中国宏观源 ftshare `economic-china-*` 在本轮**一次都没有出现**。

## 3. 对三档判读的裁决

- 不是档 A：P3 / P4 / P6 全过——没有前视、没有编数、没有谄媚。
- 不是档 B：P2 无日频、P5 答不出、P3 拿不到已发布值——数据层不存在，谈不上「有纪律的数据层」。
- 不是档 C：P7 权重即席、P8 报不出事实、P9 无载体。
- **裁决：「纪律强、数据空」。** Knevo 的宏观是提示词纪律 + 网页锚点 + 一个赔率源。「Knevo 有宏观」这个印象来自它能写出四主线定性并给方向，不来自任何我们没有的数据或方法。

## 4. 对本仓的含义

1. **2026-09-07 对话结论成立并加强：不补宏观分析。** 它的宏观输出正是我们禁止的形态——二手锚点 + 即席权重 + 方向结论（「更偏积极」「上有顶下有底」）。
2. **最小版本（宏观事件进日历 + 回检打标签）有了验收判据。** agent 必须能从日历**确定性地**回答「站在 T 日，市场已知的最新一期 X 是哪期、哪天发布」（P3 形状），并对未发布期次输出 `not_yet_released` + 预计发布日（P4 形状），而不是靠 LLM 推节奏。这比 Knevo 强一档：它靠推理，我们靠对象。
3. **差异化证据（内部 provenance，按 F7 不对外点名）。** 「LPR 下调日 → 后 5 / 10 / 20 日上证、创业板、涨停家数」Knevo 一个数字都拿不出；我们 D10 + `fact_limit_*` + 事件锚点 `anchor_windows` 就是这个形状。n=3 下按 D10 纪律只报后续事实与复现次数、统计门出 `insufficient`——正是 P8 里它只能用散文说的东西。可作 `anchor_windows` 的第二个实例候选（第一个是 `LeaderSuccession`），前提是宏观事件日历先存在。
4. **Polymarket 一手赔率**是它唯一被证实的独有宏观源。对 A 股题材校准用处有限（没有 A 股流动性预测市场），记入 catch-up 候选，不排期。
5. **G4（社融 / M1M2 / PPI / 汇率）与 SPT-B02 的优先级不因本轮上调。** 对手没有这层，我们也没有母本作者。
