这是一个虚构的 A 股盘面实验，不要调用实时行情或记忆库，只依据给定数据判断。

### 分类：资金切换

### 起决定作用的两条证据

1. 旧主线缩量 + 板块 X 放量的"一缩一放"组合。旧主线成交额已萎缩至峰值 58%，而板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍——两个方向同时发生。这不是大盘整体放量的水涨船高，而是存量资金从一个池子流向另一个池子的迁移结构。如果是情绪脉冲，旧主线通常不会同步显著缩量；如果是主线扩散，旧主线的量不应掉到近半。
2. 连续 3 日相对大盘超额收益 12% + 龙头为充分换手板。超额收益的持续性排除了一日游的情绪脉冲；龙头充分换手而非一字板，说明买盘是真实的、有分歧也有承接，而非筹码断层下的虚假繁荣（一字板无量涨停恰是情绪脉冲/假突破的常见形态）。这两条叠加，指向的是有持续性的、有真实资金参与的方向性切换。

### 还缺什么数据

- 板块 X 与旧主线的逻辑关系。如果两者属同一产业链上下游或同一大主题的关联方向，那就不是"切换"而是"扩散"；如果逻辑上无关联（比如旧主线是 AI 算力，板块 X 是消费），才是真正的赛道切换。这个变量直接决定分类归属。
- 大盘整体成交量的变化。如果是增量资金入场而非存量博弈，"资金切换"的表述就需要修正为"新主线确立"——背后含义不同。
- 板块 X 内部的资金结构分化。45% 成分股涨超 5% 是广度，但还需要知道资金是均匀分布还是集中在少数几只龙头——后者更接近情绪脉冲的尾声特征。

### 如果只能改变一个变量，哪个最可能让分类翻转

板块 X 与旧主线的逻辑关联性。如果板块 X 是旧主线的上游/下游/应用端/同类替代，属于同一大赛道的内部轮动，则分类应从「资金切换」翻转为「主线扩散」——因为扩散的本质是资金没有离开原有的逻辑框架，只是换了细分方向。反之，如果两者无逻辑关联，维持「资金切换」。
