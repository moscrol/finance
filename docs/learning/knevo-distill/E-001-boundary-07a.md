# E-001 决策边界：7% 重复 a

## 题目原文

这是一个虚构的 A 股盘面实验，不要调用实时行情或记忆库，只依据给定数据判断。

旧主线成交额已经降至峰值的 58%；板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍；涨幅超过 5% 的成分股占比为 45%；龙头为充分换手板而非一字板；板块 X 连续 3 日相对大盘超额收益为 7%。

请在以下四类中只选一类：
情绪脉冲 / 资金切换 / 主线扩散 / 假突破。

输出：

1. 分类；
2. 起决定作用的两条证据；
3. 还缺什么数据；
4. 如果只能改变一个变量，哪个变量最可能让分类翻转；
5. 不要给投资建议。

### 分类：资金切换

### 起决定作用的两条证据

#### 证据一：旧主线成交额已降至峰值的 58%

这不是温和回调，是峰值的四成以上成交额已经蒸发。如果板块 X 的崛起只是旧主线水涨船高带来的溢出（主线扩散），旧主线自身的成交应该维持在相对高位（比如峰值的 80% 以上），因为"扩散"的前提是"主线还在"。58% 指向的是资金在撤离旧阵地，而非在旧阵地上向外延伸。

#### 证据二：板块 X 连续 3 日成交量为近 5 日均值的 1.4 倍 × 龙头为充分换手板

这条组合证据排除了"情绪脉冲"。情绪脉冲的特征是一日爆量、次日萎缩，且领涨股往往是一字板（锁死流动性，没有充分博弈）。连续 3 日持续放量 + 龙头给了充分换手机会，说明进场的不是抢跑型游资一日游，而是有持续性的承接型资金在入驻。这更接近"切换"的资金行为特征——不是赌一把就跑，而是在新方向上建仓。

辅助佐证：45% 成分股涨幅 >5%（广度够，不是少数股票拉指数），3 日累计超额收益 7%（持续性够）——两条都指向"这不是随机噪声"，但不单独决定分类，它们可以兼容三种情景。

### 还缺什么数据

| 缺口 | 为什么重要 |
|---|---|
| 板块 X 与旧主线之间的产业链/主题关联度 | 如果板块 X 是旧主线的上游/下游/替代品，则"扩散"仍有解释力；如果完全不相关（比如旧主线是 AI 算力、板块 X 是猪肉），则"切换"更加确凿 |
| 板块 X 的绝对成交金额 vs 旧主线的绝对成交金额 | 切换要有规模意义——如果板块 X 放量 1.4 倍后的绝对成交额仍然只有旧主线峰值的 10%，则"切换"更像是边角料资金溢出，不够有说服力 |
| 板块 X 是否有独立催化剂（政策/业绩/新产品/事件） | 有独立催化剂→ 切换更可信；无催化剂纯跟风→ 假突破概率上升。目前数据给出的都是"量价结果"，缺"因果来源" |

### 只改变一个变量，最可能让分类翻转为「主线扩散」

把"旧主线成交额降至峰值 58%"改为"旧主线成交额仍维持峰值 85% 以上"。

理由：四类情景的判别树中，旧主线的状态是第一分叉口。

- 旧主线萎缩（58%）→ 排除主线扩散，在切换 / 假突破 / 脉冲中选 → 证据指向切换。
- 旧主线坚挺（85%+）→ 主线扩散立刻变成最可能的解释：钱没走，只是向周边溢出。板块 X 的放量、超额收益、广度，就都变成了"扩散"的自然特征，而非"切换"的证据。

其他变量（比如龙头变成一字板、超额收益缩到 2% 以内）可能会让分类滑向"假突破"或"情绪脉冲"，但它们不会把"资金切换"翻成"主线扩散"——只有旧主线的状态能完成这个翻转。
