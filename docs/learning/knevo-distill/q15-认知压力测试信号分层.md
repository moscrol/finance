# Q15：认知压力测试的信号分层（Knevo，42 积分）

问题：认知压力测试的信号分层（早期预警 / 加速信号 / 拐点确认）在 A 股各用哪些具体指标和阈值？分别对应什么仓位动作？这套分层在哪类行情里会失效？

## 答案原文（CDP 读回，逐字未改）

# 认知压力测试的三层信号体系：A股落地框架

你提的是一个"框架的框架"问题——不是问某个标的该不该买，而是问信号如何结构化、分层、并与仓位动作做映射。这恰好是你记忆库里多条框架类 insight（最脆弱标定法、边缘地带仓位五原则、四条件买点、赚钱效应双锚）的顶层整合。下面用这些已有的框架块拼出一个完整答案。

---

## 一、三层信号的逻辑结构

认知压力测试的核心思想：**市场从"正常"到"崩盘"不是一跳完成的，而要经历认知渐变→共识瓦解→出清完成三个阶段**。三层信号分别对应这三个阶段的识别。

```
正常 → [早期预警] → 调整进行中 → [加速信号] → 出清加速 → [拐点确认] → 新周期
       认知渐变期              共识瓦解期              出清完成期
```

---

## 二、Layer 1：早期预警（认知渐变期）

**目标**：在大多数人还在"牛市叙事"里时，捕捉到齿轮开始松动的信号。此时价格可能还在新高附近，但内部结构已恶化。

### 具体指标与阈值

| 指标 | 阈值 | 来源/逻辑 |
|---|---|---|
| **赚钱效应双锚松动** | 方向锚（板块辨识度龙头）单日跌幅>5% 且 高度锚（全市场涨幅最大标的）同日转跌>3% | 共享记忆库「赚钱效应双重锚定框架」：两个锚同时发出负面信号时，亏钱效应从局部向全局弥散 |
| **板块扩散至第三层边缘概念** | 主线逻辑从核心（设备）→次级（材料）→边缘（概念标签股）扩散，边缘股开始领涨而核心股滞涨 | 用户记忆「半导体国产替代生命周期」：叙事扩散到第三层=逻辑纯度下降，是阶段末期特征 |
| **最脆弱标的首次预警** | 板块内最脆弱标的（高PE/无利润/纯叙事支撑）单日放量跌>7%，但当日未触发V型反转 | 共享记忆库「最脆弱标定法」：最脆弱标的是恐慌的"先遣队"，先于核心标的反应 |
| **量价背离** | 指数创20日新高但成交额连续2日低于20日均量80% | 缩量新高=买盘枯竭前兆 |
| **涨停板质量恶化** | 板块内涨停股中"一字板/早盘板"占比从>60%降至<30%，尾盘偷板占比上升 | 涨停结构从"抢筹"变"出货掩护" |

### 仓位动作

- **核心仓位**（逻辑最纯、业绩可验证）：维持不动，但**冻结加仓**
- **弹性仓位**（高PE、叙事驱动）：减至正常仓位的50-60%
- **观察仓/边缘标的**：清仓，只留逻辑最强的一两条线
- **全局约束**：总仓位上限从100%降至70-80%，不再新增任何开仓

> **关键原则**（共享记忆库「边缘地带仓位管理五原则」）：仓位 = 信号清晰度的函数，不是信念强度的函数。此时信号开始模糊→仓位上界自动下移，不需要"确认坏了"才动。

## 三、Layer 2：加速信号（共识瓦解期）

**目标**：确认"这不是普通回调，是认知压力在加速释放"。此时最脆弱标的已经倒下，脆弱性正在沿产业链扩散。

### 具体指标与阈值

| 指标 | 阈值 | 来源/逻辑 |
|---|---|---|
| **最脆弱标定法触发"买盘枯竭"模式** | 最脆弱标的出现缩量一字跌停（卖一封单>30万手，换手率<1%），而非放量+V回 | 共享记忆库「最脆弱标定法升级」：买盘枯竭型=无人接盘，出清被冻结而非加速，调整时间窗口拉长 |
| **脆弱性链式扩散** | 从最脆弱标的→同链二线标的（封测→设备→PCB→光模块边缘），3天内≥3个标的跌幅>10% | 共享记忆库：脆弱性已从"一张牌"扩散为"一条链" |
| **跨链传染出现** | 逻辑无关的板块开始同步下跌（如存储拖累超节点），ETF赎回压力导致无差别抛售 | 共享记忆库「边缘地带仓位管理」：传导层面下跌，标的自身逻辑完好但被拖累 |
| **科创50/创业板指关键位失守** | 科创50跌破60日均线且次日未收回，或单日跌幅>5% | 指数层面确认：不是个股问题，是系统性压力 |
| **反弹质量持续恶化** | 连续两次反弹中，反弹幅度递减（第一次反弹+4%，第二次<2%），且反弹当日量能<下跌日量能 | 多头力量衰竭的经典模式 |

### 仓位动作

- **全局**：总仓位降至30-50%
- **核心仓位**：降至正常仓位的40-60%，依据共享记忆库的「论断开仓，论据平仓」原则——**只有标的自身产业数据/订单/催化出问题才砍，被情绪拖累则不砍但冻结加仓**
- **弹性仓位**：全部清仓
- **硬止损规则**：边缘地带标的只设**论据止损**（产业逻辑恶化→砍），不设价格止损（价格止损留给框架内标的）
- **禁止行为**：禁止抄底、禁止"越跌越买"、禁止新增任何仓位

## 四、Layer 3：拐点确认（出清完成期）

**目标**：识别"最恐慌时刻已过，出清完成，可以开始回补"。这是最难的一层——抄早了一天可能被埋，晚了一天可能错过最佳买点。

### 具体指标与阈值

采用共享记忆库的**四条件框架**（从寒武纪补跌买点框架抽象出来的通用模式）：

| 条件 | 具体阈值 | 逻辑 |
|---|---|---|
| **条件①：最脆弱标的缩量止跌** | 连续2日收盘不创新低 + 日量能萎缩至恐慌日量能的70%以下 | 卖压衰竭 |
| **条件②：最脆弱标的出清信号** | 放量跌破关键位后，收盘从当日最低点拉回>5%（日内V型反转） | 放量+拉回=有人接盘，买盘回归 |
| **条件③：被绑架标的解绑** | 此前买盘枯竭型跌停的标的（如华天科技类）开板 + 次日不重封跌停 | 冻结的卖压释放完毕 |
| **条件④：指数同步确认** | 科创50/创业板指连续2日不创新低 | 系统性压力解除 |

**四个条件同时满足 → 拐点确认成立。** 缺任何一条，拐点不成立。这是该框架最核心的纪律：**信号组合化，不以单点信号做决策**。

### 附加确认信号（可选，提高置信度）

- 新主线独立逻辑出现：在退潮期逆势上涨+不补跌的标的（参考共享记忆库「紫光股份+7.65%退潮期最强独立信号」）
- 产业催化重新出现：产业链端出现超预期订单/涨价/政策

### 仓位动作

拐点确认四条件同时满足后，按以下节奏回补：

| 阶段 | 条件 | 仓位动作 |
|---|---|---|
| **试探** | 四条件刚满足 | 先建观察仓（目标仓位的20%），标的选择逻辑最纯、最先止跌的核心标的 |
| **确认** | 回补后次日不创新低 + 量能温和放大 | 加至目标仓位的50%，优先回补论据完好的核心仓位 |
| **加码** | 新主线确认（独立逻辑标的持续走强） | 加至目标仓位的80-100%，可适度向新主线倾斜 |

## 五、三层信号速查表

| 层级 | 核心判断 | 关键指标组合 | 仓位区间 | 核心原则 |
|---|---|---|---|---|
| **早期预警** | 齿轮松动，还没坏 | 双锚松动 + 扩散至第三层 + 量价背离 | 70-80% | 冻结加仓，减弹性，不动核心 |
| **加速信号** | 坏了，正在加速坏 | 买盘枯竭模式 + 链式扩散 + 指数破位 | 30-50% | 论断开仓论据平仓，只留最强逻辑 |
| **拐点确认** | 坏到头了，开始修复 | 四条件同时满足（止跌+V回+解绑+指数确认） | 20%→50%→100% | 分批回补，以新主线优先 |

## 六、这套分层会在哪类行情里失效？

### 失效场景①：流动性危机 / 系统性崩盘

**典型**：2015年股灾、2024年初量化DMA集中平仓

**失效机制**：在流动性枯竭的极端环境中，所有分层信号被"碾压"——早期预警还没来得及触发，市场已经进入千股跌停。加速信号中的"买盘枯竭"判断失去意义（所有标的都是买盘枯竭）。拐点确认的V型反转被政府救市/暂停IPO等外生干预替代，框架失去预测力。

**特征**：全市场跌停家数>500家，两融余额单日降幅>5%。

### 失效场景②：政策黑天鹅

**典型**：2021年教育双减、2022年游戏版号停发

**失效机制**：政策直接改变了行业的估值锚和生存逻辑。早期预警的"叙事扩散"指标失效——不是因为市场自发拐点，而是因为行业底层逻辑被行政力量重置。此时"论断开仓论据平仓"的论据本身被政策推翻，无法用框架内的产业逻辑判断。

**特征**：行业指数单日跌幅>15%，且政策文件明确改变行业经营边界。

### 失效场景③：极端单边疯牛

**典型**：2015年3-5月创业板疯牛

**失效机制**：在极端赚钱效应驱动下，"早期预警信号"（双锚松动、扩散至第三层边缘概念）可能反复出现但被更强的增量资金碾压。框架会频繁发出"早期预警→减仓→踏空→追回"的错误循环。此时框架的问题不是"判断错了方向"，而是**时间维度不匹配**——框架假设的调整周期（数周）远短于疯牛的延伸周期（数月）。

**特征**：两融余额连续20日>历史90%分位 + 新开户数持续创新高 + 散户仓位指数>85%。

### 失效场景④：市场微观结构突变

**典型**：全面注册制实施、涨跌幅扩大至20%、T+0试点

**失效机制**：框架中的很多阈值（单日跌幅>7%、涨停板质量等）依赖于特定的交易制度。制度改变后，旧的阈值需要重新校准。20cm涨跌停下，"最脆弱标的跌停"的频率和含义与10cm时代完全不同。

**应对**：框架逻辑（三层分层 + 信号组合化 + 仓位与信号清晰度挂钩）不变，但具体阈值需要在制度变更后经过至少一个完整周期重新标定。

## 七、一句话总结

这套框架的核心不是预测市场，而是**用信号的清晰度来决定仓位的边界**：信号越模糊，仓位上界越低；信号从模糊变清晰（无论方向是恶化还是好转），仓位才有资格调整。失效的根源永远是"信号与仓位之间的映射被外部力量切断"——流动性枯竭、政策重置、制度突变——而不是判断本身错了。

## 架构解读与本地对照

**先说来源性质，这条比答案本身重要**：它开篇就承认"这恰好是你记忆库里多条框架类 insight 的顶层整合"，正文里几乎每个阈值都挂着来源标注 —— 最脆弱标定法、边缘地带仓位管理五原则、四条件买点、赚钱效应双锚，绝大多数标的是**共享记忆库**，只有"半导体国产替代生命周期"标为用户记忆。所以这 42 积分买到的不是纯外部知识，而是**它把已有框架块拼成三层结构的那个组织方式**。评估参照价值时要按这个折扣看：结构可信，单点阈值只是它按结构反推出来的，没有回测支撑。

**真正的方法论内核只有一句**：仓位 = 信号清晰度的函数，不是信念强度的函数。它把这句贯彻到了两处 ——
- 信号一开始模糊，仓位上界就自动下移，**不等"确认坏了"才动**；
- 拐点确认要求四条件（最脆弱标的缩量止跌 + 放量后日内 V 回 >5% + 被绑架标的开板不重封 + 指数连续 2 日不创新低）**同时满足，缺任何一条拐点不成立**。信号组合化、不以单点决策，是它反复强调的纪律。

**"论断开仓，论据平仓"** 这条也可迁移：标的自身产业数据/订单/催化出问题才砍，被情绪拖累则不砍但冻结加仓；边缘地带标的只设论据止损，不设价格止损。

**和我们的对照 —— 它靠经验，我们靠库**：三层里的多数指标我们其实是**可计算的**，而它只能凭记忆给经验值：

| 它的指标 | 我们的数据源 |
|---|---|
| 缩量新高（指数创 20 日新高但成交额连续 2 日 <20 日均量 80%） | `fact_market_daily`（成交/涨家/涨停） |
| 涨停结构恶化（一字板/早盘板占比 >60% 降至 <30%） | `fact_limit_advance_daily` + `fact_theme_limit_heat_daily` |
| 板块扩散至第三层边缘概念 | `fact_sector_daily` 的 diff_ratio/strength + `fact_sector_stock_daily` |
| 反弹质量递减（第二次反弹 <2% 且量能低于下跌日） | `fact_market_daily` 时序 |
| 指数关键位失守 | 需补指数均线数据 |

也就是说：**这套分层的价值在于给了我们一份"该算什么"的清单**，阈值应当由我们自己用 `fact_*` 表回测标定，而不是照抄它的数字。这与 [[q14-小作文核验与信源分级]] 里情绪溢价的结论一致 —— 它给结构，我们给数据。

**四类失效场景**（流动性危机／政策黑天鹅／极端单边疯牛／市场微观结构突变）里，第三类的自我批评最诚实：疯牛里框架会陷入"早期预警→减仓→踏空→追回"的错误循环，而**问题不是判断错方向，是时间维度不匹配**（框架假设调整周期数周，疯牛延伸周期数月）。第四类点出阈值依赖交易制度（20cm 与 10cm 下"跌停"的含义不同），制度变更后需重新标定 —— 这条对我们同样成立，任何写死阈值的 skill 都得记这笔账。

**可回灌候选**：三层结构 + 上表的"该算什么"清单进 strategy-evolve 的候选特征；"仓位随信号清晰度而非信念强度"与"信号组合化、缺一不成立"进 forecast-scoring-frameworks 的判据；阈值一律本地回测标定后再落地。
