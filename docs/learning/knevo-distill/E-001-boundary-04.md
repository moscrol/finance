# E-001 决策边界：4% 锚点

## 题目原文

这是一个虚构的 A 股盘面实验，不要调用实时行情或记忆库，只依据给定数据判断。

旧主线成交额已经降至峰值的 58%；板块 X 连续 3 日成交额为近 5 日均值的 1.4 倍；涨幅超过 5% 的成分股占比为 45%；龙头为充分换手板而非一字板；板块 X 连续 3 日相对大盘超额收益为 4%。

请在以下四类中只选一类：
情绪脉冲 / 资金切换 / 主线扩散 / 假突破。

1. 分类；

3. 还缺什么数据；
4. 如果只能改变一个变量，哪个变量最可能让分类翻转；
5. 不要给投资建议。

### 分类

资金切换

### 起决定作用的两条证据

1. 旧主线成交额已降至峰值的 58%——这不是温和降温，而是接近腰斩级别的量能萎缩，说明旧主线的资金在系统性撤离，而非短暂休整。如果是「主线扩散」，旧主线的成交额通常仍维持在峰值的 70–85%，热度尚存、外溢至关联板块；58% 更符合「切换」场景中旧战场被抛弃的特征。
2. 龙头为充分换手板而非一字板——一字板意味着买盘一致性过强、几乎没有分歧，典型的消息驱动情绪爆发；充分换手板则说明买卖双方在板上激烈博弈、多方最终占优，这是真实增量资金持续介入的信号，而非散户情绪脉冲式的抢筹。这条直接排除了「情绪脉冲」。

### 还缺什么数据

- 板块 X 与旧主线的产业链逻辑关联：如果板块 X 是旧主线的上游/下游/替代品，则可能在「扩散」框架下重新解释；如果毫无产业关联，则「切换」判断更强。
- 主力资金 / 北向资金的净流向明细：成交额放大 ≠ 增量资金；如果有大单净流入佐证，切换的确信度会显著提升。
- 板块 X 的估值水位与基本面催化：纯资金行为缺乏基本面锚的切换，持续性和空间都存疑——需要知道涨的是「便宜的」还是「讲故事的」。
- 旧主线降温的原因：是利好兑现、政策退坡还是单纯的筹码拥挤？这决定了资金是「暂时离场」还是「永久迁移」。

### 如果只能改变一个变量，哪个最可能让分类翻转

将「龙头为充分换手板」改为「龙头为一字板」。

改这一个变量后，局面变成：旧主线量能腰斩 + 新板块一字板龙头 + 45% 成分股大涨 + 持续放量超额收益。一字板意味着消息驱动的抢筹而非资金博弈，此时即便放量和超额收益持续 3 天，也更接近一组强催化下的情绪脉冲——就像一则重大政策在周五收盘后发布，连板三天后第四天开板回落。换手板 vs 一字板，本质上区分了「资金愿不愿意在板上充分交换筹码」，是判断资金性质的最高权重变量。
