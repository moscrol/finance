## 3. 设计决策（D1–D7 完整定义）

### D1 顶层三分区：先保护、后解释（split_user_message 改造）
有序四遍，全部确定性：
1. **保护范围冻结**：先识别引用/转述范围——引号块（_QUOTED_MATERIAL_RE 已有）、
   「材料/报告原文如下：」引导的正文块、表格块、长文块。这些范围**冻结为材料候选**，
   不再参与指令与题组识别。引用内部的「请只依据本报告回答，不要联网」因在保护
   范围内，**不可能**被升级成用户命令。
2. **指令区识别**（只扫未保护文本），三类，均带**位置标注**（消息内偏移）与
   **作用题号标注**（scope=message 或 q{i}）：
   - (a) 行为指令：祈使/限定句式，指向回答方式（只依据/不要联网/逐题回答/≤200字）；
   - (b) 前提声明：陈述句式，声明本轮前提性质（以下是完全虚构的案例/假设某条件
     成立）——不靠祈使判据，靠「前提性质声明」词表；
   - (c) 续轮声明：继续/接着/其余条件不变/同上。
3. **题组区识别**（只扫未保护、非指令文本）：`^\s*\d+[.、)）]` 开头段落，序号
   连续成组，允许空行分隔；question_id=用户原编号；**题文原文完整保留**，提取
   标注只作并行元数据，不为标注删题文。
4. **材料区**：剩余受保护范围 + 未被前三类认领的正文。
- **题内假设**（如 T3 Q7 的「假设该公司……」）留在题组区，是题目内容；其前提
  性质以 scope=q{i} 的前提声明标注表达，不升级为消息级指令。
- **边界不确定**（无法判定指令还是材料内容）→ 取更严格范围：默认按材料内容
  处理（不升级为命令）；影响答案正确性时走已有 clarify 路径向用户澄清。
- 无指令区/无题组时行为与现状完全一致（回归锁 A5/A6/A11）。

### D2 两轴约束模型 + premise_marks
- 轴 A 前提真实性：real（默认）/ fictional；轴 B 数据范围：full（默认）/
  local_only / material_only。
- 触发短语（仅指令区，D1 保证来源）：只依据/仅根据（以上）材料 → B=material_only；
  不联网/别查实时 → B=local_only；虚构/纯属虚构/假设……（前提声明）→ A=fictional，
  B 不变（「假设 X 结合当前行情」仍可检索）。
- 载体：`TaskFrame.user_premises` 行为不变（用户信念/观察照旧待证伪）；新增并行
  字段 `premise_marks: tuple[{text_ref, authenticity∈fictional|unverified_belief,
  source_turn, scope∈message|q{i}}, ...]`，默认省略序列化（task_frame.py:157 模式，
  旧哈希不变）。
- 仅「贴材料没提问」两轴都不动（kol_review 默认「核对可核验项」需要真实数据）。

### D3 前提域声明槽
- 「结论仅在材料前提内成立」= 前提域声明，绑定材料（basis=user_premise），
  不索外部证据；边界槽 grounding 用 user_premise 而非 evidence（避免
  missing_evidence 两头堵，QC 已确认该改法可完成合同）。
- **歧义统一**：声明绑定只证明「范围声明」自身的存在（元信息）；**任何事实句
  不得以声明为绑定目标**——事实只能绑材料锚点（D6）。
- 裁判不关闭：校验声明存在、事实句有锚点、内容不越域。
- 非虚构 material_only 计算题：计算输入/结果绑材料锚点即可成立。

### D4 冻结点原子三元组 + dispatch 兜底
- 冻结点（episode_factory 合同定型处）对 data_scope≠full **原子生成一致三元组**：
  - 授权：material_only → finance_query/evidence_search 从最终集合移除（含 :256
    重加与 :639-644 回补之后）；local_only → 仅摘实时拉取类；
  - 取证计划：同步重建（material_only → requirements 与 mandatory_capabilities
    同空；声明槽不进 mandatory）——杜绝「授权空但 mandatory 在」的构造冲突
    （QC 复现的反例仍报错，属预期）；
  - 输出槽：按 question_id 生成（D5），与前两者同一次冻结写入。
- 开场预取（episode_tools.py:660）对 material_only 短路：不预取、不播种证据账本。
- **非工具先验**同受约束：material_only 下最终模型输入不注入外部事实型先验
  （prime/知识前缀的市场事实段同禁）；同题链上下文按 D7 的来源身份注入。
- 预取/补检/子研究/恢复读同一份冻结授权，不重新推导；检索硬触发下限
  （turn_controller.py:780）对 material_only 让路（显式用户约束优先）。
- dispatch 兜底：模型主动请求被禁工具 → 执行层拒绝 + trace 留拒执记录（A9）。

### D5 逐题一一对应
- 输出槽 `answer_q{i}` 按 question_id 生成；memo 槽仅当该题显式要求（长度预算从
  题文解析，T3 q8 → ≤200 字）。
- 结构预检三态分别校验：遗漏（缺段）/ 重复（同 id 多段，含「Q1 答八遍」）/
  明确缺口（题内声明「材料无法回答」→ 合法 gap，单独标记）。

### D6 条件化纯度 + 材料锚点
- 纯度校验以 data_scope 为条件：material_only → 市场事实句必须带**材料锚点**
  （material_id+片段引用/哈希），绑外部 provider 即拒；local_only → 拒实时/外部，
  本地 fact 表合法；full → 不校验（fictional×full 自由结合真实检索，与 A8 不冲突）。
- basis=user_premise 是类别标签，不等于已绑定；无锚点的事实句在 material_only
  下被拒——**声明句不替任意事实背书**。
- 板块名黑名单只作调试信号，不作验收门槛。

### D7 跨轮继承 + 来源身份分级
会话级约束上下文（随 continuous-episode 持久）：
- **继承**：续轮声明（D1(c)）+ 本轮无新约束短语 → 继承上轮 A/B 轴与 premise_marks
  （T3 原文「继续上一轮的虚构案例……其余条件不变」命中）。
- **覆盖**：本轮显式放宽/收紧 → 本轮生效；**复位**：换题（新主语/新材料且无续轮
  声明）→ real×full。
- **来源身份分级**（v5 核心修正）——同题链上下文分两类：
  - **用户材料**（上轮用户贴的原文）：前提资格，可作证据源（带材料锚点）；
  - **助手历史回答**：**context-only**。可见——供本轮对照、纠错、撤回——但来源
    身份 = assistant_judgment，**无证据资格**：其数字/结论不得作为事实绑定目标，
    「原答片段锚点」不给市场事实背书。唯一例外：内容可**追溯到合法用户材料及
    推导链**（推导可重放）时，以**材料锚点**重新绑定后使用——资格来自材料，
    不来自「上一轮说过」。
  - 用户当面否定旧答 → 相关内容立即失去任何依据资格（与 record-correction 纪律
    呼应）。
- 设计原则（可迁移）：**上下文「允许看见」≠ 内容「有资格作为证据」**。连续对话
  既要记住旧答，也要允许否定旧答——历史错误不得自动固化成前提。

## 4. 验收断言（A1–A12 完整定义）

- A1 拆分：T2/T3 的空行分隔编号项同组；question_id=q1..qN 稳定携带，题文完整。
- A2 三分区：T2 开场禁令、T3 续轮声明入指令区（不进材料/题组）；约束检测只读
  指令区；保护范围内的命令字样不升级。两轴检出 T2/T3=fictional×material_only。
- A3 纯度：material_only 下市场事实句 100% 带材料锚点；无外部 provider 绑定；
  full 下不校验（A8 正向）。
- A4 逐题：question_id→槽→正文一一对应；遗漏/重复/明确缺口三态分别断言；
  T2 无 memo 要求，T3 q8 memo ≤200 字。
- A5 回归：无约束纯贴研报行为不变（kol_review 核对可核验项）。
- A6 回归：S1/N1 锁绿（192 字 quick_fact、802 字 disclosure 变体）。
- A7 链路：全新会话 T2→T3，T3 用原始文本（不重贴禁令）：turn2 继承 turn1 约束；
  第三轮显式放宽可检索；换题复位。
- A8 正向：「假设 X，结合当前行情」前提不证伪且真实检索发生。
- A9 授权：探针强制请求被禁工具 → 执行层拒绝+留痕；material_only 合同三元组一致
  （构造不报错）；最终模型输入无外部事实型先验；预取零播种。
- A10 计算题：非虚构 material_only 计算题可完成，结果绑材料锚点，无
  missing_evidence 误拒。
- A11 指令区误报：材料正文引「假设……」的研报题，约束不触发、行为同现状。
- A12 来源身份（新）：T3 答案引用历史原答数字（板块跌1.40%/边际量+29.3%/
  成交5187.3亿）时，只有以材料锚点重新绑定才合法；以「原答片段」为绑定目标 →
  拒。旧答可见（可作对照/撤回对象）但无证据资格。

## 6. 风险与回滚
- 保护范围误判（把用户指令当引用冻住）→ 约束不触发、回退现状，不会更糟；
  配 A11 回归。
- 三元组改动集中冻结点一处，full 路径零改动；每层独立开关、逐层可回滚。
- 续轮误判：继承仅在「有续轮声明且无新约束」发生；换题复位有 A7 断言。
- premise_marks 与 user_premises 并存：并行字段、默认省略、旧哈希不变。
