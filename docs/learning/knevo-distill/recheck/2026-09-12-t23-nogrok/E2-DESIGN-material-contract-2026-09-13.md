## 3. 设计决策（D1–D7 完整定义）

### 3.1 D1 顶层三分区：先保护、后解释、三态分类（含可实现边界规则）

有序五步，全部确定性：

**第 1 步 保护范围冻结**——多信号检测器（不允许只复用 `_QUOTED_MATERIAL_RE`：
其实测门槛为引号内 ≥40 字且不处理代码围栏，短引文会漏）。信号与**边界规则**：

| 构造 | 起始 | 结束 | 失败分支 |
|---|---|---|---|
| 代码围栏 | ```或~~~行 | 同类型围栏行 | **未闭合 → boundary_uncertain**（不得冻结到文末了事） |
| 引号块 | 「『"'"等开引号 | 同类闭引号；嵌套按栈配对；转义引号不计 | 未闭合 → 不作保护范围，且若其后文本含疑似约束短语 → boundary_uncertain |
| 引导块（「材料/报告原文如下：」等） | 引导行 | 空行后首个符合**顶层指令/题组句法**的行；或文末 | 引导块无明确终点且后文出现疑似顶层禁令 → boundary_uncertain |
| 表格块 | 连续 ≥2 行表格行 | 首个非表格行 | —（规则自洽，无歧义分支） |
| 缩进块 | 缩进 ≥2 空格行 | 首个非缩进行 | — |
| 长文块 | 多行无空行且长度 ≥ 阈值 | 首个短问句行之前 | 与相邻疑似顶层禁令无空行分隔 → boundary_uncertain |

- **相邻规则**：材料块与其后疑似顶层禁令之间有空行分隔且该句符合指令句法 →
  指令区；无空行直接相连 → boundary_uncertain。
- 冻结范围不再参与指令/题组识别；其内部任何命令字样**结构上不可能**升级。

**第 2 步 指令区识别**（只扫未保护文本），三类，带位置+作用题号标注：
(a) 行为指令（祈使/限定，指向回答方式）；(b) 前提声明（陈述句，声明本轮前提性质）；
(c) 续轮声明（继续/接着/其余条件不变/同上）。

**第 3 步 题组区识别**（只扫未保护、非指令文本）：`^\s*\d+[.、)）]` 开头段落、
序号连续成组、允许空行分隔；question_id=用户原编号；题文完整保留，标注只作
并行元数据。

**第 4 步 材料区**：受保护范围 + 未被认领正文；题内假设留题组区（scope=q{i}
前提声明标注，不升级为消息级指令）。

**第 5 步 三态分类**（即正文全部，不再有「D1.5」之称）：
- `constraint_confirmed`：指令区有约束 → 按 D2 执行；
- `no_constraint_confirmed`：**全部文本都已完成句法角色分配**（保护/指令/题组/
  顶层正文），无未闭合构造、无未分类片段，且指令区无约束短语 → real×full；
- `boundary_uncertain`：存在任何未闭合构造、无法判定片段、或相邻歧义 →
  二选一：a) clarify **先于开场预取与任何工具执行**；b) 按 §3.2 权限交集继续。
  **禁止静默回 full**。

### 3.2 D2 两轴模型 + premise_marks + 权限交集形式化

- 轴 A 前提真实性：real（默认）/ fictional；轴 B 数据范围：full（默认）/
  local_only / material_only。触发短语同 v6（仅指令区）。**B 轴本阶段仅消息级**
  （见 §3.7 P2-1 闭环）。
- **B 轴三值的允许集（按实际 IO 行为定义，不按 provider 名称或 freshness 标签）**：
  - `allow(full)` = 全部读能力（含外部 API/网络请求、CDP 代理调用、本地库、
    本地知识库、盘上缓存）；
  - `allow(local_only)` = **IO 纯本地**的能力：本地 DuckDB 读、本地知识库读
    （含向量索引）、本地文件、**已在盘上的缓存结果**；禁止：任何发生外部 IO 的
    能力（外部 API、网络请求、以及「本地进程但实际访问外部资源」）；
  - `allow(material_only)` = ∅（无任何数据读能力；只有材料绑定）。
- **权限交集（boundary_uncertain 的兜底）**：
  - 数学对象 = **最终 capability/IO 集合**，不是 data_scope 枚举；
  - 候选集固定二元：{片段按材料内容（不携带约束）→ allow(full)；片段按用户指令
    → allow(其约束对应值)}；检测器只输出片段+若为指令时的约束，不产任意候选；
  - 交集 = 候选允许集的集合交。三个值嵌套（full ⊇ local_only ⊇ ∅）时交集必可
    映射回 data_scope；**未来出现非嵌套值导致交集不可映射时**：直接以交集集合
    本身冻结授权（不命名），合同标记 `resolved_by_intersection` 供审计；
  - 交集为空（=material_only）但当前题目**必须**用材料外数据才能作答 → clarify
    或按 D5 的合法 gap 路径，不得硬答。
- 载体：`user_premises` 行为不变；`premise_marks` 并行新字段（authenticity/
  source_turn/scope），默认省略序列化，旧哈希不变。
- 仅「贴材料没提问」两轴都不动（kol_review 默认核对可核验项）。

### 3.3 D3 前提域声明槽
同 v6：声明绑材料（basis=user_premise），只证明范围声明自身；事实句只能绑材料
锚点；裁判不关闭；非虚构 material_only 计算题以材料锚点成立。

### 3.4 D4 冻结点：同一交集生成一切 + dispatch 兜底
- 冻结点对 data_scope≠full **原子生成一致三元组**，且三者**从同一个 capability
  集合**（直接检出的轴值，或 §3.2 的交集集合）派生：
  authorized capabilities、evidence_plan（requirements 与 mandatory 同步重建，
  material_only 同空）、输出槽（question_id 生成）；
- **同源过滤扩展到模型输入**：opening_prefetch、prime/知识前缀、视角注入、历史
  摘要、episode 压缩上下文、恢复读、子研究上下文、系统级默认市场摘要、非工具
  路径产生的 provider 事实——**每一条注入路径都经同一权限集合过滤**
  （material_only 下外部事实型先验零注入；同题链上下文按 D7 来源身份注入）。
- 预取/补检/子研究/恢复读同一份冻结授权；检索硬触发下限对 material_only 让路；
  clarify 分支在预取与工具执行之前。
- dispatch 兜底：模型主动请求被禁工具 → 拒绝 + trace 留痕（A9）。
- 措辞修正（QC P2-2）：local_only = 摘除**一切发生外部 IO 的能力**（按实际 IO
  行为判定），本地 IO 能力保留；不再是「仅摘实时拉取类」。

### 3.5 D5 逐题一一对应 + 合法 gap 的完成状态口径
- 输出槽 `answer_q{i}`；memo 槽仅当题文显式要求（T3 q8 → ≤200 字）。
- 结构预检三态：遗漏 / 重复 / 明确缺口。
- **完成状态口径（选定目标，与现结构探针「gap+completed 拒、gap+partial 过」
  的现状对齐）**：
  - 每题终态 ∈ `answered` / `legal_gap` / `missing`；
  - legal_gap 必须绑定 question_id + 缺什么（材料未含 X），才算「合法地说明无法
    回答」，区别于未完成交付；
  - 汇总：全 answered → **completed**；有 answered 且其余全为 legal_gap →
    **partial**（gap+completed 不允许）；任何 missing → 结构预检失败（不可完成）；
    全 legal_gap → partial 并在答复顶部声明无一题可依据材料作答。

### 3.6 D6 条件化纯度 + 材料锚点 + 历史句正式排除
- 纯度校验以 data_scope 为条件（material_only 严、local_only 拒外部 IO 绑定、
  full 不校验）。
- 市场事实句必须带材料锚点（material_id+片段）；basis=user_premise 只是类别。
- **historical_assistant_statement 正式规则**（A12b 的语义地基）：
  - 引用/纠错/撤回历史答案的句子 = `historical_assistant_statement`，**不是**当前
    市场事实主张；
  - 必须绑定 old_answer_coordinate + assistant_judgment；
  - **豁免**材料锚点要求，且不被纯度检查器当作当前事实扫描对象；
  - **混句处理**：同一句同时含历史引用与当前推断 → 拆句分别归类；无法拆 →
    整句拒绝。

### 3.7 D7 跨轮逐轴继承 + 基底不可恢复 + 来源身份分级
1. 有续轮声明 → 先继承基底（A_base、B_base、marks_base）。
2. 逐轴显式覆盖：只改 A 不动 B；只改 B 不动 A；同值重申幂等；scope=q{i} 的
   **A 轴标记**只附着该题。
3. **B 轴题级短语的处理**（P2-1 闭环）：本阶段 B 轴仅消息级。题内出现
   「只依据材料/不要联网」类 B 短语时：消息级已为 material_only → 作为该题备注；
   消息级更宽 → **不**静默局部化、**不**静默提升，按 boundary_uncertain 处理
   （澄清优先/交集兜底）。（若未来支持题级 B 轴，授权/预取/检索/模型输入/语义
   校验必须按题隔离——本阶段明确不做。）
4. **基底不可恢复**（P1-3 闭环）：续轮声明命中但会话中无可恢复的
   A_base/B_base/marks_base → 状态 `state_unavailable`：必须在预取与任何工具执行
   前澄清，或使用可证明不超过候选解释的权限交集；**禁止猜 real×full，禁止从
   助手历史答案推测权限**。
5. 复位：换题（新主语/新材料且无续轮声明）→ real×full。
6. 来源身份分级：用户材料=前提资格（可锚定）；助手历史回答=context-only
   （assistant_judgment，可见、可对照/纠错/撤回，无证据资格；可追溯至合法用户
   材料+推导链的内容以材料锚点重新绑定）；用户当面否定 → 立即失格。
- 原则：**「允许看见」≠「有资格作为证据」**。

## 4. 验收断言（A1–A16 完整定义）

- A1 拆分：空行分隔编号项同组；question_id=q1..qN 稳定；题文完整。
- A2 三分区+三态：T2 开场禁令、T3 续轮声明入指令区；保护范围内命令字样不升级；

- A4 逐题+完成状态：question_id→槽→正文一一对应；遗漏/重复/缺口三态；
  T2 无 memo、T3 q8 memo ≤200 字；合法 gap → Episode=partial（gap+completed 被拒）。

- A6 回归：S1/N1 锁绿（192 字 quick_fact、802 字 disclosure 变体）。
- A7 链路+逐轴状态表（五格）：全新会话 T2→T3 用原始文本。①只改A→B 继承；
  ②只改B→A 继承；③局部假设→消息级原样继承；④同值重申→幂等；⑤换题→复位。
- A8 正向：「假设 X，结合当前行情」前提不证伪且真实检索发生。
- A9 授权+注入路径：探针强制请求被禁工具→拒绝+留痕；三元组一致且同源；
  **§3.4 八类注入路径逐一断言经同一权限过滤**（material_only 下外部事实型
  先验零注入、预取零播种）。
- A10 计算题：非虚构 material_only 计算题完成，结果绑材料锚点。
- A11 误报：材料正文引「假设……」的研报题不触发约束。
- A12 来源身份拆对：A12a 拿旧答材料外数字支撑当前事实→拒；A12b 引用旧答
  纠错/撤回（historical_assistant_statement，绑旧答坐标）→允许，且豁免锚点要求；
  混句无法拆→整句拒。
- A13 三态行为：短句引用禁令不升级；未闭合围栏/无终点引导块/相邻疑禁令 →
  boundary_uncertain；澄清先于预取与工具执行；全程不静默回 full。
- A14 基底不可恢复：全新会话里直接发「继续上一轮……其余不变」→
  state_unavailable：澄清或交集兜底；断言**未**猜 real×full、**未**从助手历史
  答案推测权限。
- A15 权限交集数学：候选二元生成；交集=capability/IO 集合交；三值嵌套时可映射
  回 data_scope；交集=∅ 且题目必须材料外数据 → clarify 或 legal_gap，不硬答。
- A16 local_only IO 语义：断言按实际 IO 行为分类（本地库/本地 KB/盘缓存放行；
  外部 API/CDP 代理/「本地进程实际外呼」拒绝），不以 provider 名或 freshness
  标签判定。
