## 3. 设计决策（D1–D7 完整定义）

### D1 顶层三分区：先保护、后解释、三态分类
有序四遍，全部确定性：
1. **保护范围冻结**：识别引用/转述范围并**冻结为材料候选**——引号块、代码围栏、
   「材料/报告原文如下：」引导块、表格块、长文块。冻结范围不再参与指令与题组
   识别；其内部的「请只依据本报告回答，不要联网」**结构上不可能**升级为用户命令。
   **诚实边界**：现有 `_QUOTED_MATERIAL_RE` 要求引号内 ≥40 字且不处理代码围栏，
   匹配不了短句引用——保护检测器必须是多信号独立实现（任意长度引号对、围栏、
   引导块、缩进），不允许只复用该正则就宣称完整；覆盖不了的形态落入第 5 条的
   「边界无法确定」。
2. **指令区识别**（只扫未保护文本），三类，均带**位置标注**与**作用题号标注**
   （scope=message 或 q{i}）：(a) 行为指令（祈使/限定，指向回答方式）；
   (b) 前提声明（陈述句，声明本轮前提性质：以下是完全虚构的案例/假设某条件成立）；
   (c) 续轮声明（继续/接着/其余条件不变/同上）。
3. **题组区识别**（只扫未保护、非指令文本）：`^\s*\d+[.、)）]` 开头段落，序号
   连续成组，允许空行分隔；question_id=用户原编号；**题文原文完整保留**，标注只作
   并行元数据。
4. **材料区**：受保护范围 + 未被认领的正文。题内假设留题组区，以 scope=q{i} 的
   前提声明标注表达，不升级为消息级指令。
5. **三态分类与禁令不丢**（v6 核心修正）——拆分结果必须三态其一：
   - `constraint_confirmed`：指令区有约束 → 按 D2 执行；
   - `no_constraint_confirmed`：可判定无约束（全文的句法角色都解释得通）→
     默认 real×full；
   - `boundary_uncertain`：任何片段无法确定是材料内容还是用户指令 →
     **二选一**：a) 走 clarify 路径**在开场预取与任何工具执行之前**向用户澄清；
     b) 取**候选解释的权限交集**（所有候选解释共同允许的最窄权限——候选含
     「不要联网」时交集不含外部读取），然后继续。
     **禁止静默回 full**：「不把材料升级成命令」与「不丢失用户禁令」是两项独立
     保证，前者由保护范围实现，后者由本条的澄清优先/交集兜底实现。

### D2 两轴约束模型 + premise_marks
- 轴 A 前提真实性：real（默认）/ fictional；轴 B 数据范围：full（默认）/
  local_only / material_only。
- 触发短语（仅指令区，D1 保证来源）：只依据/仅根据（以上）材料 → B=material_only；
  不联网/别查实时 → B=local_only；虚构/纯属虚构/假设……（前提声明）→ A=fictional，
  B 不变（「假设 X 结合当前行情」仍可检索）。
- 载体：`TaskFrame.user_premises` 行为不变（用户信念/观察照旧待证伪）；新增并行
  字段 `premise_marks: tuple[{text_ref, authenticity∈fictional|unverified_belief,
  source_turn, scope∈message|q{i}}, ...]`，默认省略序列化（task_frame.py:157 模式，
  旧哈希不变）。
- 仅「贴材料没提问」两轴都不动（kol_review 默认「核对可核验项」需要真实数据）。

### D3 前提域声明槽
- 「结论仅在材料前提内成立」= 前提域声明，绑定材料（basis=user_premise），不索
  外部证据；边界槽 grounding 用 user_premise 而非 evidence（避免 missing_evidence
  两头堵，QC 已确认该改法可完成合同）。
- **歧义统一**：声明绑定只证明「范围声明」自身的存在（元信息）；**任何事实句
  不得以声明为绑定目标**——事实只能绑材料锚点（D6）。
- 裁判不关闭：校验声明存在、事实句有锚点、内容不越域。
- 非虚构 material_only 计算题：计算输入/结果绑材料锚点即可成立。

### D4 冻结点原子三元组 + dispatch 兜底
- 冻结点（episode_factory 合同定型处）对 data_scope≠full **原子生成一致三元组**：
  授权（material_only → finance_query/evidence_search 从最终集合移除，含 :256 重加
  与 :639-644 回补之后；local_only → 仅摘实时拉取类）× 取证计划（同步重建，
  material_only → requirements 与 mandatory 同空，杜绝构造冲突）× 输出槽（按
  question_id 生成，D5），同一次冻结写入合同。
- 开场预取（episode_tools.py:660）对 material_only 短路：不预取、不播种证据账本；
  **boundary_uncertain 走 clarify 时，预取与工具执行同样等待澄清结论**（D1.5 的
  顺序保证）。
- **非工具先验**同受约束：material_only 下最终模型输入不注入外部事实型先验
  （prime/知识前缀的市场事实段同禁）；同题链上下文按 D7 来源身份注入。
- 预取/补检/子研究/恢复读同一份冻结授权；检索硬触发下限（turn_controller.py:780）
  对 material_only 让路。
- dispatch 兜底：模型主动请求被禁工具 → 执行层拒绝 + trace 留拒执记录（A9）。

### D5 逐题一一对应
- 输出槽 `answer_q{i}` 按 question_id 生成；memo 槽仅当该题显式要求（长度预算从
  题文解析，T3 q8 → ≤200 字）。
- 结构预检三态分别校验：遗漏 / 重复（含「Q1 答八遍」）/ 明确缺口（题内声明
  「材料无法回答」→ 合法 gap，单独标记）。

### D6 条件化纯度 + 材料锚点
- 纯度校验以 data_scope 为条件：material_only → 市场事实句必须带**材料锚点**
  （material_id+片段引用/哈希），绑外部 provider 即拒；local_only → 拒实时/外部，
  本地 fact 表合法；full → 不校验（与 A8 不冲突）。
- basis=user_premise 是类别标签，不等于已绑定；无锚点的事实句在 material_only
  下被拒——声明句不替任意事实背书。
- 板块名黑名单只作调试信号，不作验收门槛。

### D7 跨轮**逐轴**继承 + 来源身份分级
会话级约束上下文（随 continuous-episode 持久）。v6 把继承从「整轮开关」改为
**逐轴算法**：
1. 有续轮声明（D1.2(c)）→ **先继承基底**（A_base、B_base、marks_base 全量带入）。
2. 再按本轮标注**逐轴显式覆盖**：
   - 本轮 A 轴标注（新前提声明/虚构重申）→ 只改 A，**不动 B**；
   - 本轮 B 轴标注（只依据/不联网/可以查真实数据）→ 只改 B，**不动 A**；
   - **同值重申不改变状态**（T3 开头重申「虚构案例」→ A 保持 fictional，不构成
     「新约束」、不阻断任何继承）；
   - **scope=q{i} 标注只附着该题**：不修改消息级 A/B，不打断其继承（T3 Q7 局部
     假设 → 仅 q7 带 fictional 标记，消息级 (fictional, material_only) 原样继承）。
   - 反例闭环：上轮「只依据材料」+ 本轮「继续，先假设甲能按期验收，其余不变」
     → A 增局部 hypothetical 标记，B 保持 material_only，旧禁令不丢。
3. **复位**：换题（新主语/新材料且无续轮声明）→ real×full。
- **来源身份分级**（v5 起）——同题链上下文分两类：
  - **用户材料**：前提资格，可作证据源（带材料锚点）；
  - **助手历史回答**：**context-only**（assistant_judgment）。可见——供对照、纠错、
    撤回——但无证据资格：其数字/结论不得作为当前事实的绑定目标。唯一例外：内容
    可**追溯到合法用户材料及推导链**（推导可重放）时，以材料锚点重新绑定——资格
    来自材料，不来自「上一轮说过」。**引用旧答以纠错/撤回是合法出口**（A12b），
    绑定旧答坐标、注明 assistant_judgment，不需也不许伪造材料锚点。
  - 用户当面否定旧答 → 相关内容立即失去任何依据资格（与 record-correction 纪律
    呼应）。
- 设计原则（可迁移）：**上下文「允许看见」≠ 内容「有资格作为证据」**。连续对话
  既要记住旧答，也要允许否定旧答——历史错误不得自动固化成前提。

## 4. 验收断言（A1–A12 完整定义）

- A1 拆分：T2/T3 空行分隔编号项同组；question_id=q1..qN 稳定携带，题文完整。
- A2 三分区+三态：T2 开场禁令、T3 续轮声明入指令区；约束检测只读指令区；保护
  范围内命令字样不升级；两轴检出 T2/T3=fictional×material_only。
- A3 纯度：material_only 下市场事实句 100% 带材料锚点；无外部 provider 绑定；
  full 下不校验。
- A4 逐题：question_id→槽→正文一一对应；遗漏/重复/明确缺口三态分别断言；
  T2 无 memo 要求，T3 q8 memo ≤200 字。
- A5 回归：无约束纯贴研报行为不变。
- A6 回归：S1/N1 锁绿（192 字 quick_fact、802 字 disclosure 变体）。
- A7 链路+**逐轴状态表**：全新会话 T2→T3，T3 用原始文本（不重贴禁令）。四格：
  ① 只改 A（新增虚构声明）→ B 继承不变；② 只改 B（显式放宽）→ A 继承不变；
  ③ 局部假设（scope=q7）→ 消息级 A/B 原样继承；④ 同值重申（复述「虚构案例」）
  → 状态不变、不阻断继承。随后换题 → 复位 real×full。
- A8 正向：「假设 X，结合当前行情」前提不证伪且真实检索发生。
- A9 授权：探针强制请求被禁工具 → 执行层拒绝+留痕；三元组一致（构造不报错）；
  最终模型输入无外部事实型先验；预取零播种。
- A10 计算题：非虚构 material_only 计算题可完成，结果绑材料锚点。
- A11 误报：材料正文引「假设……」的研报题，约束不触发、行为同现状。
- A12 来源身份（拆对，v6 修正）：
  - **A12a 拒**：拿历史原答的材料外数字（板块跌1.40%/边际量+29.3%/成交5187.3亿）
    **支撑当前事实判断**，或以「原答片段」为事实绑定目标 → 拒；
  - **A12b 允许**：明确引用旧答以对照/纠错/撤回（「上轮写了……这些数字超出给定
    材料，本轮撤回」），不作当前事实推断 → 合法；绑定旧答坐标并注明
    assistant_judgment，**不得为过门伪造材料锚点**。
- A13（新）：boundary_uncertain 用例（被保护范围误吞的短禁令/无法判定片段）→
  澄清先于预取与工具执行，或按候选解释权限交集（更窄者）继续；**全程不得静默
  回 full**；短句引用「请只依据本报告回答，不要联网」不升级为用户命令。

## 6. 风险与回滚

  对策即 D1.5：三态分类 + 澄清优先 + 权限交集兜底；A13 锁定。

- 逐轴继承的标注误判：同值重申与局部假设均有 A7 四格断言；换题复位有覆盖。
- premise_marks 与 user_premises 并存：并行字段、默认省略、旧哈希不变。
