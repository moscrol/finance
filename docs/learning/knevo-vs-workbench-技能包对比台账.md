## 记录 2：finance-lateral（金融横向联想）——4 模版并行（瑞华泰联想 / CPO→低位切换 / 制裁涟漪 / CoWoS 赛道）

## 记录 3：finance-earnings-review（财报与业绩复盘）——厦门钨业 600549 2026Q1

- **日期**：2026-07-09；Workbench 同题输出：answer_xtc.md（24 引用，replay 路由）。
- **Knevo**：sub-agent 26 次工具调用；核心数据齐——Q1 营收 157.43 亿 +87%、归母 11.07 亿 +189%、毛利率 16.47%→21.00%、正极 2025FY 利润总额 8.58 亿已扭亏；亮点是「意外发现」：每股经营现金流 -1.62 元恶化 + 股东人数 +68%，对 21% 毛利率的含金量打了折扣。**但注意数据来源**：gangtise HTTP 402、ftshare/finance_statement 全部 ✗/degraded，最终数据主要靠同花顺 F10 网页抓取——管线是残的，靠 web 兜底救回来的；分业务毛利率也没拿到（只能交叉推断）。缺口声明做得规范（学了我们的纪律？开头就有缺口表）。
- **Workbench**：实体锚定正常（600549→厦门钨业，概念 AI硬件/MIM/MLCC/PCB微钻）；**财务问直接判定证据缺口且指出现有证据全部过期（2026-01-29 ⚠️45 天复核）**，不编数——纪律保持；然后转入独有的盘面生命周期分析：AI 材料重估叙事 4 月启动 +47.13%、峰后回撤 -26.1%、保留率 18.53%、5 关联题材当日全跌、小金属主线标记「消亡」→「高位分歧向衰退观察滑落」；给出二阶导替代（东方钽业钽电容逻辑卡 high 质量）和三级跟踪清单。
- **判定**：**Knevo 胜**（业绩复盘题的本职就是财务数字，我方 0 分 vs 它 80 分）。Workbench 的盘面生命周期 + 证据过期审计是 Knevo 没有的，但答不了本职问题。
- **交叉验证**：Knevo 的「钨价高位回落」风险与我方盘面「峰后回撤 26%、关联题材全跌」互相印证——市场已经在定价这个风险。
- **清单影响**：#3 证据再 +1（连续两题因无财报数据判负）；另记一条运营提醒——知识库研报证据大量过期（2026-01-29 批次），#5 数据运营的一部分。

## 记录 4：finance-event-forecast（金融事件预测）——4 个并行推演（厦钨正极扭亏 / 瑞华泰产能爬坡 / CPO 切换 / 数据要素政策）

- **日期**：2026-07-09；Workbench 同题：answer_xtc_forecast.md（25 引用，brief+replay 路由），拿最可比的「厦钨 H1 正极能否扭亏」跑。
- **Knevo 的技能内核**：这是它设计得最"聪明"的一类——不给单一概率，而是 **决策者行为模拟 + 情景树 + 概率区间**。三层结构：①关键决策者画像（管理层历史披露模式/指引兑现率/利好利空处理习惯）②情景树（关键变量速查表 + 各情景触发条件）③概率分布（A/B/C 各 15-40%）。厦钨题给出「B 接近盈亏平衡 40% 最可能，确认扭亏仅 20%」，还给了碳酸锂/加工费/LFP 占比/产能利用率的变量方向表；4 题横切还提炼出两条隐藏线索（渐进式改善基线 + 政策为低位题材托底）。
- **Knevo 软肋（依旧）**：①概率数字全部拍脑袋无溯源（40%/20% 怎么来的？）②决策者行为模拟大量标 [inference] 置信度中/低——本质是 LLM 编的行为剧本 ③4 个子 agent 里数据要素那个直接 failed（工作区路径异常），靠主线程补跑 ④finance_statement 时好时坏（厦钨题这次 ✓ 了，瑞华泰题 ✓，但仍靠 web_search 兜大头）。
- **Workbench**：**没有专门的预测/情景模块**——路由到 brief+replay。它的处理方式很诚实：明确指出「本地数据块没有正极单季收入/产能利用率/历史毛利率基数 [D2]，无法做『毛利率回到多少算有效改善』的量化情景分级，强行设 5%/10% 阈值属于编造」，只给定性情景 A/B + 升级证伪条件，且把重心转向它的独有优势——盘面生命周期四问（叙事 4 月启动 +47%、峰后回撤保留率 18.53%、关联题材全跌、P0 替代表达已切到明阳电气/长进光子）。
- **判定**：**Knevo 胜**（本题本职是"预测"，它的情景树 + 决策者模拟框架结构完整、可读性强，是 Workbench 完全没有的产品形态）。但胜得"虚"——概率无溯源、行为模拟是编的，跟 Workbench「诚实声明无法量化」形成路线分野：Knevo 给你一个看起来完整但不可复核的推演，Workbench 给你一个残缺但每条都可回查的盘面事实集。
- **交叉验证**：两边独立指向同一结论——正极扭亏对当期弹性贡献微乎其微，真正的定价锚在钨钼/盘面强度而非正极。这条一致性本身增强了结论可信度。
- **清单影响**：
  - #3 财报/估值块 证据再 +1（第三题因无财务基数受限）。
  - **新增候选 #12「情景树/决策者推演表达层」**——注意这是 **表达层#9 的子集**，不是新数据能力：Knevo 的情景树/决策者画像不需要新数据源，是把已有证据组织成「关键变量表→情景分支→触发/监控信号」的模板。我们完全可以做一个**确定性版本**：变量表用 DuckDB 盘面 + 图谱证据填充，情景分支只写触发条件不编概率（或只给"高/中/低"定性 likelihood 并注明依据），彻底规避 Knevo 拍脑袋概率的软肋。这是低成本高感知的差异化点。
  - #10 用户记忆再 +1：Knevo 决策者画像大量引用「管理层历史指引兑现率」——这类判断来自它的记忆库，我们无。

## 记录 5：finance-industry-report（行业深度报告）——数据要素 vs 信创 vs 数据安全 中期赔率对比

- **日期**：2026-07-09；Workbench 同题：answer_sectors.md（26 引用，brief 路由，命中主题=信创）。这是**第一题真正打到 Workbench 盘面结构强项**的比较题。
- **Knevo**：四维加权打分表（确定性×弹性×兑现时间×拥挤度×是否已定价），结论 **数据安全 4.25 > 数据要素 3.50 > 信创 3.13**，逻辑锚在中期基本面：数据安全连续 11 季下行洗到无人问津 + AI 安全入法 + 美股 PANW/CRWD 历史新高映射差；给了每个方向的标的池、翻多翻空触发、7-12 月催化时间线。硬伤依旧：加权分无溯源（4.25 怎么算的？），大量 web_search 拼数据（finance_search_data ✗）。
- **Workbench**：结论 **信创中期赔率优先级最高**——但这个"最高"完全基于**当日盘面**：信创当日双红 90 分、边际量 14.75%、成交 1673 亿、13 涨停 10 新高成簇 [S1-S4]，数据要素/数据安全无独立强盘面验证故后置。证据审计 21 条 L1、0 条 L3，诚实指出「缺 L3 订单、缩量环境高低切、置信度偏低」，给出 T+3/T+5 可复核验证条件。
- **⚠️ 关键发现——时间尺度错配（新问题，比胜负更重要）**：题目问的是**未来 3-6 个月中期赔率**，但 Workbench 的 brief 模块本质是**当日盘面快照**，它把「当日谁最强（信创双红）」直接当成了「中期赔率最高」。这在时间维度上是错配的：当日最强 ≠ 中期赔率最优（信创当日强恰恰可能是短期拥挤度已高、中期赔率下降）。Knevo 的中期框架反而更契合题目时间窗。**这暴露了一个路由/表达层缺口：Workbench 无法识别「中期」意图并相应调整证据权重（把 D0 多日趋势、拥挤度、估值分位纳入，而非只看当日 double_red）。**
- **判定**：**平/各有胜负**。Knevo 胜"契合题目时间窗 + 中期框架完整"；Workbench 胜"盘面数据硬、可复核、不编加权分"，但**败在时间尺度错配**——用当日强度回答了中期问题。两者结论相反（数据安全 vs 信创）恰恰源于时间尺度不同，不是谁对谁错，是各自只看了自己那一段。
- **清单影响**：
  - **新增候选 #13「多日/中期视角与拥挤度」**（高）：把 #1 已有的 D0 多日时序 + 拥挤度（换手/成交占比分位）+ 估值分位，在"中期/赔率/配置"类意图下自动纳入并调高权重，纠正 brief 模块的单日快照偏置。这是 Workbench 目前**最实质的结构性短板**——数据都在 DuckDB，缺的是"中期意图路由 + 多日证据加权"。
  - #3 财报/估值块 证据再 +1（无业绩兑现节奏的逐季数据，"业绩兑现"维度只能定性）。
  - #1 时序块价值再确认：这题若能把 D0 三题材的多日涨停/双红趋势叠上来，就能同时回答"当日强度"和"中期趋势"，直接补上错配。
