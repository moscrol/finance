# 仓位相关语料的研究检查表（q15/q16；不产出仓位指令）

来源：`knevo-distill/q16-仓位管理框架.md`、`knevo-distill/q15-认知压力测试信号分层.md`。
2026-09-23 收窄：旧骨架虽称“不采数字”，正文仍含减半、清仓和必然回升口诀，
会把外部自述误读成本地已采纳策略。原件保留，本页只承载**研究动作**。
数字阈值继续在 `evolution/backtest-queue.md` Q-002，回测与人工确认前不升级为规则。

## 1. 研究目标与动作边界

把“浮亏怎么办”拆为：哪项原判断发生变化、依据是什么、还需核实什么。
账户盈亏不自动证明产业逻辑错误，产业进展也不自动证明当前价格合理。
不从本页产生开仓、加减仓、杠杆或止损比例；本页不是交易系统、也不是收益验证。

## 2. 先固定原判断

记录原话、日期、主体、时间窗、来源、适用框架、原定失效条件。
能在 checkpoints / judgments 找到就按原记录核；未命中与存储读取失败分开说。
没有旧记录时只分析当前材料，不杜撰过去推荐。

## 3. 浮亏研究树（R6：纸面检查表，不启用运行时规则）

| 问题 | 可用证据 | 允许的研究结论 | 不能跳到什么 |
|---|---|---|---|
| 原产业前提被证伪了吗？ | 公司/客户公告、订单/验收、实际财报；与原失效条件逐条对应 | 保留、削弱、撤回或信息不足；重新研究影响范围 | 单一毛利率下降即全公司失败；由证伪直接生成仓位动作 |
| 是否存在资金约束的竞争解释？ | 持有人披露、融资及交易统计、明确的赎回/被动调仓证据 | 说明与产业解释可并存，安排区分性核查 | 成交/两融变化等同净资金流、由价格倒推主动卖出意图 |
| 波动传播范围与时窗怎样？ | 同口径行业、个股、指数截面及时间序列 | 分清个体、行业与广泛市场共振；缺基线保留未知 | 把若干高度相关信号当独立票数，现场设置“满足N项”硬门 |
| 原方法适用于该对象吗？ | 画像/规则原始适用范围、业务模式和兑现阶段 | 适用则据新证据修订；不适用则换研究问题 | 无法归因等同“错杀”，或认定流动性恢复后必然上涨 |

“如果流动性恢复，原产业判断还成立吗”仅是反事实问题，不是价格预测。
无法区分解释时可以维持观察，但须说明未解问题和下一份证据，不给“扛/加/清”的机器动作。

## 4. 主线与标的切换：先审研究排序

将旧方向和候选方向放在同一目标、时间窗及比较口径下，分别检查：
产业进展、价格已反映程度、拥挤度与失效条件。走势相似或“同属概念”不能证明同一经营机制。
排序依据失效时重算比较，不用旧总分盖住被撤回的前提；不以本检查表决定换仓。

## 5. 已有接口与验收边界

- 原判断 / 后验：复用 checkpoints、judgments、verdicts；不新建交易台账。
- 产业与定价分开：复用 `pricing_split`；无事前预期源时只描述价格状态。
- 判断增量：复用 `judgment_delta`；反证不能被重复利好挤掉。
- 检索未命中、失效前提、窗口冲突、同走势异机制等材料算例见
  `intelligence/eval/cases/knevo_absorption_regression.json`。它们不是账户收益回测，
  也不证明真实记忆存储与检索接线。

R6 不再挂“待试用后自动代码化”：本轮明确停在此研究检查表。
要重开，先有公开可复算的失效标签与对照，且只产生研究结论；交易动作不在此项目入口范围。

## 6. 压力测试三层信号（R9：词表，不采纳阈值/仓位）

| 层 | 待研究变化 | 本地取证方向与边界 |
|---|---|---|
| 早期预警 | 核心与边缘相对表现分化、波动及成交结构改变 | canonical 板块/个股行情、涨停结构；`fact_sector_daily.strength` 曾全空，不能只查行数 |
| 加速 | 波动向其他环节扩散、指数与反弹路径变化 | canonical 行情/指数时序；宽基请求清单的两个增量已有接替代码，当前生产覆盖仍须只读验鲜 |
| 修复观察 | 波动收敛、封板/开板结构与后续日期是否延续 | 涨停股与市场序列；`first_limit_time` 用前核日期/字段非空，不将单日形态当已确认拐点 |

三层并非必然顺序；流动性危机、政策突变或微观结构变化时尤其不能套固定台阶。
本页不把来源中的“L3四条同时满足”当通用确认器。结构有解释用途，不代表已验证预测力。
