## 0. 为什么要有这份文件

本地此前**完全没有仓位层**（question-bank A2 标注「我们最缺的一块」）——复盘、判据、
回检都有，唯独「信号 → 仓位动作」这段是空的。这份骨架把这段的结构先立起来。

## 1. 顶层原则（风远94 层，原则可直接采纳）

1. **仓位 = 信号清晰度的函数，不是信念强度的函数**：退出信号可精确定义 → 正常仓位；
   退出信号模糊（"边缘地带"）→ 仓位打折。
2. **论断开仓、论据平仓**：加减仓前先问「逻辑变了还是只是价格动了」。
3. **先归因、再决策**。

## 2. 结构骨架（机制层，可实现）

### 建仓
三层情景估值定锚（超级周期/基准/衰退三档加权）→ 按当前价位置分四区
（观察/试探/重仓/崩盘），各区对应计划仓位的不同比例。
首仓大小由信号清晰度决定；边缘地带标的只设论据止损、不设价格止损。

### 加仓
- **禁止条件优先**：拥挤度三信号同现时不加仓（待标定 #6）。
- 右侧：催化落地且不破关键位 → 加至目标仓。
- 左侧：分层信号 L1 ≥N 项 → 试探仓；L2 = L1 全满足 + ≥M 项 → 加至目标（阈值待标定）。

### 减仓
竞价锚扫描（方向锚/高度锚/情绪锚）恶化 → 分档减；双锚同恶化 → 减半；
末龙补涨突破前高 = 卖点不是买点；抱团信号同现 → 减至底仓。

### 清仓
**只有一个最高优先级触发：论据层面证伪**（产业核心数据：CapEx 指引、订单取消、
出货量、毛利率拐头、商业模式被否定）→ 无条件清仓，不论浮亏。

### 总仓位
总仓 = f(共振烈度)：杠杆/叙事/竞争/业绩/利率/拥挤度六个周期同时施压的个数决定档位
（与本地 reading_baseline 的量能分区思路同构，可作对照）。

### 连续亏损降杠杆
按**账户回撤**触发（不是按亏损次数），阶梯动作 + 冷却期 + 复出首仓上限；
连续止损达档 → 停手重跑判别树，区分「框架失效 vs 执行走样」再恢复。
**四档数值待标定（Q-002 #1），本地有判断台账可做真实重放，这是我们比 Knevo 强的地方。**

## 3. 浮亏判别树（逻辑 → 资金 → 烈度 → 标的类型）

```
浮亏 X%
├─ 1 逻辑层面：产业核心逻辑证伪？（CapEx/订单/出货/毛利/模式）→ 是：清仓
├─ 2 资金层面：主动卖出还是被动减仓？（相对强弱/两融/换手/席位）
│    主动砸 = 证伪加深 → 减/清；被动挤压 → 下一节点
├─ 3 烈度层面：共振几个周期？→ 分档扛/减半/底仓/清仓
└─ 4 标的类型：框架内 → 价格止损执行（阈值待标定 #3）；
     边缘地带 → 只论据止损，浮亏期冻结加仓
```

口诀：**「明天流动性恢复正常，它能不能涨回来？」**——逻辑证伪→不能→走；
流动性挤压→能→扛；情绪错杀→不但扛还是加仓点。

边界知识（高价值）：框架覆盖外的波动，事后说"该卖"是幻觉——
alpha 恰恰来自扛住别人扛不住的波动；所以**判别树的出口必须有"扛"这个合法答案**，
否则等于默认"跌了就错"。

## 4. 主线内切换（高切低 / 龙头切补涨）

- 触发：龙头滞涨/长上影 + 低位放量启动（量阈待标定 #4）。
- 确认：低位连续领涨创新高 + 龙头不反包；补涨层必须**有真实业绩/订单锚**。
- 失败回切：龙头反包 → 切回；补涨被证情绪溢出（无业绩锚、高换手不创新高，
  阈值待标定 #5）→ 撤出。
- 铁律：高切低的弹性由**筹码干净程度**决定，不是产业逻辑差异。
- **两条禁忌**：大票补涨 = 轮动最末端（能涨的都涨完了）；杀杠杆行情里切防御 =
  双向踏空（归因为杠杆清洗时坚持主线，不做风格切换）。
