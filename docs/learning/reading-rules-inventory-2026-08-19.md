## 1. 两人共识（优先级最高，建议先内置这四条）

两套框架独立形成、措辞不同但内核相同的条目。共识 = 交叉验证，且四条全是 A 类、全有本地数据支撑。

- [ ] **CR-01 先定阶段，再谈板块，最后个股**
  内置措辞：*任何板块或个股判断，先确认市场处于哪一阶段（成交额中枢/箱体位置），再判板块在主线周期的哪一段，最后才落到个股。不脱离阶段断言新主线。*
  挂载：D0 盘面时序直查 / D6 多日中期趋势
  源：SPT `reasoning_patterns`「先量能后板块再个股」；风远 `reasoning_patterns`「先定周期位置再谈标的」

- [ ] **CR-02 证据分层顺序**
  内置措辞：*证据硬度排序：盘面量价资金结构 > 涨价/订单/产能等产业硬事实 > 第三方数据与金融验证链 > 卖方观点 > 小作文传闻。低层级证据不得推翻高层级。*
  挂载：全局元规则（常驻），与现有 `fact_hardness` / L1-L4 分层对齐
  源：SPT `evidence_hierarchy`（5 层）；风远 `evidence_hierarchy`（5 层，顺序几乎一致）

- [ ] **CR-03 结论必须条件化 + 自带证伪**
  内置措辞：*给方向判断时同时给出：需满足哪些量价确认条件才升级、当前满足几条、出现哪些信号即降级或放弃。不给无条件结论。*
  挂载：全局元规则（常驻）；与双盲答卷 T+1/T+3 证伪机制天然咬合
  源：SPT `reasoning_patterns`「推演剧本化」+ `falsification_style`；风远「条件化买点（列出当前满足几条）」+ `falsification_style`

- [ ] **CR-04 组合信号优先于单点**
  内置措辞：*不用单一指标定性。按层级/多条件组合判断，并说明各条件当前状态；缺条件时说明缺哪条，不要用其他条件补位。*
  挂载：全局元规则（常驻）
  源：SPT「板块回流三件套」；风远「三级信号体系按层级而非单点」

## 2. SPT-Molmansk 判读方法

### 2.1 A 类（候选内置）

- [ ] **SPT-A01 量能状态机定阶段**
  *用指数箱体位置 + 成交额中枢确定市场阶段；新主线只有在市场出现极小量（老主线筹码躺平）之后才可能发育。在此之前的板块启动不得断言为新主线。*
  挂载：D0 / D6　源：`market_lenses`「量能状态机」+ `anti_patterns` 第 1 条

- [ ] **SPT-A02 板块回流的前置形态**
  *主线做完复杂顶后必有回流，但回流需先满足：大幅缩量 + 回到支撑位 + 30 分钟级别底背离。三者不全不算回流。*
  挂载：D0 / D4 双红快照　源：`market_lenses`「量能状态机」+ `falsification_style` 第 4 条
  ⚠ 30 分钟底背离本地主库无分钟级数据，见 §5-G5

- [ ] **SPT-A03 承接板块的识别形态**
  *老主线做日线大型顶部后，承接板块的形态特征是：底部 N 字（否定日线下跌趋势）+ 明显放量 + 距上方压力位有较大距离。*
  挂载：D4 / D6　源：`opportunity_preferences` 第 1 条（判读部分）

- [ ] **SPT-A04 异向性异常放量 = 冷门轮动早期信号**
  *在板块统计中寻找日线底部结构下的异向性异常放量，作为冷门方向轮动的早期发现信号（早期信号，非确认）。*
  挂载：D0 / D9 L2 大单资金流　源：`opportunity_preferences` 第 8 条

- [ ] **SPT-A05 顶部信号的两种形态**
  *见顶信号有二：量价不匹配的大阴量；单一行业短期净流入极端放量后的结构超级顶值——后者次日一旦量价不匹配即为分歧确认。*
  挂载：D9 / D0　源：`market_lenses`「量能状态机」+ `risk_triggers` 第 4 条（识别部分，动作部分归 C）

- [ ] **SPT-A06 秒板未换手 → 后排无价值**
  *事件催化后核心标的若以秒板完成而未经充分换手，则后排标的不具备参与价值。*
  挂载：连板/涨停相关块　源：`risk_triggers` 第 3 条
  ⚠ 本地无封板时间与一字板/换手板区分，见 §5-G1

- [ ] **SPT-A07 题材容量决定持续性**
  *题材本质是故事，容量越大、可整合的要素越多则走得越远。宏大叙事必须能自上而下落到千亿/万亿级赛道且逻辑闭环，否则降权。*
  挂载：D4 主线题材结构 / theme-radar　源：`market_lenses`「故事容量与定价权」+ `anti_patterns` 第 4 条

- [ ] **SPT-A08 无全球定价权的事件题材降权**
  *缺乏全球定价权的事件驱动题材直接降权，尤其筹码结构差时。*
  挂载：D4　源：`market_lenses` + `anti_patterns` 第 3 条（判读部分）

- [ ] **SPT-A09 拥挤度反向使用**
  *卖方年度策略取交集当地图使用；一致性拥挤度作为反向指标——周末被一致吹爆的题材，周一大概率被兑现。*
  挂载：D4 / opinion-cross　源：`market_lenses` + `anti_patterns` 第 2 条

- [ ] **SPT-A10 基本面定地图、交易面定买卖**
  *基本面结论（赛道容量、渗透率位置、验证链）只用于确定方向地图；买卖时点必须由量价资金结构确认。逻辑再好也不替代盘面确认。*
  挂载：全局元规则　源：`reasoning_patterns` 第 3 条

- [ ] **SPT-A11 历史同构类比**
  *用历史同构案例定位当下，类比的是结构与节点，不是标的本身。*
  挂载：D8 历史类比检索 / D10 市场情绪环境类比 / D11 个股走势类比　源：`reasoning_patterns` 第 4 条

### 2.2 B 类（结构可用，数字剥离待标定）

- [ ] **SPT-B01 产业渗透率时钟**
  结构：*渗透率所处位置决定该炒产业链哪一环——炒预期期炒概念龙头 → 预期落地期炒最大价值增量 → 扩产期炒最稀缺难扩产的上游 → 格局期炒中小市值终端企业（PS 估值穿越）。*
  剥离的数字：0-1% / 1-10% / 10-30% / 30-50%、「渗透率>30% 产能缺口收敛、过程性企业估值见顶」
  ⚠ 本地无渗透率数据，见 §5-G3

- [ ] **SPT-B02 四天时（宏观定调）**
  结构：*四维定调宏观环境——国内流动性、海外流动性、超级利润产业、监管意志；国内流动性按社融→M1/M2 剪刀差→GDP→PPI 的顺序做验证链。*
  剥离的数字：「人民币重回 7」「20% 偏离度指数行情」
  ⚠ 本地无社融/M1M2/PPI/汇率数据，见 §5-G4

- [ ] **SPT-B03 压力位缩量减仓的识别条件**
  结构：*反弹至压力位若缩量未能突破则视为反弹结束；出现大阴线加跳空缺口则确认走弱。*
  剥离：「缩量」的量化口径待本地标定（动作部分归 C）

## 3. 风远判读方法

> 全部条目无原文仓可核验（`article_count=0`），可信度低于 SPT。裁定时建议只收你自己能独立复述的部分。

### 3.1 A 类（候选内置）

- [ ] **FY-A01 双锚模型**
  *方向锚（板块方向股）与高度锚（连板高标）同时恶化，且最后一龙冲高回落 = 全板块逆转信号。两锚需同时看，单锚恶化不成立。*
  挂载：D4 / 连板数据　源：`market_lenses`「双锚模型」

- [ ] **FY-A02 出清形态两分**
  *区分 A 型出清（恐慌放量 + V 型回抽）与 B 型出清（买盘枯竭、缩量阴跌）。两种形态的买点条件完全不同，不可混用同一套判据。*
  挂载：D0 / D6　源：`market_lenses`「出清形态判别」（周期天数为 B 类数字，剥离）

- [ ] **FY-A03 五维排序**
  *排序维度：确定性 × 弹性 × 兑现时间 × 拥挤度 × 是否已定价；权重按市场场景（恐慌反弹 / 主升 / 高位拥挤）动态调整；命中一票否决项直接出局，不参与排序。*
  挂载：D1 市场价值与替代队列 / D4　源：`market_lenses`「五维排序」
  💡 与仓内 `serenity-alpha`、`strategy1-matrix` 的排序逻辑存在重叠，内置前先对表避免两套排序打架

- [ ] **FY-A04 三级信号体系定周期位置**
  *按层级判断产业周期位置：领先指标（CapEx / 交期 / 产能利用率）→ 确认指标（现货价 / 涨幅收敛）→ 滞后指标（合约价转负 / 库存）。不得用滞后指标做领先判断。*
  挂载：D3 二阶导研究 / D7 逐季财报　源：`market_lenses` + `anti_patterns` 第 3 条
  ⚠ 本地无产业链价格/交期/利用率数据，见 §5-G3

- [ ] **FY-A05 供给侧通胀四条件**
  *涨价确定性排序看四条件是否齐备：全球寡头格局 + 零新增产能 + 扩产周期长 + 需求爆发 → 供给弹性≈0 的环节确定性最高。*
  挂载：D3 / D7　源：`market_lenses`「供给侧通胀框架」

- [ ] **FY-A06 资金结构归因**
  *暴跌先归因再应对：区分基本面恶化 vs 多类资金共振卖出（主动减仓 / 止损 / 割肉 / ETF 赎回）。归因不同则应对不同，不可一律当作基本面恶化。*
  挂载：D9 L2 大单资金流　源：`reasoning_patterns` 第 3 条

- [ ] **FY-A07 利多不涨 + 连板高标 = 踩踏前兆**
  *利多不涨与连板高标同时出现，是板块抱团踩踏的前兆信号。*
  挂载：D4 / 连板数据　源：`risk_triggers` 第 1 条（识别部分；「优先减仓」归 C）

- [ ] **FY-A08 纯叙事无业绩锚 = 一票否决**
  *纯叙事标的若无业绩锚、且估值锚定极远期，在排序中直接出局，不进入比较。*
  挂载：D1 / D5 估值　源：`risk_triggers` 第 3 条

- [ ] **FY-A09 反顺从检查**
  *对已有持仓的方向做反向检查，不因持有而调低其风险权重。*
  挂载：全局元规则　源：`falsification_style` 第 3 条

- [ ] **FY-A10 框架自身可被证伪**
  *不把单次观察写成定律。框架需带升级记录与显式失效条件（例：「放量 V 回 = 出清完成」已被 B 型出清证伪）。*
  挂载：全局元规则　源：`anti_patterns` 第 1 条
  💡 这条与 `CLAUDE.md`「跑马策略处于假设验证阶段，禁止把单次观察写成定律」完全同构——**内置它等于给内置的其他规则装了自限阀**，建议必收

## 4. C 类（留 persona，不内置）

不逐条展开，裁定时整体确认即可。共同特征：关掉不影响读盘能力，只少一个观点。

- SPT：极冰点按梯队资金强度选「最靓的资金仔」；渗透率 30-50% 找 PS 估值穿越的终端企业；找抗分歧的中低位堆量标的等抱团加速；不重仓无全球定价权题材。
- 风远：不接飞刀、等条件全满足才做错杀修复；优先供给弹性≈0 的上游材料；不追第一波超跌反弹、只做增量资金回流第二阶段；ETF 赎回砸盘期不接飞刀；不抱最强股穿越退潮期。
- 两人所有含具体仓位动作的条目（减 1/3、优先减仓、分歧卖出）。

## 7. 落地顺序（三批）

裁定是「全收」，但激活受数据缺口与常驻预算约束，故分批。**批次划分是工程判断，不是对裁定的打折**——三批最终都要落地。

### 批一：立即可落（无数据依赖、全局元规则，10 条）

CR-01～04、SPT-A10（基本面定地图/交易面定买卖）、SPT-A11（历史同构类比，挂现成的 D8/D10/D11）、FY-A09（反顺从检查）、FY-A10（框架可证伪）。

先落 FY-A10 —— 它是唯一约束其他内置规则的规则，**先装自限阀再装规则**，顺序反了就会有一段时间里 25 条规则不带失效条件地生效。

### 批二：需挂具体块（有数据，11 条）

SPT-A01/A03/A04/A05/A07/A08/A09、FY-A01/A02/A06/A07/A08。
前置：FY-A03（五维排序）与仓内 `serenity-alpha`、`strategy1-matrix` 的排序逻辑先对表——两套排序同时在场会打架，这是本批唯一的真前置。

### 批三：数据未就位（4 条 A + 4 条 B 结构）

SPT-A02（需 G5 分钟级）、SPT-A06（需 G1 封板时间）、FY-A04（需 G3 产业链价格）、FY-A03（对表后归批二或此批），加 B 类四条结构。
处置：**内置措辞可以先写进画像，但规则标注「数据未就位，暂不激活」**——这样规则和数据缺口在同一处可见，补数据时不用重新推导要补什么。

### 三批共同要求

1. 每条带 id（`CR-xx` / `SPT-Axx` / `FY-Axx`），答案引用时可追到是哪条规则在起作用。
2. 留一个**验证用总开关**，用于 A/B 度量「内置判读是否真的让答案变好」——没有它就永远无法回答这个问题。
3. 裁定结果回填 `user_framework` 画像差分声明：本次全部为 `[采纳]`，B 类四条为 `[结构采纳·阈值待定]`。
4. B 类数字进 `evolution/` 回测队列，标定后才允许升格为硬判据。
