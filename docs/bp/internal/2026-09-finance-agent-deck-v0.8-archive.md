# Foresight

## 带你复盘、校准你判断的 A 股个人研究工作台

**一人公司 · 一支 agent 团队 · 阶段：有 Demo + 自用数据**

炒股是大多数人的副业。盘后翻四五个 App，一小时过去，还是说不清今天发生了什么。**Foresight 每天替你把盘读完**：今天主矛盾是什么、消息传到哪一步、自选池里哪几只被打到了、明天该盯哪几个开关。

它不预测涨跌，不给买卖时点。同一条时间长河，两个入口：不会复盘的人由授课框架带读，有框架的人判断进台账、被回检、按历史成功率升格或证伪。

# 为什么现在：大厂都是 Agent 了，创业公司做了记忆，差异只剩「带读」与「校准」

- **供给**：问财升级智能投研 Agent + iFinD MCP；东财妙想 Claw + Skill 广场；万得 2026-03 发布 Wind Alice 个人版；创业侧多家决策型投研 Agent 以「长期记忆 + 决策确认」为主卖点（多在内测）
- **需求**：50.43% 个人投资者从未用过 AI 财富管理工具，深度使用者仅 14.8%——第一批深度用户最在意可信度
- **监管**：2026 年防非宣传月重点打「新型 AI 非法荐股」——荐股与「AI 决策」叙事出清，研究工具与投教叙事留下

<!--

# 产品：一条时间长河，五个场景一条线，边界写在代码里

**时间长河**：每个交易日六条轨对齐——盘面 / 题材 / 舆论 / 资金 / 个股节点 / 你的判断；读河的框架默认是授课框架，可换成你自己的。

| 场景 | 系统做什么 | 输出 |
|---|---|---|
| **自选简报**（已上线） | 用户自选清单 × 当日盘面四袋（主线 / 严格双红 / 涨停热度 / 全市场）确定性接合，盘面事实只经一次委托取得 | 每条主张带档位：（事实）袋内锁定数字 /（推断）接合陈述 /（缺口）你这只今天哪个袋都没进。**不产任何买卖动作句，词面在测试里锁死** |
| **每日复盘（两个入口的起点）** | 从本地数据仓生成市场阶段、容量板块、双红题材、涨停热度；默认用授课框架带读，有框架的用自己的框架解读 | 结构化复盘 + **明天的观察剧本**（看什么、什么条件升级或放弃；登记为可证伪点；到板块 / 题材层，不点个股） |
| **题材研究** | 定义、产业链、公司分层、证据索引、信号缺口；发酵链路回溯 | 只读报告，证据分四层标注 |
| **个股深挖** | 客户证据硬度、收入结构、强反证、估值带 | 结论 / 证据 / 反证 / 验证点 / 引用，五段缺一不发 |
| **前瞻假设与后验** | 判断登记为可证伪点，T+1 / T+3 / T+5 自动回检，按类别统计命中率 | 校准报告、经验卡、纠偏记录 |

**三个不做**：不选股、不给买卖时点、不预测价格（2012 年荐股软件规定的三类投顾动作）；不接交易。**小白问「明天买什么」，得到的是观察剧本 + 一句「这不是投资建议」。**

# 一天的人机来回：它带读，你顶一句，第二天回检

| 时间 | 它做什么 | 你做什么 |
|---|---|---|
| 早上 | **自选简报**：清单 × 当日四袋，标出事实 / 推断 / 缺口 | 扫一眼，知道自选池里谁被打到了 |
| 收盘后 | **带读**：今天主矛盾、消息传导到第几步、主线在第几幕 | 读；不同意就顶一句「不对，应该是……」 |
| 当场 | 把你那句记成**纠偏**，后续解读自动带上 | —— |
| 你写下判断时 | 登记为**可证伪点**，带规则号，回显这条规则的历史四态 | 写「明天 XX 板块若放量则主线切换」 |
| 次日 / T+3 / T+5 | **自动回检**：打脸或点头 | —— |
| 累积之后 | 纠偏 → 候选规则 → 回测出收据 → 过统计门才升格进代码，过不了进证伪库 | 方法论是这么一天一天沉下来的 |

**这一栏才是产品**：agent 不替你下单，也不替你决定。它带你读、记住你的反驳、第二天验证。已有读数：**124 条纠偏、83 个可证伪点、23 个交易日双盲前瞻答卷台账**。

# 壁垒三层：地板不加分，上限靠 know-how，机制决定速度

| 层 | 内容 | 性质 |
|---|---|---|
| **地板** | 证据可追溯、无前视、无证据即拒答、独立判官（7,386 条测试钉住）· 跨会话记忆 | **入场券，不当卖点**——Perplexity、Wind Alice 都在做，决策型 Agent 把记忆做成了默认；它的作用是让带读与校准可信 |

# 验证计划：每一步写好「继续」和「停止」

| 阶段 | 时间 | 通过线 | 停止线 |
