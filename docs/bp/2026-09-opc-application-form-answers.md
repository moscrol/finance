项目简介（100字内）：

面向以炒股为副业、想自己看懂市场的投资者：Agent 每天带读复盘，研判大盘阶段、主流板块与题材演变，给出次日观察重点并回检判断，帮用户建立自己的认知；资深投资者沉淀方法，积累认知复利。不荐股。

4.目标用户 / 服务对象是谁？

第一类是把炒股当副业、时间精力有限，但仍希望自己理解市场的个人投资者。他们需要在有限时间里持续学习，避免把判断完全交给外部答案。第二类是已有研究框架的资深投资者，需要把判断、验证与纠偏沉淀为可复用的方法，积累认知复利。两类分别验证使用与付费意愿。

5.你解决的核心痛点是什么？

核心痛点是“认知投降”：炒股作为副业，有限时间被筛选信息消耗，用户难以持续理解和复盘，逐渐把判断交给外部观点，自己的认知没有积累。这批人已经在把问题交给 AI，但通用 AI 助手不记得他昨天的判断、不区分“当时知道什么”和“后来才知道什么”、也不会告诉他哪类判断总是出错；决策型投研 Agent 直接给结论，把“学会看”这一步跳过去。两者都让投降更顺手，而不是更少；自媒体观点也受博主视角和选材影响。产品通过持续的专业视角带读与回检——研判大盘所处阶段、主流板块与题材演变，给出次日观察重点与升级、放弃条件，并回检每一次判断——帮助用户建立认知、减少时间消耗；对资深投资者，则解决判断与经验难以验证、复用和积累的问题。不荐股，不提供个股目标价、买卖时点或自动下单。

9.核心优势 / 技术亮点 / 资源基础：

核心优势有三层。第一，唯一不可复制的输入：创始人两年投教里 1000+ 付费学员反复追问收敛出来的一套看盘方法，正在被代码化为可版本化、可回测的授课框架——通用 Agent 有模型没有框架，决策型 Agent 有结论没有教法，投教机构有框架但不接盘面数据、不能每天更新、不能回测自己。第二，底座是“时间记忆长河”：盘面、题材、舆论、资金、个股节点和用户判断按交易日对齐，每条记录标明哪天的数据、何时知道、来源是什么、缺了什么，同一段历史可以重放；研报知识库作为证据源另行挂载，不当事实主库。第三，数据飞轮：用户每天确认一条观察剧本，到期回检产出候选经验，先在没见过的历史上验证、好于同期基准、样本足够，才进入个人方法库，再改变下一次带读；Agent 改进带读、证据组织与回检，规则库经过验证后沉淀，框架母本由人写、人改。已有简报、证据图谱、判断台账、回测组件和六类数据读取面第一版；完整带读、指数/题材/个股入口与私有框架仍在建设。差异在于持续带读、校准与认知积累，而非多给一个答案。

数据与工程基础：截至 2026-09-02，数据仓 52 张表、413 个交易日、约 210 万条个股日记录；已有题材证据图谱，内部记录 7,386 条自动化测试。创始人浙江大学传播学本科，2023–2025 年在投教一线接触用户，课程项目服务过 1000+ 付费学员；学员付费证明这群人愿意为“学会看”付钱，但原服务为课程与持牌投顾的组合，带读订阅本身的付费意愿将独立验证。
