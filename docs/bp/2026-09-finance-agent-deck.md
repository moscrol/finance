# Foresight
## 和你协同进化的 A 股投研 Agent

**每天带你复盘：研判大盘处在哪个阶段、哪些板块是主流、题材走到哪一步，给出明天该看什么、什么条件升级、什么条件放弃；记住你每一次判断，到期回检，告诉你对在哪、错在哪。**

小白学会自己看，高手的经验变成认知复利。不荐股，不提供个股买卖建议；Agent 在使用中改进带读、证据组织与回检，判断和规则库是你自己的。定位是研究与复盘工具，不是荐股 App。

# 从认知投降到自己的判断

- 炒股是副业，有限时间被信息筛选消耗，来不及理解和复盘，逐渐把判断交给外部答案——这叫认知投降。
- 投降的人已经在问 AI。但通用助手不记得他昨天的判断、不分“当时知道什么”和“后来才知道什么”、不告诉他哪类判断总错；决策型 Agent 直接给结论，把“学会看”跳过去。两者都让投降更顺手。
- “有没有 AI”不再是差异，“能不能带着你读、能不能校准你的判断”才是。
- 为有框架的资深投资者留下判断、验证与纠偏，积累可复用的方法和认知复利。

历史投教服务过 1000+ 付费学员，学员追问出来的三个问题（题材是什么、证据在哪、能不能信）成了产品的出门纪律；原服务为课程与持牌投顾的组合，带读订阅的付费意愿要重新验证。

# 终局是个人研究校准系统

- 底座是“时间记忆长河”：盘面、题材、舆论、资金、个股节点、用户判断六类数据按交易日对齐，每条都标明哪天的数据、何时知道、来源是什么、缺了什么；读取路径没有模型，两次读结果一致。
- 研报知识库作为证据源另行挂载，只提供来源与证据硬度，不当事实主库；创始人的授课框架是横切其上的“读法”。
- 用户每天只做一件事：确认或修改一条观察剧本（次日看哪些指数、板块和题材，什么条件升级，什么条件放弃），到期回检对照事实。
- 一次反馈只生成候选经验；在没见过的历史上验证、好于同期基准、样本足够，才进入个人方法库；跨用户复现后才考虑共享。

# 壁垒：知识体系是唯一不可复制的输入

- 壁垒不是“有人付过费”，是 1000+ 付费学员两年追问收敛出来的一套看盘方法，正在代码化成可回测、可版本化的授课框架。通用 Agent 有模型没框架；决策型 Agent 有结论没教法；投教机构有框架但不接数据、不能每天更新、不能回测自己。
- 四层随时间积累的资产：按日对齐的结构化历史、编码成规则的框架、用户带条件的判断与回检、每条经验的通过/失败/失效记录。现在没有已验证的护城河，这四层靠持续使用才变成切换成本。
- 数据飞轮：每天一条观察剧本 → 回检 → 候选经验 → 历史检验 → 个人方法库 → 下一次带读更准。Agent 改进带读、证据组织与回检，用户形成自己的判断与规则库；样本不足就显示“样本不足”。
- 反定位：不荐股、不提供个股买卖建议、暴露错误率——大厂做了伤流量与交易模型，决策型 Agent 做了丢卖点。
- 首批三条内部种子规则均未获得支持，不包装成有效方法。会否定自己方法的系统，才有资格校准用户。

内部数据规模和测试数量见 BP 第 3 页，不代表商业授权或效果证明。

# 验证按阶段推进

| 阶段 | 判断条件 |
|---|---|
| V1 0–3 月 | 3–10 人，周活 60%，至少半数登记判断；另测同任务耗时和质量 |
| V2 3–6 月 | 收费条件满足后，50–200 人测试，激活转化 10%、付费次月留存 70% |
| V3 6–12 月 | 150 名有效付费者是现金情景输入，可持续需连续 3 个月核验 |
| V4 12 月后 | 个人订阅验证、数据授权与交付成本可控后，再评估面向投教机构、研究团队的定制交付（FDE，前置交付工程师），不提前计入收入 |

未达标先停止扩招；停服时处理未履约订阅、退款与台账导出。

评估同时看用户是否更省时、能否说清判断依据、是否减少重复犯错，以及历史切片能否稳定重放，不以“模型命中率”作为唯一目标。

开发费并非每月固定 2,000 元。前 3 个月暂留预算，后期 0–1,000 元/月仅作待确认敏感性区间。

前 3 个月项目预算约 0.96 万元。完整现金情景加缓冲约 3.5–4.0 万元，不含个人生活费、税费和支付费，不代表资金已落实。

数据预算 2,000 元/月时，覆盖经营费用和创始人税前月收入 15,000 元约需 145–153 人。以真实账单复核，不保证 150 人必然达标。
