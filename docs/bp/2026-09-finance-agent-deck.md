# 壁垒三层：地板不加分，上限靠 know-how，机制决定速度

| 层 | 内容 | 性质 |
|---|---|---|
| **地板** | 证据可追溯、无前视、无证据即拒答、独立判官（7,386 条测试钉住） | **入场券，不当卖点**——Perplexity、Wind Alice 都在做；它的作用是让校准可信 |
| **上限：编码进系统的 know-how** | 一套看盘的**结构语言**（双红、边际量拐点、主线切换、题材生命周期……）· 带时间与证据硬度的**题材叙事图谱**（4,599 家公司 × 2,343 个概念）· **方法论库**：验证过的 KOL 方法论进共享层、用户自己的进私有层，含**证伪库** · 124 条**专家纠偏数据** | 全部时间积累型：切换成本 + 独占资源，晚来一年就少一年 |
| **抬上限的机制** | **升格流水线 + 统计门**（方法论回测：命中率、基准率、置信区间，一次错误改不了结论）· **评测体系**（冻结题、判官、变异测试）· **一人公司 harness** | 流程能力：决定 know-how 攒得有多快 |

**反定位**：拒答、暴露错误率、为单个用户校准——大厂不是做不到，是做了伤自己的流量与交易模型。

# 一个人怎么带一支 agent 团队——这不是比喻，是每天的运转方式

| 岗位 | 由 agent 承担 | 人做什么 |
|---|---|---|
| 规划与设计 | 写设计稿与可派发工单（统一索引、七要素模板） | 拍板方向、否掉方案 |
| 开发执行 | 在隔离代码树上按工单施工、提 PR | 决定合不合 |
| 验收与审计 | 重跑门禁、变异测试；每条修复预登记「改完会看到什么」并回填 | 读收据，不读代码 |
| 生产运行 | 写手 + 独立判官 + 修复轮；夜间定时入库、质检、回检 | 当用户，记纠偏 |
| 内容 | 按营销契约生成复盘摘要、题材长文、短视频脚本 | 审核后发布 |

# 成本：有实测，不是估

- **单次研究推理成本**：356 个真实研究 run 实测，写手侧中位 3.8 万输入 tokens；按智谱旗舰档官方定价折算 **中位 0.34 元、p90 0.72 元**；含独立判官全口径约 **1 元以内**
- **每月固定支出约 1,000 元量级**：推理 300–500 + 托管约 100 + 数据源与工具订阅
- **降本杠杆**：96% 的 token 是重复上下文——接提示词缓存（命中价为原价 1/4）输入成本再降一半；判官与路由用轻量档模型
- **用量事实**：创始人自用 20 天 495 次，远超每年 240 次的假设——所以 Pro 层必须日配额，且配额在副作用前预占

# 验证计划：每一步写好「继续」和「停止」

| 阶段 | 时间 | 通过线 | 停止线 |
|---|---|---|---|
| **V1 邀请制 Alpha** 3–10 人 | 0–3 个月 | 周活 ≥ 60%；每周 ≥ 5 次提问；**≥ 半数用户主动登记过判断** | 周活 < 30% 或没人登记判断 → 校准不是真需求 |

| **V3 可持续线** | 6–12 个月 | 付费 **120–150**；月度现金流为正 | 付费 < 50 → 市场太窄 |

# 向社区要什么、给什么，以及想请教的三个问题

**要**（钱买不到的）：算力 / API 额度 · 金融合规导师（6 个月内拍板合作持牌机构 vs 资质）· 首批 3–10 名可信种子用户 · 持牌数据商一次报价对接 · 同行 OPC 交流。**不要资金**：验证只需约 2 万元与 12 个月。

**给**：一个人带 agent 团队跑到生产级的完整方法论（可做工作坊）· 开源的 FinHot · 按季度公开验证读数，包括失败。**3 / 6 / 12 个月承诺**：Alpha 上线出周报 → 公开付费转化 → 到可持续线或公开复盘。

**想请教各位的三个问题**
1. **付费点**：「结论可信 + 自己的判断被校准」定 199 元/月，对半专业个人投资者成立吗？不成立的话，是价格问题还是价值感知问题？
2. **合规路径**：合作持牌机构，还是等条件成熟自行申请资质——在杭州、一人公司的体量，哪条更现实，第一步找谁谈？
3. **一人公司的边界**：到 1,000 付费、年收入约 150 万之后要不要扩张？什么信号出现时该扩，第一个该雇的人是谁？
