### 项目摘要

**目标用户。** 以股票投资为副业、研究时间有限，却希望保有独立判断的个人投资者；以及已有研究框架，希望持续检验判断、积累方法的资深投资者。

**核心痛点。** 个人能投入的认知、下班后挤出的时间，与市场复杂度不匹配。资料散落、口径难齐，现成结论又没时间核，长期只能选择信或不信，逐渐放弃自己研究，创始人称之为“认知投降”。不是用户不愿意学，也不意味着通用 AI 无法核验；即时研究需求不以学习意愿为前提。

**产品方案。** 市场研究底座、研究 Agent、可选个人校准层。时间长河首先组织市场自身演变，知识库与图谱提供材料和关系证据；Agent 围绕问题组织取证、历史比较与计算，交付可检查的研究产物、缺口与下一步。愿意学习的用户再选择带读、条件判断和回检。目标是让研究持续推进，而非让所有人先记判断；长期积累价值仍需验证。

**开发进展。** 历史发现、深读、结构化计算、跨轮研究与情景比较等能力已进主线和生产代码；历史比较、计算等有局部任务收据。完整题集、自然跨日续研、普通用户的可靠交付仍需验收。严格历史回放受内容快照与数据覆盖限制，不能把已合代码当作效果成立。

**创始人背景。** 林邦骞，浙江大学传播学本科，曾联合创办金融投教项目并负责内容交付，历史项目累计服务 1000+ 付费学员。学员两年里反复追问的三个问题——题材是什么、证据在哪、能不能信——原样成了本产品的出门纪律。原服务为课程与持牌投顾的组合，带读订阅本身的付费意愿将独立验证。

**近期计划。** 首轮由创始人邀请资深投资者，带真实任务测评研究质量；修复问题后，再观察目标用户能否独立完成研究、持续使用与付费。资深测评认可不等于订阅需求成立。个人订阅是拟验证方向，价格仍为草稿，服务与成本条件满足后另行确认。

**社区支持。** 希望获得产品与商业化建议，在首轮测评后共同探索匹配的体验与传播场景，交流一人团队持续交付经验；首轮测评不依赖社区招募。可回馈 Agent 开发、数据核验与自动化测试实践。算力与 API 额度为补充支持。前 3 个月项目预算约 0.96 万元，按验证结果分阶段投入。

## 1 目标用户与产品体验

### 从一个真实研究问题开始

一轮题材行情怎么形成？哪些说法有公司级证据，哪些只是概念关联？过去条件相似却没有走强的案例是什么？用户需要能核查、能比较、能继续的研究。有限时间下，从财经博主转向 AI，若仍核不了结论，就没有摆脱依赖；产品要让用户自己查得动。

副业投资者需要减少查找与搬运，资深投资者需要对齐口径、核算数据与检验反例。二者均可直接使用研究功能；希望建立框架或校准经验的人，再选择学习模式。不要求所有人每天登记判断。

### 研究对象、研究动作与研究产物

| 场景 | Agent 承担的研究工作 | 交付与边界 |
|---|---|---|
| 市场演变与历史对照 | 重建时间特征，找同类、反例和缺口 | 有条件的比较；不把相似历史当交易规律 |
| 材料取证与核算 | 深读原文，核出处、关系与可比口径，完成结构化计算 | 带来源说明、计算件；关联不等于业绩兑现 |
| 继续研究 | 接上既有依据、未解问题和新证据 | 新增信息与下一步；自然跨日仍需补验 |
| 可选学习与校准 | 带读、条件判断、回检与候选方法检验 | 积累理解；不保证越用越准或方法有效 |

这些是产品场景，不是一次自然会话已将全部能力跑通的宣称。

### 时间长河：首先是市场自身的演变

盘面、题材、舆论、资金和个股节点按交易日对齐成结构化表，用户判断是附加轨迹，不是市场事实。模型理解问题、决定查什么，数据库与计算工具负责联立和核算；结果可追溯、可复算，不靠模型生成一个看似合理的数。研报知识库与图谱补充出处，数据与计算口径仍需核验。

查询须分清事件时间、系统何时知道、采用哪版内容。固定数据版本、相同参数和受支持范围内的确定性读取可以复现；严格按当时所知回放还须有相应内容快照，缺失就标明。不是保证模型两次回答一样，也不是全历史都已无前视。历史发现仅用于研究，不直接获得方法认证或投资决策资格。

**服务范围。** 围绕市场阶段、板块和题材演变组织事实、证据、比较和观察条件；用户指定个股只做事实、证据和风险核对，不提供个股买卖建议、目标价、买卖时点或自动下单。收费前结合真实输出样本完成专业评估。

代码合入、部署上线、单次任务通过、效果成立是四个不同状态。核对当天服务健康，例行的复盘数据流程仍因质量检查未通过而中断，事后补齐数据也不把它记成成功；可靠交付只按每次任务的收据判断。

### 现在能展示什么

只讲一条已验收历史任务：机器人板块行情特征与反例比较（2026-09-09 隔离工作台，内部编号 M2）。枚举 77 个窗口，71 个缺失、1 个未成熟、5 个有效；有效窗仍有重叠，独立性未建立。PPT 展示收据摘要，不冒充产品截图或当前现场执行。原回答仍有代码与枚举跨度披露不足，不能称为完美交付；不拼接其他局部验收冒充一次全程自然会话。

### Alpha 前要补齐什么

先锁定少量真实任务，验收引用、缺口、计算件、失败收口与继续研究；补齐邀请用户的权限隔离、脱敏、数据授权范围和全口径成本。带读与个人框架按自愿需求迭代，不挡住直接研究入口。

首版框架用于组织学习；数值方法假设仍需检验、标明样本量与不确定性，不以经验编码代替验证。

### 如何体验

本轮采用历史验收摘要讲解。私有知识库不对评审开放账号；真实界面录屏、截图与公开链接须在脱敏、权限核验和彩排后另行提供，不计入本次附件。

### 一人团队如何交付

创始人负责产品方向、领域判断和最终交付，AI agent 辅助开发、测试、资料整理与日常运行。通过自动化检查和预算控制降低维护负担，先在一人能够持续负责的范围内服务用户，再根据验证结果考虑按需合作。

## 3 壁垒与持续使用价值

### 差异化：把领域经验变成可检验的方法

数据和模型不独有，差异化在于观察什么、怎样组合、何时适用。观测面就是研究问题的角度：同样板块上涨，要区分普遍走强与少数个股撑起。创始人把投教与研究经验沉淀为明确口径、适用条件和反例，让 Agent 执行并接受检验，而非只模仿措辞。

经验提供候选方法，不直接证明有效。发现规律与验证规律的数据须分开，检查不同市场阶段、样本依赖与多次尝试，降低过拟合风险；历史高命中率不能保证泛化，描述性观测面也不能统一按命中率评分。通用工具同样可以研究，产品须用同任务对照证明少遗漏、可核查、省时间，不能只凭框架数量宣称领先。历史投教学员不是当前产品客户。

### 四类可能积累的资产

| 资产 | 潜在价值 | 成立条件 |
|---|---|---|
| 带版本的市场档案 | 帮助复查当时所见、减少事后混淆 | 时间语义、快照覆盖与授权可靠 |
| 领域框架及失效案例 | 提供可检验的读法 | 经独立检验，不能只把经验写进代码 |
| 个人研究轨迹 | 依据、产物、未解问题及可选判断相连 | 用户真实保存、复用并愿意继续使用 |
| 验证收据 | 保留通过、失败与重新检验过程 | 长期维护且能实际改善研究 |

领域经验是起点优势，方法、适用边界和失败记录是潜在壁垒；必须改善真实研究，才有商业价值。当前没有已验证护城河。个人材料不默认跨用户共享，不靠限制导出制造锁定。

### 可选长期积累：协同进化分别验证

**提取前置是设计中的可选模式。** 在讲解前，先请用户说出自己的判断和依据，再核对证据与遗漏；赶时间可以关闭。它不应成为获得研究帮助的门槛，也不是已上线功能的声明。

协同进化要分别验证：你在进步、它在改进协作、双方共同积累。例如用户指出漏看板块分化，系统先拿数据核，再记录纠正，到期一起回检，下一次同类研究据此调整。这是目标场景，不是完整跨日闭环已验收。人维护框架，Agent 只提议；纠正不等于方法认证。候选方法须与发现样本分离验证、比较同期基准、披露样本依赖与不确定性；跨用户共享另需授权和脱敏，不能承诺越用越准。

首批四条内部候选均未获得与基准可区分的支持。一条规则看似有 85 个历史信号，实际集中在 15 个交易日；考虑结果窗口重叠后只剩 3 个完整时间块，被判样本不足。2026-09-11 首跑，09-15 干净主干复核一致；3 块不等于 3 个独立个股样本。这证明检验会拦下证据不足，不证明投资方法有效。历史研究与候选方法仍无投资决策或自动晋升资格。

**长期愿景：人机交互的心流平台。** 围绕问题，让想法、证据、反馈和追问连续推进，减少搬运与中断，保留质疑、暂停和结束研究的权利。不是心理学心流效果已获证明，也不以停留时长代替研究价值。当前仍聚焦 A 股研究。认知复利指理解与方法的潜在积累，不指投资收益。

| 机构探索（FDE） | 前置交付工程师（FDE，Forward Deployed Engineer）贴近团队任务，把研究方法、数据与审核流程落实到系统 | 先访谈，条件具备再评估有偿试点；未开展，不计收入 |

上述为 offer 草稿价格与原交付范围，尚未生效。本轮扩展产品叙事不自动扩展套餐；研究配额与交付范围须在实测后另行确认，不是现在即可购买的服务。尚无本产品付费用户。历史项目约 1,000 元/月的课程与持牌投顾组合服务，可提供需求观察的参考，但交付内容不同，带读订阅的价格接受度需重新验证。

### 先自主邀请测评，再探索后续推广

首轮由创始人邀请资深投资者，带真实研究任务测评，先检验证据、计算、遗漏和反例，形成待修问题。测评不是背书，资深用户认可不等于普通目标用户能独立使用或愿意付费。历史粉丝和学员不计入当前客户。

修复问题后，再与社区探索目标用户试用、研究案例分享和传播合作，观察重复使用与实际付费选择，不预设哪条渠道有效。公开材料由创始人审核，脱敏并确认权限，不以收益承诺或方法胜率招揽。既有 3–10 人规模只作小范围规划参考，不设未经验证的候补名单增长承诺。

### 单用户收入与成本假设

预算按月付与年付的组合，假设每名有效付费用户月均实收 180 元，年化 2160 元。扣除每月 20 元的付费用户推理预算，以及 22 元的免费体验成本分摊，单用户月贡献为 138 元。实际付费组合、续费率和使用成本在 Beta 阶段核验。

推理预算暂按每次 1 元、付费用户每月 20 次研究估算。已有 356 次完成任务的报告生成用量记录，按当时价表折算的中位成本约 0.34 元，尚未包括全部审查、失败和重试费用。**每次 1 元是预算假设，并非实测成本上限。** Beta 前将补齐完整账单，再确定使用配额与超额规则。

免费体验成本计入项目现金支出。另记录模型与判官、失败重试、工具与数据费用、运维及创始人救场工时；现金支出与工时经济成本分开。原预算尚不能说明真实毛利。若全口径成本或使用量超预算，将调整配额、价格或开放规模，再更新测算。

## 5 验证计划与调整机制

首轮先由创始人邀请资深投资者测研究质量，后续再让目标用户独立试用；愿意学习和校准者单独观察。以下规模与阈值沿用既有规划作待确认假设，不是本次新增承诺；测试前约定样本、周期和判据，不作统计效果证明。

| 阶段 | 时间 | 交付与判断 |
|---|---|---|
| V1 Alpha | 0–3 个月 | 先邀请资深测评，再观察独立试用、重复使用与成本；3–10 人仅为规划参考，可选校准另看回检。 |
| V2 Beta | 3–6 个月 | 满足收费前置条件后，50–200 人测试。目标激活用户付费转化 10%、付费次月留存 70%，同步核验全口径成本。 |
| V3 订阅验证 | 6–12 个月 | 现金情景目标为 150 名有效付费者。须连续 3 个月覆盖经营费用与税前收入目标，才称为可持续，人数本身不保证达标。 |
| V4 后续发展 | 12 个月后 | 机构访谈可提前；只有任务价值、数据授权和交付成本获验证，才评估扩大 FDE 服务，不把机构收入计入本测算。 |

**九十天建议路线。** 第 1–30 天邀请资深测评、记录失败并修复；第 31–60 天观察目标用户独立完成任务与回来继续研究；第 61–90 天与社区小范围探索体验、传播和订阅意愿，收费前置条件未满足则不收费。按问题修复和使用证据推进，不把日期当上线保证。

**V1 如何判断。** 测试前约定观察周期与扩招标准；周活分母为已获邀且完成首次使用者，活跃须完成阅读或研究任务。没有可靠交付与重复使用就先停止扩招，不凭满意评价或活跃率通过。判断登记与回检仅在自愿校准子组计算，不把不记判断的研究用户判为失败。

**付费如何计数。** 转化分母为测试期内完成首次核心任务的独立激活用户；分子为其中实际付费者。次月留存按首次付费队列计算。有效付费数只计算当月仍有付费服务权益者，不用历史累计购买人数替代。

### 先验即时研究价值，再看长期积累

与“通用 AI＋行情软件＋表格笔记”做同题或难度匹配对照，固定材料与截止日，交替顺序。完成率分母为预登记并启动的任务；完成须满足交付要求、有可核查依据、缺口明示，不用系统完成状态替代。失败、重试和人工救场不得从分母删除。

抽查关键断言的出处与支持程度；记录用户提问、等待、核对、修正及搬运的总时间。分别统计主动保存、后续复用和继续研究，自动存档不算主动保存。成本包括失败消耗与创始人工时，不能只看成功报告生成费用。各项报告原始分子/分母，不在看到结果后补造通过阈值。

可选校准另看解释依据、新案例迁移和重复错误；候选方法另做独立历史检验、基准比较与失效监测。研究使用价值、校准体验、方法有效性分别评估。目前无外部效果或付费留存证明。

### 根据验证结果调整投入

若只有一类用户形成持续使用，将收拢产品范围，针对该人群继续测试付费意愿。若 Beta 转化低于 5%或收费条件无法满足，则停止扩招与新收费，回到自用，或另行验证工程服务需求。

如需停止商业服务，将提前通知用户，按合同处理未履约订阅与退款，提供个人判断记录导出，并明确数据保留和删除安排。

## 7 社区协作与后续准备

### 希望社区提供的支持

**项目诊断与商业化建议。** 判断先服务谁、哪些任务值得持续交付，区分资深测评、独立试用与付费验证；机构访谈也不把兴趣当订单。

**后续体验与传播探索。** 首轮资深测评由创始人安排。产品适合试用后，与社区做小范围体验、讨论匿名任务和传播合作，不要求效果背书；数据授权与金融合规服务按实际需要对接。

**一人创业交流与补充资源。** 交流开发、测试、部署、成本与用户支持经验，帮助一人团队持续交付；算力和模型 API 额度是补充，不是首要请求。经营主体将在需要承接业务前按实际要求安排。

### 机构探索：先访谈，再评估有限试点

个人端聚焦研究价值，同时可访谈有固定任务、明确负责人和付费决策者的小型研究团队。目标是把团队自己的方法变成可执行、可核查的流程，不是出售自动投资决策。当前无机构订单或收入证明，不同时开发两套完整平台。

有真实任务、验收标准和付费意愿，且数据授权、权限隔离、专业评估与人工审核条件满足后，再评估有偿试点。拟验证“首次实施费＋持续订阅”，特殊数据和额外定制另约，不报价格、不计原预算；交付可复用、持续支持成本可控才扩大。客户私有方法与材料不得默认跨客户复用。

### 进入收费阶段前的准备

收费前将逐一核对自用数据源的取用、加工、引用与对外展示权限。免费接口或公开可访问的内容，不直接视为取得商业分发授权；没有明确许可依据的内容不进入收费服务。研报与私有笔记保持访问隔离，不向体验用户开放全量原文。

实际服务功能和输出样本将在收费前接受专业评估，不能仅凭措辞限制、免责声明或本地部署判断业务性质。若相关功能需要持牌安排，将在具备条件后再启动对应收费服务。

### 可以为社区贡献的实践

分享一人开发 Agent、数据核验与自动化测试的实践，也复盘未获支持的假设。公开案例须取得同意、脱敏并确认权限，不开放私有研究或未授权数据。
