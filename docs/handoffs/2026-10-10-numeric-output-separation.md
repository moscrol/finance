# 数字输出与解释分离的决定

## 背景

此前主线统计已在SQL截取前计算，模型仍会把全组计数写成预览数量，或者把不满足双红写成未放量。
固定证据的direct/aligned对照也未得到合格正文。用户要求继续，故本轮先划出可以纯计算核对的字段。

## 发现顺序

1. 发现已有owned_results编译器能校验D4同键输入和共享双红规则，因此复用，不另造阈值。
2. 市场总览旧卡没有结构化observations，均值只在展示文字里；本轮未猜解析器或偷查库补输入。
3. 先给作者核算记录。记录正确，模型仍把17条预览中14上涨写成预览14条，还出现超预览排名。
4. 改为独立输出：数字表在模型前生成，模型不能修改，解释另文件保存。真实表格保持完整/预览区别和资格关系。
5. Flash解释仍有资金归因和条件极性问题；在同证据、同表、同方法、同提示下显式换glm-5.3，也未签内容通过。

## 取舍

| 选择 | 被否方案 | 理由 |
|---|---|---|
| 复用已有规则编译器 | 再写一份双红判断 | 单一阈值来源已有测试与身份合同 |
| 只核结构化输入 | 从大段文字抓数字当机器输入 | 字段、主体、日期与单位未有稳定合同 |
| 数字表独立渲染 | 让模型收到核算后继续转抄 | 真实稿仍发生数量与范围改写 |
| 解释单独未通过 | 用数字正确给整篇背书 | 资金、因果、条件关系不是计算字段 |
| 显式作者模型对照 | 静默换模型补绿 | 保留源模型与实际响应身份，明确实验轴 |
