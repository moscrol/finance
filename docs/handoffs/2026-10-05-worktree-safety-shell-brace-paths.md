## 方案对比

| 方案 | 判断 | 结果 |
|---|---|---|
| 静态提取在参数展开边界截止 | 小范围修正，恢复默认代码根；不执行启动器 | 采用 |
| 把 `${…}` 或其闭合 `}` 当路径一部分 | 实际根无法解析，引用检查静默漏报 | 否决 |
| 执行/source 启动器得到真实环境 | 会触发服务、任务或其他副作用；审计不能执行被审对象 | 否决 |
| 实现完整 shell 解释器、拼回默认值后的所有后缀 | 超出本次边界修复，变量覆盖/动态拼接另需协议 | 不做 |
| 不依赖 #49、重复它的规则修改 | 难分清采集与判定两类行为变化 | 使用叠加 PR，#49 合入后再改 base |
