# 市场—板块—个股历史过程研究：候选实现与验证快照

## 背景与范围

用户在时间长河/SPT/风远能力审查后授权实施四类问题：当前市场阶段及历史相似期；当时谁走强及启动到见顶的过程；旧板块之后谁接力、证据是什么；不同板块启动有哪些可计算共性。

本轮扩展**既有 Workbench → Episode → history_query**，不新造记忆库、事实库、产品入口或执行循环。代码提交 `506e1e237ad0c8f7a61d2a94b4df9ff40c7d0b49`，工作树 `~/fwp-wt-history-market-anatomy`，分支 `feat/history-market-anatomy`，基线 `gitea/main@0a1cb8c4`。**未合并、未部署；自动化检查通过不等于生产真实模型已会用。**

主库仅只读。没有改生产用户画像、用户台账、每日全量复盘流程或历史标签库，没有补数。本轮代码地图为空，未据此推断架构缺失。

## 按发现顺序

1. 已部署审查确认：六轨时间切片、历史联立计算、SPT/风远画像注入、派生计算已有底座；工具本轮可达、实际调用、方法认证仍是不同命题。每日流水、水位、冻结快照与方法验证收据各有边界。
2. 阅读现有历史研究、阶段/类比/接力实现后，选择扩展 `HistoryQuery`：加入 market、七个增量特征和日线过程研究，不另起引擎。
3. 过程研究加入启动信号、每日累计收益路径、事后峰值/回撤确认、启动日成员排名、声明板块集内的候选接力；缺失、未触发、未到期、失败均保留。
4. 发现用户未必知道代码，补 `rank_history` 事后全集排名作为候选发现，不强迫先提供赢家；全量计算与模型预览分离。
5. 实际模型每条证据 detail 只有240字符。将数值、日期、来源拆成完整 JSON 原子；路径采样显式标注，原件留每日点，避免底层算出但模型看不到。
6. 真库阶段来源复核纠正了早期判断：`cycle_stage` 是供应商内层标签，不是本地独立派生；`market_stage` 可能来自供应商或本地模型。09-15 专属来源实际是 `local:stage-lr-v1`，不能从行级 `local:overview` 推出标签血缘。已将专属来源、模型置信度与单位投递给模型；置信度不等于校准正确率。
7. 最终复核收紧时点：回撤发生日与“它确认了本窗口最终峰值”不是一回事。后者的 `confirmation_known_as_of` 是窗口结束日，不能沿用回撤发生日冒充当时已知最终顶部。
8. 固定代码后完成四叶本机等价检查，补可重跑查询配方、原件校验和及三项反向变异收据。

## 决策、被否方案与理由

| 问题 | 采用 | 被否方案 / 理由 |
|---|---|---|
| 数据与入口 | canonical DuckDB、现有 history_query/RunStore/Episode | 新记忆库、第二问答链：会分裂事实、日期和授权合同；向量检索不能代替精确日期对齐与算术 |
| 市场定义 | `000001.SH` 表示上证价格 + 全市场成交额/家数 | 当成全市场收益指数、单只股票，或把市场/题材/授课阶段混为一族：实际定义不相同 |
| 阶段来源 | 专属 `market_stage_source` 与 `cycle_stage_source`，空值留缺口 | 按行级 source 猜、按空字段补一个阶段：其他列更新不证明标签重算；模型置信度不是准确率 |
| 启动 | 声明窗内预热5日后首次信号；板块严格双红，个股涨≥7%且金额/前5日均额≥1.5 | 倒看赢家后选最低点：未来泄漏。自动往窗外补预热：越过用户范围。规则只是固定日线代理，不冠名完整SPT/风远 |
| 峰值与确认 | 信号起算收益净值的最后最大值；其后首个≥10%回撤；峰值关联到窗尾才可知 | 把峰值日/回撤日当实时顶部识别；盘中最高价或复权蜡烛图形：本计算没有这些定义 |
| 成员与排名 | 启动日名单锁定，完整收益排序；缺失不排名但保留 | 用当前成员、只留赢家、按名称拼篮子：幸存者偏差/成分变更混入。股路径锚是板块信号，不是该股自己的启动 |
| 发现候选 | 短窗内所有已观测 canonical 代码事后排名；显式代码可固定全集 | 强迫用户先知道赢家；超限时偷偷截取热度TopN。已观测代码仍不是完整历史上市/退市宇宙 |
| 接力 | 声明代码内，新信号在旧峰后5日；同一峰后5日窗旧收益≤0、新收益>0才列候选 | 用各自启动后5日收益冒充同窗切换；从成交额或日线先后推出资金搬家：没有资金身份/因果证据 |
| 共性和相似 | 同口径特征；重叠窗口标 cluster；验证继续 compare_cases，保留失败与分母 | 把筛选规则自带条件当发现；相似距离当预测概率、相邻窗口当独立样本 |
| 版本 | 原8特征保持v1；新增7项单独 `history-anatomy-features-v1`；过程 `history-anatomy-v1` | 为新定义重标旧结果，会破坏旧公式/原件解释；新约束不顺手改写全部旧公式 |
| 模型可见性 | 完整小JSON原子；约8个NAV采样点加峰值/确认点；完整日线留原件 | 默截长JSON、把预览当统计全集；绕开预算塞全文：前者失真，后者挤掉研究上下文 |
| 独立验证 | 手算/边界/变异 + 真库原件，旧独立审计器明确 unsupported | 让不懂market/trace/rank的审计器输出“通过”；受控模型接线测试也不等于真实模型能力 |

## 实现合同

- `entity_kind=market` 可 inspect/compute/find_analogues/compare_cases；不支持 trace/rank。上证涨幅映射 `pct_chg`，全市场亿元成交额映射 `amount`，定义带 input_mapping。
- 新特征：最大回撤、上涨日占比、末日成交额/窗内此前均额、板块成交份额首末差（百分点）、市场涨家数/涨停/跌停家数均值。`amount_vs_prior_mean` 仅21日窗才是前20日均额，不混旧 `amount_ratio` 首末比。
- `trace_history` 固定规则，不借自定义features、条件或搜索窗改变定义；信号以前有缺口为 `observed_with_earlier_gaps`，不保证最早。路径价格缺日/重复/无效收益不跳过、不补零。
- 成员排名截止板块峰值，股票路径延伸至观察窗尾；`end` 与 `path_end` 不同，证据日期按后者。名单重复或快照不一致拒排名；缺快照留 `snapshot_unknown`。
- `rank_history` 必含 return_pct，不接受名称预筛、条件或搜索窗；完整窗口复合收益降序，同值代码破序，缺失 `rank=null`。不同供应商代码分开，不把同名篮子合并。
- 保留只读事务、信息截止、取消/deadline、100000输入行/5000窗口等既有上限。超限须缩范围，工具不能自行扩用户授权日期。
- 原件与引用接既有 HistorySession；trace/rank可作历史证据，但不能取代 compare_cases 的完整条件比较。
- 全部 `research_only=true`、`pit_grade=hindsight_reconstruction`、`decision_eligible=false`、`promotion_eligible=false`。计算截止不证明当时已入库，不是严格历史回放。
