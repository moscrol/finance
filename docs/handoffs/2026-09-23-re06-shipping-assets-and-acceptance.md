## 决策与替代方案

| 选用 | 被否方案 | 理由 |
|---|---|---|
| B及窄形状读兼容不变 | 扩大版本号豁免或迁移历史 | 发布包问题不授权改变同意语义或生产数据 |
| 新提交只修发布物，再整轮验收 | 把生成物当缓存忽略，或沿用f9收据 | 实际交付对象已变，收据必须绑定真实候选 |
| E2E自行build并验身份 | 依赖前一叶已构建 | 分叶调度不能假设前一叶成功 |
| 阶段声明与文件门分开 | 只信STAGE_COMPLETE/complete:true | 静态终稿可以没有所需探针 |
| 原样恢复K3代码，仍记未执行 | 宿主补写探针并算独立覆盖 | 作者身份、代码存在、运行成功是不同事实 |
| 504单列阻塞，停止追加 | 移成业务FAIL/无发现或连续重试 | 没有完成审查，健康小往返也不代完整载荷成功 |
| 可逆编码保存不规范EOF | 给原始JSON补换行再当原件 | 格式化后的字节已不是实际执行材料 |
