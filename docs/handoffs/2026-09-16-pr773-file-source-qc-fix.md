## 方案取舍

| 问题 | 采用 | 未采用与原因 |
|---|---|---|
| 损坏解包 | 非零退出立即失败，清理解压目录，保留压缩包 | 继续使用部分文件会发布残缺榜单 |
| 缺文件/空成交 | 明确失败；三榜先完整计算再写 | 推断停牌没有供应商或当日行情证据；不能冒充成功空结果 |
| 完成统计 | capital 按实际结果数，quant 按实际扫描数 | 直接复制计划候选数无法审计 |
| 零量化单 | 完整扫描但无量化簇允许 0 行 | 一律拒绝零行会误伤正常日期 |
| 旧假完成 | skip 同时核统计与实际行数；质量门对百度文件源检查 capital 覆盖 | 只修生产者会使旧假完成继续被跳过 |
| 重跑失败 | 保留历史有效 complete 与结果；失败日期不得跳过 | 一律降级历史 complete 会丢失之前成功的意义 |
| 解释器 | cd 前把相对含路径值固定到启动目录，不解开 venv 软链 | realpath 可把 venv 解释器解成基础 Python，丢环境；仅改 README 不保护实际调用 |
| 合并 | 已包含主干的提交快进合并 | 无需制造另一 revision 或重写历史 |

三榜计算成功之后，写库仍沿用原有逐表事务，不声称跨三表原子事务。写库中途失败后，未完成步骤阻止下次跳过。未将本次返修扩大为 writer 重构。
