## 决策对照

| 采用 | 否决 | 原因 |
|---|---|---|
| 先反例、再最小修复 | 全量绿即不存在边界问题 | 全量只能证明已覆盖集合，不能替代具体失效实验 |
| 每轮不可覆盖收据，latest 仅导航 | 运行结束读取全局 latest | 并发写者和自定义目录会让读方取错对象 |
| 保留失败/不完整收据并返回非零 | 读回成功等于业务成功 | 文件可解析与门禁通过是不同断言 |
| 独占组合树验收 | 在主脏树或活跃线混跑 | 无法把结果绑定到本轮代码，且会争用现场 |
| 显式拒绝父命令忽略的目标参数 | 悄悄沿环境默认目标执行 | 操作者意图与真实目标不同是危险状态 |
| 保留旧日志逐字节原件 | 清尾空格把整差异检查修绿 | 原件哈希及失败窗口比格式整洁优先 |
| 独立审查包先备齐但未提交 | 自审改名独立PASS或自动付费 | 执行者隔离、预算和授权都不能靠文件名补齐 |
