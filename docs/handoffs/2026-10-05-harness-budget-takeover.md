## 决策与被否方案

| 方案 | 评价 / 结果 |
|---|---|
| 从明确引用的 atom 确定性补回 owner | 采用；不猜正文所需出处，不改变事实资格 |
| 给所有缺口句自动加事实引用 / 丢弃未知 ID | 否；会替作者改证据选择，未知编号必须仍可被拒收 |
| 把“缩量”加入全句负幅度词表 | 否；“缩量阶段已结束，随后上涨同幅度”会误放行 |
| 数字抽取保留字段边界 | 采用；修复串接字段污染符号；不改所有字符串规范化规则 |
| 只更新 AST 指纹 | 不足；`f"…{CONSTANT}…"` 中常量值不在字符串 AST，另测实际指令 |
| 用正文变长 / 有限事实评分满分证明质量改善 | 否；长度不等于相关、完整或有据，模板补充不能冒充模型原稿幸存 |
| 为把 D4 全保留而取消数字/公司门禁 | 否；现有错误混有推导计数、公司短语识别和实际引用问题，必须逐句分辨 |
| 重跑模型直到出现好稿 | 未做；本次冻结重放足以定位确定性漏洞，不能把另一次采样当同稿修复 |
