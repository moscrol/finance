## 方案取舍

| 方案 | 评价 | 结果 |
|---|---|---|
| 在首轮/修复共用终局提示补逐句输入与比较身份 | 范围小、能确认送达，不承诺模型遵守 | 采用，保留未通过的真实稿 |
| 把数字句自动改 kind、借邻句锚点、自动执行 `.replace` 或拼引用 | 会擅改来源身份和接收边界 | 否 |
| 自动按分号拆句、限制条数或硬截断 | 分句后每句仍需自己的全部输入，机械拆分不能证明支持 | 否 |
| 关闭判官、提高预算、改题或减子问 | 改变原验收任务，不能证明原约束下可用 | 否 |
| 继续叠提示并反复重试直到偶然通过 | 本轮已经证明指引送达但未遵守，成功样本选择会掩盖问题 | 本轮停止追加写手重试；后续应先定位具体句的构造失败 |
| 冻结判官重放代签原 Episode | 脱离原任务时序与额度，只能检查固定请求重复性 | 否，单独记账 |
