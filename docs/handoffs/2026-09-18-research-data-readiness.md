## 背景与发现顺序

用户要优先把 A 股行情、财报估值、公告新闻、资金信息接到真实研究入口，不以工具数量证明能力。既有 D12 取数已存在，但失败可以被写成“没有解禁”；Episode 未消费同一核心。之后真实入口还暴露了“调用成功”被投影成“已取得证据”、缺口原因在终稿消失、财报表头占满额度等接缝问题。

1. **先修数据语义，再接工具**：`CapitalSliceResult/CapitalBundle` 区分 success/partial/empty/error/not_attempted；坏 JSON、坏日期、非有限数、身份冲突不当合法空。旧 ask 与 Episode 复用 `capital_bundle_for_llm()`。资金按东财汇总 `L2_structured`，不是公告原文；不覆盖 L2 大单流、龙虎榜、股东名单。
2. **历史与权限在外呼前保护**：原题与模型 query 的截止日只能收紧；历史解禁滚动源无披露时点，不取当前日程回填。相对日期无法可靠解释时要求明确日期。资本工具为 `external_or_mixed`，仍受授权、material contract、sealed fixture 外呼门约束；不进本地只读白名单。多切片共享绝对 deadline，不每片重置预算。
3. **估值不用概念共现凑同行**：唯一一致的细分行业、同日估值快照是候选最低门槛；空行业、冲突行业、异日候选排除。仍是“可比候选”，不是业务/成长可比认证。
4. **公告 CLI rc0 不代表成功**：stdout/stderr 诊断可揭示 403/来源错误；坏 JSON 明确 parse_error，合法空集不落文字兜底，traceback 续行不算证据。失败/partial 不缓存，缓存合同升为 `source-diagnostics-v2`；保留 `published_at`。这些修复没有恢复外部来源。
5. **缺口送达公开出口**：进度根据实际非空证据数组，不根据 `ok=True`；固定 reason_code 映射到缺口答案，不公开异常详情/路径/模型草稿。无关知识库证据的旧日期不再冒充本题截止日。资金菜单标签改用 `/`，避开封闭菜单语法的 `、` 分隔符，不放宽安全过滤器。
6. **财报从“取到了”到“可消费”**：旧六期返回的12项只有6条主表行，表头/引用挤掉全部含金量行。改从同批 `observations_by_line()` 选数据，每期最多主表/含金量两行；限定语作为说明保留。模型看不到结构化 observations，所以每条正文再由同一指标词典补主体、指标、单位，并通过240字符预算投影测试；计算器读同批结构值，不拆表格、不重取。
7. **真实复验继续反证**：ISO 历史题仍被要求补日期，根因是“当前日程”含“前日”，以及已被日期锚定的“当时”一律遭拒。修指代/相对词分流，保留“昨天+无关ISO日期”仍拒绝。随后全量抓到财报补标签丢了“2024年报”名称，恢复名称而不撤字段标签或放宽旧窗口测试。
