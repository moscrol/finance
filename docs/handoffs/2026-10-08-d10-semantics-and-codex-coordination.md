## 2. 发现顺序与实施

1. 原红控制证实：基表缺表/缺列也被写为“无数据”；常量退出与空值混标；晚/缺失/非法时间戳都可能被文案断言“被重写过”。新增 API 字段未实现也有 AttributeError，故不能把17红全部说成独立行为缺陷。
2. `market_feature_store/market_regime_vectors.py` 在**原来同一份 SQL/组装逻辑**上增加 `MarketRegimeVectorResult`：基表 `available / empty / query_failed` 与辅表查询失败列表分开。原二元 `load_market_regime_vectors` 接口和值不变，赚钱效应 regime 的调用不迁移。
3. `market_regime_analogs.py` 的同一次标准化保退出原因：查询失败、范围内无非空观测、近常量；旧 `missing_features` 兼容列表保留，不再靠它断言源表状态。常量与全局缺维退出分母，不能笼统声称“已按覆盖率降权”。
4. 显式给当前窗签名缺维/非空天数，候选共有维数/全局可标准化维数及候选缺维；不改覆盖阈值、趋势公式、距离、排名或候选选择。
5. 时间文案仅说明基表记录时间相对单个 cutoff 的标记。晚时间戳不能区分首次迟入库与覆盖修订；辅表版本未核验，旧 `strict` 标记也不是逐日历史可知认证。
6. 材料把首题材涨停份额与全分布集中度、z相对量与绝对量、终点样本频率与路径问题分开；显示为0.00的舍入值不猜正负。未新增通用判官或提示词路由，不改模型设置。
