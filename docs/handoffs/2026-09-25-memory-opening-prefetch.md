## 发现顺序与决定

| 发现 | 选择 | 被否方案及原因 |
|---|---|---|
| 工具可调不保证首请求有记忆 | 装配时复用 memory_lookup_runner，加入 opening_prefetch | 只加强提示词仍依赖模型选择；另造召回器会分叉相关性/可靠性口径 |
| 部分研究题默认不授权记忆 | 明确主体研究题默认授权，显式白名单/材料权限仍优先 | 无身份回落 default 会串号；对所有题无差别读取扩大私有读取面 |
| 只有显式回忆问题有先验落点 | 为自动预取研究题加可选 prior_recall | 必交先验会迫使空台账编造历史；市场事实槽不能装记忆 |
| 开口消息原将预取统称事实 | 标注用户先验；终止与后验校验拒绝事实绑定，gap 不得作判断 | 只贴 evidence_tier 而不校验引用，不能阻止错误引用 |
| 省略主体的纠偏下一轮可能召回不到 | 透传被纠正完成稿的 turn_intent.primary_subject | 从纠偏短句猜新主题或扩召回全集会带入无关记忆 |
| 现有加载器可吞读取/解析失败 | strict 路径显式失败；旧 CLI 默认兼容 | 把错误当空结果，会让模型误认为已经检查过且无笔记 |
| 私有文件读取没有硬时限 | 1秒子期限与根期限及合成保留取交集，两槽无积压，迟到不回灌 | 每轮新线程会无限堆积；退出等待线程池的 context manager 会让超时失效 |

`material_only/local_only` 保持既有无预取合同。这里没有实现硬取消磁盘 IO，最多两槽长期占用后回 busy；进程退出仍可能等待未完成的底层读取。
