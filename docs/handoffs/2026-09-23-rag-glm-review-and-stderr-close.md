## 其他审查意见的处置

- P3 发生位置成立，影响范围需收窄：宿主完整核对 `kb_rag.py` 捕获链，末尾防御性 `except Exception` 会兜底 ValueError，原报告只看到前面的具体异常分类便断言穿出。补修恢复的是 worker 的类型化退出错误，不能把旧行为夸大为工具层未捕获异常。原报告不改写，此处保留宿主裁决。
- P4 聚合诊断首项为空：没有直接改为“取任意非空诊断”。当前 `last_error_type` 与诊断选择同一个首错 worker；独立换取另一 worker 的诊断可能让二者错配。多实例逐项诊断可另设计，本片不扩合同。
- P4 单实例 close 不从注册表摘除：核对生产调用入口使用 `close_all()`，它先清注册表再关闭实例；直接实例 close 不是现有公共恢复入口。本片不扩大为注册表重构。
- P4 全局模块 monkeypatch：保留为同进程后台线程的隔离注意事项；不能由此推出 xdist 的不同进程会共享补丁。本次新测试只 patch 实例方法，用 Event 固定交错，不 patch 全局 os.read。
- 报告中的 fd 复用疑点未复现，不宣称已修；本补丁只覆盖上述两种确认关闭的异常形状。静态报告中的总体措辞也不扩大为任意并发交错已证明。
