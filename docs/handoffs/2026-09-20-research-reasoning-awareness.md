# 研究求证意识：第一片实现与不启用决定

## 背景

用户先提出用流动性运动链分析市场，随后明确纠正：希望 8792 从底层原理追问约束、激励、机制、证据与反证，
但不把流动性、宏观或任何固定分析顺序变成默认模板。授权是“开始落实”，不是授权跳过验收或切生产。
主检出有大量他人修改，本片从 `gitea/main=728f3271` 独立建树 `~/fwp-wt-research-reasoning-awareness`。

## 发现与选择

1. 生产 8792 是 `bf662e9310ff` 独立快照。修改主检出不会影响服务；本轮不改 launcher、不重启生产。
2. 主干已有专项研究纪律、动态 Episode 输入、批后进展与预算通道。因此以 `research_reasoning.py`
   共享纯文本接入这些入口，不加研究循环、状态对象、工具或副作用。
3. 未合的 `feat/adaptive-research-loop` 已做 PLAN 视角及支持/反证状态，不再复制。
   该枝尚未证明观察后的自主改向；本片不依赖它，也不强加额外计划轮。
4. 市场态知识门控有既有消融依据。本片不撤门、不注入流动性笔记全文；使用独立默认关闭开关实验。
5. 用现成 sidecar 与 Workbench probe，独立账号、同代码同模型，实际完成 8 个 run。
   已看过的失败不重写；非材料题、简单题与后续人工挑战分别计数，不捏造成完整留出评测。

| 方案 | 结果与理由 |
|---|---|
| 全局注入流动性/宏观框架 | 否：违背用户不固化视角的澄清，且可能重演知识层注入降低直接性的旧问题。 |
| 每轮强制列视角、反思再回答 | 否：改变预算与循环，简单问题增加负担，也与既有在途 PLAN 实现重复。 |
| 只加初始口号 | 不足：工具观察后也需要能看到同一求证提醒，因此接入原预算事件。 |
| 新增语义裁判或放松完成门 | 否：本次没有足够标注和对照，不以“能交付”为由降低证据资格。 |
| 默认关闭、双入口指导、原通道批后提醒 | 采用：变更可隔离、可回退，能精确验证送达和权限不变。 |
| 送达成功后立即启用 | 否：真实公开稿仍过强归因，部分题目交付失败，不能把机械测试当质量验收。 |

## 实验的意义与限制

新提示开场和工具返回后确实送达；quick_fact 两处都没有注入。
但开启组的行情答案仍把“抛压衰竭”“中小市值修复”当作已证实解释，
虚构材料题受既有 evidence 合同拦截；反证追问开组因未知 E1 引用而降级。
关闭组也有错误，且有一条追问交付成功；一次配对不能判定因果或收益。
