# 区间累计收益与判官不可用提示修复（2026-09-22）

## 背景

2026-09-22 的真实 local-only 自然模型验收中，东阳光个股累计收益接近正确，但申万综合、芯片、氟概念和复盘会综合的窗口累计值错误，氟概念相对强弱方向也反了。原始日线已在工具证据中，问题位于模型自行汇总/比较，而不是查询缺行。独立判官最终不可用，因此本次不以真实模型重跑证明修复。

## 决策

1. **新增受限只读摘要**：在现有 `finance_query` 内对 `stock_daily`、`sector_daily`、`sw_l1_daily` 提供 `return_compound_pct`、`return_valid_count`、`return_observed_count`，可选单日最小/最大涨跌幅。只允许代码维度、代码筛选和完整窗口，先聚合再限组数；不开放 `derived_calculation`，不做自由文本算术解析器。
2. **收益口径固定为已观测日逐日复利**：`100 * (product(1 + pct_chg / 100) - 1)`，包含首日涨跌；坏值、低于 -100%、重复日期或空主体使收益/极值未知，不跳过、不补零。证据带请求窗口和实际日期集合，卡片超过现有 240 字符模型预算直接拒绝并提示缩窗。
3. **相对强弱要求同窗同日期集合**：写手与判官提示明确平均日涨跌幅不等于累计收益，收益差使用百分点，样本数不证明交易日完整覆盖，结构绑定通过不证明数学正确。
4. **判官不可用只改公开提示措辞**：仍按原策略交付 `partial`，但首句改成“仅通过证据关联的结构检查，不代表计算或结论正确”，不宣称自动拦错完成，不扩大判官预算或重试。
