## 方案与被否选择

| 选择 | 被否方案 | 原因 |
|---|---|---|
| 已公开 finance 分支新增补证目录 | 继续只交本机 Downloads | 用户要求云端直接可读，本机路径不解决访问缺口 |
| 单独新目录、原快照冻结 | 覆写之前的来源索引/指纹快照 | 两次授权不同，应保留时间与来源范围 |
| 公开可直接抓取的 Markdown/JSON/SQL/Python 文本 | 提交 ZIP 或数据库 | agent 无需解压即可沿链接核验；仓库也明确禁止 ZIP/整库入 Git |
| 保留历史收据身份 | 把“未上传”的旧采集收据重写成发布后证明 | 旧收据陈述采集阶段，公开核验另出新收据 |
| 固定提交链接 + 匿名回读 | 只展示 push 成功或已登录 gh 可读 | push 不证明匿名云端能取；提交号固定版本避免分支内容漂移 |
| 暴露定义/实现疑点 | 顺手修算法、回填空表或给新阈值 | 本轮是证据交付，不是语义裁定或生产变更授权 |
