## 选择与被否方案

| 方案 | 判断 | 结果 |
|---|---|---|
| 先留写手实包，区分结束、语法、分句、语义 | 旧字符计数不能回答这些问题；仅记录内容与元数据，不收隐藏推理 | 实施隔离诊断 |
| 自动执行或替换JSON中的表达式 | 会改变引用原文与接收边界，且不解决主体/比较错误 | 否决 |
| 全局启用JSON模式或因一次成功新增生产开关 | 文档支持不等于供应商实际约束，语法合法仍不能通过材料审查 | 仅留隔离实验 |
| 继续叠“优先遵守材料”提示 | 仍把相冲突的义务交给模型裁决 | 否决，生成时排除不属于本合同的模板 |
| 清空所有材料方法指导或更改原题 | Q14等题需要适用纪律，原八问不可缩减 | 否决，保留typed纪律/可选求证指导/原义务 |
| 只靠压缩提示签速度与质量修复 | 最新输出反而包含更多声明，且金融错误与判官超时仍在 | 不作因果结论 |
