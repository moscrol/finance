## 发现与实现顺序

### 1. 仅恢复正文排版，不放宽 finish 准入

`finish_candidate.py::_layout_candidate` 解析一个完整的候选信封，只对**顶层 draft 字符串**
中的字面 LF/CR/TAB（换行/回车/制表符）转义；其余字段仍由严格 JSON 解码器读取。
正文内有效转义保持原样，未转义引号仍终止字符串，不猜哪里是正文、哪里是控制字段。

候选保留继续核对任务身份、绑定、历史结果引用、安全正文和已有资源边界。其他字段的
控制字符、任意深度重复键、转义拼法重复键、未闭合对象、坏转义、尾随第二对象/正文、
工具控制字段、外任务身份及伪造引用均不能借排版修复获准保留。
正式 `admit_finish` 仍返回 `not_json_object`；保留不等于准入或完成。

解析层保留原字符；既有公开正文清洗仍会把 CRLF 归一为 LF，这是呈现规则，不是新删稿逻辑。
候选账仍限同进程，不从持久事件猜稿恢复。

### 2. 有限核验发现进入原修订闭环

新增 `evidence_claim_review.py::review_evidence_claims`，只解释已绑定证据的既有投影：
D10 历史窗口表、D4 同日主线文本、`finance_query` 板块行情/题材热度字段。
不引入新查询，不擅定哪家来源权威，不把近名板块自动视为同一实体。

| 发现代码 | 核验内容 |
|---|---|
| `historical_window_minimum` | 用实际表内窗口均值求下限，不写死8 |
| `endpoint_not_path` | 终点收益不足以证明期间无下跌 |
| `historical_contraction` | 涨停均值已有下降，不能概括为不收缩 |
| `entity_metric_mismatch` | 所引百分比对应另一板块全名 |
| `source_caliber_conflict` | 同日来源计数冲突/近名概念口径需说明 |
| `uncalibrated_watch_threshold` | 观察阈值需校准依据或明确假设标签 |
| `uncalibrated_win_rate` | 胜率需分母、条件与验证方法 |

`SemanticEpisodeVerifier` 保留全文、追加具体批注，私有产物记录发现、证据ID与待修订句索引。
`semantic_repair_feedback()` 将**原句＋原因**传给 `ContinuousTurnAdapter` 的既有同会话修订入口，
仍由原 deadline/预算决定能否继续，不额外授予调用额度。判官 passed 不能盖过机械发现；
判官不可用时保留 unavailable，不冒称模型拒收。

补稿可以追加更正，但旧错误正文仍在时不能静默晋级 completed。这轮证明的是保留、发现和
反馈通路，不是模型一定会改对，也不是通用金融事实核对器。

## 决策对比

| 方案 | 评价 | 决定 |
|---|---|---|
| 全局 `json.loads(strict=False)` | 同时放宽身份/绑定等控制字段，扩大信任边界 | 否 |
| 随意截取花括号/猜引号/提取零散正文 | 无法证明完整信封和同任务归属 | 否 |
| 仅顶层 draft 的三种排版字符恢复 | 可解释、能构造恶意反例；正式准入保持严格 | 采用 |
| 质量问题直接删全文或用恢复稿覆盖 | 信息丢失，错误来源不可追溯 | 否 |
| 原稿＋具体证据批注＋原会话修订 | 保留信息，同时不把它认证为事实 | 采用 |
| 通用正则事实判官/未识别即通过 | 名称、日期、来源、统计范围稍变就会误判 | 否 |
| 只诊断已知投影与观察形状 | 覆盖有限但可以证伪；未知留给既有语义核验 | 采用 |
| 新增模型调用/幸运重跑旧题 | 无法证明机制，且超出本轮授权 | 否 |
| 撤保护测试与固定原件双向预期 | 验证测试确实能发现回归 | 采用，明确非独立QC |
