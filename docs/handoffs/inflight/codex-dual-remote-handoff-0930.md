## 这个分支做什么
补双远程盘点规则与可跨机器读取的共享交接，避免把云端已完成实现误派重做。

## 决策与被否方案
- Gitea 作为集成主干，共享分支两端同 SHA；不用双端独立合并或强制镜像。
- GitHub 当前公开，只发布共享文档；内部审计留私有归档，不整枝公开内部历史。
- 验收既有测试隔离分支，不重写实现；Mac 未提交测试保留待覆盖比较。
