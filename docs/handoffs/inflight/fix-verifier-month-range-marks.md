## 这个分支做什么

数值门（`episode_semantic_verifier` 的「待核」点名）不再把月份 / 日期、两端有据的区间当无出处数值；模型自拟判据照旧点名。来源 10-06 8792 探针 T1-turnover。PR https://github.com/moscrol/finance/pull/64 （未合，须用户确认）。展开见 `docs/handoffs/2026-10-06-verifier-month-range-marks.md`。

## 决策与被否方案

| 采用 | 未采用 | 理由 |
|---|---|---|
| 月份掩码容空白、认一月到十二月 | 只补「6 月」 | 阿拉伯「1月」早按时间点掩，汉字同等；时长（以上 / 两月）照审 |
| 年月日也容空白 | 只改月份 | 否则「6 月 30 日」剩「30 日」 |
| 区间两端各过原判据 | 按算术推导认 | 推导会放过 44% 这类自算数 |
| 整数端点不借观察值 ±0.5 | 与单个数对称 | 普查：对称版放过「后续2-3个交易日」 |
| 存证裁剪件当夹具 | 手写证据 | 手写带检查器词表；裁剪件重放与原存档逐字节同 |
