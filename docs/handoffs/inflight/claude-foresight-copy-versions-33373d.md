## v3.0 的一条设计决定：数字换通道，不是删掉

内部审计数字（第 5 页 77/71/1/5、第 7 页 85/15/3）**从口播撤下，但仍完整显示在 PPT 上**。理由：路演听众用耳朵记不住四个数，但复核的人需要它们，而且这两组数各有严格单位口径（枚举窗口 ≠ 独立验证；事件 / 交易日 / 完整时间块 ≠ 独立个股样本），凭记忆临场报极易越界。演示纪律写明：被问到确切数字时**指屏幕照页面念**。

`check-delivery.py` 为此加了一对**双向**断言：这些数字**必须在**可见文案里，且**必须不在**口播里（正则扫「七十七 / 八十五 / 七十一个 / 十五个交易日」）。只钉一个方向，另一个方向的回退就会静默通过。
