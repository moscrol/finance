## 决策与被否方案
- 原phase/定位ID保留；否计划提前消费待办。合成结算按ID去重并同步确认。
- 任务writer先锁再读并全程持有；本机flock不按时间抢占、不删锁文件。
- 实例控制锁覆盖run/manual_drive/resume；否只按task锁，共享inbox仍串线；不同实例不同任务可并行。
- step/close非阻塞互斥；否竞争异常把原驱动标结束。close须等当前step返回，不是外部请求取消接口。
- 返回plan释放锁；否直接执行，锁不证明未知效果已对账。隔离检出仍是作者复核。
