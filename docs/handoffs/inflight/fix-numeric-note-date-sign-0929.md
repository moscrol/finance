## 这个分支做什么
修待核说明的三种误报：句中短日期（本句引用了该日已绑定证据才按日期掩）、显式正号、`涨跌幅 / 换手率 / 振幅` 百分比字段（只支撑带小数的写法）。同时把 #76 L6 结线（受托代拍）记进台账。详版：`../2026-09-29-numeric-note-false-positives-and-l6-closeout.md`。

## 决策与被否方案
- 短日期只认本句引用的已绑定证据：全篇有同日证据就掩，会放过 `若价格落到9-11` 这类无单位区间。
- 百分比字段不并进通用数量集：整数阈值会被随便哪行涨跌幅巧合支撑（普查实测）。
- L6 不再发题，剩余额度 23 不用；工具口径 NOT_EXERCISED 保留，不追认 PASS。
