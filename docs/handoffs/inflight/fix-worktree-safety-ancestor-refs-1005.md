## 这个分支做什么

`worktree_safety.context_blockers` 只认「引用落在树本身或树里」；指向祖先目录（主检出根、`/private/tmp`、`$HOME`）的启动器引用不再挡嵌套树。PR #49。

## 决策与被否方案

| 选择 / 被否 | 理由 |
|---|---|
| 单向规则 / 不加豁免名单 | 名单要人维护，下一个容器目录还会撞 |
| 删 09-25 的 `$HOME` 特判 / 不留作第二层 | 只丢新规则本就不算的引用，变异杀不到 |
| `${VAR:-…}` 尾 `}` 另开任务 / 不并入 | 改的是采到哪些引用，要单独先红后绿 |

完整背景：`docs/handoffs/2026-10-05-worktree-safety-ancestor-refs.md`。
