## 决策与被否方案
- **壁垒论点**：选「知识体系是唯一不可复制的输入（1000+ 学员两年追问收敛、正在代码化）」+ 四层可积累资产（09-06 spec §11）+ 数据飞轮 + 反定位 / **否了**用户原话「用户为我的知识体系付过费 → 需求已验证」直接入文——与 v0.8 §2.1、v0.9 三处「组合服务、付费需求独立验证」口径自相矛盾，评审一句「买的是课还是老师的票」接不住。改为拆两句：需求侧可说「愿意为学会看付钱、付得起千元/月量级」；壁垒侧不用付费当论据。
- **「自进化」用词**：对外只写「规则库自进化，框架母本由人写人改」，不裸写自进化（会被读成 AI 自训练预测；spec §12 已裁「方法检验替代模型自我训练叙事」）。
