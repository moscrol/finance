## 决策与被否方案

| 采用 | 被否方案 | 原因 |
| --- | --- | --- |
| 准备模式与发布结果分开，父子均返回不可发布码 | 仅父参数挡发布、子进程返回 0 | 真实误接线反例证明普通发布路径会放行，语义必须跨进程保真 |
| 复用原锁、克隆和 canonical 列定义 | 新建生产写者、手动替换库 | 原编排已经处理并发写者、运行身份、失败保留等合同 |
| 同日报价直接保留供应商参考价 | 用前一根裸收盘重推除权/IPO 参考价 | 两者经济含义不同；不把后日参考价倒灌历史日 |
| NULL 换手率 + 逐股观测元数据 | 百分比单位正确就当 canonical 真值 | 量纲一致不等于分母相同，既有代拍已允许 NULL |
| 全新准备目录、首轮原件保留 | 重跑覆盖失败或过渡副本 | 需要保留发生顺序、负面样本和旧版本边界 |
| 继续阻断恢复发布和部署 | 股票日期已对齐就换库 | 板块身份、市场空值、其他数据门和精确工程验收仍未闭合 |
