2. 查询代码地图并读当前沙箱、表格助手、计算编号与产物实现。当前 main 是 prelude v2，

   辞典行按字符串键首次出现顺序取并集；列表/元组行按最大宽度生成第N列，短行补 None。
   外层生成器只消费一次，数据不回填 0。两种行混用、非字符串字典键或标量行明确报错，
   不猜测金融含义。显式第三参数 None 仍报错，避免把非法三参调用误判为两参。
5. 贯通测试又修正两处对既有 API 的错误预期：`ArtifactFile.filename`（不是 name）；
   CSV 带 UTF-8 BOM 且整数浮点按原格式输出。保留 1F/65P、1F/119P 原件，不改导出合同。
6. 六文件定向回归 120P；全仓 Ruff、diff whitespace 检查通过。这一阶段工作树有本次修改，
   不把基底 SHA 的脏树收据当成候选提交签字。提交后独立干净检出的门禁另见最终收据。

## 决策与被否方案

| 选择 | 被否方案 | 理由 |
| --- | --- | --- |
| 从 main 独立前向实现 | 整体移植旧材料提交 | 材料权限、输入身份和重算上下文有不同合同 |
| prelude v4 | 留 v2 或复用旧 v3 | 同脚本同输入的不同执行环境不能共享计算身份；旧 v3 已有历史记录 |
| 省略参数用独立 sentinel | 用 None 同时表示省略/显式空值 | 保持旧三参数非法输入的拒绝行为 |
| 两参推断只消费一次外层迭代器 | 扫描生成器后再次遍历 | 第二遍可能已无数据，成功空表会掩盖丢失 |
| 非字符串键拒绝，混合行拒绝 | 键转字符串后仍用原键查值，或猜行含义 | 前者可能静默丢数，后者无法可靠对齐 |
| 只给两参短行补 None | 给原三参也补齐或全局改产物渲染 | 限制兼容扩展的影响面；缺失不等于零 |
