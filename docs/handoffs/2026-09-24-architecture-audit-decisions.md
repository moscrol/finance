## 方案取舍

| 决策 | 被否方案 | 理由 |
|---|---|---|
| 复用现有检查脚本和权威清单 | 新建综合健康服务/能力清单 | 问题首先是证据与发布状态混算，不是缺少另一套实现 |
| WARN + None/error 表达未知 | 缺报告当零、或悄悄改变 CLI 退出合同 | 保留调用方兼容性，同时去掉假绿；exit 0 仍只能解释为工具执行成功 |
| 明示 inventory_only | 文件齐全就叫系统稳定 | 文件存在不证明内容质量、时效或模型实际消费 |
| 本单修审计器，业务恢复交原 owner | 直接补数/解 KB 冲突/重建索引 | 他人改动与生产授权均有独立边界，绕过会破坏版本和来源证据 |
| 用户身份显式绑定 | 把无 user 参数等同字面 default | 服务默认值来自启动器，两个用户空间实际内容不同 |
