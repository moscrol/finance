## 方案选择

| 方案 | 评价 | 决定 |
|---|---|---|
| 关闭数字门或条件句全豁免 | 会放过真实未授权阈值，消掉误报同时消掉保护 | 否 |
| 修改全局数字正则，跳过字母旁数字 | PE10/科学计数/编号等意义不同，易扩散到其他口径 | 否 |
| 仅去掉 `（E27）` 这一种括号 | 单例补丁，英文括号、小写、多引用仍会错 | 否 |
| 在语义校验器另造引用正则 | 与协议语法会漂移 | 否 |
| 从公开稿永久删引用 | 丢证据链，也让表外引用检查失去输入 | 否 |
| 复用协议语法，仅屏蔽数量提取副本 | 两端一致，公开原文和其他检查不变 | 选 |
| 改引用边界或重写完整词法解析器 | 有潜在扩展价值，但会改变现有引用合同，超出此片 | 本轮不做 |
