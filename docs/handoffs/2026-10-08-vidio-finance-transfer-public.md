## 决策与被否方案

| 议题 | 方案 | 评价与结果 |
|---|---|---|
| 审查对象 | 只搜 main | 会把未合入实现误判成不存在，否决 |
| 审查对象 | 完整补丁树 + 干净基线 | 选用；两者同环境、同选择条件 |
| 公开迁移 | 推原历史后删私有文件 | Git 历史仍含材料，否决 |
| 公开迁移 | 新 main 子提交，原包仅本地追溯 | 选用；进一步检查源码、注释和测试样本，不仅检查 JSON 文件名 |
| 导出范围 | 整表带出后加警告 | market 范围会披露个股/来源；cutoff 外数据仍在，否决 |
| 导出范围 | 显式范围、日期与可知戳均过滤，无证据表省略 | 选用；信息不够时少披露，清单解释省略原因 |
| 画像字段 | 仅顶层白名单 | 允许父字段可夹带任意子字段，否决 |
| 画像字段 | 逐层投影、外置 userspace、人工审阅正文 | 选用；结构检查不等于内容隐私或披露授权 |
| 数据还原 | 删除原目标再写 | 中途失败会丢原库，否决 |
| 数据还原 | 临时库校验后原子且不覆盖发布 | 选用；目标存在即拒绝，SHA256 仅证明完整性而非来源真实性 |
| 剧本命名 | 总成员数足够、全局闸通过就全命名 | 单例留出簇或无留出支持簇可混过，否决 |
| 剧本命名 | 每簇支持、分区 ID 校验、有限数检查 | 选用；依然是探索性诊断，不是时序预测检验 |
| 相似性 | 相对领先/相关组数 = 绝对相似/独立证据 | 否决；多个窗口可一样像或一样不像，相关不证明独立 |
| 相似性 | 同距离均值+趋势分解，匹配须在训练半径内 | 选用；不另造模型，不把经验支持范围称概率置信度 |
| 测试证据 | dirty-tree 绿当最终 SHA 绿 | 否决；固定提交后复跑并校验收据身份 |
