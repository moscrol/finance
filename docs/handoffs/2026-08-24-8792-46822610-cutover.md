   本次停机约 1 分钟（含重试与启动）。下次直接在两条之间加等待与就绪轮询。
2. **服务起来 ≠ 端口能用**：`launchctl print` 报 `state = running` 时 8792 还没监听，
   本次约 40 秒后才可达。别用 launchctl 状态当就绪判据，要轮询 `/api/health`。
3. **不要用 `scripts/deploy_workbench_runtime.sh` 做版本切换**。它是 rsync 进**现有**快照，
   而快照本身是 git 检出、`source_revision` 取的是快照的 git HEAD——rsync 完代码变了、
   HEAD 没变，会得到「标签说 A、代码是 B、dirty=true」，比切之前更难取证。
   版本切换走本文这套蓝绿（新建 detached worktree → 重指 symlink），见
   `docs/workbench/canonical-8792-cutover.md`。
4. **裸跑 deploy 脚本会重演 2026-08-22 事故**：它默认 rsync 源是主检出
   `/Users/a77/finance-workspace-private`，而主检出长期停在别的分支（本次是
