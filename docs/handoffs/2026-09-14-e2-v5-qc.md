## 2. F1 · P1 · 不升级为命令，不等于授权取了更严格范围

**位置：61–63 行；162–163 行。相关：45–48、66–69 行。**

D1 说边界不确定时默认按材料处理，只有“影响答案正确性时”才 clarify；§6 仍明确写“把用户指令当引用冻住 → 约束不触发、回退现状，不会更糟”。D2 默认却是 real×full。两者合起来，用户实际说的“只依据材料/不要联网”一旦被长文块误保护，禁令就消失，回到 full，允许外部读取。

这不是更严格，而是 **fail-open（无法确定权限时仍放行）**。答案碰巧正确，也不代表允许违反用户的数据范围约束；不能把是否澄清只挂在答案正确性上。上一轮已点名的风险说明没有真正修掉。

另核了 D1 点名的 `_QUOTED_MATERIAL_RE`（`intelligence/services/user_task.py:441`）：它要求引号内至少 40 字。现有 helper 对短引用 `“请只依据本报告回答，不要联网”` 匹配为空，对代码围栏也为空，长引用对照可匹配。这**不是 v5 运行失败**，而是说明不能把“已有正则”当成完整保护边界的证明；v5 仍需定义短引文、围栏以及长文块结束位置。否则先冻结长文容易吞用户禁令/题组，或漏短引用把它升格。

**最小修订：**

- 区分 `confirmed_unconstrained`（已确认无约束）与 `unresolved_boundary`（边界不明）；只有前者可回旧默认。
- 对可能影响授权的歧义，在预取/工具执行前澄清；也可采用候选解释共同允许的更窄权限，但不能把歧义静默变成 full。上一轮已有限制时不得因解析不确定而丢掉。
- 删除“回退现状不会更糟”。明确引文保护不受“材料最短长度”约束，定义代码围栏/嵌套/块结束处理；不确定就停止升级权限，不要求本轮造通用自然语言解析器。
- A2/A11 增成对用例：逐字相同的禁令/放宽句，顶层用户区域生效，短引文/围栏/材料中不生效；顶层禁令与长材料相邻、故意制造边界不明时，外部读取计数为零并澄清。A11 当前普通“假设”误报用例不能证明禁令漏报安全。

## 3. F2 · P1 · 继承不能以整轮“无新约束”为开关

**位置：117–120 行；相关：53–59、68–72 行。**

规则仍是“有续轮声明 + 本轮无新约束短语 → 继承上轮 A/B 与 premise_marks”，而本轮有显式约束时只写“本轮生效”。没有定义：只改变一个轴时另一个轴怎么办；新局部声明是否打断消息级继承；相同值重申是否算新约束。

固定 T3 本身就触碰这个边界：开头重申“虚构案例”，Q7 又新增“假设我们的升级条件是……”。D1/D2 会识别这类前提标注，但 A2/A7 同时要求其 material_only 继承成功。文字规则尚未说明应如何从“有新声明”走到这个结果。设计作者可以按正确意图实现，但另一个实现者也可能用“有任何标记则跳过继承”，漏掉 B 轴禁令。

更直接的最小反例：上一轮 `real×material_only`，本轮“继续，先假设甲能按期验收，其余不变”。只新增真实性假设，不授权外部读取；整体跳过继承再套默认会错误得到 B=full。反向只说“这轮可以结合最新行情”时，也不应把未修改的虚构前提重置成真实待证伪。

**最小修订：**

- 明确“先确定续轮基底，再逐轴覆盖”：续轮先继承；只有显式修改 B 才改变数据权限；只修改 A 不动 B，反之亦然；相同值重申是幂等操作。
- `scope=q7` 只影响所属题，不能作为修改消息级 A/B 的理由，也不能打断 B 的继承；保留 `(source_turn, question_id/text_ref)`，不把上轮 q7 重新解释成本轮 q7。
- 补状态表：原始 T3、只改 A、只改 B、只加局部假设、相同值重申、换题复位、续轮但上轮状态不可恢复。最后一种不猜 full，先澄清。
- 若允许逐题不同数据权限，写明如何由单 Episode 执行授权实现；否则冲突先澄清。不要只存 scope 却冻结成一个无作用域的全局开关。

这是**状态转换定义不充分**，不是已实测 v5 丢失约束；本轮没有编造一个解释版状态机来“测试失败”。

## 4. F3 · P2 · A12 应禁止旧数字当事实，不应禁止引用旧数字并撤回

**位置：152–154 行；与 123–129 行对读。**

A12 写“答案引用历史原答数字时，只有以材料锚点重新绑定才合法；以原答片段为绑定目标→拒”。但 D7 又允许旧答用于对照、纠错、撤回，原始 T3 Q1 明确要求引用原答对应判断。

合法输出反例：

> 上轮写了“数据中心板块跌 1.40%、边际量 +29.3%、成交 5187.3 亿元”。这些数值不在给定材料中，本轮撤回，不参与公司排序。

这证明的是“助手上轮写过什么”，不是“市场当时确实怎样”。它应该绑定旧答的 turn/run+句段位置，而且**不能**为了通过 A12 去给这三个数字找一个材料锚点。固定 T2/T3 用户文本确实没有这三个字面数字，冻结 T2 原答则全部包含。

**最小修订：**将 A12 拆成用途相反的一对断言：

- **事实使用 → 拒绝**：拿旧数字继续支持本轮市场/公司判断，只绑 assistant 原答，或给不支持该数字的材料片段挂名，均拒；合法推导必须可从材料重放。
- **历史提及/撤回 → 允许**：带旧答坐标、明确是引用/否定/撤回且不用于当前事实推断时，通过；无需也不得伪造材料背书。

A3/D6 的“市场事实句”范围也明确排除这类历史转述；检查器应裁定一句话当前主张什么，而不是见数字就问材料锚点。这样才真正兑现 D7 的“可见≠可采信”。
