## 方案取舍

| 决策 | 被否方案 | 理由 |
|---|---|---|
| 固定已合 KB 提交导出单个投影，临时重建标签 | 提交 KB 脏源、解他人的冲突、重建生产索引 | 不侵入其他 owner；把“代码可消费”与“生产已发布”分开 |
| 视角使用原读取器，另加只读审计脚本 | 新造 runtime、调用模型来猜是否装配 | 装配可用确定性代码直接验证，费用和副作用更低；模型使用质量留下一阶段 |
| 逐 patch 对原文/画像/上下文，明确未知人工条目 | 凭文章数和 known_gaps 文字判审批健康 | 文章存在不证明方法进入模型；提示文字也不能证明未经授权 |
| 批准值消失作为漂移，留 owner 语义裁定 | 自动重应用全部批准补丁 | 可能是有意删改，自动恢复会覆盖后续决策 |
| 复用 RPS5 加载器和六位精度常量 | 删除覆盖率断言、用较大 epsilon 放行 | 需要正确输入与规范化，不能靠松闸通过；一最小精度单位的错误仍拒绝 |
