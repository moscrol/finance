## 按发现顺序

1. 在 main tip 上重放，句 13 仍被删，句 10 不删（#868 已修）。
2. 先写用例（放在 L6 货币条件用例旁）：型号、月份、L6 原句端到端、反例、证据侧背书。修复前 12 红 4 绿，4 绿是反例守卫。
3. 第一版把月份并进 `_DATE_TOKEN_RE`，代号掩码放在日期掩码之后（早掩）。数值门相关文件跑出 4 红：`test_episode_numeric_citations.py::test_non_citation_numeric_tokens_are_not_exempted[CE4/E0/E027/E1000]`。
   - 这条钉原本是给引用语法左界做的探针，用数值门当观测点。
   - `E0`/`E027`/`E1000` 是畸形引用。引用门不认它们，数值门是唯一兜底，所以单个 `E` 必须留在数值视图里。
   - `CE4` 在 `episode_protocol.py` 自己的注释里就叫「认证名」，与 CPU1000 同类。
4. 复查表格路径时发现早掩的副作用。预检的表头识别要求表头行 `not re.search(r"\d", …)`：
   - 早掩后，`| 条件 | 10月 | 11月 |` 或 `| 条件 | H100 | A100 |` 会被认成条件表头。
   - 数据行 `| 成交额跌破 | 100亿 | 80亿 |` 于是只留条件列，阈值被筛掉，等于放宽。
   - 两个掩码因此都挪到「抽数前一刻」。补两条表格用例，用 monkeypatch 核过三种放置：修复前表头行也被误删；早掩全漏；现方案只删数据行。
5. 用修复树重放 L6-N1：句 13 不删，句 10 不变。逐数量核对后更正了旧 README 的一处说法：句 13 的 `1000` 其实有出处（已绑定 E26「海光1000系列CPU」、E27「CPU1000系列」），真正无出处的只有 `10月`。
6. 全存档差分重放（`diff_replay_archive.py`），两臂只差两个掩码。扫 4078 份，1266 份可重建。首跑结果：
   - 11 句误删解除（首版文档误写 12，是把变化清单的行数当成了解除句数）。
   - 1 句新删：「③未来20交易日双红日计数≥7与否。」。它的 `≥7` 原先只被证据里数据源标签 `AKShare · D7 逐季财报` 的 7「背书」。
7. 看兄弟会话的 L6 批 2 存档时，发现 `scripts/judge_loss_point_replay.py::_rebuild_outcome`（09-09）把证据的 `observations` 置空。数值门 09-21 起读观察值，所以首跑比生产少一路支撑。补回观察值后重跑（`diff-replay-archive-with-observations-eed1ec80a.json`）：
   - 14 份 episode、10 份不同稿有变化。
   - **9 句误删解除**，新删仍是同 1 句。
   - 少掉的 2 句在生产里本来就没删：`10月` 碰巧被值为 10 的观察值「支撑」。
   - 修那个重放工具另开了任务，不在本 PR。
8. L6 批 2 的 T3 存档（90 个观察值）：生产删了句 13/14/15/22，修复后句 22（`…（10月末三季报窗口）`）解除。13/14 是批 2 的新形状，15 是泛指量词「一个报告期」。

## 决策

| 决策点 | 方案 | 评价 | 结果 |
|---|---|---|---|
| 月份放在哪掩 | 并进 `_DATE_TOKEN_RE`（用户建议的字面做法） | 那一步也喂表头 / 标签识别，月份列头会让条件表漏阈值 | 否 |
| | 独立 `_MONTH_TOKEN_RE`，只在抽数时掩 | 语义同「月份像日期一样不是数量」，不碰分类 | **选** |
| 代号规则 | 修改 `_ARABIC_QUANTITY_RE` 加 lookbehind | 固定宽度 lookbehind 会在 `CPU1000` 内部从 `000` 重新起配；还会改变证据侧日期碎片（`-22`→`22`），反而放宽 | 否 |
| | 独立掩码 `_ALNUM_IDENTIFIER_RE`，按「名字」整体掩 | 可解释、可测 | **选** |
| 字母前缀的例外 | 一律豁免 | `PE20附近`、`PMI49.8`、畸形 `E1000` 会漏 | 否 |
| | 估值宏观缩写白名单 + 单个 E + 带单位 / 以上以下仍审 | 保守；白名单可能不全，缺的只会多删、不会漏 | **选** |
| 证据侧 | 只掩答案侧 | 证据里 `D7`/`H100` 这类代号会给答案的同数背书（重放实例 `≥7`） | 否 |
| | 两侧同一张代号视图（E 号先例「Match the answer-side quantity view」） | 只收紧；月份不掩证据侧，与日期一致 | **选** |
| CE4 钉 | 为它单开「以 E 结尾的大写串」例外，保住旧断言 | 以测试基础设施为由的特例，语义上说不通 | 否 |
| | 把 CE4 挪进新钉「不被读成引用 E4」，引用左界仍由 PE10 钉 | 保住原钉的意图（引用语法边界） | **选**（PR 里请用户留意，可一行回退） |
| L6 批 2 新形状要不要一并修 | 并进 #932 | 两者改的是「裸数不给金额背书」「计数不是字面证据」两条既有口径，需用户拍板；并进会让已验完的 #932 重跑四叶 | 否 |
| | 另开分支，改同一函数，由本会话接手（兄弟会话 `local_d1bf0c0c` 已把决定交给本会话，避免并行改同一函数） | #932 按用户原范围收口；新形状单独设计、单独留痕 | **选** |
| 回溯 | Python 3.11 原子组 / 占有量词 | `ruff.toml` 目标 py39，全仓无先例 | 否 |
| | 正则分段写死「字母+数字」交替 | 不会指数回溯；实测 1000 字符串 < 1 ms | **选** |
