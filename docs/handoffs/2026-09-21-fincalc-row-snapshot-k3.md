6. K3 场退出，轨迹有凭证解析失败，监控记录 40 回合停止阈值；native CLI exit0，但没有 REPORT.md/verdict.json，质量场未启动。三份局部探针不是完整规格裁决。本轮未自动重试或切模型。

## 决策与被否方案

| 方案 | 评价 | 结果 |
|---|---|---|
| 原样 `list(rows)` 缓冲引用 | 生成器后续赋值能覆盖先前行、键集合及宽度 | 否 |
| `dict(row)` / `list(row)` 浅拷贝 | 保护外层形状但嵌套列表/字典仍共享 | 否，新增嵌套断言约束 |
| 通用 deepcopy | 会引入与表格既有 JSON 转换不同的对象复制合同 | 否 |
| 逐行复用 `_json_safe` | 与旧三参消费时的数据表示一致，不新增依赖或序列化体系 | 选 |
| 沿用 v4 | 同脚本/输入可能得到旧版错误结果，却共用 calc_id | 否 |
| 升至 v5 并实测 calc_id | 区分 main v2、旧分支 v3、初版 v4 | 选 |
| 将原候选直接改掉 | 会破坏原封存证据与源 PR 身份核对 | 否 |
| 新修复分支 + 最终结果树外 | 原提交可重现，新版本单独接受验证 | 选 |
| CLI exit0 或局部 PASS 当独立通过 | 错把进程退出与评审完成混为一谈 | 否 |
| 凭证错误后自动重试/换提供方 | 扩大授权与额度消耗，隐藏首轮失败 | 否，本轮停在原始失败 |
