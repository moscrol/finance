# 字段质量门槛与新高语义：执行结果

**2026-09-29｜源码已同步、隔离验证通过；本轮未发布或重启 8798**

## 1. 本轮实际修改

### 请求字段不足，明确降级而不是继续报告完整成功

FinanceQuery 现在检查**本次请求的指标与返回切片**。日期新、行数非零不再自动掩盖空指标。

- 指标缺值或为 NaN / 无穷值：返回明确的 `quality_gaps`。
- Episode 保留仍然真实的名单、日期及有效字段，但状态改为 `partial`，并传播 `gaps`。
- 缺口同时进入整体观察文本、对应证据卡和 `query_basis.field_quality`，避免只复制证据卡时丢失限定语。
- 不可用指标不进入可供后续计算使用的结构化观察值；同一行其他有效指标可以保留。
- **合法的 0 不算缺失；没有请求的字段不要求齐全。**仅查询主线名单仍正常成功。
- 保留已有的时点、旧数据拒绝、权限、截止时间和资源上限机制；历史记录补充路径也保留质量提示。

这不是“所有 NULL 都有故障”。例如涨停状态已有明确的空值业务契约，仍按原契约处理。新加入的有限样本成交额均值也保留其明确分母语义，不把它误当作全窗口完整均值。

### 聚合不能偷偷忽略缺失输入

对普通数值聚合，在**同一条只读 SQL、相同筛选/分组/截断条件**中加入内部输入数量与有效数量检查，不另查其他日期、不换源。

例如输入为 `5、0、NULL`，SQL 求和会得到 5：现在保留这个可追溯的部分结果，但明确标注只覆盖 **2/3 条输入**，不能将其作为完整总量或排名依据，也不把这项不完整聚合投影为完整的可计算观察值。内部计数不会冒充公开语义字段。

### 新高空标记不再自动成为否定事实

- `sector_stock_daily.high_status` 和 `mainline_sector_daily.high_status` 的空值显示为 **“未知（新高标记未核验）”**，并显式提示缺口。
- 空字符串同样处理；来源中已有的明确“非新高”或具体新高周期标签不覆盖。
- 个股按**同日、同码**查询 `stock_high_daily` 核验正向证据；名单未命中也不单独证明“非新高”。
- 个股新高名单不能替代板块新高状态。
- 同步修正了工具使用说明，不再向 Agent 灌输“空标记就是非新高”。

**本轮修的是读取与判断语义，没有回填成分表标记，也没有做隐式跨源富化。**原生 `turnover` 也没有被拿来填主表换手率。
