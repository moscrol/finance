## 方案比较与理由
| 问题 | 采用 | 其它方案与取舍 |
|---|---|---|
| 优先增益 | 现有能力释放+深读+计算+续研 | 先换模型容易试但治不了材料丢失；重写底座会重复现有实现 |
| 判官 | 保留有效核心、按缺口补研究 | 全关不能保证回答变强；再加模板门会扩大误挡 |
| 知识库 | 复用relations/synthesis与现有索引 | 重建图数据库投入大；直接塞更多片段未必读到关键原文 |
| 方法飞轮 | 接固定协议到日常使用 | 第一刀通用化全部方法会扩大protocol且拖延真实结果 |
| 竞品比较 | 同题任务成果、计算和连续推进 | 融资、自述技能数、引用齐全不能证明整体能力胜负 |
