## 决策与被否方案

| 选择 | 被否方案 | 原因 |
|---|---|---|
| 用户指定现有 K3 | 继续要求等 Codex | 一个供应商额度失败不等于所有通道不可用；用户已选通道 |
| 40 次硬帽后停止 | 续跑直到有报告/绿 | 超原定预算；缺终审必须诚实保留 |

| 新 toy 仓复现后定性 | 只信内层 2P或把装置红全判缺陷 | 干净正控制和不同 fixture 的复现区分产品错误与量具错误 |
| 只审不修 | 发现门禁洞就顺手修改冻结树 | 当前授权不含修复；一改对象就变，旧收据不移签 |
| 原档不改，新增漂移补记 | 偷改 prompt 的“当前 main”成最新值 | 输入身份要保留事实；实际执行 before/after 才权威 |
| 探针作为有限证据封存，方法进知识笔记 | 安装长期 runner/全新通用工具或改共享 harness 脏树 | 单次复核不是工具投产；后续修复应把反例变正式回归 |
