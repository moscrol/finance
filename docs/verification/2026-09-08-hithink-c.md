## 2. 验收两条

### 每日涨停家数 vs `fact_market_daily.limit_up`（近一年 242 日）

| 项 | 结果 |
|---|---|
| 逐日完全一致 | **139 / 242 = 57.4%** |
| 中位绝对差 | **0** |
| 平均绝对差 | 0.66 |
| 差值范围 | −6 ～ +1（同花顺家数偏少） |
| 差 −1 | 65 日 |
| 差 ≤ −2 | 37 日 |
| 差 +1 | 1 日 |

口径：同花顺池子六年没有 `.BJ`。用旧题材涨停表的北交所家数去对差值，**222 / 242 = 91.7%** 能用「复盘会含北交、同花顺不含」解释（含本来就一致的 139 日）。还剩 **20 日** 差值对不上北交所家数，另有沪深口径差，不硬改任何一边。

09-07 例：`market_daily.limit_up=93`，新池 92；旧题材涨停表多 1 只 `.BJ`。

### `continue_day_cnt` vs `fact_limit_advance_daily.boards`

抽最近 20 个连板日、只比交集：**263 / 263 = 100%**。连板表通常 `min_boards=2`，1 进 2 不在旧表里，没拿去对。
