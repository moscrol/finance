## 6. 结论与待拍板

本记录只证明本批输入上的可复现构建、口径闭环和读数可见；**不把任何读数当作交易结论**，特别是 §2.2 的 `refuted`——它是 §4.1 定义与基准对齐方式的产物。骨架 §8.4 四件与区间涨幅高标取法已由第十段拍板（平台标注人机协作、可信、当参照；平台八段为准；量能比；前 10）。slice 1.5 两遍已落（§5.3 / §5.4，`tf-v0.2+6c00d6c2`）：八段、共性区间证据、训练 / 验证分离、转移约束、来源记忆、突破 / 下穿门控，一致率 16% → 33.3%（验证期 35.3%）、歧义率 44% → 21%。第三遍要靠外部输入：第二刀 C 类板块侧证据（分开顶部横盘与底部横盘）、全量参照历史重校准（限流后）、「升级」（主流主升 2.0）怎么看出来待创始人说；区间涨幅高标链在队列（spec §9.18、骨架 §1.5）。还需要创始人拍板的（spec §9）：歧义后是否保留最近有效阶段的记忆（§9.9）；水位标量进不进计分（§9.11）；「≤ 3 天且无放量的上穿 = 残差」这条接法是否认可，以及下方三段用流程量写的谓词候选（§9.13）。第八段关掉的：四维度门槛不由创始人给、从历史共性区间取（§9.12 / §9.15，替换旧 H 的方案已拟在骨架 §1.5 末条，下一步执行）；趋势中放量改作双向因子（§9.16）。第七段关掉的：突破窗口（§9.7）、并列组部分断板与组的衔接（§9.6 子问）、区间 = 腿、形态 = 高点不抬高 + 收敛、持续 = 3 天（§9.12）、两个容差与板块级赚钱效应的做法（§9.13）、上穿放量口径（§9.14）。此前关掉的：量能三档不进计分（§9.10）；旧 H 等四维度落成谓词后一并替换（§9.12）；最高标不要求唯一（§9.6）。C 类板块角色与候选规则 `money_effect_outside_volume_top3_below_ma` 留在下一刀，按第六段原则它是下方三段能否分开的前提。
