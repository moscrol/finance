### 净额 vs `fact_dragon_tiger_daily.net_amount`

| 项 | 结果 |
|---|---|
| \|新/1e8 − 旧\| < 0.01 亿 | **16,045 / 16,813 = 95.4%** |
| 中位绝对差（亿） | 0.0026 |
| 平均绝对差（亿） | 0.047 |
| 差值范围（亿） | −11.0 ～ +8.0 |
| 重叠窗旧有新无 / 新有旧无 | 295 / 570 |

不换算成亿会得到假的 2.7%——那是单位，不是数错。不硬改任何一边。
