## 3. AnswerSpec 质检：6/13 结构性假阳性

根因 `intelligence/services/ask.py:1478-1489`：`conclusion` 列表 5 个元素里只有第 1 个
含真结论，其余全是元信息，却一并进了 `answer_spec.summary` 当 claim，然后
`answer_model.py:834` 挨个要求绑定证据。

| # | 内容 | 性质 |
|---|---|---|
| 1 | `主题「X」（…）：{stance}。` | 框架头 + 真结论 |
| 2 | `图谱命中 N 概念 / M 公司暴露，证据 K 条；盘面触发：…` | **检索遥测** |
| 3 | `route_line`（洗词后 = `分析路径：…`） | **路由元信息** |
| 4 | `结论与交易含义由结构化规则生成…` | 免责声明 |
| 5 | `_conclusion_ttl_line(...)` | TTL 元数据 |

「图谱命中 0 概念 / 0 公司暴露，证据 0 条」是**对检索过程的度量**，结构上不可能有
证据。要求它绑证据是范畴错误。

**最硬的旁证**：A10 的最终答案只有 404 字、8 行有效内容，**那三行被判违规的文本
一行都不在里面**——质检在给从未呈现给用户的内部 claim 报错。

分类：假阳性 6（检索遥测 3 + 路由元信息 3）· 可争议 3（框架头+stance）·
另一种检查 4（「存在绑定到其他题材的主张」，需单独看）。

> 与既有待办对上了：上一轮 handoff 的「有意留下项」里已有
> 「洗词收敛到 humanize 单渲染边界 + `数据源状态`/`检索可观测` 移出用户 sections」，
> 并注明「golden 全域波动，需独立批次专门做快照迁移」。本次是从降级数据反向撞到
> 同一处。修法明确，代价也明确。

## 4. 任务契约未完成：根因在**路由**，不在门禁

### 4.1 C5 是一条完整因果链

| 步骤 | 事实 |
|---|---|
| 问题 | 「立新能源 2026-07-20 和 07-21 分别涨了多少、收盘价多少」——**纯查价** |
| 路由 | `invoked_skill_ids: ['theme-research']`，答案首行 `# 题材研究` |
| 契约 | `theme_analysis` 要求 `direct_assessment + chain_mapping + counterpoint` |
| 合成 | `state=accepted`、`reason_code=validated`、**28 个 claim 绑定 27 个**，过了确定性 + 语义两道门 |
| 门禁 | counterpoint 已绑定，但正文缺 `反证/风险/相反/但/除非` 任一措辞标记 |
| 结果 | **整份答案丢弃 → 192 字失败桩**「请补充数据源或稍后重试」 |

查价问题当然写不出反证。而系统里有对的类型：
`quick_fact = (fact_value, as_of_date, evidence_boundary)`，**不要求 counterpoint**。

**路由把它送错了 frame，门禁只是照章执行。**

### 4.2 这是同一道门禁第三次同型失败

`task_fulfillment.py` 的代码注释记着前两次（均 07-31 修复）：

| 子 bug | 注释原文 |
|---|---|
| `output_id in claim_id` 方向写反 → counterpoint 零候选 | 「905 字完整答案被整份丢弃，换成 190 字的『请补充数据源或稍后重试』」 |
| 反证本来无出处，要求绑证据是范畴错误 | 「counterpoint 永远判缺、整份答案被 fail-closed」 |

C5（08-02）卡在第三个条件 `marker_required and not marker`。

> **只要路由还会把查价题送进 `theme_analysis`，这道门禁就还会有第四次。**
> 前两次都是修门禁的判定条件——修的是症状。

## 6. 方法论

- **先校准分母再排优先级**。我用错误的 119 条排了一轮优先级，把 AnswerSpec 抬成
  「第二大真问题」；按正确的 95 条重算后它只有 13 条、且近半是假阳性。
- **降级通道要分级**。良性（数据未到）、误报（延迟观测）、真问题混在一个列表里，
  三分之一的噪声足以让归因失效。
- **同一处反复修判定条件 = 根因在上一层**。counterpoint 门禁修了两次仍复发，
  说明该看的是谁把问题送进这个 frame。
