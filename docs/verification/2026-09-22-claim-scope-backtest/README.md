# 口径越界 lint 的首次真实精度回测（1347 个历史 run）

在此之前，这个检出器的全部「精度」证据是 6 份仓内答案 + 2 个冻结 run。所有人（包括我）
都在文档里写「6 份不是统计样本」，但没人去跑存量。这次跑了：`~/.finance-runtime` 下
**全部 1347 个**带 `answer.md` + `continuous-episode.json` 的历史 run，14501 句，非抽样。

## 三个阶段的命中数

| 阶段 | 命中条数 | 命中 run 数 |
|---|---|---|
| A 基线 `1cf35f516`（#850 tip） | 82 | 53 |
| B 三条 fail-open 闭合后 | 96 | 67 |
| C 精度修正后（本目录） | **66** | 49 |

B→C 掉的 30 条**全部是人读确认的误报**，不是把规则放松了：两个冻结 run 的判定与首版
逐字段一致，三条探针（P1/P3/P4）仍闭合，仓内 6 份语料仍命中 0。

## 回测压出来的三类误报（6 份语料永远压不出）

| 类别 | 条数 | 真实原句 | 已修 |
|---|---|---|---|
| 限定词表缺「可得」 | 4 | `这是本轮可得的最近一个已收盘交易日` | ✅ |
| 免责词表太窄，自陈缺数据被当断言 | 16 | `两日的分板块净流入、主力资金明细未查得，资金来源结论不做断言。` | ✅ |
| 资金流数字来自新闻等渠道，只认 `finance_query` 指标而漏认 | 13 | `证券日报称特高压板块19股涨停、逾38亿主力资金净流入（E5）` | ✅ |

第 1 类**是我自己上一轮改出来的**：收紧限定词绑定时词表只收了「库内/可用」，没收「可得」。
回测把它当场抓住——这正是补这次回测的理由。

第 2 类最刺眼：答案在**诚实地说自己没数据**，却被判成越界断言。误报这种句子等于**惩罚诚实**，
比漏报更坏——写手学到的是「别写免责声明」。

第 3 类是上一轮硬化的副作用边界：我把证据判定收窄到 `finance_query` 注册指标，
于是新闻里带的资金流数字不算数了。修法不是退回子串匹配，而是**认「取回来的证据台账」**
（`outcome.evidence`），不认工具参数——模型自己敲的检索词敲什么都行，不构成证据。
决定性检查：已知真命中的那个冻结 run，证据台账 31894 字里**没有**任何资金流字样，
所以这条豁免不会放过它（实测确认）。

## 残留与已知噪音

剩余 43 条资金流命中里，15 条是条件句与假说（`若…则支持资金回流`、`假说一：增量资金回流主线`）。
**保留不改**：假说仍在断言方向，放宽条件句等于给「我只是假设」开后门。若将来认定为噪音，
应另立规则（如「假说需标注证据缺口」），而不是放宽本规则。

## 边界（这次回测测不到的东西）

- **只测命中侧，不测漏报**。66 条命中可以逐条人读分类，但没有标注语料说明「哪些答案本该被抓」，
  所以这里给的是「命中是否可信」，**不是召回率**。要谈漏报得先有人工标注集。
- `--scope-total` 对历史 run 未知，范围规则在回测里基本沉默，所以它的精度**未被测到**。
- 日历证据无来源可声明，R1 一律按未验证计——这与线上一致（工具面没有日历 dataset）。
- 1347 个 run 跨多个实验批次，同一问题的重复跑会让某些句子重复计数（去重后资金流 56 种句子）。

## 复跑

```bash
find ~/.finance-runtime -name continuous-episode.json | while read e; do
  d=$(dirname "$e"); [ -f "$d/answer.md" ] && echo "$d"; done | sort -u > /tmp/corpus-dirs.txt
# 对每个目录：build_context(run, episode, None) → review_answer_claims(answer, ctx)
```

`evidence/residual-hits.json`（C 阶段全部 66 条命中原句，供逐条复核）。
