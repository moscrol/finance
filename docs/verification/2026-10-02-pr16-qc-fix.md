| 问题 | 原风险 | 返修 |
|---|---|---|
| F1：summary 校验不全 | 矛盾 `by_class/pass_rate`、错误 failure 原因类型仍进入比较 | 拒收所有带 `total/passed/failures/by_class/pass_rate` 任一字段的汇总或混合报告，exit 2、stdout 为空 |
| F2：按当前题集猜通过题身份 | 另一套同样题数的全通过 summary 可冒充同题集；这是原设计残留 | 比较器只接显式非空 `cases`，不再调用 `cc.load_cases()`，也不强制显式题号属于当前题集 |
| 上游迁移丢身份 | 新导出初稿会忽略陌生题号、覆盖重复题号或重复 JSON 键 | `score --cases-json` 先校验 JSONL 原答卷，错误 exit 2 且不输出报告 |

新导出拒绝陌生/重复/空题号、非对象行、非字符串答案、重复键和坏 JSON。
合法输入按当前固定题集真实判分；缺整行、缺 answer 或空答案仍为 false，空答卷为全题 false。
合法 `--json` 的汇总形状不改，仍可列 `unknown_case_ids`；它不再是比较器输入。
两输出选项互斥。旧答卷必须配原题集版本重新确定性判分，不用汇总反推通过题，不重发模型请求。

比较器仍保留逐题回退优先、严格布尔值、非空题号、重复 JSON 键及四臂同题号检查：
FAIL=1、输入错误=2、其余 INCONCLUSIVE=3；selftest=0 只表示软件自检。
本次不是“所有未知顶层字段均拒绝”的全面 schema 限制。相同题号也不认证题面、模型、
预算、数据、来源保真、未见题、费用或答案质量一致。
