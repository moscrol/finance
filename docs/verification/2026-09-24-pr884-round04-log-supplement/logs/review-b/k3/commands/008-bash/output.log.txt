这是活进程故障隔离，不是崩溃续跑：写后确认丢失仍不确定，磁盘可能留已完成前缀；
P1a 前置切片已接子研究独立日志、父子双向引用及整棵运行树的保存故障隔离：
`branch-1` 仅是显示号，每次调用有唯一持久身份；PLAN/工具路径都在启动前确认父记录。
子回复留私有日志，GLMModelClient 的子稿流式出口按调用作用域关闭，不修改共享客户端。
父工具等待窗内可收回子分支已有费用；窗外关闭父事件/证据交付，线程晚归不冒充已停止。
子研究 `replay=never`，非终态关联日志恢复先拒绝，等待父子对账 driver；不能各自重跑。
其他 SDK 或自带发布出口的注入 client 不自动获得此合同。
恢复判定的合成结算现逐条同步保存，检查点确认后才返回 plan/closed；任一保存异常直接
传播，不广告下一动作。只见 finish、或 done 与日志尾不一致时拒绝猜终态；同进程修复
已有更新检查点时按其位置判定，不再被上一轮 finish 遮住。恢复计划尚未执行时保留原 phase
及预留回合/调用定位；仅合成结算推进确认前缀，不提前消费待派发工具或待解释模型回复。
重复恢复按定位点查已有结算，不重复补写应用调用中断；预算/证据捕获前缀不因此前移。
本机单写者控制已接到 ContinuousAgentEpisode 的 run/manual_drive、同进程 resume 和
restore 入口：JSONL 按 episode 持有非阻塞 POSIX flock，Memory 按对象/episode 互斥；
恢复在 load 前取得所有权，活驱动即使暂停也拒绝第二个控制者。锁随正常返回/异常/显式
drive.close 或进程退出释放，不按时间抢占，不删锁文件；不同运行器的不同 episode 与
只读诊断互不阻塞。同一运行器实例的 run/manual_drive/resume 另共用非阻塞控制锁，
即使 task_id 不同也拒并发，防共享收件箱与取消信号串线；顺序复用仍允许。
单步驱动的 step/close 也互斥，执行中的竞争抛 EpisodeWriterBusy，不把活驱动标成结束；
调用方须等当前 step 返回后再 close，不能把 close 当在飞模型调用的取消/排空接口。
新 run 拒绝已有日志/检查点，同进程修订核对存储/任务身份，重新取锁并核对原日志与
检查点，过期续修对象拒写。释放前关闭旧收件箱并等待正在投递的消息落账；异常关闭
不伪造未决消息已处理/丢弃。正常完成保留已关闭收件箱的查询与迟到拒收行为。
该锁是合作式本机控制，不覆盖旧版进程、直接 append/put_state、跨机共享文件系统、
已逃逸的子线程/外部请求，亦不把调用效果或费用的未知状态变成已对账。缺 writer 的持久
store 拒绝进入控制操作，不以空锁静默兼容；任务目录的 checkpoint 身份不匹配亦拒绝。
这仍是恢复**判定**，返回 plan 时锁已释放，不是执行器或后续执行许可，
也不证明原调用方收到过保存确认或公开交付；闭合结果尚不重建完整草稿/证据/费用现场。
根预算另有版本化快照：余额、累计分配、初始/当前硬帽及已用 grant/promotion 身份一并
校验、深冻结并随当前检查点保存；旧摘要或子预算视图不补铸成独立根额度池。恢复工厂与
新建工厂共用进程内唯一根登记，但不是跨进程单写者许可。恢复合成保留原预算前缀位置，
不把新补的中断记录冒充已对账的新余额；生成/校验快照失败同样阻断整树新效果。
