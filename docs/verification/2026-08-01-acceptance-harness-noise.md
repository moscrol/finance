# 任务 #14：验收台信噪比 —— 假设检验与修复

**结论先行**：假设「波动主要出在措辞层、事实数字层稳」**成立**，需加一条修正。
判官侧四处确定性修复后，同输入复跑的噪声从 **7% → 2%**，事实层与语义标记层归零，
**题级通过/失败数一个没变**（通过 0、失败 7）——改的是稳定性与归因，不是门槛。

---

## 1. 测量方法：先构造干净对照

handoff §4 给的三次运行不能直接横比：`034001Z → 035325Z` 之间上了 #12（选章节），
A4/A6 的 fail→pass 是**修复生效**不是波动。真正的纯噪声对照是
`025854Z → 034001Z`——中间只上了 #11（判官侧，不重启 server），
所以 10 题的输入和 server 代码都没变。

测量手段是**离线复算**：把已存 run trace 重新灌进 `acceptance_verdict`，
逐条规则比对状态。零配额。

> 可复用：评测台自身的方差要用「同输入 + 同被测代码」的对照来测。
> 拿跨越了修复的两次运行比，测到的是修复效果和噪声的混合，读不出任何一个。

## 2. 假设检验结果（干净对照，10 题 45 条确定性规则）

| rule.kind | 稳定 | 翻转 | 翻转率 |
|---|---:|---:|---|
| **数值型 fact** | 20 | **0** | **0%** |
| **must_mention（措辞）** | 1 | **2** | **67%** |
| 字符串型 fact（`str(expected) in text`，本质也是措辞） | 0 | 1 | 100% |
| entity / semantic_marker / citation / set / answer | 21 | 0 | 0% |
| **合计** | 42 | 3 | **7%** |

**干净对照里 3 条翻转 100% 落在措辞层。**

**必须加的修正**：「事实数字层稳」只在**数值正确性**上成立——三次运行没有任何一次
把数字说错。但在**是否提及**上不稳：run 3 的 A1 整个答案换了形状（跳去写
「下一交易日验证点」+ 知识库积累），17.27 / 0.25 / 116 直接消失。
判官原来把「说错了」和「没说」记成同一种红。

## 3. 三条候选的量纲

全套 28 题的措辞类断言总共只有 **8 条**（must_mention 6 + 字符串 fact 2），
分布在 6 道题上（A1×2、A2、A6、A8、A9、B6×2）。

| 候选 | 配额 | 是否消除噪声 | 关键代价 |
|---|---|---|---|
| (a) n≥3 重复 | A 组 30 次 / 全套 84 次；5h 上限约 15 次。**只重复 6 道措辞题也要 18 次** | ❌ 只测量不消除 | 不可行且打错靶 |
| (b) 看板标注 | 0 | ❌ | 诚实但信噪比不变 |
| (c) LLM 语义判定 | 约 6 次/轮，且**每次重渲看板都烧**（看板本来是从已存 run 免费重算的）| ⚠️ 在产品波动上**叠加判官波动**；要量化判官波动就得重复运行，绕回 (a) | 打破模块「不调模型/不连库/不碰运行时」的纯函数属性 |
| **(d) 确定性等价类 + 蕴含声明**（采用） | **0** | ✅ 覆盖观测到的全部 3 条翻转 | 需要纪律守住「不为绿灯放宽判据」 |

选 (d) 的依据是仓库里**已经有这个问题的解法**：C 组 4 道题的
`required_any_phrases`（17 条同义词）就是等价类写法，确定性、零波动、已在用。

> 可复用：**先用确定性规则吃掉能吃的，只把残差交给 LLM 判官**。
> RAG / Agent 评测同理——能用 exact match、正则、结构化字段判的绝不上
> LLM-as-judge，因为判官自身的方差会污染你要测的信号，而量化判官方差
> 需要重复调用，成本直接翻倍。(d) 做完后 (c) 的目标面从 8 条缩到 1 条。

## 4. 前提约束：正典密封夹具

`acceptance_cases.json` 被 `CANONICAL_CASES_SHA256` 哈希冻结
（`test_all_cases_compile_without_mutating_frozen_assets`）。这是刻意设计：
**28 题的正典定义不许改，判据表达力只能走 additive overlay。**

所以「删掉冗余的 must_mention」不能真去删条目，必须表达成 overlay 侧的机制。

## 5. 四刀修复

### ① 别名窗口回看不对称（真 bug）

`_alias_windows` 原为 `text[i-8 : i+len+40]`。run 3 的 A1 写
「`21949.97 亿元的成交额`」——数字正确且在场，但在别名前 13 字，被 8 字回看切掉。

窗口宽度扫描（3 次运行 57 条数值断言）：

| 回看/前看 | 命中 |
|---|---:|
| -8/+40（原） | 24/57 |
| -16/+40 ~ **完全不设窗口** | 25/57 |

**放开到无窗口也只多这一条**——别名机制没问题，只有不对称是缺陷。
中文修饰语在名词前后一样常见，窗口本就该对称。改为 -40/+40。

### ② `phrase_equivalents`：同义改写

答案写「处于反弹阶段」而断言要「反弹阶段」，不该判死措辞。
等价类**必须含正典短语本身**（否则一个笔误就能整条换掉原断言，
看板上完全看不出来——这是「悄悄放宽判据」最容易溜进来的缝），
且**不得跨枚举值**（「震荡」不能进「反弹阶段」的等价类）。

### ③ `phrase_discharged_by`：冗余断言的蕴含声明

A1 要求正文出现「缩量」，可同题的 `fact:amount_vs_yesterday_pct=-17.27`（±0.5）
已经断言了同一事实。run 2 答案写「较昨日**减少** 17.27%」：数值规则 PASS、
措辞规则 FAIL——那条 FAIL 零信息量，纯粹在测模型用不用某个词。

**这类不能靠往词表里堆变体解决**：中文会把数值插在名词和动词之间
（「成交额 21949.97 亿元、较昨日减少 17.27%」），子串永远追不完，
而且照着答案补词就是过拟合到某次运行。改成声明式蕴含：
指定一条更严的规则，它 PASS 才解除这条措辞要求。

- 不是放宽：被解除时同一事实仍被**带容差的数值规则**守着；数值规则没过，措辞要求原样生效。
- 规则名打错 → 进 `diagnostics` fail-closed，不静默失效。
- 落地两条：`A1 缩量 ← fact:amount_vs_yesterday_pct`、`A2 证伪 ← falsifiable`。

### ④ 两处收紧（不是放宽）

**字符串型 fact 全文缺席判 FAIL，不判不可判。** A9 别名表 `["状态","沸点"]` 里
「沸点」**既是定位别名又是期望值**，于是「沸点没出现」被 #11 的别名未命中规则
记成「定位不到」，三次运行在 ❔/❌ 间来回翻。而事实是三次都没出现——
字面量不在全文里就是真不在，不存在「定位不到」。**收紧只限字面量**，
数值仍维持不可判（光有个数字证明不了它绑在这个字段上）。

**矛盾断言锚定到操作数。** A9 三次运行「沸点」和「-66.3%」一个都没出现，
前两次却因为正文别处写了「矛盾」判 PASS——**假绿**；第三次没写「矛盾」判 FAIL，
同样无信息量。改成：题目声明了 `expect_facts` 时，那些值就是矛盾的两端，
两端没在答案里就不可能是在说这个矛盾。C5 没声明操作数（靠重复值发现矛盾），
维持原关键词行为。

## 6. 效果

| | 修前 | 修后 |
|---|---:|---:|
| 数值型 fact 翻转 | 1 | **0**（21 条全稳） |
| semantic_marker 翻转 | 1 | **0** |
| product_language 翻转 | 2 | 1 |
| **合计翻转率** | **3 / 7%** | **1 / 2%** |

剩下那条 A6 `must_mention` 是**真信号不是噪声**：run 1 的答案连「梯队」两个字
都没提，本身就更差。不该抹掉。

**题级通过/失败数一个没变**（通过 0、失败 7、不可判 3），但**红的归因变了**：

| 题 | 修前说明 | 修后说明 |
|---|---|---|
| A1 | missing product terms: 缩量, 反弹阶段 | `amount_vs_yesterday_pct=-17.27` not observed |
| A2 | missing product terms: 证伪 | answer lacks a condition or numeric threshold |
| A8 / A9 | not observed within tolerance | **absent from the whole answer** |

看板新增分层汇总：`**失败按判据层**：fact 9、product_language 3、semantic_marker 2`。

## 7. 验证

- 新增 12 条测试，**12 次突变逐条打红对应那条**。
- 回归 **3923 passed / 12 failed / 3 skipped**（基线 3911 + 12 条新测试），
  12 条红同名同数（8 `test_subconscious` + 3 `test_userspace` + 1 待办 K），零回归。
- ruff **165**，与基线同数。

> ⚠️ 踩坑记录：突变验证时 `VerdictState.PASS,` → `VerdictState.FAIL,` **字节长度相同**，
> 且突变+还原在同一秒内完成，Python 的 `.pyc` 按 `(mtime, size)` 校验源文件，
> 于是一直在跑突变版字节码，伪造出两条「新回归」。
> **同长度改动 + 秒内还原 = 字节码缓存失效检测的盲区**，清 `__pycache__` 后消失。

## 8. 本轮明确没做

- **没跑任何一道题**（全程离线复算，零配额）。
- **没碰 `acceptance_cases.json`**（密封夹具完整，sha256 未变）。
- **没动 server 侧代码**，canary 8793 不需要重启。
- B6 的 `graph_only` / `观察列表` **保留字面**——那是产品术语不是措辞。
- A9 的 `strength_status=沸点` **没加等价类**——它是数据侧枚举标签，
  且 pass_rule 明说「直接照抄『沸点』当结论 = 不通过」，加同义词只会让假绿更容易。

## 9. 遗留

- **A2 不是 handoff §5 说的「表达层——数据到位了没下结论」**。它三次运行逐字节相同的
  232 字降级桩、`degrades` 非空、看板 🟠 降级完成。#10 的「降级桩 5→0」没覆盖到它。
  **这是一条应该重新归类的真缺口。**
- A6 的 `must_mention` 仍有真波动（答案有时根本不提梯队）——那是产品侧的答案形状
  不稳，不是判官问题，属于 #12 之后的残留。
- C5 的矛盾判定仍是纯关键词（没有可锚的结构化端点），保留了假绿的可能。
  本轮刻意不动：C 组没跑过，改了没法验证。
