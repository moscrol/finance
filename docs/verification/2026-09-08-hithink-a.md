## 3. 两次同步哈希

指纹是行数 + 代码数 + 首末日 + 各行 `HASH(日期,代码,close,turnover)` 的 `BIT_XOR`（加法合计会随插入顺序漂，不用）。

同一天、同一份十年 parquet 连续灌两次：

```
1e0c42c1cf2aa2f2a0cab114bbaea6299584446f96f30a86b1c50f2244f6678e
1e0c42c1cf2aa2f2a0cab114bbaea6299584446f96f30a86b1c50f2244f6678e
```

复权事件表指纹：`925cf21e3609c3f6777b89313fb45515a4043da522eaaaeca442e8772910ba3c`。
随后用 10d parquet 再 UPSERT 一次，日 K 指纹不变（重叠日 close/turnover 与十年 dump 一致）。
