## 错误家族

1. **未交付或用“证据不足”替代可计算答案**：review-03、09、11、12、14、17。  
2. **余额变化冒充现金流或融资需求**：review-02、04、18、19，集中在“需依赖外部融资”“7.5亿/5.5亿占用现金”等表述。  
3. **算术错误**：review-18、19把应收增加4、存货增加2.5、合同负债减少1合计为5.5，正确代数合计为7.5。  
4. **反证与不利证据混淆**：review-06把“现金流下滑”称为甲的关键反证，实际上它支持原负面判断。  
5. **因果强度超过材料**：review-13将甲利润增长“主要体现为账面应收”说成事实，缺少现金流量表明细、账龄和收款证据。  
6. **正确处理的关键家族**：review-01、05正确隔离嵌入指令和同源报道；review-15、16正确区分CFO、CapEx、FCFE、净借款、增发回购及EV/股权；review-08正确处理历史数据复述。
