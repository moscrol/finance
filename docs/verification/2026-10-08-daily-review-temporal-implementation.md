# 每日复盘时间化 · 第一版实施记录

日期：2026-10-08。分支：arena/a3bfea49-finance。未提交、推送、合并或部署；工作树包含此前日历修改，测试结果仅代表当前混合工作树。

## 已实现

- 原入口 `OriginalDailyReview` 增加“单日完整复盘 / 连续复盘”切换，默认仍为单日，连续接口按需读取。
- 默认20个计划交易日，可选5/40/60，独立截止日与日期光标：点历史日不缩窗，打开完整复盘使用所点日期，不回落到最新。
- 固定行业，市场六项读数、趋势断点、当日成交前三与行业榜内顺位、双红/涨停/新高原值轨迹、当日发动机原表与前三名称预览。
- `GET /api/river/review-history?end=YYYY-MM-DD&days=20&industry=行业原名`。只读现有 daily-review/v1 JSON，不查询生产行情补档、不修改日报生成器、不调用模型。
- 人看的响应与 JSON 导出共用：窗口、缺口、指标来源、各日生成时间/SHA256、矩阵和发动机原值、限制。导出另附所选日期。
- 仅相邻计划交易日且两日报字段有效才算算术差，百分比差为百分点。重叠矩阵每个日期只读自己的报告当天列；缺档不回填；未列榜不当零；名称不做隐式归并。
- 日历缺年份时明确窗口不完整；强制运行的交易日环境覆盖被拒绝，不拿运行开关当历史日历。当前共享日历只有2026，2026年初不会猜造2025交易日。
- 5–60日请求约束、24MiB归档读取预算、每日报每节80行上限、截断标志、异常归档隔离、AbortController防过期响应、版本/窗口/行业校验、刷新与重试。
