## 可以落到证据上的问题

1. **热度第一是真的，机会第一需要比较。** 新能源车13家涨停、占当日47家涨停的27.66%、同窗-1.46%都有相应数据；不能据此判它一定弱，也不能仅凭这两项判它优于光纤或PCB。我的排序是有条件的研究选择，同样不是收益预测。
2. **Workbench的历史措辞超过实际特征。** 原历史工件spec.features只有`return_pct`，却称“相似热度/结构窗口”；没有实际比较热度或量价，就不宜这样概括。
3. **日期范围说窄了。** 产品返回9窗完整范围为2026-06-23至2026-08-31，不是全部在近1—2个月。声明近一年搜索不代表一年都存在可比板块数据。
4. **后续结果不是都不存在。** 原产品E1已经含市场情绪类比后5/10/20日结果，缺的是其板块find_analogues后续比较；这两层应分开。组件侧现在查得出板块后续，不等于产品当时已经取到了它们。
5. **0.4没有成为校准概率。** 产品批注指出缺乏支持是正确的；不能把这个数当模型可靠度或投资胜率。我的稿也没有由两个上涨案例推出高概率。

## 组件稿自身的局限

- 候选由榜单、容量和已有观察筛选，可能漏掉尚未进入榜单的方向；区间榜只是各档top10。不是最优投资组合筛选。
- 更偏近期盘面与相对强度，未给估值安全边际、盈利兑现、交易成本或个股执行方案。
- 光纤两个近似例子后续上涨，但完整条件比较中也有光纤后5日下跌样本。仅11个当日成员、6个上涨，不能包装成全面共振。
- 历史数据稀疏、窗口重叠；所选三特征不是产业机制相似度。`compare_cases`执行过不等于认证通过。
- 同一作者提出研究排序、检查数字和比较两稿，没有独立金融审查。更多调用和更长正文也不是质量证明。

## 本次能说明什么

**这一次，不必先增加新金融组件，就能用现有组件补出横向比较、成员广度、历史后续和失败案例。** 原产品最终答案没有充分交付这些内容；但差异不能简单归咎为删稿：查询选择、候选过早收窄、历史操作选择及最终压缩都可能有影响。本任务没有实施新工程修复，也没有重跑产品、改生产或改变原保留验收的not_passed。
