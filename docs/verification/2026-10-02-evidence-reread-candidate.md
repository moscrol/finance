## 最小候选及取舍

- 新工具 `evidence_read(evidence_id, field, offset, limit)`，正文/标题二选一；
  最多600个原文字符，按 JSON 转义后的900字符观察预算缩页；返回实际下一页游标。
- 只读当前 Episode **已交付池**，不读整个分支账本、文件路径、别的用户目录或网络。
  返回同一证据，不造新 hash/E 编号/来源；仍受原授权、截止日/历史窗口及工具预算约束。
- `ASK_EPISODE_EVIDENCE_READ=on` **且** contract 显式含 `evidence_read` 才装配。
  不改默认 capability 地板、不接 ASGI 产品默认；单开环境开关不能增加权限。
- 已有回合内去重/预算闸保留。该本地导航关闭 turn-wide 查询结果缓存：不同子 Episode
  都可能有 E1，不能共用另一池的 E1 结果，也不能复用旧的更宽授权窗口。
- 在**模型输入已追加后**对照原文计新展示字符；预览、完整/截断叙述、开场完整预取、
  重复页和重叠页均去重。进展记作 `new_read_chars`，不增加新证据数/独立来源数，
  避免补读被当成“零新证据”而触发停滞收口。该计数不是语义理解或事实正确率。
- 截断提示仅在候选开关开启时说明“若实际菜单提供可补读”；不假装有未授权工具。
  **工具 observation 叙述本身不在本版补读范围**，只能补原始证据 title/detail。

替代方案是抬高所有预览上限，代价是每次都塞更多上下文。按需补读给模型选择，
但多一项菜单和可能多一轮请求，延迟/成本可能变差，须实跑而非假设收益。

## R-20261002-06：冻结后才启动的模型机制诊断

持续 GLM 授权；单模型 `glm-5.3`，原生 `ContinuousAgentEpisode`，不是新建循环。
使用两臂相同的私有固定参数 HTTP 适配层，保留原生 GLMModelClient 的协议解析；
不把私有适配器的对照当成生产网络链验证。13项零模型预检已过。
**不是 ASGI 产品门端到端、不是原正式模型×harness四格、不是强模型臂。**

两份未用于实现/测试的合成材料问答（项目交付与测量记录），只用于机制可达性和恢复观察，
不冒充真实行情、独立分布检验或质量基准。A=关闭补读，B=开启；两臂同题/同原件、
同模型及预算，contract 同样显式授权候选能力，只有 B 装配菜单/补读提示/进展反馈。
不点名要读哪个字段/哪一页，不强迫调用；题目答案只在材料中，不进入工具说明。

固定次序：交付 A→B，测量 B→A；每臂一次，不重开、不选优。
每案最多6个物理请求/120秒，单次50秒，整批最多24请求/500秒；最多4工具调用。
请求 `thinking=enabled, reasoning_effort=low, temperature=0, max_tokens=4096`。
原生 JSON 纠正可在预算内继续；传输失败、身份未知/不符、控制冲突、相同请求重试或预算耗尽
即停止整批，剩余标未执行。身份是服务自报准入，不是权重认证；low 无回包证明则记未验证。

预先判据：两题均可完成正确完整回答、保留材料日期/范围/否定边界，未扩大来源；
B 若相对 A 恢复了被截信息且无新增事实错误，才支持**合成任务机制**的有限改善。
A 如实承认材料不足是正确缺口披露，不算幻觉；完成度与事实保真分开记。
保留每个终稿、调用轨迹、原始 HTTP、全部失败、输入/输出 token 与延迟；人工逐字来源核对，
原生 completed/绑定通过不能替代全文核查。更多补读、更多门禁不是收益。

若两题有差异，仍需未参与调试的真实任务及不同模型档位检验；不凭此默认开启或放行 PR8/四格/240。
