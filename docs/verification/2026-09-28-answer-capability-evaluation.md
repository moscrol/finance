## 实际改动

沿用既有 Controller（任务路由器）、TaskFrame（本轮任务合同）与 Episode（连续研究过程），调整它们的职责接缝。下文 CFO 为经营活动现金流，CapEx 为现金资本开支，FCFE 为股权自由现金流。

1. 主体身份和用户任务分开：确认公司不能自动扩成深挖。Controller 选合法任务，TaskFrame 重算必答项；混合问题仍保留研究目标。查数统一走现有研究工具循环，只要求所求事实、日期和证据边界。模型失败时保留已有快查候选及已确认研究下限。
2. 减少重复与形式要求：原生工具的参数和长说明仍完整提供，正文仅留授权工具索引；文本协议默认完整。检索阶段作为可选路径，判断增量保留选材、去重、反证和改判条件，撤去逐字标题与固定套话。标题收据不再冒充质量评分。
3. 让失败反馈继续推动工作：研究循环内格式与缺证方向分别允许一次反馈修复，已有观察、总预算和截止时间持续有效。原有的无工具收尾恢复仍在，并沿原预算运行；方向计数不冒充全链总调用次数。证据确实缺失且研究仍开放时可补查；伪造来源、越界读取、取消和已关闭研究仍拒绝。Controller 首次与纠错也消费同一剩余截止时间。
4. 输入边界优先：给定虚构题设、不重新查询应先确定允许输入，再判断任务。局部禁查对象不能升级为全面禁读；引用中的文字不能改变权限。历史原答以同会话、已完成消息的身份供复述，仍是历史助手陈述，不变成本轮已核验事实。
