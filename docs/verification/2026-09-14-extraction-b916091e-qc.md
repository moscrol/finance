## 发现

### Q1 · P2 · 确认复用草稿时，显式读取尝试 B 被静默改成草稿提交尝试 A

位置：`intelligence/cli.py:3616–3618`。

序列：`draft → read(A) → read(B，复用 A 的草稿) → confirm --from-draft --attempt-id B`。

实测确认 exit=0，`source_draft_id` 正确，但 `extraction_attempt_id` 与 `action_event.attempt_id` 都是 **A，不是 B**。原因是选完草稿后又用 `mine.extraction_attempt_id` 覆盖了用户显式指定的尝试。原第二轮探针和新增 R3 回归只验 exit 与 source_draft_id，没有验最终事件归属。

后果：按 B 查询确认事件查不到；确认动作键也跟着折回 A，同内容分别在 A/B 确认可能被当作一次动作。工单 §2.1 要求确认保留关联的 source_draft_id/attempt_id；第二轮 R-S1 也明确要求“保留本次关联”。

建议：保留请求选定的读取尝试身份；草稿来自哪次提交由草稿记录/source_draft_id 表达，不能用它覆盖当前关联。缺省确认可保留明定的原策略。验收须同时断言选中版、记录尝试、投影事件尝试、按尝试查询及动作键。

对应反例：`test_residual_s1_confirmation_preserves_selected_read_attempt`。

### Q2 · P2 · 已完成收据不是选版最高依据，关闭失败后新增草稿会替换实际所读版本

位置：`intelligence/services/observation_script.py:1056–1065`。

序列：提交 v1 → read 完成收据成功落盘 → 仅关闭行追加失败 → 正常 draft 入口在仍 pending 的同一尝试提交 v2 → 同 ID 重试补关闭 → 按该尝试确认。

实测收据 `source_draft_id=...001-782637be`，确认却是 `...002-1a55a3be`；v2 从未出现在这次 read 中。`draft_for_attempt` 先返回“该尝试最后提交的一版”，仅在该尝试没有提交过时才查完成收据。修复只覆盖了复用场景的“没有草稿”分支，没有实现原复审要求的“已完成尝试优先按原 read 收据选版”。

这与允许重试补终态的 R-N2 是同一故障窗口，不需要损坏/伪造台账：只注入一次真实 writer 的关闭失败，后续全部走正常 CLI。

建议：存在完成收据时，严格按其 source_draft_id 选版；没有完成收据才用未完成尝试策略。若完成收据缺来源，不得悄悄回退成另一份草稿。可另让收据已落的 pending 尝试先收口，但不能只靠该收口替代选版依据。

对应反例：`test_residual_s1_completed_receipt_wins_over_later_draft`。

### Q3 · P2 · 手填关联把终态校验整体豁免，完全 abandoned 的尝试也能新增确认与 checkpoint

位置：`intelligence/cli.py:3551–3577, 3698–3700`；落盘闸为 `observation_script.register` 的 require_open_attempt。

序列：read 提示（没有 draft/skip/read_completed）→ 显式 close，已记录 `closed/abandoned=true` → 完整手填 `confirm --attempt-id <同一 ID>`。

实测 exit=0，新增确认事件并真实创建 checkpoint；原 abandoned 保留，同一尝试同时表示“未行动即离开”和之后的新增确认。探针只把 is_late 固定为及时，以实际覆盖 checkpoint 副作用；不 mock 登记 writer。即使不固定及时状态，late 确认事件仍会新增。

手填分支现在验了用户/日期/实体，却不验允许状态，且 register 仅给 from-slice 设置 require_open_attempt。代码注释把手填一并称作“引用出处”，但本例没有任何草稿或完成收据可以引用。工单 §2.4.4 对旧尝试后续确认的例外是“已完成尝试的具体草稿版本”，不能扩大为所有关闭尝试均允许新动作。

建议：显式手填关联按允许状态在 writer 持锁、副作用之前复验；没有可证明的合法历史引用则拒绝关闭尝试。`--from-draft` 对完成旧尝试的合法引用仍必须保留，不做全局一刀切；已有同动作收据的重放也不应产生新副作用。

对应反例：`test_residual_s2_manual_cannot_write_to_abandoned_attempt`。
