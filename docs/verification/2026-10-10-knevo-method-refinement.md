# Knevo 复盘方法：范围与检验对象细化

## 背景

前轮真实答案在入口已修好后仍有三类错误：把主线预览当总体、从量价/高度推资金或参与者、用未来走势改写当日统计判断。
既有 skill 已写禁止事项，但研究步骤仍要求“普涨/分化/主线带动”选标签，并为当日定性凑未来反证。
本轮改的是方法的对象关系与步骤，不新增正文拒收器、不改 8792，也不把失败归咎于模型额度。

## 修改

- `finance-market-review`：先固定判断对象、比较集和时间；分开当日领涨、成交主流、登记名单；两批取证之间先核范围。
- 多数采用确定性覆盖界限：总数 N、已见 n、符合 k，符合数范围为 `[k, k+N-n]`。界限足够即可判断，界限跨过一半才保留缺口；未知分母不做总体比例。
- 排名允许由目标范围内“先排序、后截取”的查询证明，不强求把全部行展示给模型。
- 将当日判定、解释性判断、未来观察剧本分开；反证和观察条件各绑定检验对象。
- 观察阈值说明规则、推导或假设。已有数据支撑的结论保留，缺证句子收窄，不靠末尾免责声明修饰前文断言。
- `finance-mode`：相同的范围/时间原则进入共用研究循环与自检；检索重试统一引用已有上限，消除同一缺口一次/三次的冲突。
- 仓词表原地补齐比较集、覆盖界限、当日判定、检验对象、观察阈值、当日领涨。既有两种主流口径不改名、不改阈值。

这些是可逆的方法文档调整，不涉及新的难逆架构决策，因此不另立 ADR。

## 边界用例

`intelligence/eval/fixtures/knevo_market_scope_20261010.json` 为已揭示的回归用例，不冒充盲测：

| 用例 | 压测边界 |
|---|---|
| SCOPE-01 | 6/8 的预览，全集36，无法确认总体多数 |
| SCOPE-02 | 总数10、已知6符合，即使缺2也足以确认多数 |
| SCOPE-03 | 总数12、已知3符合且缺2，上界5不足多数 |
| SCOPE-04 | 分母与成员规则未知，不把行比例当总体比例 |
| RANK-01 | 全比较集排序后取第一行，仍可确认限定范围名次 |
| TIME-01 | 后一天上涨不改前一天计数，但可削弱弱势延续假设 |
| IDENTITY-01 | 缺少高标不证明机构参与；价格结构仍可描述 |
| TERM-01 | 价格第一、成交第一与登记名单不同，不必然冲突 |

`tests/test_knevo_market_scope_cases.py` 穷举未知成员验证用例的数量界限，检查回归/基准身份与题目未嵌入 skill。
这些测试不判模型答案。含原有入口与注册回归共92P；Ruff与注册表四项通过。
