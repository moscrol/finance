# 市场假设验证 / 跑马策略执行规则

> 从 `CLAUDE.md` 迁出的按需参考（2026-09）。适用于跑马策略、板块相对强度、后验收益等仍处于**假设验证阶段**的实验；
> 相关 skill：`strategy-evolve`（确定性生成与参数升版台账）、`strategy1-matrix`（策略一矩阵人工终判）。

- 假设验证阶段的观察不写成定律或硬规则。
- 默认「实验台账 + 半自动查询」：每个实验记录输入窗口、假设、数据完整性、候选池、后验结果、结论状态、下一步。
- 分步、最小单元、短脚本短命令：一次只做一个原子动作（数据核验、候选池生成、相对强度计算、后验收益计算、报告写入）。复杂查询拆成多个短查询或临时小脚本，便于中断、复核、定位失败；不写一次性长 SQL、长 Python 或大批量回填。
- 数据不完整先补阻塞性缺口；补不齐就在报告里标注缺口及影响，不用缺失数据推断规律。
- 指数环境只作背景放大器，不作板块或个股强势的决定因素；优先看容量行业、双红题材边际量、新高映射、涨停映射、个股加权强度、分歧日相对强度。
- 后验收益不只看固定第 10 日终值：比较 3 / 5 / 7 / 10 日窗口、区间最高收益、到峰值天数、峰值后回撤，并记录双红题材回流后、再分歧前是否有退出机会。
- 实验性代码、台账和报告默认不提交不推送，除非用户明确要求。
