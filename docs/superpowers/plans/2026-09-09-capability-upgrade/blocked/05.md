# 05 · 范围外需求（不在本单白名单内，记录后继续范围内工作）

白名单：`task_frame.py` / `query_understanding.py` / `user_task.py` / `episode_factory.py` 的输入上下文装配及其测试。下面每条都写清「谁接 / 最小改动 / 为什么需要」。

## B05-1 · turn_controller 把对话上下文传给 build_task_frame（1 行）

- 现状：`turn_controller.decide_turn(query, context=...)` 拿到 `context` 字符串，但 `build_task_frame(query, resolution.envelope, inherited_subject=...)`（`turn_controller.py:1058`）不传它；`turn_control_core._frame_from_decision/_frame_from_intent` 同样不传。
- 需要：`build_task_frame(..., conversation_context=context)`。本单在 `build_task_frame` 上加了可选参数 `conversation_context: str = ""`，默认空串时行为与现在完全一致（fail-safe：认不出上一轮材料就不做「这篇」绑定，也不发确定性的材料缺失澄清）。
- 为什么：「这篇 / 这份材料」的代词绑定和「题面引用材料但对话里根本没有材料」的确定性澄清都需要知道上一轮里有没有材料；只靠 LLM 写歧义文本是 fail-open。
- 归属：turn_controller 属路由/准入层，06（计划与调度）或 01（准入）接；改动是一行传参 + 一条测试。

## B05-2 · 控制器提示词允许输出 user_premises / competing_explanations / method_candidates（可选）

- 现状：`_controller_messages` 要求键只能是 `route_id,confidence,reason,user_goal,assumptions,ambiguities`；`_parse_llm_decision` 键集合不符直接判 None。
- 需要：若要让模型补充这些语义，提示词键集合与解析器白名单要同步放宽。本单的 `align_task_frame` 已能接收这些键（缺则忽略），规则抽取不依赖模型输出。
- 归属：01/06；非阻塞，规则版先跑。

## B05-3 · 理解卡的展示与编辑（UI / API）

- 现状：无「本轮理解」卡片。controller trace 与 report 都带整份 `task_frame.to_dict()`，但公开 API 隐藏 `pending_task_frame` 等控制键，webapp 只读 task_frame 三键。
- 需要：把 `task_frame.render_task_understanding(frame)` 的文本（或 `to_dict()` 里的 `understanding` 键）在「understanding」阶段展示，允许用户改对象 / 日期 / 目标后重跑本轮。
- 归属：09 唯一集成 UI（INDEX「04/05/10 的 UI 接线由 09 唯一集成」）。

## B05-4 · 材料作为绑定源（判官 / 证据层）

- 现状：所有 required output 默认 `grounding_mode="evidence"`，绑定必须引用工具产出的 E 号；用户贴进来的材料留在 `raw_question` / `conversation_context`，后者被标「不得当作事实证据」。材料原文永远成不了可绑定证据原子。
- 需要：材料类题（提纯 / 评述 / 核对一份材料）允许 `user_material` 一类的绑定源，或 02 把材料喂进可读材料通道后发 E 号。
- 归属：01（语义准入）+ 02（可读材料）。本单只在输入侧给材料身份、表头、段落、日期，模型可引用，判官如何认由 01 定。

## B05-5 · 第二刀输入面（文件上传 / PDF / 图片 / CSV 解析）

- 现状：`POST /api/conversations/{id}/messages` 只有 `content` 字符串；无 multipart、无文件路由；`vision.describe_image` 只在已退役飞书 bot。
- 需要：附件上传 API + 存储 + 文档解析（PDF/CSV）+ 材料 id 进 `Message`。接口合同建议：`attachments: [{material_id, kind, title, text_ref}]` 随消息；`material_id` 沿本单的内容哈希口径（同一内容跨轮同 id）。
- 归属：09（接口合同与串行接入）。本单不造文档平台。
