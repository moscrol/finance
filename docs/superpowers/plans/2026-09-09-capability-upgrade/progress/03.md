## 实现要点

- 题材范围：精确 → 别名 canonical → 子串 → 子节点；主节点取精确/别名，否则公司数最多者。
- 研究包六块全部带 `page`（`page_id` 与 RAG `get_page` 同形）：产业环节（14 个归一层级 + 「标准环节为空」点名）、关键变量（报告需求驱动 / 有方向的边 / theme_signals / 概念页章节指针）、公司暴露（含兑现状态 `realization`，转述 `financial_validation`）、支持/限制（硬证据 vs claim；guardrail / validation_focus / 证伪回链 / superseded）、最近变化（最新证据日期 + 距 as_of 天数 + 90 天陈旧阈值 + 催化日历）、缺口（空环节 / 无硬证据 / 无实体页 / 无关键数据 / 未登记财务验证 / 待补证清单 / 陈旧）。
- 向下追踪默认只走有方向 / 结构边（`上位概念` 只准从上位走到下位；泛化「相关」占全图七成，要看需显式 `--include-generic`）；同一公司多路径并列；公司带实体页抽出的财务锚，unknown 就是 unknown。
- 向上追踪按共同驱动分组（上位 / 有方向边 / 报告需求驱动），共享公司经同概念、子方向、兄弟方向计入并标 `via`；共享公司 >200 或子方向 >40 的驱动标 `broad` 只计数不列名，排最后。
- 对比：11 个相同维度，`known / computable / unknown`，unknown 的 `value=null`（不输出 0）；`computable` 只给公式与输入（不做第二套财务计算器）；报告期归一 `FY2025` 并保留 `period_raw`；单位按 亿元>万元>亿>万>元>% 取，括号里的同比不当单位。
- 视图：按「题材子集指纹（相关节点/边/暴露/证据/上下文）+ 依赖页 sha256」判重建，无关 ingest 与无关页改动不重建；`serve` 陈旧时列出变了的依赖页（回原页查证）并默认重建；`diff` 给公司 / 证据 / 环节 / 缺口 / 限制 / 有方向边 / 需求驱动 / 最近变化的差量。
