## Workbench 真实输入面（任务 0 核验，只读探查 2026-09-09，全部 [实测] 读代码）

结论：对话入口只接受**一个 JSON 字符串字段** `content`（`CreateMessageRequest`，`app.py:1468-1474`，只有 `min_length=1`，无长度上限）。没有上传、附件、multipart、图片、PDF、CSV 解析、材料身份。`Composer.tsx:82-94` 是单个 textarea，无 `onPaste`/`onDrop`/`type="file"`（webapp 与打包产物均 0 命中）。

| 输入 | 可上传 | 可解析 | 能进入模型 | 支持追问 |
|---|---|---|---|---|
| 口语问题 | 是（textarea） | 规则路由 `understand_query` | 是：`raw_question` → 契约 `question` → episode 输入 | 是：`Message.content` 持久化，`RECENT_MESSAGE_LIMIT=6` 条原文 + 更早 2400 字符尾截断 |
| 粘贴长文/材料 | 只能粘进同一 textarea，无分块、无预览 | **否**：全文当问题跑正则路由，无材料切分 | 首轮在 `raw_question`；次轮只在 `conversation_context`，且被标「历史对话…不得当作事实证据」（`episode_protocol.py:363`） | **无材料身份**：`classify_reference` 不认「这篇/这份/这段」；澄清路径只记字数（`task_frame.py:374`） |
| URL | 只是字符 | 否：查询路径无 URL 抽取 | 文本到模型；不自动抓取。`web_fetch` 工具存在（`research_tool_registry.py:306-344`），但契约要求 url 来自 web_search 结果 | 无 |
| CSV/表格 | 否（无文件入口）；表格文本可粘贴 | 否：无表格解析 | 仅作字符 | 无 |
| PDF | 否 | 否 | 否（预解析文本只能当长文粘贴） | 无 |
| 图片 | 否（Workbench 无） | 否（`vision.describe_image` 只在已退役飞书 bot） | 否 | 无 |
