## 任务 0 · 现状核对（2026-09-09，[实测] 除注明外）

**结论：现有 kb_search / evidence_lookup 不能定向取任意段落；第一损失点在模型可见投影，不在召回。**

1. 模型可见投影（`intelligence/services/tool_result_budget.py`，**不在白名单**）：Engine A 每条工具结果进模型上下文前经 `research_harness.project_tool_result → budget_tool_observation`，证据 `detail` 截 240 字、叙述截 900 字，并对模型声明「被截掉的原文没有工具可以取回」。kb_search 每条命中送达的 `llm_evidence`（命中块 + 相邻块居中窗，按题 1200–1600 字）模型只看到前 240 字；web_fetch 取回 6 段×800 字，模型看到页首 6 段各 240 字。→ 记 blocked；白名单内的对策是「一段一条 ≤240 字证据」（web_fetch 本就是一段一条）。
2. 取页 / 读节工具：无。kb_search 只接受 `query` 一个参数（`parse_query_arguments` 拒绝多余键）；知识库侧 `rag/agent.py::KnowledgeBaseTools.get_page` 存在但未接金融侧；worker 协议只跑 `rag_index.py query`。金融侧 V9a `kb_window_reexcerpt.reexcerpt_hits` 已按 `file_path` 直接读源 markdown 页并按标题切节——深读可在 `kb_rag.retrieve` 就地实现，不改知识库侧、不加新工具。
3. evidence_lookup：精确字符串匹配 `evidence_index.json` 条目（120 字），不是取段。graph_lookup：图谱映射，不是取段。
4. 新鲜度：按页判（`a8022698`）在 main 与生产都已生效。真索引实测（`store.page_freshness(wiki_root, 全部 14410 页)`，1.3 s）：fresh 14362 / stale 48（0.33%，全在 `wiki/entities/`，对应知识库工作树未提交的实体页改动）。stale 命中当前处置是丢弃 + 「去跑 rag update」提示，没有当轮重读原页。**日历悬崖**：索引 `built_at=2026-08-31T11:01Z`，`RAG_MAX_INDEX_AGE_DAYS=14` → 2026-09-14 起整库判 stale，所有命中被丢（生产 09-06 23:54 一次 run 已出现「丢弃 24 条非 fresh」形状，09-07 三个 run 均 6 命中无丢弃）。
   - 探针教训：`page_freshness(vault_root, …)` 的 `vault_root` 必须是 `wiki/` 目录（`repo_root = vault_root.parent`），传知识库根会让全部页「找不到」判 stale 且 0 秒返回。第一次探针就踩了这个坑，读数作废。
5. web_fetch 来源分类：`evidence_tier` 恒 `public_web`，注册表契约按工具名把官方网页也说成二手；`WebPageResult` 没有发布主体 / 文档类型字段。
6. 闭环检索（evidence_search）：narrow/broad/counter 三口径固定跑满（`_run_aperture` 只在口径内去重，跨口径同一查询会重跑）。KC-05 反方保底槽是判官侧契约，不改口径结构。
7. 已有冻结题集可复用：知识库仓 `eval/queries.real.jsonl`（40 题真实口语问题 + 期望页，仅到页级）；本仓 `intelligence/eval/cases/retrieval_recall_v1.jsonl`（20 例，其中 kb_rag 通道仅 2 例）。**都没有「正确原文位置」标注**，02 的 20 题要自建（页 + 章节 + 关键短语）。

## 实施（已落代码，2026-09-09）

- `intelligence/services/kb_rag.py`
  - **自动深读** `deep_read_hits`：对最终送达的前 3 条命中（`DEEP_READ_MAX_PAGES`）读源页、定位命中所在节（面包屑全等 → 末级同名 → 窗口前缀 → 问句词），整节切成 ≤240 字的段（`DEEP_READ_ITEM_CHARS` = `tool_result_budget.MAX_EVIDENCE_DETAIL_CHARS`，测试钉同值）；表格分片每片带表头与分隔行；若同页另有一节问句词更多（「所缺章节」），剩余预算再读它；同页其余章节面包屑进 `page_outline`；节内最晚日期进 `section_latest_date`。预算：每页 1200 字、整次 3000 字（`KB_DEEP_READ_TOTAL_CHARS`，0 关）。
