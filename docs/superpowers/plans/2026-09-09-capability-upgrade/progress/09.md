## 2. 设计（一段话）

研究项目 = **对现有对象的只读投影**：会话 → run 链（`parent_run_id`）→ 每轮（问句 / 状态 / 数据截止 / 引用数 / 产物 / 缺口 / 追问 / 本轮延续自哪张卡）+ 相关可证伪点及最新裁决（`session_id` 关联 + 题材/实体召回）。同一投影渲染成 ≤ 600 字的「研究项目状态（跨轮先验，非市场事实）」块，仅研究车道、仅有先验时注入 `conversation_context`（该字段已是 `prompt_assembled` 的 durable 载体，不开新的模型可见通道）。追问卡片带 `kind ∈ {gap_fill, alternative_explanation, condition_test, continue}` 与 `inherits{subject, standing_date, question_type}`；点击时前端把 `continuation{run_id, source, kind}` 一起 POST，服务端校验 run 归属后落在用户消息上，编排器据此设 `parent_followup_prompt / same_bind / standing_date`。裁决改先验：相关点出现 `miss` → 卡片排序把 `condition_test` 提到首位，并在先验块写一句「上次哪个判断让我这次这样查」。
