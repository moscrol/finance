## 方案（拍板）

1. **结构化财务证据**：`financial_data` 每行证据挂 `StructuredObservation`（指标名带单位与口径：`revenue_cum_yi` / `net_profit_cum_yi` / `gross_margin_pct` / `ocf_cum_yi` …，subject=ts_code，as_of=报告期截止日）；新增 `subjects` 参数一次取多家公司（`query_scope=episode` 不改）。
2. **沙箱结果协议 v1**：`emit_result(summary, tables, charts, params, formulas, notes)`；prelude v2 附财务助手 `fincalc`（累计→单季、同比、安全除法、单位换算、情景表、敏感性网格）；`params` 参数进 `PARAMS` 与 calc_id；`inputs_from_calc` 复用上一轮计算的输入快照（不重取数）。
3. **产物**：`calc-<id>.json / .csv / .html`（HTML 自带 SVG 图，无脚本）由 orchestrator 在写 `continuous-episode.json` 后从 `telemetry.derived_calculation` 渲染并 `add_artifact`；下载走既有 run artifact 端点；`api/artifacts.py` 认 csv。
4. **验收**：6 道冻结题 + 独立参照（`scripts/calc_case_reference.py` 直接读 F10 原始行算）+ Workbench 真实对话驱动脚本（`scripts/calc_case_acceptance.py`），在本单自己起的 Workbench 实例上跑，不切生产。
