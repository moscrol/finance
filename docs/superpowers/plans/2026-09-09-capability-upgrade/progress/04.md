## 方案（已落地）

1. **结构化财务证据**：`financial_data` 每行证据挂 `StructuredObservation`（`revenue_cum_yi` / `net_profit_cum_yi` / `gross_margin_pct` / `ocf_cum_yi` … 指标名带口径与单位，subject=ts_code，as_of=报告期截止日）；新增 `subjects` 参数一次取多家（`query_scope=episode` 不改）。
2. **沙箱结果协议 v1**：`emit_result(summary, tables, charts, params, formulas, notes)`；prelude v2 附财务助手 `fincalc`（`series` / `to_single_quarter` / `yoy` / `qoq` / `ratio_series` / `safe_div` / `pct` / `to_yi` / `scenario_table` / `sensitivity_grid` / `table` / `chart`，纯标准库，仓内 `sandbox_fincalc.py` 原样拷进沙箱）；`params` → `PARAMS` 并进 calc_id；`inputs_from_calc` 沿用上一轮计算的输入快照（P1..Pn，不重取数、哈希链不断）。
3. **产物**：`calc-<id>.json / -t<n>.csv / .html`（HTML 内联 SVG，无脚本）由 orchestrator 在写 `continuous-episode.json` 后从 `telemetry.derived_calculation` 渲染并 `add_artifact`（完成与失败分支都发）；下载走既有 run artifact 端点；`api/artifacts.py` 认 csv（viewer=download）。
4. **验收**：5 道冻结题 + 3 条追问（含「数据修订后重算」）+ 独立参照（`scripts/calc_case_reference.py` 直接读 F10 原始行算，写 `progress/04-cases.json`）+ Workbench 真实对话驱动（`scripts/calc_case_acceptance.py`，只走公开 API），在本单自己起的 8794 实例上跑，不切生产。
