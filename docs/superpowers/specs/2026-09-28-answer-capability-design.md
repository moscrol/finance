## 目标

提高用户任务的实际完成质量：同义查数一致、研究保留有效金融方法、证据不足可以继续取证、最终答案有依据且覆盖问题。
复用现有 Controller、TaskFrame、Episode、工具注册表、证据账与验证器；模型、事实权限、总预算和生产配置保持固定。

## 决策

1. 任务意图与主体身份分开。识别出公司/题材不能直接认定用户要求深挖；未被明确工作流或精确意图规则裁决的实体请求，交现有 Controller 做语义选路。已验证主体、日期、材料权限仍不可由 Controller 改写。Controller 失败保留原确定性研究下限和失败记录。
2. 查数可以直接进入现有研究工具循环，必需输出限于所请求事实、日期和边界；不能因为没有 ISO 日期而转另一条合成链。复杂判断的用户目标仍保留。避免新增财务指标/股票关键词补丁。
3. 判断增量和标准检索阶段是研究建议：保留材料去重、来源、反证与改判条件的实质，撤逐字栏目/固定缺反证声明/所有阶段必须查的要求。诊断不得把缺标题当质量失败。
4. 连续引擎的原生工具 schema 已包含说明与参数，动态正文只保留授权工具索引；需要文本协议的其他调用方继续默认完整说明。注册表仍是唯一描述源，不改变菜单与执行授权。
5. 终局恢复按既有错误码区分格式、证据和实质修订；研究未关闭、有工具与预算时允许补查。同一错误方向不得空转；格式后缺证据可在原总预算内接续。伪造哈希/越界来源保持拒绝，取消/已关闭研究不得重新开工具。
6. 金融方法的作用通过同题答卷验证；求证指导、自主视角不整体默认打开。已有数字句处理分支不在本单重写。
7. 实测暴露的输入约束误读沿现有材料合同修复：给定虚构题设与明确不重新查询先确定本轮输入上限，不能再要求新取证。局部禁查对象、引号中的指令不升级为全面禁读；旧答不升级为当前事实。保留逐条来源校验，不通过放松引用核验让答卷过关。
