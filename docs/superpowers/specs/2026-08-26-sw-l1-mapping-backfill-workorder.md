## 方案（已实证）：成员多数派推导 + 阈值 fail-closed

对每个板块，取当日成员的 `split_part(sw_industry,'-',1)` 分布，多数派占比 ≥ 阈值才写映射，否则**保持 NULL**（宽度袋如实「缺数」——跨行业概念本来就不该硬给单一行业对照）。

2026-08-25 实测读数：

- 阈值 ≥50%：可映射 **248/402**（现状 119 的两倍余）；≥60%：216/402
- 与既有 119 条静态映射的一致率：**70/72（97%）**（分母 72 = 双方都有值且多数派≥50% 的交集；2 条分歧执行时人工裁）
- 样例：光纤光缆→通信（100%，正是 react 臂当日用的映射）、农林牧渔→农林牧渔（94%）
- 正确落空的负例：海洋经济（多数派 35%）、超导概念（23%）——真跨行业，留 NULL 是对的
