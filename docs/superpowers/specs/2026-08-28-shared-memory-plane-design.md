## 0. 一句话原理

按 Knevo 契约把记忆分两个平面：**shared_memory（产品自带，方法论先验，只读）**
与 **user_memory（个人判断偏好，读写）**。新用户开箱即得前者；后者从零开始积累。
个人卡经人工策展可升格进共享层（user → shared 单向、显式、有评审）。

## 1. 策展判据（2026-08-28 对 43 条真实沉淀的分类实测）

| 类别 | 数量 | 去向 | 例 |
|---|---|---|---|
| 可泛化金融方法论 | 13 卡 + 7 纠偏 | **进附带库** | 深挖顺序、市场结构推演、卖方观点框架、A股炒预期澄清≠证伪、答案组织规范 |

> 混在一个库里发给别人既泄运营细节又污染注入。

## 3. 实现清单（gate 过后开分支 `feat/shared-memory-plane`）

1. `intelligence/shared_memory/methodology_cards.jsonl` + `methodology_corrections.jsonl`
   —— 从本轮策展产物（`users/ablation-shared-probe/`）迁入，schema 沿用现有
   experience_cards / corrections 字段（`promotion` 已够表达常驻语义，第一版不做
   Knevo 卡片契约的 schema 迁移，避免为 20 条卡写 migration）。
2. `experience_cards.load_cards`：支持 `(user_path, shared_path)` 合并；
   个人卡优先、同 `corrected_principle` 归一去重；空个人层回退 shared 全量。
3. `user_memory` M 块：`relevant_memory_records` 检索面并入 shared corrections
   （`source_plane=shared_memory` 标注，渲染时与个人纠偏区分措辞）。
4. 写权限（Knevo 契约 §6）：shared 文件运行时只读，变更只走 git 评审；
   个人卡升格 = 人工策展移行，不给提炼器直接写权。
5. 失效传播：个人层 `invalidated=True` 的卡若已升格，共享层同步标记
   （策展时检查，不做自动同步——量小，先手工）。
6. 回写能力图谱（新节点「共享方法论层」，spec 钉 `::load_cards` 符号级）+
   `docs/agent-product-door.md` 不动（这是积木不是门）。

## 4. 与 Alpha/Beta 的关系

- Alpha 即可用：附带库解决「新用户首日体验低于作者体验」的最大缺口之一；
- 防蒸馏立场不变：附带库是文本层资产，随回答外泄的本来就是它的应用结果；
  结构性护城河仍在数据管线与个人闭环（hosted-alpha-gate §3.5）；
- Beta 若走多租户，shared 层天然共享、user 层按租户隔离，形态不用改。

## 6. 第一轮读数（2026-08-28 04:15，run 20260827T191014Z）

单评读数：veteran 12.33 / coldstart 11.83 / shared_pack 11.83，Δ 全部落在噪声内。
**但本轮不构成「附带库无效」的证据**，两个归因发现：

1. **判官方差实测 ±3/20，单评分辨率不足**。确定性短路题 index-rebound-space
   三臂答案 md5 完全相同，盲评却打出 12/13/15——同文本重评方差比方差治理文档的
   历史噪声底（2.4）还大。处置：`exp_umd_rejudge.py` 对 18 份答案补评到 3 次取中位。
   > 可迁移：确定性短路题 = 免费的判官校准探针。以后每轮盲评都应故意塞一对
   > 相同答案实测当次方差，不引用历史噪声底。
2. **题型错配**。13 张卡 applies_to 集中在个股深挖/上涨空间/卖方观点/高位主线，
   而消融题集是大盘/指数/研判题——附带库主战场没被考到。活性检查证实注入发生
   （2066 字），但注入的方法论与题型不对口。若中位分仍无差，下一步不是放弃，
   是补 2-3 道个股深挖题定向重测。
3. 顺带发现：确定性题型（引擎 B 短路）三臂必然同答案——个人化/附带库只影响
   研究型题，聚合时此类题应标 `not_applicable` 剔除。

## 7. 终局裁决（gate 证伪，但产品结论是好消息）

1. **不做 shared_memory JSONL 注入层**：附带库经验卡与已固化管线内容重复，
   边际贡献 ≈ 0（三轮实验一致）。§3 实现清单作废，策展产物保留归档。
2. **「数据库附带」的真实答案：你的方法论已经附带了，形态是代码而非数据**。
   编排层 + 契约 + 质检门就是 Knevo 意义上的 shared_memory 平面，且强于
   prompt 注入（代码强制执行 vs 提示词有限遵循率——L1 双层约束原则的现场验证）。
3. **冷启动焦虑解除**：新用户首日答案质量 ≈ 作者账号（三轮读数无稳定差）。
   Alpha 可以放心发；「养熟」的真差异化在 corrections/checkpoints 的个人观点
   （veteran +2 残差待更大 n 验证），产品叙事 = 「方法论开箱即得 + 越用越懂你」。
4. **经验卡治理（已执行，`feat/promoted-to-code`）**：13 张方法论卡标
   `promoted_to_code`，`load_cards` 跳过注入。7 条纠偏里 1/2/3/5 走
   `memory_status` 归档（已在管线或含运营泄漏）；4 澄清≠证伪、6 相对日期绑复盘日、
   7 结构化腔留下——代码里还没有等价强制点。闭环：corrections → 经验卡（中转）→
   固化进代码/契约 → 卡片退役。

> 可迁移（本轮三条）：① 同文本重评是判官方差的免费探针，每轮盲评都该塞一对；
> ② 结构探针（关键词组覆盖）是比盲评分更便宜的「行为改变」证据，先跑它再花钱
> rejudge；③ 测「记忆/画像贡献」前先确认方法论是否已固化进管线，否则测的是
> 重复注入——「个性化价值」的分母是管线没做的事，不是全部方法论。

### 泛化纠偏原则（7 条）

1. 反模板化：评分器必须惩罚生搬硬套，奖励独立 thesis、具体数据权重、非共识判断和可交易的情景分歧。…
2. 多维动态推理：策略不是结论模板，而是判断市场状态和个股所处生命周期的概率框架；回答要显式说明个股当前更像启动核心、趋势延续、分歧回踩、低位补涨还是高位兑现，并给出时间窗口和证伪条件。…
3. 第一性原理 + 二阶导：问答先拆产业瓶颈与价值传导，再比较产业链暴露和逻辑生命周期；策略框架是可迁移的方法论工具，不是结论模板。…
4. 判断A股题材股：公司澄清/否认只锁定当期事实，不硬抹杀预期；证伪炒作靠催化落空、资金退潮、时间过期，不是公司一句话。把澄清当硬反证=用价值投资框架套预期交易市场，会系统性误判方向。事实层(含公司否认)…
5. 日度市场推演 = 盘面内生结构 + 外生映射 + 卖方/机构共识或拥挤度 + 早间增量。验证时看市场路径和题材/方向路径，不用单日个股涨跌推翻方法；缺源判断必须区分'材料不存在'与'本地镜像未同步'，…
6. 金融复盘语境中的相对日期必须从用户业务语境和已指定数据截止日推断；若用户已给‘截至7.3收盘’或‘7.3复盘’，‘今天’应绑定该复盘日期，不能按系统当前日期自动替换。…
7. 结构化数据不等于结构化腔；面向用户的答案按结论、依据、风险、明日观察组织，内部审计信息降级到详情。…
