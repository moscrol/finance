# 同花顺数据进时间长河：不是照搬看板，是按我们的契约把它们变成 agent 的 context（2026-09-08）

> 用户：「他的这些数据，其实给我们提供的是思路，结合我们的时间记忆长河和多维度，就是看怎么消费这些数据，用我们自己的契约和法则来消费这些数据，作为我们 agent 的 context。」
>
> 上游：`docs/superpowers/specs/2026-09-05-time-river-endstate-design.md`（钦定词：时间长河 / 联立 / 代码化 / 三维对照 / 观察剧本 / 环境剧本 / 流动性出口）；入库派单 `2026-09-08-hithink-finance-ingest-workorder.md`（工单 #41）。本文是 #41 的 **E 单（消费方）的设计稿**，不含实现。

## 0. 一句话

同花顺那 16 张「灵感看板」回答的是「今天这堆数长什么样」；我们的河回答的是「站在 as-of 那天，这堆数在五条轨上是什么对象、和别的轨怎么联立、按授课框架读出来是哪一段、明天该看什么」。看板是一次性的画面，河对象是可重算、带缺口声明、能过统计门的 context。**数据同一份，消费方式是两种产品。**

## 1. 六条不变的法则（新数据一条都不能绕）

| 法则 | 对新数据的具体要求 |
|---|---|
| **as-of + recorded_at** | 每个对象带 as-of 交易日与「我们什么时候能知道」：涨停池 / 龙虎榜 / 板块日 K 收盘后当天可知；个股 dump 是次日早上到的（recorded_at = 同步时刻）；热榜是盘中快照，记抓取时刻，历史热榜按 `date` 回补的行 recorded_at = 回补时刻——回放 `require_strict` 会把它们滤掉，这是对的 |
| **缺口不是零** | 源断更 / 未授权 / 当日无数据 / 一年窗之外，各有 gap 原因；`limit-up-pool` 2019 年之前返回空集，写 `beyond_source_depth`，不写「0 只涨停」 |
| **只到板块，不到个股名** | 带读 / 产品面只出板块级与市场级聚合；涨停原因、龙虎榜席位、热榜个股名只进旁路库 / 分析师侧（`guided_reading.lint_output` 照旧拦） |
| **四态门** | 看板里的任何「规律」（突破回测台、动量、反转、「机构净买入后 N 日」）进共享层前必须走 `methodology_backtest` 的 `stats.readout`（Wilson / 前后半段 / BH），N 不够就是 `insufficient_n`；读数不是结论 |
| **观察 / 确认 / 失效** | 输出永远是这三种事件与观察剧本，没有买卖点、概率、目标价；「策略」一词只能以「环境剧本」出现 |
| **可重算** | 同一 as-of 两次全新构建哈希一致；对象的 payload ≤ 20 键，源哈希进收据；换模型也算得出同一份 |

十年个股 dump 多一条**专属缺口**：只含今天在市的股票（2016 年只 2,771 只有行），任何用它做的历史横截面读数都要带 `survivorship_bias` 标注。

| 看板（思路来源） | 放到哪条轨 | 我们的对象 / 读数 | 看板做了什么 vs 我们做什么 |

## 2.5 候选维度与解读规则（用户第二十五段「基于这些数据做出新的维度解读规则」）

进入方式统一：先作**视角**写出（`tf.*` 标签，不计分），在 `stage_separation.candidates` 里按七段 η² 单列（训练 / 验证两半），两半都分得开、创始人认了才进靶子或证据目录。数字全是 B 类候选。

**已量出来的（用我们库里现有的个股 OHLC 与背离事件，#672 第二十五段）**：20 日新高家数 η² **0.46**（训 0.45 / 验 0.52，比官方最强的一年新高 0.43 还高，沿周期单调：底部 < 300、共建 559、主升 748、2.0 1116、高位震荡 807）；个股周均线（MA5）上方占比 **0.37**（底部两段中位 22% / 30%，上行三段 65%，高位震荡 53%；阈值 40% 分底部与上行 74% / 88%）；20 日新低家数 0.27（补亏钱效应那一侧）。背离广度 0.03–0.04，不认阶段——它是个股 / 板块层的事件筛，不是市场刻度。

**要等 #41 入库才能量的**（公式先定，接单 agent 落表时保证字段够用）：

| 候选维度 | 来源 | 公式（市场级，逐日） | 预期读法（待数据裁决） |
|---|---|---|---|
| 早盘封板占比 | 涨停池 `limit_up_time` | `#(涨停时间 ≤ 10:00) / #涨停` | 主升 / 2.0 高、高位震荡回落；与「承接」并排看情绪强度 |
| 封单留存率 | 涨停池 `seal_money / max_seal_money` | 全部涨停股该比值的中位数 | 低 = 抛压在消耗封单，是「亏钱效应日」的盘中前兆 |
| 炸板率 | 炸板池 ÷（涨停池 + 炸板池） | `#炸板 / (#涨停 + #炸板)` | 亏钱效应直接量；与 20 日新低家数、负承接天数一起补亏钱那一侧 |
| 涨停原因题材集中度 | 涨停池 `limit_up_reason` → 题材词（确定性词表，精确匹配） | 第一题材占涨停的份额；题材数 | 主线纯度：共建主线集中度升、高位震荡题材数多而份额散 |
| 涨停家数六年 | 涨停池 2020 起 | 逐日 `#涨停` | 授课框架校准靶子 `src.limit_up` 的训练期从 2025 拉到 2020（η² 两半不降才换） |
| 机构 / 游资净额分板块 | 龙虎榜 all + hot_money | 按 `.TI` 板块聚合当日与 5 日累计净额；`净流入前三 ∩ 成交前三` 的个数 | 流动性出口：钱去了哪些板块、和成交占比前三是否同一批 |
| 游资集中度 | 龙虎榜 hot_money 席位组 | 前 5 席位买入 / 全部游资买入 | 高 = 少数席位在抬，主升后段常见；待数据 |
| 注意力集中度 / 更替率 / 时差 | 热榜前 30（一年） | 前 30 里属成交前三板块成分的占比；今日前 30 有多少昨日不在；板块热榜席位数领先 / 滞后板块涨幅的天数（交叉相关取峰） | 舆论轨第三源：注意力晚于涨幅到 = 追涨拥挤；早于 = 先知，先量再说 |
| 板块相对强度 / 板块层结构 | 848 个 `.TI` 真 K 线 | 板块收盘 / 上证收盘 的 20 日变化；板块层 DIF 背离与分型 / 笔 | 板块角色多一条视角；`build-structure` 板块层改吃真点位 |

## 3. 联立：一个 as-of 切片长什么样

```text
as-of T（PIT）
  盘面轨  teaching_stage（七段 + fine）· teaching_capital（已有）· capital_exit（新：钱去了哪些板块）· limit_pool（六年：承接 / 促进率 / 早盘封板占比）· sector_structure（新：板块层背离 / 分型，真点位）
  题材轨  theme_lifecycle（已有）· limit_reason_theme（新：涨停原因归题材）
  舆论轨  teaching_narrative（卖方）· teaching_briefing（晨汇 Tier）· attention（新：热榜落在哪些板块）
  个股轨  节点事件（财报 / 公告 / 订单，日期 + 硬度）—— 不出名单
  判断轨  观察剧本登记 + 到期回检（不变）
```

三维对照多出的一句读法只可能是这种形状：「盘面在缩量右底、板块 X 出了 DIF 背离观察；注意力（热榜）还没落到 X 所在板块；龙虎榜净流入前三里也没有它」——**错位本身是信息**，不是买点。

## 4. 作为 agent 的 context：走投影，不走原表

带读与 agent 不直接读 `fact_*_hithink`；它们读 **上下文投影**（#667 的投影契约：切片 → 投影 → `projection_hash` 进台账门禁）。新对象加进投影要过三关：(1) 对象定义进 `river_objects`（payload ≤ 20 键、有 recorded_at、有 gap 原因）；(2) 投影 hash 变化在台账登记；(3) 带读文案过 lint（无名字、无方向词）。`river.window`（#670）负责区间视图（5 / 10 / 20 日），新对象的区间派生走同一契约，不另写窗口逻辑。

## 5. 顺序（接在 #41 的 A–D 之后，另开 E 单时按此拆）

1. **限定校准靶子回算**（价值最大、改动最小）：六年涨停池 → 承接 / 促进率 / 亏钱效应日 六年逐日 → 授课框架 `calibrate-stages` 的训练期从 2025 拉到 2020，η² 两半都不降才换。
2. **`capital_exit`**（流动性出口一等对象）：龙虎榜按板块聚合 + 游资集中度；市场级读数进 `teaching_capital` 旁边。
3. **板块层真点位**：`build-structure` 板块层与缠论改吃 `fact_sector_kline_daily`；`.FP` 对不上的 182 个题材保留复盘会口径、记缺口。
4. **`attention`**（舆论轨第三源）+ 涨停原因归题材（题材轨）。
5. 看板里的规则类（13 / 14 / 15）只在有人提出具体假设时才立单走四态，不批量做。

## 6. 不要做

- 不要把看板 HTML 当产物进仓库；不要让 agent 在对话里画表代替对象。
- 不要用热榜 / 龙虎榜个股名生成任何面向用户的文字。
- 不要因为十年 dump 深就把回测样本拉满十年而不标幸存者偏差。
- 不要用当前成分股回算历史板块指标后当真（只能标近似）。
- 不要绕过四态门把「突破 / 动量 / 反转」写进共享层。
