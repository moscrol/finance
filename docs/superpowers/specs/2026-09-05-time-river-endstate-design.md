## 0. 一句话

Foresight 的终局不是「又一个会写研报的 Agent」，也不是 Knevo 那种给加仓区和无溯源概率的决策助手。它是一条 **时间长河**：每个交易日的盘面、题材、舆论、个股节点、用户决策、agent 判断都落成可联立的代码对象；小白走 **授课框架** 学会复盘和次日观察；高手把自己的框架沉进私有层，系统按历史成功率升格或证伪。Knevo 已做成的记忆与证据回溯是 **入场券**，不加分。

完成标准：读完本文能回答四件事——给谁、河上有几条轨、三维对照是什么、哪些已经在仓里 / 哪些还是愿望。不能回答就本文没写完。

## 1. 要解决的两件事

同一条河，两个入口。不是两个产品。

| 路径 | 人不会什么 | 系统给什么 | 不给什么 |
|---|---|---|---|
| **小白路径** | 不会复盘、看不懂题材怎么演变、不知道明天该观察什么 | 授课框架带读：今天主矛盾、三维对照到哪一段、次日 **观察剧本**（看什么、升/降级条件） | 买哪只、几点买、涨到多少 |
| **高手路径** | 判断留不住、方法说不清成功率、换会话就要重讲 | 自己的框架进私有层；判断进台账；按环境剧本回测；越用越懂 | 用一次对错改规则；把召回次数当胜率 |

两件事的公共底座是同一条时间长河。小白缺的是 **坐标系**（授课框架），高手缺的是 **复利**（私有框架 + 统计门）。Knevo 的「千人千面 + 聊完即散」只覆盖高手这件事的一半（记得住），没有覆盖「方法过不过自己的门」。

## 2. 钦定词

| 词 | 它是 | 不要写成 |
|---|---|---|
| **时间长河** | 以 as-of 交易日为索引、多轨对齐的可查询对象河 | 聊天记录、向量库、一篇长上下文 |
| **联立** | 同一 as-of 切片上，多轨对象一起进入推理，缺轨声明缺口 | 先写完报告再补几条引用 |
| **代码化** | 轨上每条都是带 as-of / 实体 / 硬度 / 来源哈希的对象，规则可重算 | prompt 里的散文、截图、口头经验 |
| **三维对照** | 同一题材在同一天的题材生命周期 × 舆论生命周期 × 盘面生命周期并排 | 三份互不相干的报告 |
| **授课框架** | 创始人系统授课、学员认过的底层看盘方法，编码为共享层默认判读 | 某个 KOL 蒸馏稿、一次纠偏 |
| **观察剧本** | 次日要看的变量、升级条件、降级/放弃条件；可登记为可证伪点 | 第二天的方向、买卖时机、目标价 |
| **环境剧本** | 某类指数/流动性环境下，历史走过几次、共性、近期流动性出口、该环境下授课框架怎么读 | 交易策略、选股策略、量化信号 |
| **判读方法** | 这个数据该怎么读（2026-08-19 已分层，领域基线） | 判断倾向（怎么下注，persona 开关） |
| **入场券** | 必须有、不加分的能力。本终局把 Knevo 级记忆与证据回溯标成入场券 | 护城河、卖点 |

「策略」一词禁止出现在对外物料和 agent 输出里，除非前面加了「环境剧本」。单独写「策略」会被读成交易策略。

「第二天的方向」是小白的口语症状，产品语言一律翻译成 **观察剧本**。边界场景：用户问「明天买什么」→ 输出观察剧本 + 声明不是投资建议；用户问「按我的框架明天该看什么」→ 同一对象，只是框架换成私有层。

## 3. 时间长河：五轨一张索引

河的主键是 **as-of 交易日**（PIT，认不出的日期声明缺口，不猜）。每个 as-of 上至少五条轨，缺哪条就写哪条 gap，禁止用别的轨补编。

```text
as-of T
  ├─ 盘面轨    量价、双红、涨停热度、指数阶段、流动性指纹
  ├─ 题材轨    叙事版本、发酵节点、题材生命周期阶段
  ├─ 舆论轨    认同度/覆盖密度、逻辑版本（v1 概念 → v2 订单 → v3 兑现/证伪）
  ├─ 个股轨    节点（公告、订单、财报、相对强度），不是推荐名单
  ├─ 判断轨    用户决策 + agent 判断，到期回检，带规则号
  └─ （横切）授课框架 / 用户私有框架：决定「怎么读这五轨」，本身也版本化
```

**联立**的最小动作：给定 T + 实体（题材 / 个股 / 指数），取出五轨对齐切片，用当前生效的框架读，输出结论 / 证据 / 反证 / 观察剧本 / 缺口。五段缺一不发——这是已有出门纪律，终局不改。

**代码化**的判据：换一个模型，同一 as-of 的标签、阶段、回测收据必须能重算出来。重算不了的东西不算在河里，只算聊天。

## 4. 三维对照

把图文经验收成三条可版本化的阶段轴，同一题材同一天必须能并排。

| 轴 | 问的是 | 仓内已有 [实测] | 终局还缺 |
|---|---|---|---|
| **题材生命周期** | 市场把这个题材交易到哪一段 | 八阶段诊断 `theme_lifecycle.py`；时间线回放 `theme_lifecycle_timeline.py`（酝酿→首发→发酵→主升→分歧→退潮→回流）。两套词表口径不同，引用必须标明模块 | 两套词表尚未统一；逻辑版本（叙事怎么改写）只在 fermentation-tracer / recognition_timeline 里，没有和阶段轴锁死 |
| **盘面生命周期** | 指数/板块自身走到哪一段、量能和拥挤度 | 词表已有指数完整周期（左底向下…回踩周均线）；标签层 12 个逐日标签；D10 `market_regime_analogs.py` 市场级情绪对标 | 指数阶段判定还没有像题材八阶段那样成为每次复盘的强制切片；流动性出口（谁在提供成交、资金从哪来到哪去）没有一等对象 |
| **舆论生命周期** | 这个逻辑被多少人、以哪个版本在喊 | `opinion-cross` / `consensus_staging.py`：事实硬度轨 vs 舆情广度轨 | **没有阶段词表**。终局需要一条与题材轴可并排的阶段（例如：无人问津 → 卖方萌芽 → 覆盖扩散 → 共识拥挤 → 证伪/退热），只存事件、阶段派生，不落库状态机 |

三维对照的输出不是三张表，是一句可读的并置：「题材在升温验证，舆论还在卖方萌芽，盘面已连续双红」——错位本身就是信息。历史推演当下 = 在河上找三维结构相似的窗口，只报后续事实与复现次数，不编概率数字（沿用 D8/D10 纪律）。

## 5. 方法论三层

沿用 08-19 的慢变量容器，把「授课框架」放进共享层默认位。

| 层 | 谁的方法 | 默认 | 升格条件 |
|---|---|---|---|
| **授课框架** | 创始人课纲里被学员追问出来的底层看盘（三问：题材是什么、证据在哪、能不能信 → 出门纪律；以及系统授课的结构语言） | 开 | 先代码化成规则/词表，数字阈值进回测队列，过统计门才变硬判据 |
| **共享验证层** | 过了统计门的规则（含已收的 SPT/风远 A 类判读、未来的匿名策略族） | 开，可关单条 | 必须持 `supported` 收据；到板块/题材，不到个股名单；不用于对外营销 |
| **私有层** | 这个用户自己沉进去的框架与纠偏 | 只对本用户 | 只对本用户回测；召回次数 ≠ 胜率 |

Knevo 71 页分享说的「认知复利」落在私有层 + 判断轨。授课框架是产品人格：小白第一次打开就有坐标系，不是空聊天。

与 08-19 清单的关系：已裁定的 25 条 A 类 + 4 条 B 类结构是 **判读基线候选**，不是授课框架本身。授课框架要以课纲/直播里反复被问倒的结构为准，KOL 蒸馏是差分参考，不能反客为主。

## 6. 环境剧本（多种「周期下的策略」）

用户说的「多种周期下的策略」钦定为 **环境剧本**：

1. 先判定当前指数阶段 + 流动性指纹（成交额中枢、边际量、涨停热度、拥挤度）。
2. 在河上查出同指纹窗口：历史走过几次、后续 5/10/20 日事实、共性、失效边界。
3. 标出近期 **流动性出口**（成交从哪类板块来、往哪类去）——有数报数，没数写缺口。
4. 把授课框架或用户私有框架套进这个环境：这类环境下，框架历史上的四态是什么。
5. 输出观察剧本，不输出买卖指令。

D10 已经能做市场级窗口对标并只报后续事实。[实测] 缺的是：把指数词表阶段、流动性出口、框架条件化（「主升 / 反弹」过滤）收成一张可版本化的环境剧本对象，而不是合成阶段的一段散文。

## 8. 已有 vs 愿望（对照，不发明新平台）

08-13 spec 的结论仍然成立：三个旧愿望都不需要新建平台。终局多出来的是 **河的统一索引、舆论轴、授课框架默认位、小白路径**。

| 终局零件 | 已有 | 愿望 |
|---|---|---|
| 无前视 / 拒答 / 五段出门 | 判官 + PIT + 测试门禁 | 保持 |
| 判断轨回检 | checkpoints / verdicts / 83 个可证伪点 | 胜率面板按框架 × 环境拆，与记忆召回分列 |
| 方法论统计门 | `methodology_backtest` 四态；首批三条常识规则全部没过门 | 授课框架的数字阈值进同一条门 |
| 题材轴 | 八阶段诊断 + 时间线回放 | 与舆论轴锁死；词表统一 |
| 盘面/环境对标 | 标签层 + D8 题材类比 + D10 市场类比 | 环境剧本对象 + 流动性出口 |
| 舆论轴 | 观点事件库 + 认同度 staging（两轨） | 舆论生命周期阶段词表 + 三维并排 |
| 越用越懂 | memory_gate + 退出机制 + user_memory 只作先验 | 授课框架常驻；用户框架从 corrections 流水账搬进慢变量容器（08-19 已设计、待审） |
| 小白路径 | 无独立入口；产品默认按半专业自用 | 授课框架带读 + 观察剧本，不另做「荐股版」 |
| 时间长河索引 | 各轨分散在 DuckDB / 图谱 / 用户态 JSONL | 同一 as-of 的联立读取面（查询 API，不是新库） |

## 13. 审阅记录（2026-09-05，审阅方：Cursor agent）

用户口头确认终局；三道分叉未逐条拍板，按「没拍板之前按推荐答案执行」的约定，审阅方在推荐答案上加条件，用户可否任何一条。

### 13.1 §11 三题裁决

**1. 授课框架 vs 已收 KOL 判读 → 授课框架做共享层默认人格；KOL 25 条 A 类作差分参考。** 理由三条：(a) 它是唯一带着人和付费验证的方法——1000+ 学员用钱投过票，KOL 判读没有；(b) 授权与署名干净——KOL 判读一旦做默认，§7 / v0.6 §4.4 的共享层合规硬门（匿名化、授权另议）立刻被触发，一人公司验证期不该背这个；(c) 与 BP 创始人故事同源，对外一句话能讲通。**附加条件**：授课框架必须先成为可版本化的 artifact（课纲 → 词表 → 判读规则 → 数字阈值队列）。[实测] 仓内 `rg 课纲|授课` 只命中 `UBIQUITOUS_LANGUAGE.md` 与本 spec，`perspective_lab.py` 的 `user_framework` 画像仍是占位符——**这是终局最大的缺口，排在舆论轴之前**。差分方向反过来用 08-19 §4 的差分声明：授课框架为主坐标系，KOL 每条标「采纳 / 结构同阈值异 / 拒绝」。

**2. 舆论生命周期 → 独立派生轴，v1 只从仓内已有事件派生。** 理由：错位本身是信息（题材主升 × 舆论萌芽 = 早；舆论拥挤 × 盘面分歧 = 晚），做成题材轴上的修饰字段就测不出错位，三维对照会降成两维半。**附加条件**：(a) 阶段只派生、不落状态机（§4 已写）；(b) 数据源现实——仓内只有研报覆盖密度（`wiki/sources` 7,036 份带日期）与 `skills/opinion-cross` 的观点事件 / 认同度 staging 两轨，没有社媒热度；v1 词表的每一段都必须能从这两类事件确定性算出，算不出的段（「无人问津」需要负证据）标 `unverifiable`，不猜；(c) 不为此新增任何抓取器——v0.6 §8.3 停掉短视频 / FinHot 抓取的纪律同样适用于舆论轴。
