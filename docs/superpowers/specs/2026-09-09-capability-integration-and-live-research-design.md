## 4. 三条完整工作流验收

这些是额外集成验收，不替代原 00–10 单的冻结题集。选实际有材料和数据的对象，首跑前固定输入、独立参考、日期与判卷点。每条至少四轮，自动保存原始用户输入、回答、事件、结果和版本；不手改历史正文后续跑，不只留成功轮。

| 工作流 | 四轮最小过程 | 必须看见的结果 |
|---|---|---|
| J1 材料与财务研究 | 贴材料及比较目标 → 原页/公司差异 → 实算及排序 → 修改假设重算 | 正确材料身份与引用；真实执行；两次假设修改可跨追加轮完成；旧新产物齐；排序有经济解释，不要求强行翻转 |
| J2 缺数后恢复 | 原题留下具体缺口 → 既有维护链隔离补齐 → 回执恢复原研究 → 追问新增可回答部分 | 指向原会话/问题的身份；三个缺口各有正确答案增量；复用、幂等及实际数据根证据 |
| J3 跨日研究与方法结果 | 首日判断和验证条件 → 当日竞争解释 → 下一真实自然日续问 → 新材料或到期回检后更新 | 同一未篡改会话；研究先验可见；至少两种追问推进；方法/证据身份可追溯；改变查询、适用条件或结论中的至少一项 |

J3 自然隔日、隔离历史回放、真正前向回检三种证据分列。隔日但尚未到期时只能记录 pending；回检后更新可先用隔离历史材料验工程消费，最终生产前向结论仍等真实结果。候选方法不因一次命中晋升为有效方法。

反向验收：原文只改一个数、只改假设、只改来源日期、重复补数回执、已结束后重进同一会话、故障后恢复。验证受影响结果随之变化，无关结果被保留；服务失败与产品错误各自可见。
