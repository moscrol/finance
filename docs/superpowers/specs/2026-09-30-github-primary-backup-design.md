# GitHub 主协作与本地备份设计

目标：金融仓以 GitHub 为唯一日常开发入口，Gitea 保留可恢复的历史备份。
用户已要求按上一轮确定的单向备份方案搭好基础环境。

采用本地独立运行器而非反向 push mirror：使用固定源 SHA 的普通原子推送，
源端删除不传播到 Gitea，分叉写归档引用，任何源端写入路径禁用。
采用每日完整 Git bundle 和 API 元数据导出，为账号不可用时提供独立恢复入口。
Mac 登录会话每小时执行；离线期间补齐能力限于下一次本机运行。

配置切换保留用户工作树内容和所有提交，只改金融仓默认推送及旧 Gitea 跟踪入口，
GitHub main 固化原有两项必需检查。其他私有配套仓不自动公开或迁移。
Agent 正门、workspace doctor 和工作树盘点使用 GitHub 主干。
生产服务、数据库和业务候选合入不属于本次环境切换。

验收：临时真实 Git 仓验证快进、删枝保留、分叉保全、源端推送禁用和无 GitHub 恢复；
实际双端回读确认源提交得到备份、旧分支未复活、镜像仍为空、任务已加载。
