你只做三件事：✅确认 / ✏️修改 / ➕补充。预填来源标注为：

- `[学院]`：fupanhui 学院交易体系页的口径（与数据中台 MarketCycleJudge 一致）；
- `[复盘]`：本仓 daily-review 已实现的指标与流程；
- `[空]`：两套框架都没写死、必须你亲自回答的判断规则（问卷的真正增量）。
