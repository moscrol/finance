## 0. 一句话

第一刀收口时的瓶颈是**顶部横盘（承接盘反复）与底部横盘（缩量右底 / 共建主线）在六个指数视角上分不开**——创始人第六段说这两段「和成交占比前三板块主流板块是一体两面的，还有市场的赚钱效应也是相关的」。第二刀先把板块侧能在**市场级**聚合出来的量拿到平台八段上量区分度，有区分度的进八段证据；再往下才是板块级的角色标签与赚钱效应聚类。

### 1.2 落法

- `scripts/teaching_framework.py` 新增 `SECTOR_SQL`：逐日聚合 `new_high_1y_count / dual_red_theme_count / limit_themes_ge3 / limit_top1_share_pct`（双红阈值直接 import 回测层 `DUAL_RED_DIFF_RATIO_GT / DUAL_RED_AMOUNT_GT`，同一口径）；某表当日无行 → NULL，不用 0 冒充。
- `flags.py`：`SECTOR_FIELDS` 四列作视角写出（`tf.` 前缀，6 位规范化），缺失 → NULL + 缺口行（`sector_rows_absent` / `<field>_null`）。

- `SOURCE_TABLES` 加三张表进收据的源行数指纹。

## 3. 第三步（待做）：板块级赚钱效应——特征向量与并排聚类

创始人第六、七、十段：「赚钱效应其实就是市场的聚类分析，得有特征值才能分析」「特征聚类应该可以组合，就是要联立分析，不一定要直接锁死答案」。落法：

- 特征表 `history_sector_features(trade_date, sector_ts_code, …)`：`pct_chg`、`amount` 与占比、`diff_ratio`、`limit_up_count / limit_up_ratio / market_share / fd_amount`、`rps_3/5/10`、`dual_red_strict`、`new_high_count`（板块内 1 年以上新高数，经 `fact_stock_high_daily.plate / whitelist_sectors_json` 映射，覆盖待核）。
- 「赚钱效应板块集合」几套并排、都进收据、不锁死：(i) 涨停家数前 10；(ii) 严格双红集合；(iii) 5 日涨幅前 10；(iv) 各特征名次均值前 10；(v) 确定性 k-means（固定初始化、标准化特征、k 进参数）的「最热簇」。差分本身是读数。
- 与市场级 regime（`feat/money-effect-regime-rules` 的四轴，未合 main）联立：先只并排出表，不合并。

## 4. 第四步（待做）：候选规则 `money_effect_outside_volume_top3_below_ma`

骨架 §3.2 骨架不变：条件 = 指数在周均线下方（或来源状态属周期下半场）；outcome = 赚钱效应板块集合（第 3 步各定义并排）里过半板块的 `sw_l1 ∉ 前三申万`；基准 = 上方 / 上半场同定义；`stats.readout` 出四态。第一步的市场级读数（热门前 10 在前三之外的比例八段都 0.40–0.50）提示这条在申万一级层可能不成立——但 `sw_l1` 只覆盖 297 / 403 个板块，题材层再验后再下结论。

## 5. 第五步（待做）：板块侧证据进八段（题材层）

第 2–3 步落成后，把「主流板块是否更替（前主流出清）」「赚钱效应集合的板块周期位置」等作为市场级聚合再走一遍 §1.1 的「先量再建」；有区分度的进 `BAND_VIEWS`，重校准、验证期不掉才采纳。

## 6. 验收

1. 两次全新重建 labels / succession 哈希一致（§1.3 已过）。
2. `calibrate-stages` 两次输出逐字相同。
3. 板块侧四列的缺口按表分别记（`fact_stock_high_daily` 当日缺 → `new_high_1y_count_null`，涨停热度表当日缺 → `limit_*_null`），不出 0。
4. 采纳任何新视角进 `BAND_VIEWS` 前，收据里必须有 `agreement_train / agreement_validate` 两段读数，且验证期不明显变差。
5. 门禁：pytest、ruff、层级 / 路径 / 未读字段 / 数据集注册 / 工具可达。
