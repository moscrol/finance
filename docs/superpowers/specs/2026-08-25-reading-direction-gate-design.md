## 0. 一句话

公开稿里「放量下跌」「缩量回踩」「边际量转正」这类**读向词**，模型读反了照样出门——语义验证器只管数字编造（数字全对时不响），删句闸只对 market_watch / market_forecast 两路由的特定词面生效。5.2 在冻结题上把两个板块的量向标签互换写反（库实况：医药医疗 08-21/08-24 边际量 -16.83/-20.34 = 缩量，半导体 08-24 +16.25 = 放量，5.2 全写反）——这正是台阶组件立项要供数的「跌但边际量转正」形状被**拿着正确数据读反**。本单加一道确定性读向闸：能唯一锚定（板块 × 日期）的**陈述性**读向断言，对照注册观察值 `diff_ratio` 的符号，矛盾先**影子记账**（P0 不改稿），拿到基线率并标定提取器精度后再决定执法方式（P1：确定性换词 / revise-once / 仍只记账，三选一走消融）。

**激发案例校准（二审）**：5.2 的两处错误中，医药医疗句是「08-21 与 08-24 连续两天放量下跌」——窗口聚合形态，P0 按 §6 #11 skip；半导体句「08-24 缩量续跌」单日显式锚，P0 能抓。**live 复放 5.2 原文的期望战果 = mismatch 1 + skipped ≥1，不是 2**。离线 #7 夹具用两句独立单日错句测「多处命中」，与 live 期望分开写死，收尾对稿才对得上。

**判别变量**（验收只锁这一条）：人工植入单日读向互换的残差稿过闸 → trace 出现 `reading_direction_gate` 步、`mismatches` 逐条带（板块, 日期, 稿内读向词, 注册符号, 注册值, 句内摘录）；干净稿过闸 → `checked>0`、`mismatches=[]`、**公开稿逐字节不变**。不是「多删了句子」，不是「稿子更保守」。

人话：厨师端菜前，专门有个人对着台账念一遍——「你说这盘是加了量的，台账写的是减量」。P0 这个人只记小本本不拦菜（先搞清楚：厨师多久真错一次、以及这个对账员自己多久看走眼一次）；P1 才决定是让他直接把标签撕下来换正（换词）还是叫厨师重做（修订）。

## 1. 范围

### 1.1 做（P0，全部影子）

**新模块 `intelligence/services/reading_direction_gate.py`**，提取分三步、每步 fail closed：

1. **分句**：稿件按 `。；\n` 切句，句内再按 `，` 切子句；子句是判定单元。
2. **候选断言抽取**（先抽再锚，不是只扫注册名——否则「科技」永远不会进 skipped，#4 变异就测不到锚定纪律）：子句内出现读向词（词典冻结：`放量` / `缩量` / `边际量转正` / `边际量转负` / `量能放大` / `量能萎缩`）即成候选；再抽 subject 候选（子句内的连续中文名词串）与 date 候选（显式 `YYYY-MM-DD` / `MM-DD` / `M月D日`，或「当日/站立日」→ standing）。
3. **语气与锚定过滤**（全部 skip 计数，不判）：
   - **否定**：子句含 `并未/没有/尚未/未见` + 读向词 → skip（naive 读词会把「并未放量」判成「放量」，方向随语境翻转，P0 不解析否定语义）；
   - **引用**：`「」/『』/""` 引号内的内容整段剔除（画像原文引文不是对站立日的断言）；
   - **条件/前瞻**：子句含 `如果/若/将/能否/等待/预计` → skip（「能否缩量止跌」是期望不是陈述）；
   - **多日期子句**：一个子句里 ≥2 个日期 → skip（「08-21 与 08-24 连续两天放量下跌」锚不唯一——正是 5.2 医药医疗句的形态）；
   - **锚定**：subject 候选必须**精确等于**某注册观察值 subject（「科技」≠「量子科技」；「医药」≠「医药医疗」——两者 2026-08-24 同时在注册表且值不同：-21.28 vs -20.34，混用即误判）；date 锚不上 → skip。
4. **判定**：查同轮注册 `StructuredObservation`（`metric="diff_ratio"`，subject/as_of 精确命中）。`>0` = 放量/放大/转正，`<0` = 缩量/萎缩/转负；无注册值、值为 0 → skip。（`转正/转负` P0 按**状态近似**判——见 §2 术语注；昨今符号差的真变迁判定归 P1-b。）

**接线三句硬约束**（二审新增，抄错会让 P0 对激发它的路由是死的）：

- 门控 = **本轮注册观察值含 `metric="diff_ratio"`**（唯一条件；§6 #8 与本节同一扇门。台阶组件合入后冻结题自然覆盖；不制造「等台阶合 main 才能开工」之外的额外依赖）。
- 只挂 orchestrator 的**两处终稿留痕点**（以 `apply_market_watch_delivery_gate` 的 3080 owner/合成终稿、3992 Engine A 回退两处为锚并挂），**不挂 2976 草稿静默点**。
- **不复用 watch 闸的题型早退**——watch 闸对 `general_finance_qa` 直接 `applied=False`，冻结题整条事故链就是这条路由；新闸不看 `question_type`。验收 #13 变异锁死。

**产出与影子纪律**：payload `{checked, skipped, mismatches: [{subject, date, word, registered_sign, registered_value, excerpt}]}`（六字段，§7 #1 与此同构）；applied 即落 trace 步 `reading_direction_gate`——零命中也留痕（R-20260825-08 先例）；不改稿、不删句、不占 degrade 通道、异常回空不杀 run。

### 1.2 不做

- **不执法**——P0 不删句不换词不修订；执法方式（换词/修订/仍记账）在 P1 由影子基线率 + 提取器精度抽查 + 消融决定。
- **不解析否定/条件语义**——统一 skip（宁漏勿误）；不做语义近义扩词（「承接乏力」「资金流出」不是读向词）。
- **不判窗口聚合句**（「连续两天放量」）——P1-b。
- **不重做 #343**——判读规则进开场消息是入口侧（它的单）；本单只管出口侧对账。两侧词汇对齐即可，无代码耦合。
- **不管未注册阈值**（「约 1.8 万亿」形状——**原文有此阈值但未进本轮注册表**，见 P2-c）。
- 不实施 `probe.menu`（P2 预留原样）；不加模型回合、不改 tier、不动既有删句闸词面与路由。
- 不动台阶/资格盘组件本身（判定源零改动；其既有测试必须逐字节同绿）。

## 2. 术语

| 词 | 本稿含义 | 不要当成 |
|---|---|---|
| **读向词** | 对「量的方向」的定性词：放量/缩量/边际量转正/转负/量能放大/萎缩 | 涨跌方向词（pct_chg 符号另族，P1 可扩）、资金流向词 |
| **放量/缩量（本闸口径）** | **日环比边际量（`diff_ratio`）符号**——本仓另有「成交额对 20 日均额」口径（foresight_methodology），孤立句「放量」可能指后者；本闸只按 diff_ratio 判，正文写死，对 5.2「数字对、词贴反」形态成立 | 20 日均额比口径的放缩量 |
| **转正/转负（P0 近似）** | P0 按**当日状态**近似（>0 即认「转正」不误杀）——连续五天为正仍说「转正」这类**真变迁误用 P0 抓不住**（宁漏）；昨今符号差的变迁判定归 P1-b | 已实现的变迁校验 |
| **读向断言** | 子句内可唯一锚定的（subject, date, direction）三元组，且非否定/引用/条件语气 | 任何提到板块的句子 |
| **判定源** | 本轮注册 `StructuredObservation(metric="diff_ratio")` | grid 渲染文本、库直查（闸不开新查询）|
| **影子闸** | 判定 + trace 记账，稿件字节不动 | 灰度删句 |
| **提取器精度标定** | 影子期人工抽查每条 mismatch：真读反 vs 提取器误伤——**先有这个分类，mismatch 率才能归给模型** | 把 mismatch/checked 直接当模型错误率 |
| **同席** | 判读规则切片与对应数据组件一起进开场消息（P1-c，衔接 #343） | 把整本画像塞进 prompt |

## 6. 契约

1. **判定源唯一**：只读本轮注册 `StructuredObservation`（`metric="diff_ratio"`，subject/as_of 精确等值）。不查库、不读 grid 文本——闸不得开第二条取数口径。
2. **锚定 fail closed**：subject 候选必须精确等于某注册观察值 subject（「科技」≠「量子科技」，「医药」≠「医药医疗」）；日期必须显式或「当日/站立日」→ standing。锚不上 → skipped，不猜。
3. 注册值为 0、同日无值（上游冲突不产值）→ skipped。
4. **影子不变稿**：闸前后公开稿字节相等；不占 degrade 通道；门开时 trace 步必落（`checked=0` 也留痕）。
5. mismatch 记录六字段 `{subject, date, word, registered_sign, registered_value, excerpt}`；excerpt 只截断句内最短片段（trace 落 run 私有目录，与既有稿件落盘同级）。
6. 词典与语气标记词冻结为模块常量；扩词必须带新夹具，不改正则骨架。
7. 异常一律回空 payload——闸不得杀 run（预取件同款纪律）。
8. **门控唯一条款**：本轮注册观察值含 `metric="diff_ratio"` → 启用；否则不落步（与 §1.1 同一扇门；「applied 即留痕」的前提是门开）。**不看 `question_type`**。
9. **语气 skip**：否定（并未/没有/尚未/未见）、引号内（「」『』""）、条件前瞻（如果/若/将/能否/等待/预计）→ skipped。
10. 放量/缩量按 **diff_ratio 符号口径**判；`转正/转负` P0 按状态近似（§2 注），真变迁校验归 P1-b。
11. **多日期子句 skip**（「08-21 与 08-24 连续两天…」）；单子句单日期才判。
12. **影子期停规**（二审新增）：分母 = `checked`（成功判定的断言数），不用 run 数；`checked ≥ 50` 且全部 mismatch 完成人工二分（真读反 vs 提取器误伤）后，才允许评估 P1 执法；提取器误伤率 > 真读反率时**先修提取器再谈执法**。没有停规，「等自然样本」会无限期。
