# 金融 Agent 使用手册（人读版）

> 这份手册是写给「使用者」的，不是写给机器的。
> 你不需要记任何命令——你只需要知道：**这套东西能帮你干什么、你该怎么开口、它会给你什么**。
> 命令、脚本、字段这些细节，agent 自己会处理。

---

## 一、它到底是什么

你养了一个**盯盘 + 做研究的助手**。它干两件事，并且把这两件事**对在一起**：

1. **盯盘（盘面）**——每天 A 股收盘后，它去把行情数据扒下来：哪些板块强、哪些题材资金在进、连板梯队、涨停热度、个股新高、涨家数……存进一个本地数据库，随时能查、能回测。
2. **做研究（认知）**——你平时看的研报、纪要、公告、卖方观点，它帮你消化、归档、连成一张**知识图谱**：哪个题材、属于什么产业链、链上哪些公司、有什么证据支撑、市场到哪一步了。

它最值钱的地方是 **把这两边对齐**：
> 不是孤立地告诉你「今天 CPO 板块涨了 3%」，而是告诉你「CPO 今天双红放量 → 这是因为上周那篇研报提到的某个催化 → 链上核心公司是这几家 → 但消息面其实还没兑现，属于预期博弈阶段」。

它服务于两个最终目的：**帮你做交易决策参考**，以及**帮你产出内容**（长文 / 视频脚本）。

## 二、它由几块拼成（你大概知道就行）

- **你的 Mac**：真正存数据的地方。行情数据库、你登录好的 Chrome（用来抓数据）、各种凭证都在这。
- **两个代码仓库**：
  - 「金融库」——管盯盘、数据库、复盘、回测。
  - 「知识库」——管研报消化、知识图谱、问答。
- **一套编排层**：横跨两个库，统筹「每天该干哪几步、用哪个工具、产物落哪、跑没跑全」。它让上面两个库不是各跑各的，而是被串成有节奏的早/晚流程并自动对齐（详见第三·补节）。
- **一条远程隧道**：让 agent（在云端）能伸手到你 Mac 上干活。这条隧道偶尔会掉（Mac 重启、服务崩了），掉了的现象就是「连不上、回填跑不了」，解决办法就是在 Mac 上重启一下那个服务（agent 会告诉你具体怎么敲）。

你日常**唯一需要操心的硬件层面的事**：Mac 开着、Chrome 开着且登录着、隧道服务在线。其余 agent 自理。

## 三、你平时怎么用它（按场景）

下面每一条，左边是「你想干的事」，右边是「你直接跟它说什么」。不用记命令，说人话就行，括号里是它背后会做的事。

### 1. 看盘 / 复盘

- **「帮我复盘今天」** / 「复盘 6 月 25 号」
  → 它把当天全市场数据抓一遍存库，给你一份结构化的当日总结（市场强弱、板块边际、题材资金、连板梯队、涨停热度等）。
- **「最近这周的行情数据补一下」** / 「把缺的几天补上」
  → 它检查数据库哪几天/哪些表有缺口，小批补齐（它会先审计再补，不会乱跑）。

### 2. 看排行 / 找强势股

- **「今天涨幅排行」**「这一段区间谁涨得最多」→ 纯涨幅榜。
- **「放量上涨的排一下」→ 量价加权**（既要涨得多、又要成交大）。
- **「强势股入库，顺便看哪些回踩均线了」→ 入库 + 均线回踩筛选。**
- **「连板晋级」/「晋级」→ 连板梯队晋级情况。**
- **「自选股里哪些回踩了 10 日/20 日线」→ 只看你的自选股。**

### 3. 研究一个题材（这是它的强项）

- **「液冷服务器是什么题材，帮我拆一下」**
  → 它给你：这词到底指什么、产业链上中下游怎么分、链上核心公司分层（主线/相关/边缘）、有哪些证据、目前哪一环还缺信息。**这是一份只读的分析报告，不动任何数据。**
- **「液冷这个题材是怎么一步步发酵起来的」**
  → 它把「消息面（哪天出的研报/催化）」和「盘面（哪天首板、哪天板块双红、哪天补涨扩散）」按时间轴对齐，告诉你谁先启动、谁是补涨。
- **「XX 公司/题材现在怎么样」**
  → 它综合「盘面 + 知识图谱 + 证据」给你一份六段式回答：**结论 / 证据链 / 分歧反证 / 还需要验证什么 / 交易上意味着什么 / 引用来源**。每条判断都带出处编号，不编。
- **「猜我想问什么」/ 「潜意识模式」**
  → 反过来，它替你问——基于当前盘面和你的关注点，主动抛出你「还没想到但最该问」的问题。

### 4. 消化你投喂的资料（研报 / 纪要 / 公告）

- **「这份研报 PDF 入库」**「这个怎么入库」
  → 它先识别这是什么类型的材料，告诉你该喂给哪几个模块、各喂什么，然后归档 + 更新图谱。**注意它很克制**：研报里的「受益判断、产业链名单」默认只进图谱，不会污染公司正文；只有公告/订单/中标/量产这类**硬事实**才会写进公司页。
- **「晚间这几篇卖方研报分个层」**
  → 它切成「行业要闻 / 个股逻辑」两层，逐家标注库里是已有/缺卡/没页，并判断是「信息增量」还是「扎堆跟风、可能透支」。
- **「晨汇」/「盘前把这些纪要消化一下」**
  → 盘前把公告/纪要跟知识库做三维交叉（公告 × 认知 × 盘面），分 Tier 1/2/3，生成一份盘前简报。

### 5. 批量 / 高风险任务

- **「我要批量回填历史数据」**「开个新题材大批入库」
  → 它**不会闷头开干**，会先「采访」你：范围多大、目标是什么、允不允许建新公司页、缺数怎么办、跑哪个分支……问清楚、过一道门控校验，才放行。这是故意的——批量任务一旦跑歪，清理代价很大。

## 三·补、它的「编排层」——谁在指挥这些活

上面那些事不是各跑各的，背后有一套**编排层**在统筹「每天该干哪几步、用哪个工具、产物落到哪、跑没跑全」。它分三层，互相兜底：

### A. 运营编排层（定流程的「值班表」）
这是核心，对应一份《每日运营总编排手册》，agent 每次开工先读它。它把每天的活拆成**固定的早/晚两套流程**：

- **🌅 早间（盘前，你投喂公告精选 + 电话会纪要）**：
  PDF 转写归档 → 建来源索引页（按 L1-L4 分层）→ 主题交叉匹配 → 生成晨汇 → 三维交叉分析（公告×认知×盘面，分 Tier）→ 把带时间窗的催化事件入池 → 登记留痕提交 → 重建检索索引。
- **🌃 晚间（盘后，你投喂复盘资料 + 卖方研报）**：
  研报存档 → **卖方覆盖密度交叉**（同一逻辑被几家卖方覆盖：0-3家=首篇增量🟢 / 4-10家🟡 / >10家=可能透支🔴）→ 盘面兑现回溯（涨停连板比对题材发酵到哪一步）→ 认知页更新 → **提及频率刷新** → 重建本地驾驶舱 → 登记提交 → 重建检索索引。

> 它会自动把活分派给下面的子模块（晨汇、三维交叉、卖方交叉、催化日历、资料路由等），你不用一个个点。

### B. 自动化编排层（串代码的「流水线」）
金融仓里有一套用代码把盘面和认知**自动对齐**的工作流：
- **每日 agent**：把当天盘面候选 × 知识图谱里的逻辑自动匹配，给每个候选打标签（新候选 / 老题材唤醒 / 数据缺口 / 噪声），产一份当日台账。
- **题材雷达**：一个题材一键 fan-out 出「定义 / 产业链 / 公司分层 / 证据 / 缺口」。
- **统一问答**：你问一句，它同时去盘面、图谱、证据三个后端召回，再融合成带出处的回答。

特点是它**不重写各模块，而是把它们当后端按需调用再融合**——所以你问一句，背后可能动了好几个数据源。

### C. 门控 / 工作记忆层（防漏步、防跑歪的「安全闸」）
- **采访门控**：批量回填、开新题材这类大动作，开跑前先「采访」你问清范围/目标/缺数处置，过一道校验才放行。
- **工作记忆 + 完成闸门**：多步流程开跑前先在本地落盘「计划/证据/进度」三份文件（防中途崩溃、防 `/clear` 丢上下文），**收尾前自动校验关键步骤跑没跑全**（比如晚间的「卖方交叉」「提及频率刷新」最容易漏，没跑就硬卡住不放行）。

> 一句话理解这三层：**A 管「今天该干哪些步」，B 管「把盘面和认知自动对上」，C 管「跑全、跑对、不闷头乱跑」。**

## 四、它的几条「做人原则」（你该知道，这样才信得过它）

1. **保守，不污染**：研报观点 ≠ 事实。它默认把研报判断放进「图谱/线索」，只有官方公告级的硬事实才写进公司正文。所以你看到它写进公司页的东西，可信度是高的。
2. **不编数据**：数据源超限/报错时，它会**停下来如实说**「这块没取到」，而不是随手编一份贴个标签。
3. **留痕**：每条结论带出处；犯过的错单独记在一个「教训本」里，避免重犯。
4. **大动作先分支、合并先问你**：涉及批量写入、改规则、跨库改动的，它会单开一个分支干，要不要合并回主线**一定等你点头**。
5. **省着读**：知识库很大，它不会为了「了解一下」去通读几千个文件烧 token，而是走索引和脚本。
6. **不用未来信息**（2026-06 新加固）：每份资料都记「什么时候产生、我们什么时候能看到」两个时间。回看历史（比如「以 3 月 1 日的视角看某题材」）时，它只用当时真能看到的信息，不会拿后来才发生的事去「事后诸葛」。这条由几个自检脚本把关，回填/分析时自动挡住穿越。
7. **结论可复现**：每份产物记得清「是哪个版本、哪天的数据出的」；关键日志只能往后追加、不能改历史，改了会被自检直接报错。
8. **守本分（永久研究员，只建议不下单）**：它的定位是**分析顾问**——只出「带出处的定性建议」，交易决策永远交给你。「目标权重/下单/成本」这类操盘手字段在 schema 里**强制留空**，填了直接报错。这不是「升级前的占位」，而是**永久护栏**：agent 不打通交易闭环、不替你做交易决策。

> 上面 6~8 条是这轮按一篇「LLM 交易 agent 复现性」综述做的「市场工程纪律」加固，对应 MR-1~MR-7 自查表（见 `agent-mr-checklist.md`）。一句话：**从「相信它守规矩」升级成「能脚本验证它守了规矩」**；定位锁定为**研究员/分析顾问（终态）**，不做操盘手。

## 五、需要你出手的时候（就这几种）

agent 绝大多数事能自理，但有几类事它替你做不了，会停下来找你：

- **隧道掉了**：现象是连不上 Mac、复盘/回填跑不了。解决：在 Mac 上重启隧道服务（它会把具体命令贴给你，照敲即可）。
- **Chrome 没登录 / 没开调试**：抓 fupanhui 数据要用你登录好的 Chrome，没开它就抓不到，会提示你。
- **要凭证 / token**：换新环境时需要你贴一次 token，这是安全边界，省不掉。
- **批量任务的关键决策**：范围、要不要建新页、缺数怎么办——它会问你拍板。
- **合并到主线**：永远等你确认。

## 七、一句话总结

> **你把研报和盘面丢给它，它帮你消化、对齐、连成图谱；你想看盘就说「复盘」，想研究就说「拆一下 XX 题材」，想问就直接问。它会给你带出处、分层级、留缺口的答案，绝不替你拍板买卖——它是你的研究员，不是你的操盘手。**
