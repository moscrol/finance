## 范围与隐私

包含：6 篇 SPT 文章中的 7 段相关连续摘录、4 条完整历史补丁、2 条纠偏记录、6 段相关项目讨论/问卷/审计摘录、必要算法、少量市场数据及覆盖统计。

不包含：文章全文合集、私人记忆仓、原始聊天运行目录、个人账户/持仓/凭证、整库、生产画像。保留公开股票代码是为了核验市场样本，不代表用户持仓或推荐。

包内路径均为可移交相对路径，没有本机用户名及用户空间 ID。公开形式为本目录中的文本文件，不上传 ZIP 或整库。`data/run_receipt.json` 等保留的是本机采集时的历史收据，其中“无上传”描述采集动作，不是否认后来获准的本次公开。

原私密包未改动。本副本只更新阅读入口、交付状态和 manifest，另附 [公开范围与核验](PUBLICATION.md)；其余算法、摘录、状态、样本和历史收据保持原字节。每次扩大来源或刷新数据须重新审阅范围，不自动同步用户目录。

## 核验与复现

- 在本目录运行 `python3 tools/verify_bundle.py`：校验包内文件指纹与基本结构；成功不等于语义正确。云端没有数据库时也能运行。
- `tools/collect_data.py`：需本机两份数据库与 `duckdb`，用 `--main-db`、`--labels-db` 指定；只读连接、独立事务、临时视图，不运行 build-labels 或任何写库命令。它会刷新本包 `data/`，随后需重做包指纹。
- `tools/collect_sources.py`：只为本机重提调保留，需 `--repo`、`--userspace`；云端没有原件时无需运行。
- 本次代码工作树 revision：`148a09ec85d2d5ef63957f3318ce88e8b18ef05b`，分支 `docs/cloud-research-context`。它不同于原公开快照内记录的导出 revision；代码和公开来源指纹分开标识。

本包核验：正文摘录/源码读取日期均为 2026-10-07；未对文章网站重新取证。数据库日期范围和查询时刻见数据收据；历史讨论里的旧测量数字不冒充本次结果。
