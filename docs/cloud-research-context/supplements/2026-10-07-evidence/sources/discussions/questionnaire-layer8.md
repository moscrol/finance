## 第八层（用户口述）：完整周期底层原理（2026-07-03 补充采访）

> 用户主动补充的周期链路全文 + 逐点答疑，是大盘/情绪/板块三层坐标的运转原理，
> 编译时并入 market_lenses 与 reasoning_patterns。

### 周期链路

转点（上升 → 盘整 → 转下跌）→ 确认左底 → 左底向上（站上周均确认左底有效）
→ 若无新的接力量价 → 二次探底出清 → 二次探底确认底部（夺量与夺价在轮动中进行）
→ 缩量右底（情绪回暖极致日站上周均）→ 共建主线（板块轮动：量引领的轮动 × 价传导的轮动；
轮动到位 = 涨跌家数配合指数小冰点回踩，关注容量日）→ 轮动后分歧转一致共振
→ 主流主升（诞生自身容量核心 = 抱团载体）→ 见顶（量价时空：容量顶/情绪顶/时间周期/空间高度）。

关键判断点：
- **转点触发**：指数级别最大——出现缺口、跌破周均线；题材层面和情绪周期层面作辅助判断。
  （另两类背景条件：主流主升走完自身情绪周期获利盘出清；情绪周期走完二/三阶段。）
- **确认左底**：指数企稳 + 当日量板块/价板块 + 前主流是否出清 + 亏钱效应趋缓、赚钱效应建立；
  底部区间**情绪往往先于回暖**（春江水暖鸭先知），情绪先回暖会传导给容量走强；
  情绪走强日关注成交额靠前的领涨个股；底部阶段**重点关注价的板块**。
- **左底向上**：指数的趋势性（持续放量+空间），板块持续性配合；确认后重视主流持续性——
  自身带量且有情绪资金 → 有望抱团穿越周期。
- **指数连续走弱时（价的方面）**：看趋势量（加权涨幅靠前个股）有没有波段抗跌；
  关注是否情绪领涨、价的分歧最强、是否弱转强。
- **二次探底判别**：赚钱效应继续延续 → 良性轮动；亏钱效应放大 → 谨防二次探底
  （注重赚钱/亏钱效应的**边际变化**）。
- **主流主升见顶（量价时空）**：
  量 = 绝对容量、板块量相对 120 日均（现在**双红题材优先级更高**）、板块内自身有量；
  价 = 板块 RPS 强度、情绪周期、板块新高个股、板块内波段涨幅个股、涨停个数；
  另研究方向：**个股成交额/流通市值比值**——回查历次行情加权涨幅靠前个股见顶时的比值规律（TODO）。
- **价的小周期分歧**：主流主升内部，价的分歧会给量的载体带来情绪小冰；
  关注核心载体情绪负反馈后的分歧转强（仅分析框架，不出买卖建议）。

### 答疑澄清（2026-07-03）

1. **量板块**：容量占比前三的申万一级里的板块；**价板块**：5 日涨幅靠前但量能不足以进占比前三的板块。
2. **情绪周期阶段划分**：旧口径按连板个股高度周期；**现口径按个股区间涨幅**——
   结合涨家数 MA5 的波峰波谷，看个股区间涨幅和加权涨幅是上升还是下降。
3. **转点**：指数级别最大（缺口+破周均线），题材/情绪周期辅助。
4. **趋势量**：加权涨幅靠前的个股，看有没有抗跌。
5. **容量日**：与全量复盘「量日/双量日」同一口径。
6. **市值容量顶比值**：个股成交额/流通市值；需回查历史行情找见顶比值规律（研究 TODO）。
7. **板块量 120 均**：板块成交额相对自身 120 日均量；但现在双红题材优先级判定更高。
8. **核心载体判定**：靠**相对强度**——分歧时强于其他，上涨时强于其他。
