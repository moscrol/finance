- **正式口径进 `structure.py`**（`divergence_events`，指数 / 板块 / 个股同一份）：摆动低点 = 收盘是前后各 `swing_k = 2` 天里唯一的最低，第 2 天后才算知道；`macd_bottom_div_observe` = 相隔 ≤ 60 日的两个摆动低点收盘更低、DIF 更高，记在第二个低点确认日，`macd_div_anchor_idx` 指向那个低点；`macd_bottom_div_confirm` = 连续三个摆动低点收盘递降、DIF 递升，记在第三个低点确认日；`macd_bottom_div_failed` = 观察 / 确认之后 `fail_horizon = 20` 个交易日内第一次收盘跌破锚点低点，记在跌破那天；`macd_top_div` = 两个摆动高点收盘更高、DIF 更低（柱口径不过门，不做正式事件）。三个参数都在参数文件 `structure` 块里。原先按分型算的 `macd_bottom_div_dif / hist` 等八列保留为读数。
- **进证据（B 类候选，参数 `structure_evidence = true`）**：观察或确认日给**缩量右底**（照旧受「周均线下方」的门）与**共建主线**各记一分 `H:macd_bottom_div`；其余五段不给（横截面里那几段背离后与随便一天一样）。上证 402 天里这条只在 4 天亮（共建主线 3、缩量右底 1），**阶段分布、平均 η² 0.1490 / 训 0.1548 / 验 0.1989、一致率 44.5% 一个数字都没变**——指数日线级背离太稀，这条证据在指数上是「不伤、也不帮」；它的价值在下面两层。关掉开关（`false`）只写出不计分，目录里也没有它。
- **板块与个股层（`build-structure` + `structure-screen`）**：同一定义套到 `fact_sector_daily`（板块没有收盘价，用 ∏(1 + pct_chg) 从 100 起造合成点位）与 `fact_stock_daily`（收盘），只落**事件日**一行进 `history_teaching_labels`（`entity_type = sector / stock`，`label = tf.macd_bottom_div_observe / _confirm / _failed / tf.macd_top_div`，`value_text` = 锚点日，名字放 `status_reason`），少于 120 个可用日的序列不算。快照上板块 549 条序列（**2026-07-27 板块宇宙从 630 个 `.TI` 换成 403 个 `.FP`，按代码接每条只剩 28 天、全被门槛挡掉，所以按名字接、116 条跨代码，`entity_id` 取事件日当天代码**）出 2,916 行，个股 5,568 只出 74,594 行。`structure-screen --date D` 列当天两层的事件清单、锚点日、当日市场粗段、板块的四个角色标签（成交前三 / 涨幅前十 / 双红 / RPS5 名次），`--events` 过滤。**这是分析师侧的工具，输出是观察 / 确认 / 失效事件，不是买卖点**——「找低吸买点」是你拿着这张清单、叠上阶段与角色自己做的判读；带读 / 产品面不读 sector / stock 这两类行（`guided_reading.lint_output` 照旧拦名字与方向词）。板块层的事后读数见 §8.19：观察后 20 日为正 65.8%（基线 58.2%），在缩量右底 85.9%、共建主线 80.6%，在左底向下 46.6%（比基线还差）——**和个股层同一个形状：背离认阶段**。
