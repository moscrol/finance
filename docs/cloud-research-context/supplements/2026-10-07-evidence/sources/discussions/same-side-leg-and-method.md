- **高位震荡的区间结构 = 高点不抬高 + 收敛**——已建两对旗标 `index_high_not_rising_{5,10}d`（近 N 日最高 ≤ 前 N 日最高）/ `index_range_converging_{5,10}d`（近 N 日高低幅 < 前 N 日），只作视角。真库上现在标成高位震荡的 18 天里两者同真只 4 天——因为现在的高位震荡主要是 `偏离度 ≥ 1.5` 的进入日（还在冲高），你说的形态描述的是见顶之后的震荡段，要等四维度替换旧 H 后才看得到。

- **「一般都会触碰一下周均」** + 上一条的三日窗口，合起来给出「残差」的一种可计算读法（**agent 的操作化，标出来等你认**）：不放量、且 ≤ 3 天就跌回的上穿 = 触碰周均的反弹，不是转点；其后的再次下穿 = 回踩探底（`cross_below_kind = retest`），而不是新的「第一次下穿」（`first`）；`below_ma_cycle_day` 从第一次下穿起数，跨过这种残差上穿不中断，直到某次上穿放量、或在上方待满 3 天以上。真库：下穿 53 次里 first 28 / retest 25；54 段碎的下方运行接成 **29 轮周期，中位 7 个交易日、最长 31**，覆盖全部 161 个下方日加 103 个残差日。这就是 缩量右底 与 左底向下 分界的候选谓词原料：缩量右底 = `cross_below_kind = retest` 之后的下方段。

- **原则 · 先有可计算、可聚类的数据形式，agent 才能联立分析；定义也可以通过真实历史数据做优化。** 前半句就是本骨架的全部工作方向（A 类旗标 / B 类标量 / C 类角色都是数据形式）。后半句是授权：阈值、窗口、容差这类 B 类数字可以在历史上调——但要走 §5 E 类的门：候选值 → 四态收据 → 前后半段一致才算、不一致标 `not_distinguishable`；调参用的样本与验证的样本分开；每次调整 = 新 `framework_version`，旧收据 `incomparable`。**不允许**用同一段历史既选阈值又报命中率。
