# 团队「周会证据包＋交接」样例与测量

只用于需求验证访谈与样例演示，不建设多租户团队系统。私有判断默认不共享；意愿不算订单。

## 样例：一页证据包

| 栏目 | 样例内容 | 来源对象 |
|---|---|---|
| 冻结依据 | 会前资料清单：3 份公告（含哈希）、1 张数据表（截止 2026-10-02） | `object_refs`（kind / id / namespace / version_or_hash） |
| 旧判断 | 「某板块 Q4 需求转弱」——登记于 2026-09-10，触发条件：订单同比转负 | 既有 judgments 台账（只引用，不复制） |
| 变化 | 新增证据 2 条：一条支持、一条相反；触发条件未满足 | 01 的变化项（needs_review，不写「已证伪」） |
| 分歧 | 研究员 A：维持；研究员 B：修订为中性；理由各一句 | 会议记录（假名） |
| 负责人 / 复核日期 | 负责人 X；下次复核 2026-10-20 | `due_rechecks[].due_at` |

## 要测的三件事（访谈 + 样例演示时记录）

| 测量 | 做法 | 落到哪 |
|---|---|---|
| 准备时间 | 研究员按平常方式准备一次周会材料的耗时 vs 用证据包 | `time_interval(manual_actual)`，条件 original / assisted |
| 遗漏 | 对照冻结依据清单，平常方式漏掉的资料与变化数 | 访谈记录 + 样例对照表 |
| 依据还原 | 新同事拿证据包能否在 10 分钟内回到原始资料 | 演示计时 + 是否成功 |

## 边界

- 私有判断默认不共享；团队聚合可见范围由同意范围 `team_share` 决定。
- 「愿意采购」记为需求证据等级（口头 / 有预算 / 有流程），不进 `payment_recorded`。
- 多个客户购买同一流程、数据权利与交付成本可证后，再各立独立 spec（总合同 §7）。
