# 金融回答质量 Rubric

`answer-score` 用来给一段金融 agent 回答打行业质量分。它补的是 `agent-eval`
没有覆盖的部分：不只检查引用和工具调用，还检查回答有没有符合 A 股研究和交易复盘的思考路径。

## 使用

```bash
python3 -m intelligence.cli answer-score \
  --question "瑞华泰还有上涨空间吗" \
  --answer-file /path/to/answer.md \
  --local-source knowledge-base-private \
  --local-source market_feature_store
```

加 `--json` 可以输出机器可读结果，方便后续接 dashboard 或回归测试。

## 评分维度

满分 100 分：

| 维度 | 分值 | 看什么 |
|---|---:|---|
| 本地数据优先 | 15 | 是否优先使用知识库、金融 repo、market_feature_store，而不是把 web 当主脑 |
| 证据分层 | 15 | 是否区分 L1 产业叙事、L2 基本面、L3 公司硬事实、L4 盘面情绪 |
| 盘面阶段 | 20 | 是否判断预期交易、事实验证、兑现分歧、退潮，以及双红、放量、扩散、流动性 |
| 产业推导 | 15 | 是否能从题材传导到订单、客户、收入、产能、毛利率 |
| 反方审稿 | 15 | 是否主动质疑老预期、已交易、证伪点、替代标的和置信度 |
| 结论可用性 | 10 | 是否给出分层结论和后续观察指标 |
| 个人方法论贴合 | 10 | 是否体现全量盘面体系：资金推动价格、量能决定周期、20 日量能回归、四维复盘、成交占比环比、双红、题材生命周期、预期差、流动性切换等用户经验 |

## 个人方法论底座

从全量盘面体系说明沉淀的底层逻辑：

- 资金推动价格，量能决定周期。价格是结果，量是行为密度，资金是推动价格变化的真实力量。
- 市场先看 20 日量能回归，区分缩量、温和放量、暴量；温和连续放量比单日暴量更健康。
- 市场复盘四维是量能、情绪、结构、行业聚散度。
- 市场周期拆成下跌、反弹、探底、底部横盘、主升、顶部横盘。
- 板块周期用成交占比环比衡量承接能力。
- 个股选择要看市场环境、板块周期、产业逻辑、量价结构和资金承接共振。

## 设计取舍

第一版是确定性评分：用可解释规则检查答案里的关键思维信号。
优点是稳定、便宜、可离线复现；缺点是无法完全理解语义。

后续可以叠第二层 `LLM-as-judge`：让模型按同一套 rubric 写评语。
更像 Claude/Codex 的自我评审，但成本更高，也需要防止裁判模型主观漂移。

这套模式可以迁移到其他 RAG/agent 项目：先用确定性门禁保证不乱编，再用
rubric 评价高阶思考质量，最后把用户纠偏写回 `corrections.jsonl`。
