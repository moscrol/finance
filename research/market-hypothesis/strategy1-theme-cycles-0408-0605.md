## 策略1周期口径

### 1. 题材周期定义

对每个双红题材，按时间排序其双红日期：

```text
D1, D2, D3, ...
```

则周期为：

```text
D1 → D2
D2 → D3
D3 → D4
...
```

其中：

- `D1/D2/...` 是该题材的双红日。
- 周期起点是启动/再次启动日。
- 下一次同题材双红日视为回流兑现日。

### 2. 启动日核心筛选

在周期起点执行策略1：

```text
当日成交占比前三申万一级行业
+
该行业内双红题材成分股
+
个股开根加权强度 Top20%
+
新高状态 或 双红命中数 >= 3
+
次交易日分歧相对强
```

相对强路径包括：

```text
抗住且相对强
补跌但相对强
```

### 3. 买入与卖出口径

同一只启动核心，统计两种收益：

```text
启动日买入 → 回流日卖出
确认日买入 → 回流日卖出
```

即：

- `buy_start_to_reflow_pct`
- `buy_confirm_to_reflow_pct`

### 4. 回流日 cohort 分类

回流日再次执行策略1，得到回流日核心池。

对比启动日核心池：

| 类型 | 定义 | 含义 |
|---|---|---|
| 延续核心 | 启动日核心，回流日仍满足策略1 | 第一批核心继续走强 |
| 新晋补涨核心 | 启动日不在核心池，回流日新进入核心池 | 第二批补涨/扩散核心 |
| 兑现掉队 | 启动日核心，回流日不再满足策略1 | 回流日更偏兑现对象 |

### 5. 回流 / 切换预判层

回流日当天的 `涨幅 > 0`、`边际量 > 10`、`成交额 > 500亿` 只能证明双红已经发生，不能作为预判条件。

策略1新增一层题材级预判判断，观察上一轮双红后的 1-3 个交易日：

```text
上一轮双红题材
→ 分歧/降温期相对强度观察
→ 判断后续更可能回流原题材，还是切换到新分支
```

预判回流时，优先看：

| 观察项 | 回流倾向 | 含义 |
|---|---|---|
| 容量地位 | 双红当天成交额在同批题材中靠前 | 资金主战场仍在该题材 |
| 成交额保持 | 双红后成交额保持率高，未明显塌缩 | 边际量降温但资金未撤退 |
| 相对抗跌 | 双红后 1-2 日跌幅小于同批题材中位数 | 分歧期承接更强 |
| 同链共振 | 同一产业链有多个题材同时抗跌或提前修复 | 不是孤立反抽，链条仍有承接 |
| 先锋修复 | 少数同链题材先于全链恢复双红 | 后续可能扩散成主线回流 |

预判切换时，优先看：

| 观察项 | 切换倾向 | 含义 |
|---|---|---|
| 老核心放量下跌 | 老双红题材边际量高、成交额大，但涨幅为负 | 高换手分歧 / 老资金兑现 |
| 修复无量 | 老核心价格反弹但边际量弱 | 只是价格修复，不是主动增量回流 |
| 新分支连续相对强 | 新分支连续 2-3 日边际量排名靠前、价格相对抗跌 | 资金开始试探新方向 |
| 成交额爬坡 | 新分支成交额持续放大并逼近或突破 500亿 | 从观察层升级为双红候选 |
| 主线内部扩散 | 大容量链条降温，低位补涨链条继续增强 | 更像主线内部切换，而非原题材回流 |

落到策略1执行上：

```text
若上一轮双红后的分歧期，老核心题材成交额不塌、相对抗跌、同链不散：
    继续按原题材回流预判，等待后续双红确认，并在回流日执行 cohort 分类。

若老核心题材放量下跌，随后修复无量，同时新分支连续相对强、成交额爬坡：
    将新分支纳入切换观察层；若新分支进入容量前三行业或自身突破双红阈值，再进入策略1主线池。
```

该层只用于预判和观察，不替代策略1原有硬筛选。个股层仍必须同时满足：

```text
开根加权 Top20%
+
新高状态 或 双红命中数 >= 3
+
分歧日相对强
```

## 对用户观点的验证

### 观点1：双红题材首日会诞生一批核心个股

结论：支持。

本轮共生成 `1972` 条周期交易记录，说明策略1在双红题材首日/再次启动日能筛出大量核心候选。

### 观点2：买点可以在首日或次日确认日

结论：支持，但首日收益更高。

| 买入口径 | 平均收益 | 正收益占比 |
|---|---:|---:|
| 启动日买入 → 回流日卖出 | 6.76% | 75.99% |
| 确认日买入 → 回流日卖出 | 2.98% | 60.51% |

解释：

- 启动日买入收益更高，说明策略1确实偏向“启动日/启动初期”的收益捕捉。
- 次日确认相对强后再买，胜率和收益下降，但确定性更高，适合作为确认买点。

### 观点3：回流日是锁定收益窗口

结论：支持。

启动日至回流日平均收益 6.76%，正收益占比 75.99%。这说明同题材下一次双红回流日，确实具备兑现意义。

### 观点4：回流日会出现第二批补涨核心

结论：支持。

在可判断回流日核心的 296 个周期中：

```text
61.15% 的周期出现新晋补涨核心
```

这说明题材回流不是简单重复第一批核心，而经常出现第二批补涨/扩散核心。

### 观点5：第一批核心有一部分会延续

结论：支持，但比例低于补涨。

```text
34.80% 的周期出现延续核心
```

说明第一批核心中确实有部分会在回流日继续成为核心，但它不是多数情况。

### 观点6：第一批核心也会在回流日兑现掉队

结论：支持。

```text
61.49% 的周期出现兑现掉队
```

这支持策略1-B 的 cohort 观点：

```text
回流日不能只看题材再次双红，必须拆分个股身份。
```

## 关键观察

### 1. 回流日卖出确实能锁定收益

平均收益和正收益占比都支持：

```text
启动日核心 → 下一次同题材双红回流日兑现
```

这是策略1目前最强的交易节奏验证。

### 2. 启动日买入优于确认日买入

启动日买入平均收益 6.76%，确认日买入平均收益 2.98%。

这说明：

```text
策略1更适合在双红首日/启动初期埋伏或半确认买，
次日确认相对强后再买会牺牲收益空间。
```

### 3. 次日相对强仍然必要

虽然确认日买入收益较低，但次日相对强用于判断“哪些启动核心有效”。

尤其 `补跌但相对强` 不能剔除，因为高收益样本中大量来自这个路径。

### 4. 回流日必须做 cohort 拆分

回流日同题材再次双红时，个股分为三类：

```text
延续核心
新晋补涨核心
兑现掉队
```

如果只看题材再次双红，会把这三类混在一起，导致误判。

### 5. 新晋补涨更常见，延续核心更稀缺

本轮统计：

```text
新晋补涨核心出现率：61.15%
延续核心出现率：34.80%
兑现掉队出现率：61.49%
```

这意味着：

- 回流日应主动找第二批补涨核心。
- 第一批核心只有少数能延续。
- 第一批核心若回流日不再满足策略1，更偏兑现。
