# 策略1每日优先个股矩阵

> 用途：记录每日复盘后，按“策略1”筛出的优先个股。列为日期，行是股票；每天新增一列。单元格记录当日分层、主要入选理由和风险状态。

## 填写规则

| 标记 | 含义 |
|---|---|
| T1 | 第一梯队 / 核心优选 |
| T2 | 第二梯队 / 进攻观察 |
| OBS | 观察组 |
| DEG | 降级优选：当日不满足完整策略1硬条件，但在弱环境下最接近策略1精神 |
| - | 当日未入选 |

策略1标准硬条件：

```text
容量前三行业
+ 所属题材当日双红
+ 个股在行业内开根加权 Top20
+ 新高状态或多题材命中优先
```

若当日 `双红题材=0`，不得标记为标准 T1，只能标记为 `DEG/OBS` 并注明风险。
