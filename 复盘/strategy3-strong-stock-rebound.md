# 策略三：强势股反抽策略

## 1. 策略定位

强势股反抽策略不是追高策略，也不是连板晋级策略，而是寻找前期已经被市场证明过的强势品种、核心品种，在情绪分歧和价格回落之后，跟随市场情绪修复产生的反抽机会。

核心假设是：

```text
前期强势品种已经完成资金记忆和辨识度积累。
当市场从分歧、冰点走向反抽时，这些品种比普通个股更容易获得资金回流。
```

这个策略关注的是：

```text
强势股分歧后的再修复
核心品种回踩后的反抽
题材穿越后的资金回流
```

## 2. 底层原理

### 2.1 顺情绪强势股的反抽

市场情绪有明显周期：

```text
MA5上升 → 情绪扩张 → 强势股加速
MA5回落 → 情绪分歧 → 强势股回撤
MA5冰点/低位反抽 → 情绪修复 → 前强品种反抽
```

在涨家数 MA5 上升区间里，区间涨幅和加权涨幅排名靠前的品种，往往是顺情绪阶段资金最认可的方向。

当 MA5 回落到冰点或低位后，如果出现反抽，这些前期强势品种更容易成为资金修复的优先选择。

### 2.2 双红题材核心股的反抽

另一个候选来源是双红题材里的核心品种。

如果一个题材在多个周期中持续出现双红特征，说明它不是一次性脉冲，而是有资金反复参与。

如果某只个股持续处在这些双红题材中，并且多次成为题材内的核心品种，那么它在分歧后也更容易获得资金回流。

核心逻辑是：

```text
双红题材提供题材记忆。
核心品种提供个股辨识度。
多个周期穿越提供持续性确认。
```

## 3. 候选池一：顺情绪强势股池

### 3.1 选股窗口

顺情绪强势股池主要从涨家数 MA5 上升区间中筛选。

典型窗口是：

```text
MA5确认波谷 → MA5确认波峰
```

或者：

```text
MA5低位开始回升 → MA5阶段性高位
```

这个区间里表现最强的个股，是后续情绪分歧后重点观察的反抽对象。

### 3.2 核心筛选指标

优先看：

```text
区间涨幅
加权涨幅
成交额
题材辨识度
是否处于当时主线题材
是否为题材核心而非后排补涨
```

其中：

```text
区间涨幅 = 情绪扩张阶段的价格强度
加权涨幅 = 强度与成交、容量、持续性的综合表达
```

### 3.3 强势股质量分层

#### A类顺情绪核心

```text
区间涨幅靠前
加权涨幅靠前
成交额具备容量辨识度
处于当时主线题材
有明显资金记忆
不是一日游补涨
```

#### B类顺情绪观察

```text
区间涨幅较强
但加权涨幅一般
或题材辨识度一般
或成交承接不足
```

#### Risk类顺情绪剔除

```text
只是短期补涨
题材已经退潮
高位放量破位
回落后没有承接
强度来自单日脉冲而非区间持续
```

## 4. 候选池二：双红穿越核心股池

### 4.1 选股来源

双红穿越核心股来自每日双红题材筛选结果。

重点不是只看某一天是否双红，而是看题材和个股是否能跨周期反复出现。

观察维度：

```text
题材是否多次双红
题材是否穿越 MA5 上升、回落、反抽周期
个股是否多次出现在双红题材中
个股是否是题材核心标的
```

### 4.2 穿越性判断

一个题材或个股更有价值的状态是：

```text
MA5上升期出现
MA5分歧期没有完全消失
MA5冰点反抽期重新活跃
```

这类品种说明资金记忆没有断，反抽时更容易被重新选择。

### 4.3 双红核心分层

#### A类双红穿越核心

```text
题材多周期双红
个股多次出现
个股在题材中有核心辨识度
分歧后仍有承接
UP偏离度回落到合理区
```

#### B类双红观察

```text
题材双红持续性尚可
个股出现次数有限
或不是题材唯一核心
需要等待反抽确认
```

#### Risk类双红剔除

```text
只出现一次双红
题材没有穿越性
个股是后排补涨
题材退潮后无资金回流
```

## 5. 反抽触发条件

强势股反抽策略不是看到强势股就买，而是等待市场和个股同时进入反抽条件。

执行顺序必须是：

```text
先筛核心品种 → 再看UP值和偏离度 → 最后判断是否进入反抽买点
```

UP值和偏离度只能用于判断位置是否舒服，不能反过来作为核心品种筛选器。

### 5.1 核心品种优先筛选

第一步只解决一个问题：

```text
这是不是值得等待反抽的核心品种？
```

核心品种来自两条路径：

```text
路径一：最近一轮 MA5 上升区间里的顺情绪强势股
路径二：多个周期持续穿越的双红题材核心股
```

如果距离最近一轮 MA5 上升区间已经比较久，中间已经经历了 MA5 下降期、震荡期，原来的区间强势股名单会衰减，不能机械沿用。

这种情况下，核心筛选权重应切换到双红题材穿越：

```text
MA5上升期刚结束不久：优先看区间涨幅和加权涨幅
MA5上升期已经过去较久：优先看双红题材穿越和核心股持续性
经历下降期+震荡期后：必须用双红穿越重新确认核心
```

原因是：

```text
区间强势说明过去强。
双红穿越说明现在仍有资金记忆。
```

只有先确认个股仍然是核心，后面看 UP 值和偏离度才有意义。

### 5.2 位置和反抽触发

优先触发条件：

```text
涨家数 MA5 回落到低位或冰点
市场出现 MA5 反抽迹象
前强品种已经经历分歧回落
个股接近 UP 值或关键支撑
UP 偏离度回落到合理区间
题材没有彻底退潮
```

如果只有个股回落，但市场没有反抽，容易继续杀跌。

如果只有市场反抽，但个股不是前期核心，弹性和确定性都不够。

### 5.3 冰点与分歧环境标签

冰点和分歧环境不是新的候选池，而是买点质量标签。

执行顺序仍然是：

```text
先确认核心品种 → 再确认UP回踩位置 → 最后标注环境质量
```

同样是强势股 Touch UP，发生在涨跌家数冰点、MA5低水位、指数分歧、容量板块分歧或双红题材回踩日时，反抽效率通常更高。

#### S3-L-A-E1：冰点分歧左侧买点

```text
个股已经是核心品种
个股首次或接近首次 Touch UP
涨跌家数处于冰点或MA5低水位区间
指数出现分歧日
容量板块或双红题材出现回踩
题材记忆没有断
```

这是策略三里质量最高的一类买点。

#### S3-L-A-E2：标准分歧左侧买点

```text
个股已经是核心品种
个股 Touch UP 或偏离度明显收敛
市场不在高位亢奋
指数、容量板块或题材至少有一项处于分歧
但涨跌家数/MA5没有达到冰点
```

这是标准左侧买点，可以进入主观察。

#### S3-L-A-E3：低质量左侧买点

```text
个股 Touch UP
但市场仍处于高位亢奋
或题材已经退潮
或容量板块没有分歧承接
或个股核心身份需要重新确认
```

这类只能降级观察，不能因为 UP 位置舒服就直接升为核心买点。

## 6. UP值与偏离度使用

UP值和偏离度用于判断反抽位置是否舒服。

使用前提是：

```text
个股已经通过核心品种筛选。
```

如果个股不是核心品种，即使 UP 偏离度很好，也不能进入主观察池。

### 6.1 适合观察的状态

```text
个股从高位分歧回落
价格接近 UP 值
偏离度明显收敛
没有有效跌破核心趋势结构
成交没有出现连续失控
```

### 6.2 不适合观察的状态

```text
价格仍远高于 UP 值
偏离度仍然过大
刚进入加速末端
高位放量破位
题材已经退潮
```

### 6.3 理想反抽结构

```text
核心确认 → 分歧回落 → 接近UP → 偏离度收敛 → MA5反抽 → 个股修复
```

## 7. 策略分层

### 7.1 S3-RB-A：核心反抽

满足：

```text
前期区间涨幅强
加权涨幅强
题材或个股有核心辨识度
MA5进入低位反抽阶段
价格接近UP值
偏离度收敛
题材没有退潮
```

这类是强势股反抽策略的主观察对象。

### 7.2 S3-RB-B：观察反抽

满足：

```text
前期强势明确
但题材穿越性一般
或UP位置不够舒服
或偏离度仍略高
或个股不是唯一核心
```

这类只做观察，等待更清晰的反抽确认。

### 7.3 S3-RB-RISK：剔除或谨慎

出现任一情况需要降级：

```text
题材退潮
个股高位破位
UP偏离度仍高
前期只是补涨
双红只出现一次
没有资金记忆
回落时连续放量杀跌
```

## 8. D0分析纪律

强势股反抽策略必须严格执行 D0 分析纪律。

回填历史日期时，只能使用当日及以前已经可见的数据。

允许使用：

```text
当日及以前的 MA5 数据
当日及以前的区间涨幅
当日及以前的加权涨幅
当日及以前的双红题材记录
当日及以前的 UP 值和偏离度
当日及以前的成交、涨跌幅、题材、行业数据
```

禁止使用：

```text
次日是否真的反弹
后续是否涨停
后续是否破位
后续题材是否继续发酵
后续实际收益率
```

回填时最后一列只能写：

```text
次日验证计划
```

不能写：

```text
实际验证结果
```

## 9. 每日复盘输出字段

如果后续做成 HTML 矩阵，建议字段如下：

```text
日期
市场环境 / MA5位置
冰点/分歧环境标签
核心筛选口径
顺情绪强势股池
双红穿越核心池
反抽触发条件
UP值 / 偏离度
优先级分层
风险过滤
次日验证计划
```

## 10. 策略一句话总结

```text
先用区间强度或双红穿越筛出核心品种，再等待核心品种回落到 UP 附近并完成偏离度收敛，最后用涨跌家数冰点、MA5低水位、指数/容量板块/双红题材分歧标注 E1/E2/E3 买点质量。
```
