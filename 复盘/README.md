# 复盘目录

本目录存放本地市场复盘产物、策略矩阵和人工筛选记录。

## 目录结构

- `index.html`：驾驶舱总入口，用卡片/导航把每日复盘、卖方机构胜率榜、晨汇边际变化、策略矩阵串成一个可点进去的界面（本地生成，不入 git）。
- `daily/`：按交易日归档的每日复盘 HTML 和涨家数 MA5 图片。
- `matrices/`：跨日期矩阵，包括策略1、策略2、策略3、二板晋级和申万题材矩阵。
- `templates/`：复盘模板。
- `selections/`：人工筛选、双红选择等专题记录。

- `matrices/strategy1-priority-stock-matrix.html`：策略1每日优先个股矩阵。
- `matrices/strategy1-priority-stock-matrix.md`：策略1矩阵 Markdown 辅助稿。
- `matrices/strategy2-weak-market-matrix.html`：策略2弱市三路径观察矩阵。
- `matrices/strategy3-touch-up-rebound-matrix.html`：策略3 Touch UP 左侧反抽矩阵。

- `matrices/sw-theme-matrix-2026-04-08-2026-06-05.html`：申万题材矩阵。
- `strategy3-strong-stock-rebound.md`：策略3强势股反抽策略说明。

## 生成与校验流程

- 推荐全量入口：`python3 -m intelligence.cli daily --date YYYY-MM-DD --kb-wiki "/path/to/知识库/wiki"`。这条 workflow 会依次生成每日复盘、题材候选、`agent-daily`、复盘工作台和驾驶舱总入口；DuckDB 在哪台 Mac，本命令就在哪台 Mac 跑。
- 如果两台 Mac 分工：在有 DuckDB 的 Mac 跑上面的全量入口；跑完后同步金融 repo 和知识库 repo。`--kb-wiki` 指向该机同步后的知识库 `wiki/`，不要依赖另一台机器的绝对路径。
- 只补跑 Agent 简报：`python3 -m intelligence.cli agent-daily --date YYYY-MM-DD --kb-wiki "/path/to/知识库/wiki"`，随后执行 `python3 scripts/render_review_workbench.py` 和 `python3 scripts/render_cockpit.py --knowledge-root "/path/to/知识库"`。
- 数据完整性闸门：`python3 scripts/check_daily_review_data.py YYYY-MM-DD`。
- 仅生成每日复盘 Markdown：`python3 -m market_feature_store.cli daily-review --trade-date YYYY-MM-DD --output market_feature_store/exports/YYYY-MM-DD-daily-review.md --chart-output market_feature_store/exports/YYYY-MM-DD-advancers-ma5.png`。这条是底层老入口，不会触发 `agent-daily`、工作台或驾驶舱。
- 渲染每日复盘 HTML：`python3 scripts/render_daily_review_briefing.py YYYY-MM-DD`，输出到 `daily/YYYY-MM-DD/`。
- 渲染统一工作台：`python3 scripts/render_review_workbench.py`。
- 生成驾驶舱总入口：`python3 scripts/render_cockpit.py --knowledge-root "/path/to/知识库"`，输出 `index.html`，聚合 `daily/`、`winrate/`、`matrices/` 与知识库仓 `dashboard/briefings/` 晨汇看板，复用最新每日复盘的 `<style>`（浅色投研主题）。全量入口会自动把 `--kb-wiki` 的上一级传给这里。
- 二板晋级抓取：`python3 skills/limit-advance/scripts/scrape.py MM-DD --min-boards=2`，必要时用 `--json` 复核梯队数据。

## 策略矩阵回填约束

- 只写 D0 当日及以前可见数据，不用后续涨跌或晋级反推当日判断。
- 策略1、策略2、策略3和二板晋级矩阵都需要同步标题日期范围、当前已填日期和页脚说明。
- 策略3固定使用真实 UP 公式 `UP = MA26 + 0.764 × STD26`，候选池来自近端交易日单日加权涨幅 Top20 回溯，不只看目标日或区间终点榜。
- 二板晋级矩阵需要同时看市场环境、题材热度、题材成组、新高演化、前高目标空间和三板确认；唯一性与历史新高按下方数据验证口径作风险提示项，不作加分项。

## 策略1准确率口径（2026-06-10 数据验证版）

基于 2026-04-08~2026-06-05 窗口、每种买点 1000 条候选的后验验证（`research/market-hypothesis/strategy1-drawdown-risk-detail.csv`），策略1回填采用以下口径：

- 基础池不变：当日成交占比前三申万一级行业 + 双红题材（涨幅>0、边际量>10、成交额>500亿）。
- T1 硬条件：基础池内 + 涨家数 MA5 趋势非下降 + 次日相对强度>=2% + 个股身份为容量趋势核心或阶段核心（limit_medium 可替代身份条件）。验证结果：回流胜率 71.2%、10日峰值>=10% 命中 64.5%（基准 66.9%/55.0%）。
- 最优买点：确认日（次日承接日）尾盘买入，回流胜率约 71%；双红当日收盘买叠加次日过滤的高胜率是后验口径，不可交易。
- 无条件 DEG 降级：MA5 中位区/下降日（回流胜率仅 44%）；mature_reflow + limit_weak 组合。
- MA5 下降趋势日整体降权：剔除后胜率 66.9%→69.4%、深回撤率 26.9%→20.6%，是性价比最高的单条过滤。
- 生命周期分层：d1/d2 早周期深回撤率 18.2% 优先；mature_reflow 深回撤率 36.3% 默认降一档，仅 MA5 有利时保留。
- 涨停映射：limit_medium 优于 limit_strong，不按映射强度加分；limit_weak 回流弹性最高（中位 6.17%）但深回撤率 43.3%，只允许进低位补涨小仓观察位，严禁进 T1。
- 新高标签、双红命中>=2、板块加权前5 不再作为筛选加分条件（验证无胜率提升），降为展示字段和 tie-break。

## 策略2准确率口径（2026-06-10 数据验证版）

基于 2026-04-08~2026-06-09 窗口、弱市日（双红<=5）308 个多周期上榜题材事件 + R2 题材内 3828 条个股样本的后验验证（多周期榜用 `fact_sector_daily` 复算 1/3/5/10 日 Top20），策略2回填采用以下口径。基线：弱市日上榜题材 5 日胜率 60.1%。

- S2-T 题材确认（核心提升）：弱市日 + 跨周期>=3 个榜单 + 当日涨幅<=3%（未高潮），5 日胜率 80.6%、中位 +4.16%；全周期 4/4 共振时 5 日胜率 96.3%、中位 +5.30%（n=27），为最高优先。
- 跨周期数量是第一筛选：只上 1-2 个周期榜的题材是噪音（胜率 51-56%），不入池。
- 当日未高潮是关键确认：跨周期>=3 但当日已涨>3% 追入胜率仅 52.9%（6.1 电力反杀模式）；当日涨停>=5只且当日>3% 的题材次日中位 -2.34%，按兑现日处理，禁止追买。
- 边际量 diff_ratio 在弱市无区分度，不作为策略2条件。
- S2-A 稳健腿：确认题材内 20 日涨幅<0 的低位滞涨成分股，5 日胜率 69.8%、MAE 中位 -0.55，按 5 日周期执行。
- S2-B 弹性腿：确认题材内当日加权强（>=30）或有涨停的成分股，峰值最高（涨停股峰值中位 7.13%）但胜率更低（56-59%）、回撤更深，仅 T+1 承接确认后升级。
- 修正 CORE_HOLD 思路：双红穿越核心股作持仓延续观察；新买入腿优先题材内低位补涨，不优先当日最强。
- 个股层无效因子：新高标签在弱市题材内无胜率区分度。
- 验证局限：R3 全周期共振组 n=27，单窗口约 2 个月，初步有效，持续追加验证。

## 策略3准确率口径（2026-06-10 数据验证版）

基于 2026-04-08~2026-06-09 窗口、3779 个强势股 UP 触碰事件的后验验证（强势池 = 近 15 个交易日单日加权 Top20，UP = MA26 + 0.764 × STD26），策略3回填采用以下口径：

- 现行标准 Touch(-3~+3) 不加过滤时 5 日胜率仅 52.5%、中位 +0.44%，不可单独作为买点。
- 强势新鲜度是第一过滤器：最近一次单日加权 Top20 距今 <=7 个交易日才有效；gap 8-15 天的 touch 胜率 47.2%、跌破 UP 仅 39.5%，一律剔除或降级观察。
- 买点方向按涨家数 MA5 环境分两套逻辑：
  - S3-C 修复期回踩：MA5 上行 + gap<=7 + 偏离 UP <=0%（回踩至 UP 及下方），5 日胜率 66.7%、5 日中位 +3.84%、MAE 中位 -3.82%；收益 5 日内兑现，应 5 日内止盈。
  - S3-D 弱市抗跌：MA5 下行 + gap<=7 + 仍站 UP 上方 3~8%，10 日胜率 59.5%、10 日中位 +4.80%、峰值中位 11.4%；可持有约 10 日。
- 弱市（MA5 下行）禁止接跌破 UP 的刀：该组合胜率仅 51.6% 且 MAE 更深。
- 与 E1/E2/E3 标签的衔接：E1/E2 分歧/冰点日执行 S3-D 逻辑（买仍站 UP 上方的抗跌核心），MA5 转上行后执行 S3-C 逻辑（买回踩）。
- 无效因子：D0 当日红绿、加权排名前10 vs 11-20 区分度弱，不作为筛选条件。
- 验证局限：单一窗口约 2 个月，覆盖一轮完整涨跌周期但未跨牛熊，作为初步有效规则使用并持续追加验证。

## 二板晋级准确率口径（2026-06-10 数据验证版）

基于 2026-04-08~2026-06-09 窗口、373 个二板事件的后验验证（`fact_limit_advance_daily` boards=2，晋级 = 次日出现 boards=3），二板晋级矩阵回填采用以下口径。基线：晋3率 31.6%、五日内4板率 16.6%。

- A 类升级条件（验证最优组合，晋3率 48.7%、五日4板率 41.0%、次日中位 +7.24%、5日峰值中位 +15.46%）：同题材>=2只成组 + 当日成交<10亿 + 新高标签为1年及以下（非历史/2年新高）。
- 题材成组共振优先于唯一性：唯一题材二板晋3率仅 26.0%、五日4板率 6.8%；同题材>=3只成组晋3率 46.2%、五日4板率 36.6%。"唯一高度龙头"规律只适用于 5板+ 高度阶段，不适用于二板晋级阶段。
- 新高标签在二板阶段反转：历史新高二板晋3率仅 19.4%（已兑现位），1年新高最优（晋3率 52.6%、五日4板率 36.8%），无新高低位首轮二板也有 42.9%。"理论四板突破前高"应改为看是否仍有1年/历史前高可作目标空间，而不是已创历史新高。
- 轻量封板优于放量封板：成交<5亿晋3率 46.0%，>20亿仅 16.1%；大成交二板=分歧放量，次日大概率开板。
- 降级/剔除组：唯一题材且成交>20亿（晋3率 14.8%、五日4板率 3.7%）；历史新高且成交>10亿（15.9%、2.3%）。
- 唯一性、历史新高从加分项改为风险提示项。
- 环境因子区分度弱：MA5方向、双红数、二板池规模不作筛选条件；涨停数>100 高潮日二板整体降权（晋3率 25.2% vs <70日的 35.1%）。
- 验证局限：最优组合 n=78，初步有效，持续追加验证；20cm 二板样本仅 18 个（晋3率 22.2%）暂不单列规则。

## 使用规则

- 新增某日复盘时，放入 `daily/YYYY-MM-DD/`。
- 新增跨日期矩阵时，放入 `matrices/`。
- 新增模板时，放入 `templates/`。
- 新增人工筛选记录时，放入 `selections/`。
- 不提交 `.DS_Store`、临时文件、数据库或压缩包。
